# 변경 이력

## 1.4.0 — 2026-10-20

- 텍스트 셀에 마크다운 도구 막대와 실시간 미리보기를 추가한다. 편집 중에는 원문과 미리보기를 나란히, 작은 화면에서는 위아래로 배치한다. 닫으면 서식이 적용된 내용만 보이며 편집 버튼이나 두 번 클릭으로 다시 연다.
- 제목·강조·취소선·목록·인용·링크·이미지·코드 블록·구분선·표를 지원한다. 교사의 읽기 전용 노트북도 같은 렌더러를 사용한다.
- 원문을 기존 텍스트 셀에 그대로 저장하고 자동 저장·JSON 다운로드·일반 Python 실행을 유지한다. 서버 API·DB 스키마·노트북 형식은 바꾸지 않는다.
- 마크다운 파서를 로컬 자산으로 번들하고 원문 라이선스와 무결성 검사를 추가한다. HTML은 문자로 표시하며 위험한 링크·이미지 URL을 차단한다.

## 1.3.2 — 2026-10-20

- 정상 종료·오류 종료 뒤에도 ‘디버깅 중단’ 버튼을 유지한다. 다시 디버깅을 시작하지 않고 단계 기록과 줄 강조를 닫을 수 있다.
- 완료된 기록의 중단 버튼은 해당 기록만 닫는다. 실행 결과·변수와 다른 셀의 실행·입력 대기·실행 대기열을 보존하며, 이미 닫힌 기록의 이벤트도 새 디버거에 영향을 주지 않는다.
- 실행 중인 디버거의 중단은 기존처럼 런타임과 변수를 초기화한다. 서버 API·DB 스키마·노트북 형식은 바꾸지 않는다.

## 1.3.0 — 2026-10-13

- D-010 통합 디자인을 적용한다. 콘솔 사이드바 메뉴를 ‘코드 실습실’(학습 활동) 하나로 합치고, ‘학생 노트북’과 ‘추천 데이터’를 로컬 내비 구획으로 둔다(플랫폼 2.1+, `AddonConsoleLocalNavBuilderV1` 확인). 학생 공개 메뉴의 부모를 `problems`에서 `learning_support`로 옮긴다.
- 콘솔 세 화면과 학생 노트북의 이모지 배너를 `ojp-page-header`로 바꾸고 `ojp-button`·`ojp-input`·`ojp-select`·`ojp-table`·`ojp-notice`·`ojp-status-badge`를 쓴다. Kaggle 입력 이름을 ‘Kaggle 사용자 이름’·‘Kaggle API 키’로 바꾼다.
- 노트북 도구 막대·셀·삽입 버튼·디버거 패널을 `--ojp-*` 토큰으로 다시 그린다. ‘전체 실행’이 유일한 주요 버튼이고 저장 버튼의 초록색 강조를 없앤다. ‘▶ 실행’·‘🐞 디버그’ 등 버튼의 이모지를 인라인 SVG 또는 글자로 바꾼다. 문구는 다운로드·가져오기로 통일한다.
- `Page_Response`가 Addon API 1.3의 `page()`가 있으면 콘솔은 standard, 노트북은 immersive 레이아웃과 어두운 화면 지원으로 응답하고, 없으면 `html()`을 쓴다.
- ‘최신 노트북 불러오기’의 `window.confirm`을 `OJP.confirm`으로 바꾼다(없으면 기존 확인 창). 플랫폼 2.1+에서는 추천 데이터 삭제와 Kaggle 연동 정보 삭제 전에 확인 시트를 띄우고, 완료 알림은 `OJP.toast`로 보여 준다.
- Kaggle 설정을 교사 메뉴로 옮긴다. `operations`에 붙였던 설정 메뉴를 지우고 ‘코드 실습실’ 로컬 내비의 마지막 구획 ‘설정’(`/oj-console/addons/oj-code-lab/settings`, 그대로)으로 둔다. 플랫폼 2.0.x(`AddonConsoleLocalNavBuilderV1` 없음)에서는 `learning_support`에 ‘코드 실습실 추천 데이터’(순서 98)와 ‘코드 실습실 설정’(순서 99, 마지막) 메뉴를 따로 등록한다. 수정: 2.0.x에서 추천 데이터 화면으로 가는 메뉴가 없어지던 문제를 재검증 중 찾아 고쳤다. 설정 화면 머리말은 학습 활동 › 설정이다.
- 설정 권한 `oj_code_lab_settings`는 키를 유지하고 이름을 ‘코드 실습실 설정’, audience를 `operator`에서 `educator`로 바꾼다(역할 화면에서 교사에게 부여, 자동 부여 없음). 설정 읽기·저장·연동 정보 삭제 REST(`/settings/kaggle`)는 `is_super_admin() || current_user_can(AddonCapabilityKeyV1::wordpress('oj_code_lab_settings'))`로 검사한다. 추천 데이터 관리와 Kaggle 검색·파일 목록은 자기 권한(`oj_code_lab_manage_datasets`)을 유지하면서 사이트 관리자도 허용한다. REST nonce·경로·옵션 저장 형식은 그대로다.
- 테스트: `tests/console-menu.php`(메뉴·로컬 내비·2.0.x 대체 메뉴·권한 정의·wp-admin 메뉴 없음)를 추가하고, `tests/regression.php`에 설정·추천 데이터 권한 시나리오 2개를 더한다.
- 주소·권한 키·REST·DB 스키마 2·노트북 형식 2·Ace/Pyodide 실행 동작은 바뀌지 않았다. `docs/release-gates.json`에 1.3.0 정식 게이트 R1–R7 재검증 결과를 기록했다(증거: `_notes/oj-code-lab-1.3.0-release-review-20261013.json`).

## 1.1.0 — 2026-09-14

- Kaggle·URL·교사 업로드에서 JSONL·NDJSON과 일반 ZIP 응답을 읽는다. UTF-8/CP949를 정규화하고 JSONL의 한 줄 객체·배열, 1MiB 줄 크기와 파서 깊이 64를 검사한다. CSV 동작과 파일 전체 크기 제한은 유지한다.
- 서버 `ZipArchive`로 요청 파일명과 정확히 일치하는 내부 파일을 선택하고 없으면 지원 파일 하나만 자동 선택한다. 모호한 ZIP은 원하는 원본 파일 선택 또는 압축을 풀어 업로드하도록 안내한다. 항목 수·압축률·전체 및 선택 파일 크기를 제한하며 중첩·ZIP64·분할·암호화 ZIP은 지원하지 않는다. 외부 라이브러리 번들은 추가하지 않는다.
- JSONL·NDJSON은 `pd.read_json(..., lines=True)`, CSV는 `pd.read_csv(...)`를 사용한다. 미리보기 코드를 자동 실행하여 표를 출력하며 기존 코드·메모·출력은 보존한다.
- 추천 관리의 ‘파일 선택’과 ‘첫 지원 파일 추가’를 구분하고 후자는 실제 선택한 파일명을 저장한다. 지원하지 않는 파일의 선택 버튼은 비활성화한다.
- `dataset-file-v2:` 원격 캐시에 정규화한 내용·실제 내부 파일명·형식을 함께 저장한다. 기존 원문 캐시는 강제 삭제하지 않고 자연 만료한다. DB 스키마 2와 노트북 형식 2는 유지한다.
- 이번 릴리즈에서 OJ Platform은 수정하지 않는다. 기존 공개 Editor API·Ace 자산과 GPL-2.0-or-later 및 플랫폼 연동 추가 허락을 유지한다. 검사 환경과 결과는 ZIP 옆 공개 검증 보고서를 참조한다.

## 0.7.1-dev — 2026-09-07

정식 배포 준비를 위한 개발 빌드. 운영 배포 승인이나 1.0.0 릴리즈가 아니다.

- 노트북 DB 조회·저장 실패를 HTTP 오류로 전달하고 손상된 JSON을 빈 노트북으로 바꾸지 않는다.
- 최초 불러오기에 성공하기 전 저장과 편집 버튼을 잠근다. 저장 요청 중 추가 편집·출력은 미저장 상태를 유지한다.
- 학생용 추천 목록에서 서비스키가 포함될 수 있는 원본 URL을 숨긴다. 추천 관리 권한만 있는 교사도 목록을 조회할 수 있다.
- URL 다운로드에 WordPress 안전 HTTP API를 사용해 리다이렉트 대상도 검증한다.
- 원격 파일은 상한보다 1바이트 더 읽어 HTTP 200으로 잘린 응답을 탐지한다. UTF-8 변환 후 크기도 검사한다.
- 업로드·추천 데이터 DB 저장 실패를 전파하고 추천 메타데이터 저장 실패 때 해당 업로드를 정리한다.
- Kaggle ZIP 응답을 텍스트로 손상시키지 않고 미지원 오류로 반환한다.
- 업데이트 시 교사가 삭제한 샘플을 자동 복원하지 않는다. 수동 복구 실패를 정상 성공으로 표시하지 않는다.
- 학생·교사 화면에서 외부 오류 문구를 HTML 대신 텍스트로 표시한다. 자동 생성 Python 코드의 파일명 문자열을 안전하게 이스케이프한다.
- 패키지 메타데이터, 회귀 테스트, 검사·빌드 도구, 릴리즈 게이트와 샘플 파일 체크섬 목록을 추가한다.
