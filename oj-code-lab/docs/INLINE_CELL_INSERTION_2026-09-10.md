# 코드 셀 사이 추가 — RC5

첫 셀 앞, 셀 사이, 마지막에 항상 보이는 `+ 코드` 버튼을 추가했다. 선택한 위치에 빈 셀을 삽입하고 새 편집기에 입력 포커스를 옮긴다. 버튼은 키보드로 사용할 수 있고 최소 높이는 44px이다. 상단 추가와 데이터 가져오기는 기존처럼 마지막에 셀을 추가한다.

`lab.js`는 새 셀과 삽입 버튼만 DOM에 넣는다. 기존 셀을 다시 그리지 않아 실행 출력과 `input()` 폼·입력값을 유지한다. 삭제할 때 그 셀에 연결된 삽입 버튼을 함께 제거하며, 모든 셀을 지워도 맨 앞 추가 버튼이 남는다. 교사용 읽기 전용 화면과 DB·저장 API는 변경하지 않았다.

## 검증

- JavaScript 32개 통과: 학생 노트북 19개, Worker 10개, 교사 화면 3개. 이번 변경의 첫·중간·끝 삽입/저장 순서, 저장 진행 중 삽입, 입력 대기 보존, 삭제 후 추가 위치, 빈 노트북·포커스 검사 5개를 포함한다.
- PHP 8.5.5 / Node 24.19.0으로 릴리즈 빌드의 전체 로컬 검증 통과. PHP 파일 57개, JavaScript 파일 10개의 문법과 UTF-8/BOM을 확인했다. 자세한 결과는 RC5 ZIP 옆 verification JSON에 있다.
- 실제 인앱 브라우저에서 현재 `lab.js`와 CSS를 사용하는 로컬 노트북 화면을 열었다. 첫 셀과 두 번째 셀 사이에 추가하고 자동 포커스, 기존 출력 보존, 편집·저장 후 새로고침 시 삽입 순서 유지, 버튼 배치를 확인했다. 이 화면의 REST 저장은 메모리 기반 테스트 서버이며 운영 DB·Python 실행 수용 검사를 뜻하지 않는다.
- RC4와 ZIP을 비교했다. 변경은 버전·공개 설명 5개와 JS/CSS 2개, 합계 7개 파일이다. ZIP의 57개 파일 모두 현재 배포 대상 소스와 바이트가 일치한다.
