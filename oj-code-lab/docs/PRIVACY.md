# 개인정보와 외부 연결 안내

검토일: 2026-09-14. 아래는 이 플러그인의 처리 동작이다. 사이트 운영자는 실제 보관 기간·문의처·백업 정책을 사이트 개인정보 처리방침에 명시한다.

## 사이트에 저장되는 정보

로그인 사용자 ID와 연결된 노트북 한 개에 코드, 텍스트 메모, 셀 종류와 순서, 입력한 값, 텍스트 출력, 오류, PNG 그래프, 마지막 저장 시각과 revision을 저장한다. 수동 저장과 30초 자동 저장을 사용한다. 담당 학급·모둠에 보고 권한이 있는 교사가 노트북을 열람할 수 있다. 노트북에 비밀번호나 비밀키를 입력하지 않는다.

코드 편집기는 같은 사이트에 설치된 OJ Platform의 Ace 자산과 현재 계정의 제출 페이지 테마·글자 크기를 사용한다. 이 설정을 변경하거나 편집 내용을 외부 구문 강조 서비스에 보내지 않는다.

마크다운 텍스트는 원문으로 저장하고 학생·교사의 브라우저에서 서식을 적용한다. 파서는 설치 ZIP의 로컬 자산이며 원문을 외부 변환 서비스로 보내지 않는다. 마크다운에 외부 이미지 URL을 넣으면 미리보기와 교사 열람 시 브라우저가 이미지 서버에 접속하여 IP·요청 URL 등 일반 HTTP 정보를 전달할 수 있다. 이미지 요청에는 `referrerpolicy="no-referrer"`를 적용한다.

추천 자료에는 파일 내용, 이름, 표시 제목, 원본 URL 또는 Kaggle 데이터 식별자, 작성자 ID를 저장한다. 원본 URL에 서비스키가 포함되면 관리자 화면과 DB에도 남는다. 키가 없는 다운로드 URL을 사용하거나 지원 데이터 파일을 직접 업로드하는 편이 좋다. 공유 자료의 개인정보는 업로더와 운영자가 검토한다. CSV·JSONL·NDJSON은 UTF-8로 정규화하여 보관하며, ZIP 업로드는 선택한 내부 파일의 내용과 파일명을 보관한다. ZIP 처리에 사용하는 서버 임시 파일은 처리 종료 시 정리한다. JSONL 형식 오류에는 줄 번호를 표시하고 해당 줄의 원문을 오류 메시지에 넣지 않는다.

노트북에는 자동 만료 기간이 없다. WordPress 개인정보 내보내기·삭제와 사용자 삭제 기능을 지원한다. 사용자 삭제 시 노트북을 삭제하고 공유 자료의 작성자 연결을 해제한다. 공유 파일 내용과 백업 안의 정보까지 자동 삭제하지는 않는다. 일반 플러그인 삭제는 데이터를 보존한다. 운영자가 OJ_CODE_LAB_DELETE_DATA=true를 설정한 뒤 플러그인을 삭제하면 해당 사이트의 자체 테이블과 설정을 지운다.

원격 데이터 캐시는 정규화한 내용·실제 파일명·형식을 함께 저장하고 기본 24시간 후 만료되며 매시간 WP-Cron이 정리를 시도한다. 1.1.0은 `dataset-file-v2:` 키를 사용하며 기존 원문 캐시를 업데이트 때 강제로 지우지 않는다. 기존 항목도 만료·정리 정책을 따른다. 서버의 cron이 지연되면 실제 삭제도 늦어질 수 있다. 설정 감사 기록에는 마지막 이벤트 종류·UTC 시각을 남기며 플랫폼 감사 기능에는 작업자 ID가 전달될 수 있다. 웹 서버와 WordPress 자체 로그·백업 정책은 별도로 적용된다.

| --- | --- | --- |
| jsDelivr (`cdn.jsdelivr.net`) | 처음 Python을 실행하거나 실행 환경이 필요한 데이터를 가져올 때 Pyodide 0.26.4 및 필요한 패키지를 받는다. 브라우저 IP·요청 URL·일반 HTTP 메타데이터가 전달된다. 플러그인은 노트북 원문을 CDN으로 보내지 않는다. | [약관·개인정보 안내](https://www.jsdelivr.com/terms/privacy-policy) |
| PyPI (`pypi.org`, `files.pythonhosted.org`) | seaborn 내장 패키지 로딩 실패 시 micropip으로 seaborn 0.13.2를 설치한다. 브라우저 IP와 요청 패키지·HTTP 메타데이터가 전달된다. | [PyPI 개인정보 안내](https://policies.python.org/pypi.org/Privacy-Notice/) |
| Kaggle (`www.kaggle.com`) 및 다운로드 리다이렉트 대상 | 운영자가 연동 정보를 저장하고 사용자가 검색·파일 목록·가져오기를 요청할 때 서버가 요청한다. Kaggle에 계정명·API 키·검색어·데이터 식별자와 서버 IP가 전달된다. 다른 origin의 다운로드에는 인증 헤더를 보내지 않는다. | [이용약관](https://www.kaggle.com/terms), [개인정보 안내](https://policies.google.com/privacy) |
| 교사가 지정한 데이터 파일 URL의 호스트 | 해당 자료를 가져올 때 서버 IP와 요청 URL·HTTP 메타데이터가 전달된다. URL에 포함된 인증값도 그 호스트에 전달된다. | 해당 자료 제공자의 정책 확인 |

Kaggle은 선택 기능이며 설정하지 않아도 코드 실행·저장과 번들 CSV·교사 업로드 자료를 사용할 수 있다. API 키는 WordPress salt에서 유도한 키로 암호화해 사이트 DB에 저장하고 학생 브라우저에 전달하지 않는다. 사이트 관리자나 ‘코드 실습실 설정’ 권한을 받은 교사가 설정 화면(교사 메뉴 › 코드 실습실 › 설정)에서 삭제할 수 있다. salt 변경 뒤에는 다시 입력해야 한다.

Python 실행은 브라우저 Worker에서 이루어진다. 사용자가 작성하거나 가져온 Python 코드는 네트워크 요청 기능을 사용할 수 있으므로 신뢰할 수 없는 코드의 실행 결과와 외부 연결은 별도로 검토해야 한다. 플러그인은 독립적인 추적·광고·사용량 분석 서비스를 추가하지 않는다.
