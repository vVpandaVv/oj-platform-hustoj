## RC4 업데이트 순서

1. 최종 ZIP의 SHA-256과 검증한 후보 대비 변경 파일·추가 검사 결과를 확인한다.
2. 학생 편집을 마무리하고 운영 DB·코드·옵션·salt 백업과 복구 수단을 확보한다.
3. RC4로 업데이트하고 활성 버전·사이트 건강을 확인한다. 기존 자료와 브라우저 자산을 확인한다.
4. 학생 실행·저장·다시 열기, 교사 학급/모둠 조회, 자료 가져오기와 실제 서버 상한 오류 처리를 검사한다.
5. 문제가 생기면 편집을 중지하고 변경 전 코드·DB·옵션을 같은 시점으로 복원한다. ZIP만 되돌려 데이터 복구로 간주하지 않는다.

검증 수치·후보 해시는 [VALIDATION.md](VALIDATION.md), 배포 판단은 [release-gates.json](release-gates.json)에 기록한다.
