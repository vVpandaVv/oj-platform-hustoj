# RC4 릴리즈 준비 상태

현재 작업·운영 버전은 **1.0.0-rc.6**이며 OJ Platform은 **2.0.0-dev.104**다. Ace 테마 공유·텍스트 셀의 검증 및 설치 결과는 [RC6 변경 검증](ACE_TEXT_CELLS_2026-09-10.md)과 [RC6 reviewed 배포 증빙](../../_releases/oj-code-lab/1.0.0-rc.6/reviewed/release-evidence.json)을 참조한다. 아래 RC4 검사 수치·산출물·운영 설치 기록은 당시 증거로 보존하며, 공개 정식 배포 판단은 **NO-GO**를 유지한다.

검토일: **2026-09-10** · 후보: **1.0.0-rc.4** · 공개 정식 배포: **NO-GO**.

RC4는 운영 DB의 16MiB packet 제한에 맞춰 저장 상한을 조정하고, 데이터 조회 실패를 빈 목록이나 없는 자료로 처리하지 않도록 보완한다. 새 ZIP의 기본 샘플은 권리와 변환 증거를 확인한 펭귄 데이터 1개다. 기존 설치 자료는 업데이트 때 유지한다. Kaggle 파일 목록의 여러 페이지 처리를 보완하고 PHP 8.1.34와 8.5.5에서 HTTP 회귀 21개씩을 포함한 최종 로컬 검증을 통과했다. [공식 API 계약 검토](KAGGLE_CONTRACT_REVIEW_2026-09-10.md)는 공개 무인증 요청과 실계정 수용 범위를 구분한다.

최종 산출물은 `_releases/oj-code-lab/1.0.0-rc.4/reviewed/`의 RC4 ZIP이다. PHP 8.1/8.5 검증을 마친 중간 빌드에서 공식 개인정보 고지 링크만 정정했으며 실행 코드·자료는 같다. 정확한 해시와 후보별 검사 범위는 [검증 기록](VALIDATION.md)에 연결한다.

## 검증한 범위

- 최소 PHP 8.1.34와 WordPress 6.6.2·7.1에서 후보 ZIP의 실제 통합 검사를 조합별 79개 통과했다.
- 실제 OJ Platform dev.101 전체 Kernel·설치·인증·권한·학급/모둠 서비스에서 44개를 통과했다. fixture로 대체하지 않은 API·DB 검수다.
- RC3→후보 RC4 전체 DB 복원 38개와 별도 새 설치 5개를 통과했다. 기존 노트북·자료·키를 보존하고 새 설치는 펭귄 자료만 생성했다.
- 실제 16MiB packet 경계 19개와 로컬 요약 SQL 2,000회(실패 0, p95 1.7905ms)를 확인했다. 운영 네트워크·인증을 포함한 부하 결과는 아니다.
- 후보 ZIP의 Chromium·Firefox·Playwright WebKit에서 실제 Pyodide 시나리오를 각각 16개 통과했다. Windows의 WebKit 엔진 검수이며 Apple Safari 앱은 미검증이다. 정확한 버전과 범위는 [검증 기록](VALIDATION.md)에 있다.

이전 후보에서 구현한 Worker 중단·입력 복구, CAS 저장 충돌, 개인정보 내보내기·삭제, 안전한 외부 데이터 가져오기와 교사 조회 권한은 유지한다. 상세 검사 개수를 이전 RC와 누적해 완료율로 표현하지 않는다.

## 정식 배포 전에 남은 결정과 실행

1. **코드 라이선스 결정**은 소유자가 보류한 상태다. 승인을 받기 전 GPL 등으로 선언하지 않는다. 지원·문의 URL도 확정해야 한다.
2. Kaggle을 운영에서 사용할 경우 계정을 설정하고 검색·전체 파일 목록·다운로드·키 오류·429를 실계정으로 확인한다. 키는 운영자가 설정 화면에 직접 입력한다.
3. 최종 RC4 ZIP은 2026-09-10 운영에 설치·활성화했으며 건강과 학급·모둠 읽기 전용 검수도 통과했다. 운영 백업·복구 수단을 확보하고 학생 실행·저장과 실제 역할/화면 전체를 검수한다.
4. 서버 공개 로그·웹/프록시 제한·cron 실행을 확인하고, 실제 Safari와 운영 부하·프록시 정책을 검증한다.
5. R1–R7의 해당 버전 증빙과 라이선스 승인을 모두 충족한 뒤 1.0.0 정식 빌드를 진행한다.

[공개 데이터 정책](PUBLIC_DATASETS.md)은 `penguins.csv`의 CC0 근거를 확정하고 나머지 28개 CSV를 새 ZIP에서 제외한다. 이는 Code Lab 코드 라이선스 승인과 별개다. [게이트](release-gates.json)는 전체 NO-GO를 유지한다. RC4 운영 설치·건강·학급/모둠 확인은 `_releases/oj-code-lab/1.0.0-rc.4/production-postcheck-20260910.json`에 기록하며, [이전 운영 기록](OPERATIONS_JUDGE_2026-09-08.md)은 당시 RC3 및 서버 조건의 이력으로 보존한다.
