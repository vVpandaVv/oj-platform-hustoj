PLATFORM-LINKING-EXCEPTION.txt는 자체 코드와 플랫폼 공개 Addon API 연동에 한정한 추가 허락입니다. 플랫폼·WordPress·제3자 자료의 라이선스나 재배포 권리를 변경하지 않으며 Code Lab의 소스 제공·고지 의무는 유지합니다.

== Description ==

Python 코드를 브라우저 Worker에서 실행하고 코드·텍스트 메모·입력·출력·그래프를 사용자별 노트북에 저장합니다. 셀 사이의 + 코드 / + 텍스트로 내용을 추가합니다. OJ Platform dev.104 이상에서는 제출 페이지와 같은 계정 테마·글자 크기의 Ace Python 편집기를 사용합니다. 담당 교사는 학급·모둠의 노트북을 읽기 전용으로 확인합니다. 실행 중단·재시작, 저장 충돌 감지, JSON 다운로드를 제공합니다. 코드 셀의 ‘디버그’로 한 줄씩 실행하며 변수 값·호출 순서를 확인하고, 줄 번호를 눌러 중단점을 놓고, 지나온 단계를 다시 볼 수 있습니다.

기본 팔머펭귄 CSV의 출처·CC0 및 변환 내용은 docs/PUBLIC_DATASETS.md에 있습니다. 교사 업로드·파일 URL과 선택적인 Kaggle 연동에서 CSV·JSONL·NDJSON·ZIP을 지원합니다. JSONL·NDJSON은 pd.read_json(..., lines=True)로 읽고 미리보기 코드를 자동 실행하여 표를 출력합니다. 교사는 ‘파일 선택’ 또는 목록의 ‘첫 지원 파일 추가’로 추천 자료를 등록합니다.

1.4.0은 DB 스키마 2와 노트북 형식 2를 유지합니다. OJ Platform 코드는 이번 릴리즈에서 수정하지 않으며 기존 공개 Editor API와 Ace 자산을 사용합니다. 검사 환경과 결과는 ZIP 옆 공개 검증 보고서를 참조하세요.

텍스트 셀은 마크다운 도구 막대와 실시간 미리보기로 작성합니다. 닫기를 누르면 서식만 보이고 편집 버튼이나 두 번 클릭으로 다시 수정합니다. 원문을 저장하며 교사 화면에도 같은 서식을 표시합니다.

== Installation ==

1. WordPress 6.6+, PHP 8.1+, OJ Platform >=2.0.0-dev.30 <3.0.0 / Addon API >=1.0.0 <2.0.0을 준비합니다.
2. OJ Platform을 활성화하고 OJ Code Lab ZIP을 설치합니다. 네트워크 전체 활성화는 지원하지 않습니다.
3. 플랫폼 /oj-console/roles에서 학생 사용·교사 열람·추천 자료 관리 권한을 배정합니다. Kaggle 연동은 교사 메뉴 › 코드 실습실 › 설정에서 사이트 관리자 또는 ‘코드 실습실 설정’ 권한을 받은 교사가 설정합니다.
4. HTTPS, CDN 접속, COOP/COEP와 사이트 건강 상태를 점검합니다. ZIP 읽기에는 PHP zip 확장의 ZipArchive와 서버 임시 파일 쓰기 권한이, CP949 변환에는 iconv 또는 mbstring이 필요합니다.
5. 업데이트 전 ZIP·DB·설정과 salt를 백업하고 업데이트 후 기존 탭을 새로고침합니다.

== Frequently Asked Questions ==

= Kaggle 계정이 필수인가요? =
아니요. 코드 실행과 저장, 기본 CSV 및 교사 업로드는 Kaggle 없이 사용할 수 있습니다.

= JSONL과 ZIP에는 어떤 제한이 있나요? =
JSONL은 각 줄에 JSON 객체 또는 배열 하나를 쓰며 빈 줄은 건너뜁니다. UTF-8·CP949 텍스트를 UTF-8로 정규화하고 한 줄 최대 1MiB, JSON 파서 깊이 한도 64와 기존 파일 전체 상한을 적용합니다. ZIP은 요청 파일명과 정확히 일치하는 내부 파일을 우선 선택하고, 없으면 지원 파일이 하나일 때만 자동 선택합니다. 여러 개이면 Kaggle 목록에서 원본 파일을 고르거나 압축을 풀어 하나만 업로드하세요. 중첩·ZIP64·분할·암호화 ZIP과 Store·Deflate 이외 압축은 지원하지 않습니다. 디렉터리 포함 1,000개 항목, 각 항목 압축률 200배, 전체 압축 해제 크기는 실제 파일 상한의 8배와 128MiB 중 작은 값을 적용합니다. 자세한 한도는 README.md를 참조하세요.

= JSONL인데 Word 문서라는 안내가 나와요. =
파일 이름이 .jsonl이어도 내용이 Word 문서(DOCX)이면 읽을 수 없습니다. Word 문서는 ZIP 구조를 사용합니다. 이름만 바꾸지 말고 데이터 제공자의 실제 UTF-8 JSONL 또는 CSV 원본을 사용하세요.

= 런타임을 재시작했더니 파일을 찾지 못해요. =
재시작하면 변수와 가져온 파일이 사라집니다. 셀과 이미 표시한 출력은 유지되므로 추천 자료나 파일 목록에서 데이터를 다시 불러오세요.

= 삭제하면 학생 자료도 지워지나요? =
일반 삭제는 보존합니다. 운영자가 OJ_CODE_LAB_DELETE_DATA=true를 지정한 뒤 삭제하면 해당 사이트의 자체 데이터와 설정을 삭제합니다.

= 다른 Python 패키지를 쓸 수 있나요? =
Pyodide 0.26.4에 포함된 패키지(numpy, pandas, matplotlib, scipy, scikit-learn, sympy, networkx 등)는 import만 하면 처음 실행할 때 자동으로 내려받습니다. 그 밖의 PyPI 패키지를 셀에서 설치하는 기능(micropip)은 아직 지원하지 않습니다.

= 어디에 문의하나요? =
사용 권한·학급 소속·개인정보 요청은 사이트 운영자에게 문의하세요. 코드 오류는 이 ZIP을 제공한 배포자에게 버전과 최소 재현 절차를 전달하세요. 오류 신고에 비밀키·학생 정보·전체 로그를 포함하지 마세요. docs/SUPPORT.md를 참조하세요.
