사용 설정

AI 피드백 기능만 끄며 제출, 내 학습과 전체 랭킹에는 영향을 주지 않습니다.

제출 AI 피드백채점 완료 뒤 사용자가 명시적으로 요청할 때만 Jobs에 등록합니다.
요청 가능 결과채점이 완료되고 상세 접근이 허용된 제출에만 버튼을 표시합니다.

답변 정책

각 수준에 등록된 활성 지침 중 하나를 선택합니다. 선택하지 않은 활성 지침은 보존되며 언제든 교체할 수 있습니다.

자료 부족 기본 지침수준을 추정하지 않고 결과 이해와 자기 점검 질문만 제공합니다.
초급 지침오류 위치와 다음 확인 행동을 구체적으로 좁혀 줍니다.
중급 지침변수 값과 실행 흐름을 스스로 추적하도록 돕습니다.
고급 지침경계값, 예외 입력과 복잡도를 질문 중심으로 확인합니다.

응답 보호

정답 코드 전체 제외완성된 정답 코드나 그대로 적용할 수정문을 생성하지 않습니다.
