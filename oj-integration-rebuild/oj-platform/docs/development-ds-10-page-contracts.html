DS-10 · 상세 설계 1/4

페이지·권한·데이터 계약

Problems가 직접 제공하는 24개 화면의 주소, 책임, 접근 권한과 읽는 원본을 한 표에서 확인한다. 화면 동작과 저장 규칙은 연결된 기능 문서가 소유한다.

기능 설계 동결 사용자 10개 관리자 13개 호환 경로 0개
개요 페이지 계약 문제 콘텐츠 퀴즈 관리 도구·구현

공통 접근 규칙

메뉴 노출과 주소 직접 접근은 같은 Policy 결과를 사용한다.

CF-1·DS-07 유지
  1. 회원가입·비밀번호 복구 등 DS-09의 명시적 비로그인 예외를 제외한 모든 Problems 화면은 로그인한 active 사용자만 접근한다.
  2. 사용자 화면은 문제 공개 상태, 수업·대회·평가 참여 범위와 평가 보호 정책을 추가로 검사한다.
  3. 관리자 화면은 WordPress capability와 문제별 소유자·공동 편집자·테스트데이터 담당 범위를 함께 검사한다.
  4. 메뉴, GET, POST, AJAX, Jobs 등록, Worker 실행 직전, 파일 응답과 내보내기에 같은 문제 Context를 전달한다.
  5. 권한 거부 화면은 보호 대상의 제목·본문·답안·파일 경로를 노출하지 않는다.

상태 변경 액션

화면 조회와 저장 명령을 분리하고 GET 요청에서는 상태를 바꾸지 않는다.

POST·AJAX·Jobs
명령실행 방식중복·권한 보호상세 원본
퀴즈 응시 시작POST oj_quiz_start_attempt문제별 nonce, 64자 멱등 키, 진행 시도 고유키퀴즈 응시 흐름
퀴즈 최종 제출POST oj_quiz_submit_attempt시도 소유자, 상태 조건, 재전송 시 같은 결과 반환퀴즈 응시 흐름
메타데이터·문제·테스트 AIAJAX는 Jobs 등록만 수행현재 권한·입력 해시를 Worker 실행 직전 재검사AI Jobs
테스트데이터 파일 명령POST oj_problem_test_data_action의 타입이 있는 operation으로 루트 파일 생성·편집·이름 변경·다중 삭제·다운로드, ZIP 생성·미리보기·해제와 SPJ Job 등록. 폴더 생성·열기·이동·복사 operation은 등록하지 않는다.문제별 nonce·현재 테스트데이터 범위·루트 경로·원본 해시·문제 잠금, 디렉터리 항목 차단, ZIP 해제 한도와 재확인테스트데이터 편집기
테스트 환경 저장POST oj_save_problem_test_data_settings에서 데이터 루트와 SPJ 실행 파일 묶음을 구분해 저장oj_manage_system, nonce, 설정 revision, 절대·실재·읽기·쓰기 경로, WordPress 경로 비중첩, 승인된 /usr 실행 파일 검사테스트 환경
문제 번호 변경·퀴즈 재적용oj_problem_change_id는 연속·임의 매핑의 영향 계획을 승인한 뒤 Job만 등록하고, 퀴즈 재적용도 검증 계획 뒤 Jobs 실행대상 스냅샷, 일대일 매핑, 저장소 Registry, 체크포인트, 멱등 키, 원본 보존고위험 도구
문제·퀴즈·문제집 저장전용 POST 액션대상별 nonce, capability, 담당 범위, 원본 해시각 기능 문서
분야·세부 주제 추가POST oj_problem_topic_create위험 작업 nonce, 최고 관리자 재검사, 키·이름·별칭 중복, 분야→세부 주제의 정확히 2단계와 문제 링크 불가 분야 검사주제 사전 계약
