/oj-console/community/settings

게시판

전체 게시판과 연결형 질문의 사용 범위를 정합니다.

게시판 사용끄면 게시판 메뉴와 모든 문맥 질문만 제거됩니다.
전체 글쓰기활성 사용자가 전체 게시판에 글을 작성할 수 있습니다.
문맥 질문문제·수업·대회·그룹 Provider가 있는 공간만 사용합니다.

공지

게시판과 독립적으로 서비스 전체 공지를 운영합니다.

공지 사용끄면 공지 목록과 홈 공지 영역만 제거됩니다.
공지 댓글 기본값공지별로 운영자가 다시 허용할 수 있습니다.

첨부

보호 저장소와 전용 다운로드 응답을 사용합니다.

첨부 사용끄면 새 업로드만 막고 기존 파일은 권한 확인 후 제공합니다.
파일당 크기최대 10MB를 넘길 수 없습니다.
ZIP 허용실행형 내부 파일 검사를 보장할 수 없어 기본 차단합니다.

작성 제한

WordPress transient 또는 객체 캐시를 사용하며 영구 활동 테이블을 만들지 않습니다.
