DS-01 공통 사용자·관리자 UI 시스템

학습자·강사 서비스와 관리자 콘솔이 같은 용어, 상태, 입력, 명령과 접근성 규칙을 사용하도록 공통 UI 계약을 정의한다. 두 화면의 업무 밀도와 탐색 방식은 구분하되, 기능별 화면이 임의 스타일과 상호작용을 다시 만들지 않게 한다.

작성일: 2026-07-22확정일: 2026-07-22상태: 사용자 확정선행: DS-00 확정적용: DS-02~DS-15 전체인코딩: UTF-8 한글 원문
완료 범위: 디자인 문서만 만드는 단계가 아니다. 구현 시 로그인, 사용자 홈, 관리자 대시보드와 역할 관리 화면에 실제로 적용해 시각·조작 기준을 승인받아야 I-01의 UI 기반이 완료된다.

셸과 탐색 구조

사용자와 관리자의 작업 환경을 구분하면서 이동 규칙은 일관되게 유지한다.

환경구조탐색·명령

CSS 단일 원본: oj-ui-system.css가 토큰, 글꼴, 입력, 버튼, 표, 상태, dialog, 일괄 선택, 사용자·관리자 셸을 소유한다. 기능 CSS는 기능 고유 그리드와 시각화 배치만 소유하며 :root, 공통 선택자, 색·간격·모서리 재정의, 인라인 레이아웃 스타일과 !important를 허용하지 않는다. 빌드와 정적 검사에서 위반을 실패로 처리한다.
시안 자산도 같은 구조: 모든 UI 시안은 docs/assets/oj-ui-system.css와 oj-ui-prototype.js를 먼저 사용한다. ds08~ds14-prototype.css는 해당 기능의 고유 배치만 남기며 별도 토큰 파일과 DS-10 이름의 공통 CSS·JS는 제거했다.

브라우저 관문

각 화면은 Chromium 데스크톱·모바일을 통과하고, 배포 전 Firefox·WebKit 데스크톱·모바일을 추가 검증한다.

  1. 새 공통 자산을 기존 자산과 함께 로드하되 기준 화면 단위로만 적용한다.
  2. 동작·권한·URL 회귀 검사 뒤 새 화면의 데스크톱·모바일 결과를 사용자에게 보여 승인받는다.
  3. 승인된 화면이 사용하던 기존 선택자·직접 출력만 제거하고 다른 화면은 유지한다.
  4. 모든 화면 전환 후 임시 호환 CSS·JS와 사용하지 않는 변수를 I-09에서 제거한다.

DS-01 확정 항목

앞선 결정을 유지하면서 새로 구체화한 네 항목이다.

2026-07-22 확정
  1. DS01-Q01 · 보완: 사용자 데스크톱은 설정된 1차 메뉴와 최대 한 단계의 2차 드롭다운을 사용한다. 모바일은 운영자가 지정한 최대 4개 1차 메뉴와 나머지 1차 메뉴를 모은 더보기로 구성하고, 자식이 있는 메뉴를 누르면 같은 2차 항목을 시트로 연다. 외부 HTTPS 메뉴는 설정된 단계와 부모에서 외부 아이콘·호스트·새 창 정보를 표시한다.
  2. DS01-Q02: 중립 표면, 파란 주요 행동과 의미별 상태색, 4px 간격 체계, 최대 8px 모서리의 실행 토큰을 공통 기준으로 사용한다.
  3. DS01-Q03: src/Ui가 공통 표현 계약을, oj-ui-system.css와 oj-ui.js가 공통 시각·상호작용 구현을 단일 소유한다. PublicUi·AdminConsole은 각각 셸 조립만 소유하고 기능 CSS·JS는 고유 배치·상태 연결 외의 공통 코드를 만들지 않는다.
  4. DS01-Q04: 로그인·사용자 홈·관리자 대시보드·역할 관리 네 화면을 최초 기준 화면으로 구현·검증하고 사용자 승인을 받아 확장한다.
