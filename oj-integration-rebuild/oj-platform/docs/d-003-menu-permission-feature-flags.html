OJ Platform 재정비 기준 · D-003

메뉴·권한·기능 설정 재정비

이 문서는 관리자 메뉴, 작업 권한과 기능 활성화 판정을 하나의 실행 계약으로 재정비한 기준서다. 중앙 메뉴·권한·액션·기능 계약은 실제 코드에 반영됐으며, D-002의 제출 경로 전환, D-007의 목표 58개 메뉴 Registry 재배치, Jobs 신규 액션 3개와 서비스 수업·대회·문제의 담당 범위 정책은 후속 구현 대상으로 분리한다.

핵심 결론

메뉴와 GET 화면은 실제 경로를 권한 기준으로 유지했다. POST·AJAX 작업 122개를 중앙 액션 계약으로 모았고, 기존 Judge 사용자 일괄 가져오기 화면·메뉴·작업 2개를 제거했으며, 기능별 화면·권한·액션·자산은 실행 저장소에서 자동 계산한다.

현재와 목표의 경계

이 문서의 9개 상위·42개 하위 메뉴와 연결 경로 수는 현재 코드 기준선이다. 구현 4단계에서 D-002의 제출 맥락 경로 8개를 *.submissions로 바꾸고, D-007의 7개 업무 묶음으로 메뉴를 재배치한다. 이때 메뉴 Provider와 경로 키를 같은 변경에서 갱신하되 이 문서에서 확정한 권한·액션·기능 OFF 계약은 유지한다.

재정비 기준이 되는 현재 접근 흐름

화면 열기와 작업 실행은 서로 다른 경로로 검증된다.

기본 방어 적용
1 · 메뉴표시 가능 여부

기능 플래그와 메뉴 권한, 연결 화면의 실제 권한을 모두 확인한다.

2 · GET 경로화면 접근 여부

기능 상태, 로그인, 경로 권한 또는 맥락 규칙 순으로 검사한다.

3 · POST·AJAX작업 실행 여부

중앙 액션 저장소가 기능을 먼저 검사하고, nonce와 대상별 권한은 기존 처리 함수가 이어서 검사한다.

4 · 서비스업무 규칙

소유자, 그룹 범위, 제출 공개 범위 등 대상별 조건을 추가로 확인한다.

구현된 공통 계약

모든 작업은 소유 모듈, 전송 방식, 로그인 노출, 기능, 권한 정책, nonce 정책을 기록한다. 중복 액션과 존재하지 않는 기능 키는 등록 단계에서 거부된다.

로그인 우선 진입: 모든 OJ 화면은 기본 로그인 필수다. 비로그인 사용자는 /login으로 이동하고 active 상태로 인증에 성공하면 메인 홈 /을 연다. 로그인, 가입 기능이 켜진 회원가입, 로그인 화면의 비밀번호 복구·재설정, 법정대리인 확인과 법적 문서 4개만 로그인 전 접근 예외다.

관리자 메뉴 재정비 근거

  • 시스템 오류 기록 삭제도 중앙 계약에 포함

    완료

    oj_platform_clear_last_fatal은 필수 관리자 콘솔 기능에 연결했고, 기존 nonce와 oj_manage_system 또는 oj_manage_settings 검사를 유지했다.

  • 제출 상태 조회 AJAX 기능 가드 적용

    완료

    oj_submission_poll은 submissions 기능을 먼저 확인한다. 기능이 꺼지면 콜백을 실행하지 않고 404로 응답하는 테스트를 추가했다.

  • 중앙 액션 저장소를 실제 등록 창구로 전환

사용자 확정 · 완료

  1. D3-01 · 작업 액션 중앙 계약

    구현 완료

    Admin_Post_Registry를 실제 등록 창구로 사용한다. 각 액션에 소유 모듈, 허용 로그인 상태, 기능, 권한 또는 맥락 규칙, nonce 이름, 처리 함수를 명시하고 등록과 검증 테스트를 자동화한다.

  2. D3-02 · 기능 연결 정보의 단일 기준

    구현 완료

    기능 설정에는 키, 기본 상태, 잠금, 의존 관계만 둔다. 연결 화면과 권한은 실제 Route_Registry와 Capability_Registry에서 계산해 기능 관리 화면에 표시한다.

  3. D3-03 · 운영 권한 역할 분리

    구현 완료

    기존 역할의 권한을 예고 없이 넓히지 않는다. 가입 정책, 제출 설정, AI 피드백, 메일 설정을 담당하는 전용 역할 4개를 추가하고, 일반 역할 미배정 권한은 고위험 관리자 전용 7개와 그룹 맥락 판정 7개로 제한한다.

  4. D3-04 · 그룹 권한 규칙 단일화

    구현 완료

    그룹 서비스 기반 규칙 하나만 실제 대상별 권한 판정을 소유한다. 소유·위임 그룹 공급자는 관리자 메뉴 진입 범위 계산에만 사용하고, 그룹 권한 범위에는 전역 또는 특정 그룹에서 허용될 수 있음을 명시하는 범주를 추가한다.

  5. D3-05 · 기능 OFF 동작 통일

    구현 완료

    기능 OFF 시 메뉴 숨김, GET 404, POST·AJAX 404, 전용 자산 미적재를 공통 계약으로 확정한다. 먼저 제출 상태 조회 AJAX에 기능 가드를 추가하고 자동 검사로 누락을 막는다.

  6. D3-06 · 메뉴 계약 유지

    검증 완료

    중앙 메뉴 제공자, 실제 경로 권한 우선, 접근 가능한 첫 하위 메뉴 연결 방식을 유지한다. 상세·수정·삭제 확인 화면 46개에는 별도 메뉴를 만들지 않는다.
