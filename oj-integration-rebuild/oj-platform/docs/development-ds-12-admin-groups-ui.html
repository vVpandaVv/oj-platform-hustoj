기본 정보

그룹 역할

  • 그룹은 수업·대회 콘텐츠를 소유하지 않습니다.
  • 그룹 연결만으로 수업·대회 권한을 주지 않습니다.
  • 가입 코드는 원문으로 저장하지 않습니다.

그룹 설정

위임 운영자는 일반·수행 모드를 포함한 운영 설정을 변경할 수 있습니다.

/oj-console/groups/{group_id}/edit

운영 설정

수행 모드 적용 범위활성 일반 구성원은 그룹 밖에서 제출한 것을 포함해 본인의 모든 제출 상세·코드·오류·AI 피드백을 볼 수 없습니다. 풀이·제출·채점·결과 목록은 유지됩니다.

현재 상태

  • 활성 구성원 24명
  • 위임 운영자 2명
  • 연결 수업 2개
  • 진행 대회 1개
