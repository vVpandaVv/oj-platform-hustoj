문제 상세 설계

Problems의 기능·화면·권한·데이터·구현 경계를 확인하는 시작 문서다. 큰 표와 세부 동작은 기능별 문서로 분리하고 이 문서에는 전체 기준과 확정 결과만 유지한다.

목표 경험: 학습자는 난이도와 주제로 문제를 찾고, 본문·예시를 이해한 뒤 제출·퀴즈·질문·문제집으로 자연스럽게 이동한다. 강사는 담당 범위 안에서 문제·메타데이터·테스트데이터·퀴즈·공용 문제집을 관리한다.
범위 경계: Problems는 문제 콘텐츠, 전체 코드·빈칸 완성 작성 방식과 학습 콘텐츠 구성을 소유한다. 전체 코드·코드 빈칸 완성·Blockly 제출과 빈칸 답안 복원, 채점 결과 상세와 재채점은 DS-11, 게시글·댓글·첨부 원본은 DS-14가 소유한다.

확정 사항

사용자가 확정한 기준을 요약하고 세부 근거는 원본 문서로 연결한다.

DS10-Q01~Q09
번호확정 내용세부 문서
DS10-Q01Problems는 문제 콘텐츠·퀴즈·문제집을 소유하고 사용자 10개·관리자 13개 최신 주소만 제공한다. 주제 관리 화면은 최고 관리자만 접근한다.페이지 계약
DS10-Q02전역 capability와 문제 소유자·공동 편집자·테스트 담당자 범위를 모든 진입점에서 같은 Policy로 검사한다.담당 범위
DS10-Q03문제 상세의 제한·제출·관리 명령과 문제별 전체 코드/빈칸 완성 작성 방식, 제출 금지 코드·자동 앞·뒤 코드, 문제별 질문, 퀴즈 5단계 화면과 게시 보호·재적용 UI를 사용한다.문제 UI · 제출 코드 규칙 · 퀴즈 UI
DS10-Q04난이도는 AI 요청부터 DB까지 정수 1~5로 제한한다. 주제 사전은 분야 → 세부 주제의 정확히 2단계이며 문제에는 정확히 맞는 활성 세부 주제 키만 선택 사항으로 최대 3개 저장한다. 해당 항목이 없으면 주제 없이 저장하며 새 분야와 세부 주제는 최고 관리자만 추가한다.메타데이터
DS10-Q05메타데이터·문제 작성·테스트케이스 AI는 Jobs로 실행하고 수동값·원본을 자동 덮어쓰지 않는다.AI Jobs
DS10-Q06Problems가 문제별 테스트데이터 편집기와 파일 경계를 소유한다. ZIP 해제는 미리보기와 한도 검사를 거치고 SPJ 컴파일은 격리 Job으로 실행한다. 문제 번호는 연속 범위·임의 집합을 하나의 매핑으로 만들어 모든 등록 참조와 파일을 단계 변경하며 삭제는 복원 가능한 보관으로 처리한다.테스트데이터 · 도구
DS10-Q07Judge 원본·Problems 12개 테이블·파일·Jobs를 분리한다. 제출 코드 규칙은 새 테이블 없이 Judge problem.bann·front·body·rear와 기존 problem_metadata의 작성 방식·빈칸 스키마·해시를 사용하고, 퀴즈는 공유 불변 버전과 사용자 답안만 저장한다.제출 코드 저장 · 퀴즈 저장 · 데이터 경계
DS10-Q08문제 목록·메타데이터를 첫 수직 기능으로 구현한 뒤 작성·파일 도구·사용자 콘텐츠 순서로 확장한다.구현 순서
DS10-Q09설명·입력·출력·힌트는 MathJax 3 LaTeX, 예시 입력·출력은 서식 없는 원문으로 저장·표시한다.LaTeX·예시
후속 연계: DS-14 요구로 문제 상세에 최근 문제별 질문 최대 5개를 추가했다. Problems의 Route·Controller·테이블 수는 늘리지 않고 Board 선택 Provider의 ViewModel만 사용한다.
