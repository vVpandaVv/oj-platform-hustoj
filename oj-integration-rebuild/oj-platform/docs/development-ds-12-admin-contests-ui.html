현재 채점 방식: 부분 점수를 사용하지 않는 일반 점수형입니다. 각 문제 배점의 90%는 정답 기본 점수, 10%는 시간 점수이며 문제를 처음 맞히기 전의 오답 1회당 5점을 뺍니다.
시간 차이 확인: 김하늘과 최민준은 모두 4문제를 해결하고 오답 감점도 30점으로 같지만, 김하늘의 문제별 풀이 시간이 더 짧아 시간 점수 24점을 받고 최민준은 22점을 받습니다. 따라서 총점은 354점과 352점으로 달라지며 각 셀에서 실제 풀이 시간과 계산 내역을 확인할 수 있습니다.
동점: 시간 반영 총점이 같으면 해결 문제가 많은 순, 현재 총점을 완성한 정답 제출 시각이 빠른 순으로 정합니다. 모든 값이 같으면 공동 순위로 표시합니다.
실시간 집계: 화면을 열거나 갱신할 때 Judge의 현재 유효 제출을 다시 계산하며 참가자별 순위 스냅샷은 저장하지 않습니다. 재채점으로 결과가 바뀌면 같은 공식으로 점수와 순위를 다시 계산합니다.
다른 채점 방식: ICPC를 선택한 대회는 해결 수·벌점 표로, OI를 선택한 대회는 최고 통과율 점수·완전 해결 수·벌점 표로 같은 화면 구성이 전환됩니다.
