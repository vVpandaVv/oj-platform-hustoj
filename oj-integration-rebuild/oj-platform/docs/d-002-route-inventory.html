OJ Platform 재정비 기준 · D-002

화면·접근 경로 재정비

이 문서는 경로 목록 자체가 아니라 OJ Platform의 화면과 접근 경로를 단일 소유, 일관된 용어와 권한 계약으로 재정비하기 위한 기준서입니다. 공개·관리자 경로와 현재 호환 경로를 실제 코드에서 확인해 F-01, F-04~F-08의 해결 계약을 확정했습니다.

기준일 2026-07-18 페이지 구조 검산일 2026-07-22 근거 Compatibility_Route_Provider.php, modules/*/Module.php 상태 선행 보강 반영 · 제출 맥락 경로 8개 구현 대기
137사용자가 여는 화면 경로
47공개 화면
90관리자 화면
0현재 중복 선언된 화면
핵심 결론: 현재 코드는 화면 137개와 리디렉션 39개를 합쳐 GET 경로 키 176개이며 중복 선언은 없습니다. 목표 구조에서는 대회·수업·그룹의 제출 목록 8개를 submissions로 통일하고 이전 status 주소를 포함한 호환 경로는 등록하지 않습니다. 퀴즈는 사용자 목록·상세·응시·결과·통계와 관리자 목록·생성·편집·통계로 분리합니다. 최고 관리자 전용 문제 주제 관리, AI 작업 배정, 테스트 데이터 루트·SPJ 실행 파일을 관리하는 테스트 환경 설정, D-007의 허브 화면 2개와 D-005의 Jobs 진행 화면 1개를 포함한 렌더링 화면은 150개입니다. Jobs 결과 내보내기와 DS-14 보호 첨부 내려받기 파일 응답 2개를 더해 목표 GET 경로 키는 총 152개입니다.
신규 설치 경계: 정상 운영 152개와 별도로, 설치 미완료 동안에만 WordPress 관리자 /wp-admin/admin.php?page=oj-platform-setup 화면 1개를 SetupBootstrap이 등록합니다. 이 화면은 OJ AccessRouter·사용자 메뉴·관리자 메뉴 Registry에 포함하지 않으며 설치 완료 뒤 Hook 등록은 0개입니다.
조사 범위: 저장·삭제·일괄 작업에 사용하는 admin-post.php 작업은 화면 경로에 포함하지 않았습니다. 해당 작업과 권한은 D-003에서 메뉴 및 연결 화면과 함께 조사합니다.
