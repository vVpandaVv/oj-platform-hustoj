문제

길이가 \(N\)인 수열이 주어진다. 수열의 일부 구간에 포함된 수의 합을 구하는 질문 \(M\)개에 답하는 프로그램을 작성하자.

각 질문은 두 정수 \(i\)와 \(j\)로 주어진다. 수열의 \(i\)번째 수부터 \(j\)번째 수까지의 합을 출력한다.

\[ \sum_{k=i}^{j} A_k \]

입력

첫째 줄에 수의 개수 \(N\)과 합을 구해야 하는 횟수 \(M\)이 주어진다.

둘째 줄에는 수열을 이루는 \(N\)개의 정수가 주어진다. 다음 \(M\)개의 줄에는 합을 구해야 하는 구간 \(i\)와 \(j\)가 주어진다.

\(1 \le N, M \le 100{,}000\)이며 \(1 \le i \le j \le N\)이다.

출력

각 질문 \((i, j)\)에 대한 구간의 합을 한 줄에 하나씩 출력한다.

제한

  • 1 ≤ N, M ≤ 100,000
  • 수열의 각 수는 1 이상 1,000 이하의 정수이다.
  • 1 ≤ i ≤ j ≤ N
  • 시간 제한 1초, 메모리 제한 256MB
