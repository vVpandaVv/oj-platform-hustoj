# OJ Research

OJ Platform의 수업 연구 기능을 분리한 **별도 WordPress 플러그인**입니다. 독립적으로 설치·업데이트·활성화하며, 학생은 기존 OJ 문제 풀이 화면을 사용합니다. OJ Platform 없이 단독 실행하는 제품은 아닙니다.

| 구성 | 담당 기능 |
| --- | --- |
| OJ Platform | 학생 계정·그룹·문제·제출·채점, 기존 학생 수준평가, 수준별 AI 지침·모델 연결 |
| OJ Research | 연구 설정·두 집단 배정·사전/사후 단계·집단별 AI 정책·활동 기록·성취 분석·논문용 보고서 |
| 플랫폼의 공통 애드온 API 1.2.0 | 연구 플러그인의 정책을 OJ 제출·피드백·문제 추천·다른 애드온의 AI 요청에 연결 |

## 설치

1. 함께 제공하는 **OJ Platform 2.0.5**을 업데이트합니다. 이 연구 플러그인은 공통 애드온 API 1.2.0 이상(2.0 미만)이 필요합니다. 연구 기능이 내장된 2.0.4와 이전 분리 시안 2.0.5-dev.1에서는 활성화를 차단합니다.
2. `oj-research-1.0.0.zip`을 WordPress의 **플러그인 → 새 플러그인 추가 → 업로드**에서 설치·활성화합니다.
3. 설치 준비 안내가 표시되는 신규 사이트에서는 OJ Platform 설치 화면에서 **설치 재개**를 실행합니다. 연구 테이블 세 개만 추가합니다. 이미 연구 기능을 사용했던 사이트에는 이 작업이 필요하지 않습니다.
4. OJ Console의 **운영 → 기능 관리 → 그룹 수업 연구**를 켭니다. 기존 저장 설정을 자동으로 덮어쓰지 않습니다.
5. **학습지원 → 수업 연구**에서 연구를 관리합니다. WordPress 플러그인 목록의 **연구 관리** 링크도 같은 화면으로 연결됩니다.

정식 패키지는 OJ Platform 2.0.5와 OJ Research 1.0.0입니다. 두 ZIP 옆의 배포 명세에서 소스 커밋·태그·SHA-256을 확인할 수 있습니다. [정식 배포 안내](docs/release-1.0.0.md)를 참고하세요.

## 유지되는 연구 동작

- 기존 학생 수준평가 결과와 기존 OJ 수준별 지침을 읽어 사용합니다. 평가 알고리즘을 복제하거나 다시 설계하지 않습니다.
- 기본 비교는 **수준별 AI / 공통 AI** 두 집단입니다. **수준별 AI / AI 없음** 비교와 사용자 지정 조건도 유지합니다.
- 집단·사전 수준·문제 자료·프롬프트·모델 배정을 기존 방식으로 동결합니다. 수준별 피드백을 순차 힌트로 바꾸지 않습니다.
- 사전·사후 독립 평가, 차시별 AI 통제·제공량 제한, 조건 이탈 방지, 제출·응답 기록을 기존 OJ 흐름에서 처리합니다.
- 직관적인 수업 관리 화면과 논문용 결과 보고서를 분리합니다. Markdown·HTML·CSV·JSON 내보내기를 유지합니다.
- ANCOVA, HC3/CR1 불확실성 추정, 수준별 탐색 분석, 결측·철회 처리와 분석 보류 기준은 기존 구현과 같습니다.

## 기존 데이터와 비활성화

`research_studies`, `research_participants`, `research_records`의 이름·스키마·플랫폼 설치 소유권을 유지합니다. 자료 복사, 재배정, 수준 재산출, 테이블 삭제는 하지 않습니다. 비활성화하거나 플러그인 파일을 삭제해도 자료는 남습니다.

진행 중인 연구는 종료·보관한 뒤 플러그인을 비활성화해야 합니다. 파일 삭제 등으로 플러그인이 사라져도 플랫폼은 활성 연구 참여자의 AI 요청·제출·문제 추천을 중단하여 기록 누락과 조건 이탈을 막습니다. 그 외 학생은 일반 OJ 기능을 계속 사용합니다.

연구 자료가 남아 있는데 플러그인이 꺼져 있으면 계정 삭제는 연구 자료 정리 확인을 위해 보류됩니다. OJ Research를 다시 켜고 계정 삭제를 진행합니다. 재활성화 시 기존 연구 자료를 다시 연결합니다.

## 개발·검증

플랫폼 소스와 이 폴더를 형제 디렉터리로 둡니다.

```text
oj-integration-rebuild/
  oj-platform/
  oj-research/
```

```sh
php oj-platform/tools/run-tests.php --release
php oj-research/tools/run-tests.php
php oj-research/tools/build-package.php
```

플랫폼 ZIP은 기존 `scripts/build-release.ps1`로 생성합니다. 연구 ZIP은 별도 버전·검증·패키지 명세를 갖습니다. 통계 검증용 합성 자료와 테스트는 배포 ZIP에 포함하지 않습니다.

정식 빌드는 깨끗한 Git 작업 폴더와 현재 커밋을 가리키는 `v2.0.5`·`oj-research-v1.0.0` 태그를 요구합니다. 개발 버전에서만 `--allow-dirty`를 사용할 수 있으며 정식 버전에서는 거부합니다. ZIP과 명세가 이미 있으면 덮어쓰지 않습니다.

연구 확장은 공통 애드온 API의 초기 등록 훅 `oj_platform_register_extensions`에서 `AddonExtensionRegistrationGatewayV1::registerResearch()`로 한 번 등록합니다. 연구 계약은 `CodingPanda\OjPlatform\AddonApi\V1\Research`에 있습니다. 플랫폼이 모듈·스키마·경로를 구성하기 전에 연결하며, 플러그인 로드 순서에 의존하지 않습니다.

API 버전은 `OJ_PLATFORM_ADDON_API_VERSION=1.2.0` 하나로 관리합니다. 별도의 연구 API 버전 상수는 없습니다. 기존 애드온의 `oj_platform_register_addons`, `register()`, `onReady()`, Context·AI 작업·편집기 계약은 그대로 유지합니다. `V1`은 주요 버전 1을 뜻하므로 1.2.0에서도 namespace를 바꾸지 않습니다. 자세한 등록 순서와 호환 범위는 [공통 API 1.2 안내](../oj-platform/docs/addon-api-1.2.md)를 참고하세요.
