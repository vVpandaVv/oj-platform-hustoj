# OJ Research

OJ Platform과 연결하는 별도 WordPress 플러그인입니다. **그룹 설정·시작 설문 → 수업 → 종료 설문·결과**로 현장 수업을 운영합니다. 학생은 기존 OJ 문제 풀이 화면을 사용합니다.

| 구성 | 담당 |
| --- | --- |
| OJ Platform | 계정·그룹·문제·제출·채점, 기존 학생 수준평가, 수준별 AI 지침·모델 연결 |
| OJ Research | 그룹별 수업, 시작·종료 설문, 두 집단 배정, AI 정책, 관찰·수행 기록, 논문·자문 보고서 |
| 공통 애드온 API 1.x | 연구 정책을 OJ 제출·피드백·문제 추천·공용 AI에 연결 |

## 설치와 사용

설치 안내서 원본은 플러그인 루트의 `_release-kit/guides/oj-research.md`입니다. 생성된 안내서는 `_releases/latest/install-guides/`에 있습니다.

1. OJ Platform 2.0.5 이상(3.0 미만)을 먼저 설치합니다. 공통 API 1.2 이상(2.0 미만)이 필요합니다. PHP는 사용하는 플랫폼의 요구 버전을 따릅니다.
2. WordPress 관리자에서 OJ Research ZIP을 업로드하여 설치·교체하고 활성화합니다. 신규 사이트에서 안내가 나오면 OJ 설치 화면의 설치 재개를 실행합니다.
3. OJ Console의 **운영 → 기능 관리 → 그룹 수업 연구**를 켜고 **학습지원 → 수업 연구**를 엽니다.
4. 그룹 카드에서 수업을 만듭니다. 문제, 차시, 풀이 시간, 비교 조건을 정하고 참여 동의 방식과 보관 계획을 선택합니다. 설문·세부 조건·수업 맥락은 각각 모달로 수정합니다.
5. 동의를 확인한 학생만 선택해 시작 설문을 엽니다. 학생은 `/research`에서 응답합니다. 교사가 수업을 시작하면 A·B가 한 번 자동 배정됩니다.
6. 학생은 풀이 시작을 눌러 기존 OJ 문제 화면으로 이동합니다. 마지막 차시 종료 시 종료 설문이 열리고 보고서를 조회하면 최신 판정·설문·관찰 결과가 반영됩니다.

그룹은 관리 화면의 단위이고 A·B는 비교 조건입니다. 기본은 기존 수준별 층화 배정으로 수준별 AI와 공통 AI를 비교합니다. AI 없는 수업과의 비교, 학생 무작위·그룹 단위 배정과 사용자 지정 조건도 선택할 수 있습니다. 수준별 피드백은 기존 수준에 맞는 지침을 선택하며 순차 힌트가 아닙니다.

시작·종료 설문은 현장용 초안입니다. 기존 학생 수준을 새로 산정하거나 검증된 척도로 간주하지 않습니다. 각 문항의 응답 수·평균·해당 없음·무응답을 따로 집계하며 서로 다른 문항을 합친 총점을 만들지 않습니다.

새 기본 문항은 조건문·반복문·오류 위치 찾기에 관한 동일한 시작·종료 자기평가 3문항, 종료 수업 만족도 1문항, 실제 읽은 OJ AI의 이해·확인 방향·난이도 적합성 3문항입니다. AI 미사용·미열람은 해당 없음으로 안내하고 5점 척도의 모든 응답값에 뜻을 표시합니다. 기존 저장 설문은 자동으로 교체하지 않습니다. 전문가 검토와 소수 학생의 문장 이해 확인을 거쳐야 하며 자기평가를 실제 성취 점수로 해석하지 않습니다.

집단의 목표 인원 비율 A:B=1:1은 비슷한 수, 2:1은 A에 B의 약 두 배를 배정하려는 설정입니다. 소수 수준 집단이나 학급 단위 배정에서는 비율이 정확히 일치하지 않을 수 있습니다. 공통 AI용 실제 프롬프트는 공통 AI 조건의 `response_policy.instructions`로 모델 요청에 전달합니다. 수준별 AI에는 기존 수준별 지침이 선택되며 공통 AI 문장을 합쳐 넣지 않습니다. 등록 뒤에는 저장한 조건을 고정합니다.

새 수업은 중학교 2학년, 기초 경험, Python, 1인 1PC, 4주·6차시·45분의 **설정 예시**를 제공합니다. 학년·경험·기기·기간·교사 도움·해설 공개·외부 AI 규칙은 드롭다운, 학습 주제·중점 지표는 체크박스로 선택합니다. 선택 항목과 보충 설명을 보고서 문장으로 함께 저장합니다. 기존 수업을 편집할 때는 예시로 덮어쓰지 않으며 기존 서술을 유지합니다. 공통 수업 규칙은 두 집단의 조건에 동일하게 기록합니다.

동의서 관리번호는 동의서를 찾기 위한 이름이나 번호이며 필수가 아닙니다. 보관 계획은 장소·담당자·기간·폐기·철회 방법을 선택하는 방식입니다. 실제 동의 완료나 기관 승인 여부를 예시로 채우지 않습니다. 계획이 미정이어도 초안 저장은 가능하지만 시작 설문 전에는 선택을 완료해야 합니다. 기존 서술형 절차는 직접 작성으로 유지합니다. 이 선택은 보관·삭제·해설 공개·외부 접속을 자동 집행하지 않습니다. 중점 지표는 보고서의 분석 계획에 기록되며 기본 수집·집계는 그대로 유지합니다.

## 결과와 보고서

관리 화면은 그룹 카드와 다음 활동 버튼을 중심으로 유지합니다. 설문·세부 조건·교사 관찰·명단·종료 관리는 모달로 열 수 있습니다. 모달에서 편집한 설정은 창을 닫은 뒤 수업 설정을 저장해야 반영됩니다.

보고서는 결과 본문, 전문가 자문 요청서, 첨부자료로 나뉩니다. 설문지·수업 조건과 AI 지침·문제 자료·상세 결과·교사 관찰 및 자유 의견을 각각 모달로 미리 보거나 독립된 화면으로 엽니다. 문서별 HTML(인쇄/PDF)·Markdown과 전체 CSV·JSON을 내보낼 수 있습니다. 자유 의견의 개인 정보는 공유 전에 확인하세요. 모달 내용도 관리 권한을 다시 확인한 뒤 불러오며 JavaScript 없이도 별도 화면과 펼침 설정이 동작합니다.

- **시스템 작동**: 제출·채점 대기·AI 생성·전달 기록. 전달은 학생의 읽기·이해를 증명하지 않습니다.
- **학생 경험**: 시작 경험·자기평가와 종료 피드백 이해·만족도를 문항별로 표시합니다.
- **학습 수행**: 해결/시도 단위, 유효 제출 정답률, 재제출, 같은 학생·차시·문제의 최초→최종 오류, 최초 정답까지의 풀이 시간을 제공합니다.
- **선택 성취 평가**: 시작·마무리 과제를 따로 설정하면 완료·최종 판정이 확보된 학생의 점수와 변화량을 제공합니다. 평가가 없으면 독립 성취 상승 폭을 산출하지 않습니다.

코드 원문 변경분, 전체 AI 실패 요청과 응답 시간 계측은 자동 수집하지 않습니다. 재제출을 코드 수정의 질로 해석하지 않습니다. 교사 도움·반복 연습 등을 고려하여 자료가 뒷받침하는 범위를 전문가가 검토하도록 보고서에 명시합니다. 전문가 의견란은 검토자가 직접 작성합니다.

## 기존 연구와 데이터

기존 상세 시범 연구와 독립 채점 연구는 그대로 유지됩니다. 간편 수업으로 자동 변환하거나 수준·집단을 다시 계산하지 않습니다. 기존 상세 연구의 ANCOVA·수준별 탐색 분석도 유지합니다.

`research_studies`, `research_participants`, `research_records`를 그대로 사용하며 새 스키마 변경은 없습니다. 설문·관찰은 참여자별 기록으로 저장하므로 동의 철회 시 보고서에서 제외되고 계정 삭제 시 기존 정리 절차가 적용됩니다.

종료 설문과 채점 확인 후 수업을 보관하면 입력을 닫고 결과를 고정합니다. 채점 대기 제출이 있으면 보관할 수 없습니다. 활성 연구가 남아 있으면 비활성화를 막습니다. 파일을 제거해도 자료는 남으며, 플랫폼은 활성 연구 학생의 제출·AI·추천을 차단하여 기록 누락을 방지합니다. 재활성화하면 같은 자료에 다시 연결합니다.

## 개발·검증·패키지

소스는 `oj-integration-rebuild/oj-platform`과 `oj-integration-rebuild/oj-research` 형제 폴더에 둡니다. 플러그인 루트에서 실행합니다.

```text
D:\php\php.exe oj-integration-rebuild/oj-research/tools/run-tests.php
_release-kit\release.cmd package -Plugin oj-research
_release-kit\release.cmd docs
_release-kit\release.cmd check
```

설치 ZIP과 안내서는 릴리스 킷으로만 생성합니다. `tools/verify.ps1`이 패키징 전 PHP 문법·UTF-8·전체 연구 회귀 검사·JavaScript 문법을 실행합니다. 출력은 `_releases/oj-research/<버전>/`이며 이미 생성한 버전은 덮어쓰지 않습니다. 테스트·합성 자료·도구는 ZIP에서 제외합니다. 이전 직접 ZIP 빌더는 사용을 차단했습니다. 해시는 킷이 생성한 manifest와 SHA-256 파일에서 확인합니다.

연구 확장은 `oj_platform_register_extensions`에서 `AddonExtensionRegistrationGatewayV1::registerResearch()`로 등록합니다. 별도 연구 API 버전은 없으며 기존 API 1.1 방식 애드온은 공통 API 1.x 호환 범위에서 함께 동작합니다. 현행 OJ Platform 2.5.8/API 1.8.0과 두 로드 순서의 통합 회귀 검사를 수행합니다.
