4. 자료 수집 및 결과 분석

정답률은 공통 평가 문항을 기준으로 산출한다. 채점 방식은 전 테스트 통과 문항의 비율이며 100점 척도로 환산한다. 학생의 평가 완료 확인이 없거나 판정이 미확정인 경우 점수를 결측으로 남긴다.

오류율은 문항별 최초 유효 제출 중 정답이 아닌 제출의 비율이다. 오류 감소율은 (사전 오류율−사후 오류율)/사전 오류율×100으로 산출하며, 사전 오류율 0은 계산하지 않는다.

문제 해결 시간은 풀이 시작부터 최초 정답 코드 제출까지의 일시 중단을 제외한 활성 시간이다. 미해결 문제는 시간 평균에서 제외하며 해결 문항 수를 함께 내보낸다. 채점기의 실행 시간을 풀이 시간으로 사용하지 않는다.

만족도는 두 집단에 동일한 5점 척도 3문항을 제공하여 학생별 평균을 산출한다. 무응답은 결측이다.

5. 피드백의 학습 효과 분석

연구 질문: 저장된 두 집단의 수업 조건에 따라 알고리즘 성취가 얼마나 달라지는가?

비교 설계: 직접 설계 · 저장된 수집 자료 기준. 양의 차이는 A집단의 성취가 높은 방향이며, 단위는 100점 척도의 점수 차이다. 상대 향상률(%)이 아니다.

주 분석은 사후 성취 = 절편 + 집단(A/B) + 사전 성취 + 초기 수준 범주의 선형 회귀(ANCOVA)이다. 사전·사후가 모두 있는 참여 동의 학생을 배정된 집단대로 분석하고, AI 사용 여부를 기준으로 제외하거나 집단을 바꾸지 않는다.

학생 단위 분석은 HC3 표준오차와 잔차 자유도의 t 구간을, 학급 보정은 CR1 표준오차와 학급 수−1 자유도의 t 구간을 사용한다. 자동 선택은 분석 자료에 복수 학급이 있거나 학급 단위 배정이면 학급 보정을 적용한다.

분석 보류: 비교할 각 집단에 사전·사후가 모두 있는 학생이 최소 3명 필요합니다. 이는 수치 계산의 최소 조건이며 표본 수 계획을 대신하지 않습니다.

표준화 차이는 보정된 A−B 점수 차이를 완전 사례의 집단 내 합동 사후 표준편차로 나눈 값이다. Hedges g나 상대 향상률이 아니며, 분모의 변동이 없으면 계산하지 않는다.

6. 수준별 탐색 분석과 해석 범위

수준별 효과는 주 모형에 집단×초기 수준 항을 추가한 별도 모형에서 추정한다. 각 수준의 사전·사후 평균은 완전 사례 기준이다. 자료 부족 수준을 초급으로 합치지 않는다.

수준별 추정 보류: 각 수준의 두 집단에 분석 자료가 필요합니다.

직접 설계한 비교입니다. 집단 간 차이를 수준별 맞춤만의 효과로 단정하지 마세요.

문제 추천·순서가 학생 또는 집단마다 달라 피드백 효과와 함께 나타날 수 있습니다.

사전·사후 평가의 내용 범위·난이도·채점 기준이 비교 가능한지 검토하고 근거를 기록하세요.

완전 사례 분석: 사전·사후가 모두 있는 학생만 추정에 포함합니다. 결측·철회에 따른 편향을 검토하세요.

사전 점수와 사후 점수의 선형 관계 및 집단 간 공통 기울기를 가정합니다. 분포·잔차와 가정은 별도로 확인하세요.

수준별 비교와 수준 간 효과 차이는 탐색 분석이며 다중 비교를 보정하지 않았습니다. 한 수준에서만 차이가 보여도 수준 간 차이가 입증되는 것은 아닙니다.

학습 자료와 분리한 공통 평가 점수를 주 결과로 사용한다. 오류·풀이 시간·만족도는 보조 지표이며, AI의 응답 품질 검사 자체는 학습 효과 검증이 아니다.

기존 학생 수준평가는 변경하지 않았다. 초기 수준은 공변량 및 탐색적 수준별 분석에 사용하며, 수준 등급의 변화만을 주 성취 결과로 삼지 않는다.
