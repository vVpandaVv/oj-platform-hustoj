# OJ Research 분리 검증 기록

이 문서는 **2.0.5-dev.1 / 1.0.0-dev.1 분리 시안**의 기록이다. 현재 공통 API 1.2.0 통합 결과와 설치 대상은 [dev.2 검증 기록](addon-api-1.2-verification-2026-09-16.md)을 따른다. 아래 수치와 ZIP은 당시 검증 근거로 보존한다.

검증일: 2026-09-16. 이 기록은 로컬 소스·합성 자료·테스트 DB 대역을 이용한 검증이다. 실제 학생 데이터나 외부 AI 호출을 사용하지 않았다.

## 변경 범위

- 기존 `oj-platform/modules/Research`의 26개 PHP 파일을 `oj-research/src`로 이동하고 `CodingPanda\OjResearch` 이름공간으로 분리했다.
- 연구 스키마·설정·화면 CSS/JS·테스트·통계 기준 자료를 연구 플러그인으로 옮겼다.
- 플랫폼의 Research API 1.x에서 기존 수준평가·활성 지침·문제·제출 조회를 제공하고 연구 정책을 연결한다.
- 연구 테이블 이름·소유권·버전·열·색인을 유지했다. OJ Platform 2.0.4의 Git 원본에서 따로 추출한 스키마 기준 자료와 비교한다.
- 일반 애드온 API 1.1.0, 학생 수준평가 알고리즘, 통계 모형·측정 기준은 바꾸지 않았다.

## 자동 검증

연구 플러그인 PHP 46개 파일의 문법·UTF-8 검사와 테스트 스크립트 10개가 통과했다.

| 검증 | 결과 |
| --- | --- |
| 연구 설계·배정·조건 동결·제공량·내보내기 | 기존 단위 검사 46개 통과 |
| 수업 시범 적용 흐름 | 38개 검사 통과 |
| ANCOVA·HC3/CR1·결측·작은 표본·퇴화 모형 | 독립 statsmodels/scipy 기준 자료를 포함한 177개 검사 통과 |
| 실제 피드백 작업 서비스·큐·처리기·캐시 연결 | 17개 통합 검사 통과; 외부 모델 대신 제어된 응답 사용 |
| 플랫폼 먼저 로드 / 연구 플러그인 먼저 로드 | 각 34개 수명주기 검사 통과 |
| 플랫폼 부재·구버전 | 연구 플러그인 활성화 차단 검사 통과 |
| 연구 화면·명령·보고서·권한·이스케이프 | 각각 14 / 9 / 24개 검사 통과 |

수명주기 검사에는 기존 스키마 채택, 활성 연구의 비활성화 차단, 비활성 상태의 일반 학습자 허용, 연구 참여자 AI·제출·추천 보호, 조회 실패 시 차단, 재활성화 시 자료 보존, 연구 테이블 3개만 추가 설치, 미완료 설치의 비활성화 허용, 기존 사이트 이전 과정과의 연결을 포함한다. 반복 포함되는 공통 준비 검사는 위 항목을 단순 합산할 때 중복된다.

플랫폼은 PHP 1,408개 파일의 문법 검사와 전체 테스트 스크립트 61개가 모두 통과했다. 별도로 사용자 메뉴의 이전 저장값 검사 24개도 통과했다. 플랫폼 전체 배포 검증 결과와 ZIP 체크섬은 `dist/oj-platform-2.0.5-dev.1.manifest.json`, 연구 ZIP 명세는 `dist/oj-research-1.0.0-dev.1.manifest.json`에 기록했다. 두 경로의 `dist`는 저장소 루트 기준이다.

## 브라우저 확인

별도 플러그인의 PHP 화면으로 미리보기를 다시 생성했다. 새로 분리한 CSS/JS를 연결하여 다음을 확인했다.

- 기본 A 수준별 AI / B 공통 AI 표시.
- ‘기존 수업 대비 피드백 효과’ 선택 시 B의 AI가 ‘사용 안 함’으로 전환.
- ‘직접 설계’ 선택 시 현재 조건 유지.
- 카드·탭·진행 단계가 있는 관리 화면과 별도 논문용 보고서 표시.

미리보기의 60명·7.68점 등은 계산과 화면 검증을 위한 **합성 자료**이며 실제 연구 결과가 아니다. 저장·설치는 미리보기에서 실행하지 않는다.

## 실제 사이트 상태

`judge.codingpanda.kr/wp-admin/plugins.php` 접속 시 관리자 로그인 화면이 표시되었다. 이 검증 기록 작성 시점에는 사이트 업로드·활성화·실제 DB 설치 검증을 수행하지 않았다.
