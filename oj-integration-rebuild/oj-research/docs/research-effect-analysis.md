# 수준별 AI 피드백의 학습 효과 연구

## 연구 관리

새 연구는 `/oj-console/research/new`에서 만든다. 기존 학생 수준평가의 계산 방법과 저장 결과는 변경하지 않는다. 새 연구의 기본 비교는 A=수준별 AI, B=공통 AI이다.

- **수준별 맞춤의 추가 효과**: A 수준별 AI / B 공통 AI. 공통 문제 순서·같은 풀이 제한·같은 추가 지원 조건·사전 및 사후 AI 비허용을 저장 단계에서 검증한다.
- **기존 수업 대비 피드백 효과**: A 수준별 AI / B AI 없음. 위 공통 조건을 유지한다. AI 제공 자체와 맞춤을 합한 효과이다.
- **직접 설계**: 기존의 모든 집단별 설정을 허용한다. 추천·시간·평가 AI 조건이 다르면 보고서에 해석상 주의점을 표시한다.

비교 설계를 변경하면 화면의 AI·문제 순서·B집단 풀이 제한과 추가 조건·평가 지원이 갱신된다. 저장 전 확인한다. 기존 저장 연구에는 새 기본값을 소급 적용하지 않는다. 초기 수준 저장 이후 조건 고정 규칙도 유지한다. 다른 설계가 필요하면 새 연구를 만든다.

각 수준 안에서 두 집단으로 배정하는 층화 방식이 기본이다. 학급 단위 배정, 학생 무작위, 수동 배정도 유지한다. `자료 부족`은 초급으로 바꾸지 않는다. 수준별 지침은 기존 OJ의 활성 지침을 연결하며 초기 저장 시 버전을 보관한다. 공통 AI 요청에는 학생 수준 프로필을 전달하지 않는다. 두 집단의 지침이 수준 반영 이외에서도 달라지는지는 연구자가 검토한다.

학생은 기존 OJ에서 문제를 풀고 제출한다. 연구 활동에서 풀이 시작을 누른 제출만 연결된다. 한도는 학생별 단계·차시에서 피드백이 생성된 서로 다른 제출 수이다. 클릭 수나 공급자 API 호출 수의 과금 상한은 아니다.

## 평가와 분석

사전·사후 평가 문항의 범위, 난이도, 채점 기준의 비교 가능성을 검토하고 방법 메모에 기록한다. 연습과 평가 문제는 분리한다. 수준평가는 배정과 피드백 선택에 쓰고, 주 결과는 별도 사후 알고리즘 성취 점수이다. 향상·차이 없음·저하 모두 그대로 보고한다.

기존 점수 계산은 유지한다. 평가 완료 확인과 최종 판정이 있어야 점수를 계산하고, 확인 후 풀지 않은 문항은 0점이다. 평가 완료가 없거나 채점이 미확정이면 결측이다. 시간 평균은 해결한 문항만 포함하므로 해결 수를 함께 해석한다. 만족도와 해결 시간은 보조 지표이다.

분석 버전 `pilot-analysis.1`:

1. 현재 동의한 배정 학생 중 사전·사후 점수가 모두 있는 완전 사례를 사용한다. AI 사용량으로 학생을 제외하거나 집단을 바꾸지 않는다. 결측이 존재하면 전체 무작위 배정자를 포함한 ITT 분석이라고 표현하지 않는다.
2. 주 모형: `사후 점수 ~ 집단(A=1) + 사전 점수 + 초기 수준 범주`. 공통 선형 기울기와 가산 효과를 가정한다. 사전 점수는 수치 안정성을 위해 중심화한 뒤 100으로 나누며 집단 차이는 원래 점수 단위이다.
3. 학생 단위 표준오차는 HC3와 잔차 자유도 t 구간이다. 학급 보정은 CR1 배율 `G/(G−1) × (N−1)/(N−K)` 및 자유도 `G−1`의 t 구간이다. 자동 선택은 분석 자료에 복수 학급이 있거나 학급 단위 배정이면 학급 보정을 사용한다. 독립성을 검토한 뒤 HC3를 명시할 수 있지만 학급 단위 배정에서는 선택할 수 없다.
4. 최소 계산 조건: 비교할 집단마다 완전 사례 3명 이상, 잔차 자유도 양수, 설계행렬 가역, 잔차 변동 존재. 학급 보정은 총 6개 학급 이상, 각 집단에 2개 학급 이상이다. 이는 수치 계산 가드이며 검정력이나 충분한 표본 수의 기준이 아니다. 20개 미만 학급에는 주의를 표시한다. 조건을 충족하지 않으면 이유와 기술통계만 제공한다.
5. 표준화 차이 = 보정 집단 차이 / 완전 사례의 집단 내 합동 사후 표준편차. Hedges g가 아니다. 신뢰구간은 점수 차이에 대해 제공하며 표준화 분모의 불확실성을 무시한 구간을 효과 크기 구간으로 제시하지 않는다.
6. 탐색 모형: 주 모형 + `집단×초기 수준`. 수준별 A−B 효과와 수준 간 효과 차이의 직접 대비를 제공한다. 희소 수준이 있으면 탐색 추정을 보류한다. 구간은 다중 비교를 보정하지 않았으며 어느 수준의 효과가 확정되었다고 자동 결론 내리지 않는다.

회귀 가정, 표본 수, 학급 내 상관, 선택 편향, 결측·철회, 평가 동형성은 연구자가 검토한다. 자동 계산은 인과적 타당성을 인증하지 않는다. 연구 중 값은 중간 분석으로 표시한다.

## 별도 논문 보고서

수업 관리는 카드·단계·현재 할 일 중심으로 유지한다. `/oj-console/research/{id}/report`는 방법 문안, 실제 기술통계, 분석 대상·결측, 사전 균형, 보정 차이와 95% 신뢰구간, 수준별 탐색 결과와 해석 범위를 제공한다.

- Markdown: 논문 문안·표.
- HTML: 인쇄용 보고서.
- CSV: 가명 학생·가명 학급·초기 수준·사전 및 사후 점수·변화량·보조 지표. 철회자 점수는 제외한다.
- JSON: 같은 분석 행, 분석 버전·선택 모형·계산값·자료 해시. 학생 이름과 계정 번호는 포함하지 않는다. 가명 자료도 연구 자료로 관리한다.

생성된 피드백 수와 전달 이벤트 수는 별도 제공한다. 전달 기록은 시스템에서 제공한 기록이며 학생이 읽거나 이해했음을 입증하지 않는다. 삭제된 참여자의 집단 정보가 사라진 경우 최초 배정 인원은 원래 명부와 대조한다.

## 계산 검증

`scripts/verify-research-analysis.py`는 고정 난수의 합성 자료만 생성하고 statsmodels 0.14.6을 독립 기준으로 사용한다. 실제 학생 자료를 불러오지 않는다. 양의 차이·음의 차이·학급 보정·불확실한 차이의 주 모형과 상호작용 대비, Student-t 임계값을 `tests/Fixtures/research-analysis.json`에 저장한다. PHP 단위 검사에서 수치 차이 1e-7 이내인지 대조한다. 일반 실행 서버에는 Python 또는 statsmodels 설치가 필요 없다.

방법 참고: [statsmodels 강건 표준오차](https://www.statsmodels.org/stable/generated/statsmodels.regression.linear_model.OLSResults.get_robustcov_results.html), [WWC 연구 설계·결측·동등성 안내](https://ies.ed.gov/ncee/wwc/standardsbriefs). WWC 인증을 받았다는 뜻은 아니다.
