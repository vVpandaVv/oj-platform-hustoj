# OJ Research 1.0.0 · OJ Platform 2.0.5 정식 배포

확정일: 2026-09-17. 연구 기능을 별도 플러그인으로 분리하고 공통 애드온 API 1.2.0으로 연결한 구성을 정식 버전으로 확정한다. 학생 수준평가 알고리즘과 기존 연구 데이터를 유지한다.

## 설치 파일과 순서

1. `oj-platform-2.0.5.zip`으로 OJ Platform을 업데이트한다.
2. `oj-research-1.0.0.zip`을 설치·활성화한다. 이전 연구 개발 시안이 설치되어 있으면 같은 플러그인을 업데이트한다.
3. OJ Console에서 수업 연구 화면과 기존 연구 목록을 확인한다. 연구 테이블이 없는 최초 설치에만 플랫폼 설치 재개가 필요하다.
4. 기능이 꺼져 있으면 운영 → 기능 관리 → 그룹 수업 연구를 켠다.

연구가 내장된 OJ Platform 2.0.4에서 업데이트할 때도 두 ZIP을 함께 적용한다. 플랫폼만 업데이트한 동안에는 연구 화면이 제공되지 않으며 활성 연구 참여자의 AI·제출·추천 보호 정책이 작동한다. 플러그인 설치 후에는 기존 연구 테이블과 설정을 이어서 사용한다.

## 확정 내용

- 별도 WordPress 플러그인 OJ Research가 연구 설정·두 집단 배정·AI 통제·기록·분석·보고서를 담당한다.
- 공통 애드온 API 버전은 1.2.0 하나이며 기존 1.1 호출 계약을 지원한다. 연구 초기 등록 훅은 공통 API의 선택적 단계다.
- 수준별 AI / 공통 AI 비교를 기본으로 제공하고, AI 미제공 및 사용자 지정 비교 조건도 유지한다.
- 학생은 기존 OJ 문제 풀이 화면을 사용한다. 수업 관리 화면과 논문용 보고서를 분리해 제공한다.
- 기존 수준평가 결과·연구 데이터·집단 배정·문제 자료·분석 규칙은 유지한다.

## 빌드 기준과 검증 자료

플랫폼 태그는 `v2.0.5`, 연구 태그는 `oj-research-v1.0.0`이며 같은 확정 커밋을 가리킨다. 정식 빌드는 변경 사항이 없는 작업 폴더에서 수행한다. 각 ZIP 옆의 `.manifest.json`에 실제 `source_commit`, `source_tag`, `source_dirty=false`, SHA-256과 검증 결과를 기록한다.

플랫폼 빌드는 전체 PHP 문법·필수 확장·회귀 검사 후 패키지를 생성한다. 연구 빌드는 PHP 문법·UTF-8, 기존 연구 기능, API 의존성, 양방향 로드 순서, 기존 애드온 공존과 정식 배포 조건을 검사한다. ZIP 내용은 태그가 가리키는 소스와 대조한다. 개발 시안의 검증 이력은 [API 1.2 검증 기록](addon-api-1.2-verification-2026-09-16.md)에 보존한다.

이 문서는 정식 설치 파일의 배포 안내다. 운영 사이트 업로드·활성화 여부와 실제 학생 수업에서의 학습 효과 검증은 별도로 기록한다.
