# 공통 애드온 API 1.2.0 통합 검증

이 문서는 dev.2 검증 당시의 기록을 보존한다. 2026-09-17에 확정한 정식 버전과 설치 순서는 [OJ Research 1.0.0 · OJ Platform 2.0.5 배포 안내](release-1.0.0.md)를 따른다.

검증일: 2026-09-16. 대상은 OJ Platform 2.0.5-dev.2와 OJ Research 1.0.0-dev.2이다. 로컬 소스·합성 자료·DB 대역을 사용했으며 외부 AI를 호출하거나 실제 학생 자료를 변경하지 않았다.

## 수정 결과

- 연구 기능은 별도 OJ Research 플러그인에 유지했다.
- API 버전을 `OJ_PLATFORM_ADDON_API_VERSION=1.2.0`으로 통합하고 별도의 연구 API 버전 상수를 제거했다.
- 연구 공개 계약을 `AddonApi\V1\Research`로 옮기고 공통 API의 선택적 초기 등록 게이트웨이를 추가했다.
- 초기 등록은 `oj_platform_register_extensions`에서 진행한다. 기존 일반 애드온의 `oj_platform_register_addons`와 `register()`·`onReady()` 실행 시점은 유지했다.
- OJ Research는 공통 API `>=1.2.0 <2.0.0`과 인터페이스 존재를 확인한다. 패키지 명세·활성화 검사·안내문이 같은 조건을 사용한다.

## 확인한 항목

| 항목 | 결과와 근거 |
| --- | --- |
| 기존 공개 계약 | 기존 인터페이스·DTO의 메서드, 이름 있는 인자, 기본값을 그대로 검사. 새 게이트웨이 1개만 기본 공개 표면에 추가 |
| 초기 등록 계약 | 30개 검사 통과. 선택 설치·중복 방지·등록 동결·예외 전파·실패 후 핸들 동결·공통 namespace 확인 |
| 1.1 애드온 호환 | `^1.1.0` 요구 애드온이 공통 API 1.2.0에서 승인되고 기존 방식으로 자기 런타임을 받는 것 확인 |
| 실제 조립 흐름의 공존 | 일반 애드온과 연구 플러그인을 동시에 등록하고 Context·AI 작업·편집기 게이트웨이를 확인 |
| 플러그인 로드 순서 | 연구 먼저 / 플랫폼 먼저 각 40개 검사 통과 |
| 연구 미설치·비활성 | 일반 애드온 실행 유지, 연구 화면·스키마 미등록, 기존 연구 참여자 보호 동작 확인 |
| 재활성화·데이터 | 기존 연구 자료·사전 수준·집단 배정 보존, 추가 설치는 연구 테이블 3개만 생성 |
| 의존성 검사 | 플랫폼 없음, API 1.1, 계약 파일 없음, API 2.0 차단. API 1.2·1.3 허용 |
| 연구 기능 회귀 | 두 집단·프롬프트 동결·서버 AI 정책·작업 큐·분석·관리 화면·별도 보고서 검사 통과 |

플랫폼 테스트 스크립트 **62개**, 연구 테스트 실행 **15개**가 모두 통과했다. 연구 실행 수에는 버전별 의존성 검사와 양방향 로드 순서가 포함된다. 연구 PHP 파일 46개의 문법·UTF-8 검사도 통과했다.

플랫폼 최종 릴리스 검사에서는 PHP **1,410개 파일**의 문법 검사와 필수 확장 확인, 62개 회귀 스크립트가 모두 통과했다. 생성된 두 ZIP의 모든 항목을 원본 파일과 바이트 단위로 비교했고 명세의 SHA-256도 일치했다. 플랫폼 ZIP에 과거 `ResearchApi` 또는 연구 구현 모듈이 포함되지 않고 공통 API의 연구 계약 4개가 포함된 것을 확인했다.

## 생성한 개발 패키지

| 패키지 | 항목 | SHA-256 |
| --- | ---: | --- |
| `dist/oj-platform-2.0.5-dev.2.zip` | 1452 | `bc3efd4e66c56fe27ead80a8f6b75126f773112dca30a2562d59acdf35409a5e` |
| `dist/oj-research-1.0.0-dev.2.zip` | 37 | `6e8d3a781d18136f09ba2eb0b20c3cd16a1b62e87de8b426695ee6980fef96f6` |

경로는 저장소 루트 기준이다. 각 ZIP 옆에 `.manifest.json`을 제공한다. 두 패키지는 `source_dirty=true`인 개발 후보이며, 플랫폼 명세의 `source_commit`은 `unavailable`로 기록되어 있다. 정식 태그·커밋 기반 릴리스로 표시하지 않는다. 기존 dev.1 ZIP은 덮어쓰지 않았다.

코드 실습실·교육 게임·학습자료의 `^1.0`, AI 평가·ML 실습의 `>=1.1.0 <2.0.0` API 선언이 1.2.0을 허용하는 것을 소스에서 확인했다. 이 확인은 각 소비자 플러그인의 전체 사용자 기능을 운영 사이트에서 검증했다는 의미가 아니다. 정확히 1.1.0으로 고정한 별도 소비자는 요구 범위를 검토해야 한다.

## 설치와 검증 범위

플랫폼 2.0.5-dev.2를 먼저 업데이트하고 연구 플러그인 1.0.0-dev.2를 이어서 설치·업데이트한다. 이 버전은 별도 Research API를 사용하던 dev.1 분리 시안을 교체한다. 기존 일반 애드온의 1.1 호출 계약은 유지한다.

현재 결과는 로컬 소프트웨어 검증과 개발 패키지 생성이다. `judge.codingpanda.kr`에 업로드·활성화한 결과가 아니며, 학생 수업에서의 학습 효과를 입증한 결과도 아니다. 운영 사이트 반영은 관리자 로그인 후 진행해야 한다.

계약 설명은 [공통 애드온 API 1.2 안내](../../oj-platform/docs/addon-api-1.2.md), 이전 분리 시안의 검증 기록은 [dev.1 분리 검증](extraction-verification-2026-09-16.md)을 참고한다.
