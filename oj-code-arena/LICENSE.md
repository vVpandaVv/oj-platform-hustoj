## 게임 규칙의 출처

게임 방식(팀이 한 판을 나눠 블록을 차지하고 코드를 입력하는 규칙, 보스·아이템의 큰 틀)은 한국정보교사연합회(KAIT) 의
KAIT-PLAY 를 참고했습니다. KAIT-PLAY 의 소스 코드, 화면 디자인, 문제 문장은 쓰거나 옮기지 않았으며, 이 플러그인의 코드·화면·문제은행은
모두 새로 작성했습니다(게임 규칙 자체는 저작권 보호 대상이 아닙니다).
