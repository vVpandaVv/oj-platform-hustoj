# 변경 기록

## 1.3.3 - 2026-10-15

- 학생 로비·대기실·경기 화면을 흰색·회색 바탕, 시스템 서체와 파란 주요 버튼으로 통일했습니다. 최대 1120px 너비, 제한된 모서리·그림자, 키보드 초점과 동작 줄이기 설정을 적용합니다.
- 에듀게임과 같은 시각 규격을 따르지만 자산과 설치는 독립적입니다. 경기 규칙, REST/WebSocket 엔진과 서버 설치 방식은 이번 UI 변경의 대상이 아닙니다.

## 1.3.0 - 2026-10-14

- 원클릭 설치를 공통 실시간 서버와 아레나 확장 모듈 구조로 통일했습니다. 티칭툴 없이 단독 설치 가능하며 두 플러그인의 설치 순서에 제약이 없습니다.
- 두 플러그인의 설치 ZIP이 같은 런타임을 포함합니다. 한 서비스·3210 포트를 공유하며 앱·채널·방, 인증키, 결과 파일은 분리합니다.
- 상태 확인에서 공통 서버·아레나 등록 및 비밀키 인증을 확인합니다. 기존 3200 독립 서버 사용자는 내부 주소를 3210으로 변경하고 새 설치 명령을 실행합니다.
- 재설치 시 다른 모듈과 미전송 결과를 보존합니다. 공통 서버 갱신은 모든 실시간 연결을 재시작하므로 수업이 없을 때 실행해야 합니다.
- 로컬 독립 설치·양방향 설치 순서·실제 WebSocket 통합 테스트를 추가했습니다. Ubuntu/systemd/nginx 운영 서버 설치는 아직 실행하지 않았습니다.

## 1.2.0 - 2026-10-14

- 설정 화면에서 Ubuntu/Debian 서버용 원클릭 설치 명령을 제공합니다. 서버 SSH에서 한 줄을 실행하면 Node.js 준비, 아레나 서버 복사, systemd 서비스 등록, nginx 프록시 설정과 상태 확인을 수행합니다.
- WordPress 설치 ZIP에도 서버 실행 파일을 포함합니다. 별도 서버 ZIP과 기존 수동 설정 방식도 유지합니다.
- 갱신 전 백업, 실패 시 이전 설치 복구, 중복 설치 잠금, 사용 중인 포트와 다른 사이트 설치 보호를 추가했습니다. 미전송 결과와 추가 환경 설정은 보존합니다.
- 티칭툴과 같은 서버 컴퓨터에서 운영할 수 있지만 서비스·포트·비밀키는 분리합니다. 경기 중 업데이트는 지원하지 않으며, 재시작하면 메모리에 있던 진행 중 경기는 종료됩니다.
- 로컬 설정·nginx 구성·게임 회귀 테스트 대상입니다. 실제 Ubuntu/systemd/nginx 서버 설치는 별도 운영 확인이 필요합니다.

## 1.1.0 — 2026-10-13
정식판입니다. 소유자 결정(2026-10-13)으로 1.1.0-rc.1을 코드 변경 없이 정식 승격했습니다. 실제 사이트 점검은 아직 하지 않았습니다.

## 1.1.0-rc.1 — 2026-10-13
- **통합 화면(D-010)**: 교사 콘솔 메뉴를 하나로 묶었습니다. 사이드바에는 "코드 아레나" 하나만 있고, 화면 위 탭으로 수업 게임 · 문제은행 · 경기 기록을 오갑니다(OJ Platform 2.1 이상).
  예전 메뉴 "코드 아레나 문제은행", "코드 아레나 기록"은 없어졌고 주소는 그대로입니다.
- **설정 화면을 OJ 콘솔로**: `/oj-console/addons/oj-code-arena/settings`. 같은 설정 값과 저장 방식을 씁니다(위치와 권한은 아래 항목).
- 콘솔 화면이 플랫폼 공용 부품(머리말, 버튼, 표, 알림, 빈 상태, 입력)과 색 토큰을 써서 어두운 화면도 맞습니다.
- 경기 끝내기, 수업 게임 닫기, 학생 내보내기, 봇 모두 빼기, 문제 삭제는 플랫폼 확인 창으로 묻습니다(없으면 예전처럼 두 번 누르기).
- 학생 게임 화면과 전광판은 몰입형 화면(사이드바 없음)으로 열리고, 게임 색은 그대로입니다.
- 문구: 편집, 삭제, 가져오기, 내보내기, CSV 내보내기, 다운로드.
- **설정은 교사 메뉴에서**: 설정 화면이 **교사 메뉴 › 코드 아레나 › 설정**(`/oj-console/addons/oj-code-arena/settings`)로 옮겨, 수업 게임 · 문제은행 · 경기 기록 다음 마지막 탭이 됐습니다. 운영 › 코드 아레나 메뉴는 없어졌습니다.
  OJ Platform 2.0.x(탭 없음)에서는 "코드 아레나 설정" 메뉴가 따로 보입니다.
- **설정 권한 추가**: `oj_code_arena_settings`(코드 아레나 설정, 교사용). 사이트 관리자와 이 권한을 받은 교사가 설정, 상태 확인, 부하 시험, 게임 서버 설정 파일(.env) 다운로드를 할 수 있습니다(예전에는 `manage_options`만).
  역할에 자동으로 넣지 않습니다. 교사에게는 `/oj-console/roles`에서 줍니다. 옵션 이름, 저장 형식, REST 주소는 그대로입니다.
- **WordPress 설정 → 코드 아레나 화면 삭제**: wp-admin 설정 메뉴가 없어졌습니다. 첫 안내와 플러그인 목록의 [설정] 링크는 콘솔 설정으로 갑니다. 화면 안내, 오류 문구, 게임 서버 메시지(`index.js`, `setup.js`, 생성되는 .env 머리말)도 새 위치를 가리킵니다.

## 1.0.0-rc.2 — 2026-10-12
- **교육게임(Edu Games) 연결**: 교육게임이 켜져 있으면 교육게임 허브에 "코드 아레나" 카드가 나타나고, 누르면 코드 아레나로 들어갑니다.
  교육게임 코드는 바꾸지 않습니다(교육게임의 게임 등록 훅 사용). 교육게임 [게임 공개 설정]에서 카드를 숨길 수 있습니다.
  아레나 기록은 코드 아레나에만 남고, 교육게임 순위·점수 API 에는 들어가지 않습니다.

## 1.0.0-rc.1 — 2026-10-12

정식 배포 전 후보판. 실제 사이트 점검을 마치면 1.0.0 으로 냅니다.

**보안**
- 내장 엔진: 학생당 초당 명령 40개 제한(Node 와 같게), 요청마다 구성원 다시 확인(내보낸 학생은 더 이상 소식을 받지 못함)
- 입장권을 중계 단계에서 늘려 주지 않음 — 브라우저가 만료 전에 WordPress 에서 새로 받아 권한을 다시 확인
- 서버 사이 서명을 요청 방식·경로에 묶음(`METHOD\nroute\ntime\nbody`) — 다른 API 로 다시 보내도 통하지 않음
- Node 모드 자유 대전 방 태그를 통한 저장형 XSS 차단(화면 이스케이프 + 서버에서 HTML 문자 제거)
- 문제은행: 교사는 자기가 만든 문제만 고치고 지움. 기본 문제·전체 바꾸기는 운영자만
- 학생의 강제 재전송 요청은 수업 게임마다 30초에 한 번
- Node 서버: 기본 수신 주소 127.0.0.1, API 본문 2MB 제한, 속도 제한을 사용자 단위로, 인증 없는 소켓 10초 뒤 끊기
- 기록 CSV 수식 주입 방지

**운영**
- 매시간 정리 작업(오래된 이벤트·접속 기록·닫힌 게임), 경기 기록 보관 기간 설정
- 개인정보: WordPress [개인 데이터 내보내기/지우기] 연동, 개인정보처리방침 안내 문구
- 설정 화면에 부하 시험(가상 학생으로 이 사이트의 응답 시간 측정)
- 두 엔진이 같은 규칙인지 확인하는 공용 시나리오 시험(`tests/scenarios/rules.json`)
- 릴리스 도구: `tools/test-all.js`, `tools/bump-version.js`, `tools/release/pack.ps1`
- 문서: 교사용 안내서, 운영자 안내서, 라이선스
