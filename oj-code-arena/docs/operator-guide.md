# 코드 아레나 — 운영자 안내서

## 설치와 업데이트

- **설치**: 플러그인 → 새로 추가 → 업로드 → `oj-code-arena-x.y.z.zip` → 활성화. OJ Platform(Addon API v1)이 먼저 켜져 있어야 합니다.
- **활성화 때 자동으로**: 표 7개 생성, 기본 문제은행, 권한 연결(로그인 역할 → 참가, 반·그룹 관리 역할과 관리자 → 수업 운영. 이미 정해 둔 권한은 그대로), 자유 대전 허용, 매시간 정리 작업 예약.
- **업데이트**: 새 zip 으로 덮어쓰기. 표 변경은 자동으로 적용됩니다. 0.1.0 에서 Node 서버 주소를 써 왔다면 계속 Node 모드입니다.
- **삭제**: 비활성화는 데이터를 지우지 않습니다. 플러그인을 **삭제**하면 표·설정이 모두 지워집니다.

## 엔진 고르기

| | 내장 (기본) | Node 게임 서버 |
|---|---|---|
| 준비 | 없음 | Node.js 20+, https 사이트면 nginx 프록시 |
| 반응 | 0.3~0.8초 | 즉시 |
| 권장 | 한 번에 한 반(30명 안팎) | 여러 반 동시, 느린 호스팅 |

**판단 방법**: OJ 콘솔 교사 메뉴 › 코드 아레나 › 설정 → **부하 시험**에서 학생 수만큼 가상 학생으로 1분 돌려 보세요.
95% 응답 시간이 600ms 이하면 좋고, 1.5초를 넘으면 Node 서버를 권합니다. 수업이 없는 시간에 하세요.

## Node 게임 서버 (선택)

1. 서버에 `oj-code-arena-server-x.y.z.zip` 풀기 → `cd oj-code-arena-server/game-server && npm install --omit=dev`
2. OJ 콘솔 교사 메뉴 › 코드 아레나 › 설정에서 엔진 = **Node 게임 서버**, 주소 `wss://사이트/arena` 저장
3. 설정 화면의 한 줄 명령 `node src/setup.js oca1.…` 실행(또는 `oj-code-arena.env` 내려받아 game-server 폴더에)
4. `node src/index.js` 또는 `deploy/oj-code-arena.service`(systemd), nginx 에 `deploy/nginx-arena.conf`
5. 설정 화면 **상태 확인** → "정상"

비밀키를 새로 만들면 3번을 다시 하세요. WordPress 로 못 보낸 결과는 `game-server/data/unsent-results.jsonl` 에 남습니다.

## 교육게임(Edu Games)과 함께 쓰기

두 플러그인은 따로 설치·업데이트합니다. 둘 다 켜져 있으면 교육게임 허브에 **코드 아레나** 카드가 생기고, 누르면 코드 아레나 학생 화면으로 이동합니다.
교육게임 관리 화면의 게임 공개 설정에서 이 카드를 숨길 수 있습니다(코드 아레나 메뉴 자체는 그대로). 경기 기록은 코드 아레나 기록에만 있습니다.

## 권한

| 권한 (WordPress) | 하는 일 |
|---|---|
| `oj_addon_oj_code_arena_play` | 학생 화면, 수업 게임 입장, 자유 대전, 내 기록 |
| `oj_addon_oj_code_arena_teach` | 수업 게임 만들기·운영, 문제은행(자기 문제), 기록 |
| `oj_addon_oj_code_arena_settings` (코드 아레나 설정) | 교사 메뉴 › 코드 아레나 › 설정: 게임 엔진, 자유 대전, 기록 보관 기간, 게임 서버 설정 파일, 상태 확인, 부하 시험 |
| `manage_options` (관리자) | 수업 운영 모두 + 모든 교사의 게임·기록, 기본 문제 |

사이트 관리자는 설정 권한 없이도 설정 화면을 씁니다. 설정 권한은 역할에 자동으로 들어가지 않으므로 설정을 맡길 교사에게 OJ 콘솔의 역할 관리(`/oj-console/roles`)에서 줍니다.

## 데이터와 개인정보

- 경기마다 학생의 사용자 번호·표시 이름·팀·푼 블록·보스 수를 저장합니다(`oj_code_arena_rounds`, `_round_players`).
- 경기 중 상태(`_live`), 소식(`_events`, 3분), 접속 기록(`_presence`, 1시간)은 매시간 정리됩니다.
- **기록 보관 기간**: OJ 콘솔 교사 메뉴 › 코드 아레나 › 설정 → 경기 기록 보관(일, 0 = 계속).
- 도구 → **개인 데이터 내보내기 / 지우기**에 "코드 아레나 경기 기록"이 들어 있습니다. 지우면 그 학생 줄이 지워지고 결과 안의 이름은 "삭제된 사용자"로 바뀝니다.

## 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 학생 화면이 "연결하는 중"에서 멈춤 | 브라우저 개발자 도구 네트워크에서 `relay.php` 응답. 403/404 면 호스팅이 플러그인 폴더 PHP 실행을 막은 것 — 자동으로 REST 로 바뀌지만, 보안 플러그인이 REST 도 막는지 확인 |
| "수업 명단에 없어요" | 수업 게임에 고른 반/그룹에 학생이 들어 있는지. 명단은 입장할 때 다시 읽습니다 |
| 반응이 점점 느려짐 | 부하 시험, 호스팅 CPU, DB 느린 쿼리. 많은 반이 동시에 쓰면 Node 서버 |
| 메뉴가 안 보임 | OJ 콘솔 애드온 상태(코드 아레나 애드온이 "accepted"인지), 역할 권한 |
| 경기 결과가 기록에 없음 | 봇만 있던 경기는 저장하지 않습니다. Node 모드면 서버의 `unsent-results.jsonl` |
