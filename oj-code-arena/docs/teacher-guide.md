# 코드 아레나 — 선생님 안내서

팀원들이 한 판을 나눠 블록을 차지하고, 블록에 적힌 코드를 정확히 입력해 판을 모두 푸는 게임입니다.
타자 연습과 코드 읽기를 함께 하고, 보스 문제로 코드의 실행 결과를 예측해 봅니다.

## 수업 전 (5분)

1. OJ 콘솔 → **[코드 아레나]** → **새 수업 게임**
   - 제목: 예) `3반 반복문 대항전`
   - 참가 대상: 우리 반(또는 그룹). 고르면 **그 반 학생만** 들어올 수 있어요.
   - [게임 설정]은 처음엔 그대로 두어도 돼요. 단원만 고르고 싶으면 **문제 단원**에 체크하세요.
2. **만들기** → 오른쪽에 대기실이 열려요.
3. 프로젝터에는 **[전광판 열기]** → 새 창에서 **전체 화면**.

## 수업 중

| 할 일 | 방법 |
|---|---|
| 학생 입장 | 학생은 메뉴 **[코드 아레나]** → 우리 수업 **입장** → 팀 고르기 |
| 팀 나누기 | 학생이 고르거나, **[팀 자동 배정]**. 학생 옆 목록에서 팀을 옮길 수 있어요 |
| 인원 맞추기 | **[봇으로 인원 맞추기]** — 빈자리를 연습봇이 채워요(봇은 기록에 남지 않아요) |
| 시작 | **[경기 시작]** → 5초 뒤 시작 |
| 잠깐 멈추기 | **[잠시 멈춤]** / **[다시 시작]** — 모든 시간이 멈춰요 |
| 끝내기 | **[경기 끝내기]**를 두 번 — 결과가 저장되고 대기실로 돌아가요. 다시 **[경기 시작]**하면 다음 판 |
| 팀끼리 공격 | **공격 아이템** 체크 — 경기 중에도 켜고 끌 수 있어요 |
| 학생 내보내기 | 이름 옆 **[내보내기]** 두 번 — 그 수업에 다시 못 들어와요 |
| 수업 마치기 | **[수업 게임 닫기]** 두 번 — 기록은 [코드 아레나 기록]에 남아요 |

## 학생에게 알려 줄 조작법

- 이동: 방향키, Tab / Shift+Tab — **Ctrl+방향키**로 빠르게, Home/End 로 줄 끝
- **Enter**: 블록 차지 → 코드 입력 → **Enter** 제출 (틀리면 블록을 놓쳐요. 다시 차지하면 돼요) · **Esc** 놓기
- **보스**(빨간 블록): 보스 **왼쪽 칸에서 Delete**, **오른쪽 칸에서 Backspace** → 출력 결과나 빈칸 코드를 맞히면 아이템! 기회는 한 번
- **모여라 보스**(노란 블록): 팀원 모두 보스 바로 옆 칸(같은 줄)으로 6초 안에 모이기
- **아이템**: Ctrl+Shift+1~5 · 공격을 막는 **방패**: Ctrl+Shift+9
- 띄어쓰기(따옴표 밖)는 상관없고 `'` 와 `"` 는 같게 봐요. 한/영 키가 한글이면 입력이 지워져요.

## 순위와 기록

- 판을 **먼저 다 푼 팀**이 높은 순위, 나머지는 진행률(%) 순
- 학생별로 푼 블록 수와 보스 수가 저장돼요 → **[코드 아레나 기록]**에서 보고 **CSV** 로 내려받기
- 학생은 [코드 아레나] 화면 아래 **내 기록**에서 자기 기록을 봐요

## 문제 바꾸기

**[코드 아레나 문제은행]**에서 문제를 추가하거나(한 줄 코드 = 일반 문제, 출력 예측/빈칸 = 보스 문제),
여러 문제를 한꺼번에 **붙여 넣어 추가**할 수 있어요. 내가 만든 문제는 고치고 지울 수 있고, 기본 문제는 운영자가 관리해요.
**채점 시험** 칸에 학생 답을 넣어 보면 정답으로 처리되는지 바로 확인할 수 있어요.

## 자주 묻는 질문

- **학생 화면에 수업이 안 보여요** → 그 학생이 고른 반(그룹)의 구성원인지 확인하세요. 반을 고르지 않고 만들면 참가 권한이 있는 모든 학생에게 보여요.
- **반응이 조금 늦어요** → 기본 엔진은 0.3~0.8초 늦을 수 있어요. 여러 반이 동시에 하면 더 늦어질 수 있으니 운영자에게 [부하 시험]이나 Node 서버를 부탁하세요.
- **새로 고침하면?** → 같은 자리로 돌아와요(경기 중이면 판과 점수가 그대로).
- **한 학생이 두 창을 열면?** → 내장 엔진에서는 둘 다 같은 학생으로 움직여요. 한 창만 쓰도록 안내해 주세요.
