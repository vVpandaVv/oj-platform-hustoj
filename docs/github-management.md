## 업데이트 기록 작성

GitHub 갱신마다 [CHANGELOG.md](../CHANGELOG.md)를 함께 갱신합니다.

1. 이전 공개본과 이번에 올릴 소스·ZIP을 비교합니다.
2. 한국 시간 기준 날짜, 변경된 플러그인의 이전·새 버전, 주요 변경 사항을 기록합니다. 신규 플러그인은 최초 공개 버전을 표시합니다.
3. 배포 ZIP·체크섬 링크와 수행한 검증 결과를 덧붙입니다. 문서나 설치 도구만 바뀐 경우에도 변경 내용을 기록합니다.
4. 기존 기록을 보존하고 최신 항목을 위에 추가합니다. 같은 날 여러 번 갱신하면 시간이나 순번으로 구분합니다.
5. README·ZIP 목록의 기록 링크를 유지하고, 업로드 후 GitHub에서 코드·ZIP·기록이 함께 반영됐는지 확인합니다.
