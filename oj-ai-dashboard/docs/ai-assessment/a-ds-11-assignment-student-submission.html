  • 학생 화면은 site timezone의 절대 시각을 우선 표시하고 상대 문구는 보조로만 쓴다.

마감 자동 제출·미시작 학생

자동 제출은 공개 REST가 아니라 애드온 내부 AutoSubmitDueAssignments Application command다. A-DS-07의 60초 trigger adapter를 공유하되 AI 평가 run table·AI Gateway·OJ Platform 작업 배정 기능은 사용하지 않는다. close·manual close transaction이 oj_ai_outbox_events에 assignment별 assignment.auto_submit_due를 넣고, worker는 outbox의 lease·attempt·error·idempotency를 정본으로 사용한다.

  1. 60초 주기의 애드온 trigger가 close transaction이 만든 due outbox를 깨운다. 누락된 close event는 closes_at_utc <= server_now와 auto_submit_completed_at_utc IS NULL 대조로 보상 생성하며 worker는 assignment별 outbox 한 건을 lease한다.
  2. target snapshot 전원을 대조해 draft|conflict|reopened이면서 유효한 current revision이 있는 학생만 처리한다.
  3. conflict는 자동 병합하지 않는다. 마지막으로 서버에 정상 저장된 revision만 정책이 허용할 때 official로 승격하고 receipt에 auto_submit을 기록한다.
  4. 한 번도 시작하지 않은 학생은 submission root나 빈 답안을 만들지 않는다. target row에서 not_started로 계산해 교사 모니터링에 미제출로 표시한다.
  5. pending·rejected 첨부, invalid response schema, current revision 없음은 자동 제출 실패 항목으로 기록하고 교사 해결 작업에 남긴다.
  6. WP-Cron 지연 뒤 실행되어도 effective close와 schedule hash로 판정하며 재실행은 같은 receipt를 반환한다.
즉시 차단과 작업 지연 분리: close 시각부터 학생 명령은 동기적으로 즉시 거부한다. 자동 제출 receipt 생성은 worker가 최대 60초 늦을 수 있지만 학생이 그 사이 새 revision을 저장할 수는 없다.

보안·개인정보·권한 재검사

  • Q30은 현재 actor의 target row만 반환하고 다른 학생 public ID·제출 상태·명단을 노출하지 않는다.
  • Q31·C22~C26은 capability, self Context, active target, learner ID=actor, assignment schedule, object ownership을 매번 재검사한다.
  • 교사가 담당에서 해제되거나 학생이 탈퇴하면 snapshot이 남아 있어도 현재 접근은 거부한다. 보존·분쟁 처리는 별도 권한으로 한다.
  • student document는 allowlist로 새 tree를 만들고 모든 깊이에서 correct_answer, grading, rubric, teacher_note 0건을 검증한다.
  • private file은 public URL·절대 경로를 저장·반환하지 않고 Q24 또는 owner-aware stream query에서 현재 원본 Policy를 재검사한다.
  • ZIP preview는 target learner와 upload response만 반환하고 email·login·원본 path를 숨긴다. C20은 현재 교사 Context와 기존 official pointer를 item마다 다시 검사한다.
  • 파일명은 표시용이며 경로에 사용하지 않는다. MIME·byte·hash·scan·owner·response ID를 모두 확인한다.
  • submission·receipt·audit에는 provider secret·AI routing·플랫폼 내부 table key를 저장하지 않는다.
  • rate limit은 actor·submission·operation 조합으로 적용하고 제출·PDF에는 안정 idempotency key를 요구한다.
