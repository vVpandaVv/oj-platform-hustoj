A-DS-03 · Access Policy and Object Scope

권한·역할·객체 범위 정책

AI 평가 애드온의 기능 권한을 정확히 15개 capability로 선언하고, 플랫폼의 역할·사용자 배정과 학급·그룹 Context, 애드온의 활동지·배포·제출·평가 객체를 하나의 복합 Policy로 연결한다. 메뉴, 직접 주소, REST, PDF와 백그라운드 작업은 같은 판정 결과를 사용한다.

한 줄 결론

허용 조건은 capability + platform context + add-on object + state다. capability는 할 수 있는 일의 종류만 정하고, 플랫폼 Context는 어느 학급·그룹을 담당하는지, 애드온 객체는 어느 활동지·배포·제출·평가에 연결되는지, state는 지금 그 작업을 수행할 수 있는지를 정한다.

Fail closed: 네 요소 중 하나라도 없거나 최신 상태를 확인할 수 없으면 거부한다. 메뉴가 보이거나 URL·파일 ID·Job ID를 알고 있다는 사실은 접근 권한이 아니다.

복합 Policy 판정 순서

요청
  1. 애드온 accepted·enabled, 기능 준비 상태
  2. active 로그인 사용자와 요청 무결성
  3. 화면 gate
     Console = oj_access_console + oj_ai_dashboard_view_workspace
     Public  = oj_ai_dashboard_participate
  4. 명령별 애드온 capability
  5. 플랫폼 Context authorize + expected revision
  6. 애드온 객체 관계 + 현재 revision
  7. 객체 상태·전이·멱등 조건
  8. 허용된 데이터 projection만 반환
규칙고정 내용
기능 권한Manifest에 선언된 key만 검사한다. audience는 권한 부여가 아니라 플랫폼 관리 화면의 분류 metadata다.
Console gate모든 C01~C06 Route는 core oj_access_console과 oj_ai_dashboard_view_workspace를 모두 요구한다. 화면 안 데이터와 명령은 추가 capability를 다시 검사한다.
Public gate모든 P01~P03 Route는 active 로그인과 oj_ai_dashboard_participate를 요구한다. 목록·상세는 본인 배정·제출·공개 결과로 다시 제한한다.
관리자 정책슈퍼 관리자·manage_options의 전역 우회 여부는 플랫폼 CF-1 정본이 결정한다. 애드온은 별도 관리자 우회를 만들지 않고 Context Gateway 결과를 그대로 따른다.
목록 쿼리허용된 Context·객체 ID를 query 조건에 먼저 적용한다. 전체 행을 읽은 뒤 PHP에서 숨기지 않는다.
공통 서비스메뉴 resolver, Page Handler, REST permission callback, file controller와 Job Handler가 같은 Policy service와 reason code를 사용한다.
불확실성Gateway 누락·예외·stale revision·알 수 없는 key·지원하지 않는 state는 모두 deny다.

진입점동일성 규칙
OJ Console 메뉴oj_access_console과 view_workspace를 통과할 때만 “AI 활동지”를 표시한다. C01~C06 탭은 추가 capability가 있는 업무만 표시한다.
PublicUI 메뉴active 로그인·participate를 통과하면 “학습 > 활동지”를 표시하며 배정이 없으면 짧은 빈 상태를 보여 준다.
직접 URL·새로고침메뉴 표시 여부와 무관하게 Route와 객체 Policy를 처음부터 다시 검사한다. 메뉴를 숨겨도 승인된 direct assignment URL은 유지된다.
RESTPage와 같은 actor·capability·Context·객체·state Policy를 호출하고 브라우저 cookie 인증은 표준 wp_rest nonce 하나만 사용한다.
파일·Job 상태생성자 또는 ID 일치만으로 허용하지 않고 현재 요청 시점의 원본 객체 Policy를 다시 검사한다.

플랫폼 학사 Context 정책

애드온은 학년·학급·그룹·학생 원장을 만들지 않는다. 배포 대상 선택은 listTeachingContexts를 types=['class','group']로 호출하며, v1에서 선택 가능한 대상 type은 class|group 두 가지다.

Context typev1 사용규칙
