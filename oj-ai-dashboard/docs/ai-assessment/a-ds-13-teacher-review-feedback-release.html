교사 검토·피드백·학생 공개

교사가 AI 점수 후보를 기준별로 확인해 공식 결과를 만들고, 학생에게 보여 줄 피드백을 별도로 작성·승인한 뒤 정확한 공개본을 배포한다. AI 결과는 어느 단계에서도 자동으로 공식 점수나 학생 공개본이 되지 않는다.

교사 업무 흐름

1 · 검토할 결과 선택
학생 답변·AI 제안·근거·직접 확인 항목을 한 화면에서 비교
2 · 결과 확정
기준별 점수를 수용하거나 조정하고 사유를 남겨 공식 review 생성
3 · 피드백 준비
직접 작성하거나 AI 초안을 받아 교사가 수정·승인
4 · 학생에게 공개
보여 줄 점수·기준별 결과·피드백을 선택해 불변 공개본 생성
5 · 정정 또는 회수
새 공식 review와 공개 revision을 만들고 이전 이력을 보존
작업함 정렬: 안전 차단, abstain, 마감 경과, 낮은 confidence, 오래 대기 순으로 우선 표시한다. confidence는 정렬에만 쓰며 점수나 승인 여부를 자동 변경하지 않는다.

  • 미해결 safety flag는 공식 결과와 공개를 차단한다. 해결 여부와 조치 기록은 review payload에 남긴다.
  • 새 review는 과거 review·result·item을 갱신하지 않고 previous_review_id로 연결한다.
G4-IMP-03-S02 구현 반영: S02에서 S01의 exact 점수·안전 검증을 유지하면서 불변 review append, 기존 공개본 stale revision, evaluation·submission 두 root CAS, audit·outbox를 한 transaction으로 결합하고 C34 REST를 활성화했다. stale 사유는 official_review_changed이며 반려 review는 공식 review와 current release pointer를 바꾸지 않는다.
G4-IMP-03-S03 구현 반영: S03 점수·근거 검토 UI에서 OJ Console 평가 화면에 학생 제출 탭을 통합하고 Q16·Q17·C34를 연결했다. 학생 답변·근거·점수를 한 화면에서 비교하며, 안전 항목은 AI 점수 직접 승인을 막고 항목별 교사 판단을 요구한다. Q17의 additive review_precondition은 화면에 표시하지 않고 C34 expected에만 전달한다.
G4-IMP-03-S04 구현 반영: S04에서 result·공식 review pointer·current release와 evaluation·submission 두 root CAS 경합을 실제 transaction fixture로 재현했다. stale 요청은 review_source_stale로 rollback하고 review·item·release·audit·outbox 이력을 바꾸지 않는다. OJ Console은 409 뒤 최신 상태를 다시 읽고, 403 권한 회수 뒤 점수 입력과 변경 제어를 즉시 제거한다.
G4-IMP-04-S01 구현 반영: C35 피드백 초안은 현재 공식 review와 점수만 학생용 안전 입력으로 구성하고 strict 학생 피드백 출력만 허용한다. worker는 source·정책·동의·routing을 실행 전후 재검사하며, source가 그대로일 때만 oj_ai_submission_feedback_revisions에 불변 ai_draft를 추가한다. 교사 검토·승인 전에는 학생에게 보이지 않는다.
G4-IMP-04-S02 구현 반영: C36 교사 피드백 검토는 교사의 직접 작성, AI 초안 수정, 기각을 지원한다. 공식 review와 직전 feedback의 ID·hash·revision no를 exact source로 고정하고, transaction CAS를 통과할 때만 teacher_draft|rejected 불변 revision을 추가한다. exact replay는 같은 결과를 돌려주며 승인 전 학생 공개는 0건이다.
G4-IMP-04-S03 구현 반영: C37 피드백 승인은 최신 teacher_draft의 exact ID·content hash·revision no와 현재 공식 review를 잠근다. 요청 payload는 빈 객체이며 서버가 저장 profile을 다시 검증해 같은 JSON·hash·AI provenance를 새 approved revision으로 복제한다. 승인만으로 학생 공개본은 생성하지 않는다.
G4-IMP-04-S04 구현 반영: 피드백 작업대·통합 동결에서 기존 OJ Console 학생 제출 평가 상세에 Q17과 C35~C37을 연결했다. 공식 review 전에는 작성을 막고, AI 초안·교사 수정·기각·승인을 상태별로 제한한다. 409는 최신 상세 재조회, 403은 점수·피드백 제어 제거로 복구하며 approved는 “학생 공개 전” 읽기 전용 상태로 표시한다.
