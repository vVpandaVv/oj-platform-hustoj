A-DS-02 · Amendment AM-01 · Consumer Adoption

onReady() 적용 계획

OJ Platform의 보안 개정 AM-01을 AI 평가 애드온 소비자 계약에 반영한다. 전역 oj_platform_loaded와 조회형 AddonRuntimeGatewayV1::forAddon()을 폐기하고, Manifest builder 안에서 등록한 애드온 전용 onReady() callback으로만 Runtime Context를 받는다.

재확인일 2026-08-12 사용자 확정 2026-08-12 플랫폼 C28-I01~I05 구현 확인 플랫폼 계약 테스트 4종 통과 상태 사용자 확인·동결 C28-I06 G0 구현 완료 검증 릴리스 증거 기록clean package·G1 인수 대기 애드온 Runtime 변경 0건

한 줄 결론

oj_platform_register_addons action 하나만 구독하고, 그 callback의 $gateway->register('oj-ai-dashboard', ...) builder 안에서 Manifest 기여와 $addon->onReady(...)를 함께 선언한다. 승인된 Manifest만 자기 전용 AddonRuntimeContextV1을 받으며 공개 호출 보장은 최대 한 번이다.

현재 적용 시점: 이 문서의 AM-01 소비자 보정은 그대로 유효하며 플랫폼은 2.0.0-dev.33·Addon API 1.1.0으로 준비됐다. 검증 G0 릴리스 증거는 기록했다. 제공자 문서 commit과 clean production package 뒤 애드온의 Admin_Module 구형 연결을 G1에서 onReady() 기반 Bridge로 교체하며, 설치 과정에서 플랫폼 파일을 수정하지 않는다.

제공자 정본은 플랫폼의 계약 개정 기록 AM-01이고, 실제 전환 절차는 onReady 전환 안내서를 따른다.

변경 이유와 경계

이전 전역 Gateway는 모든 애드온 callback에 같은 객체를 전달하고 호출자가 임의 addon ID를 forAddon()에 넣을 수 있었다. 따라서 한 애드온이 다른 애드온의 Context·AI Task Gateway를 받는 impersonation 경로가 API 자체에 존재했다.

보안 결론: 구형 훅을 호환 fallback으로 남기지 않는다. 새 플랫폼에서 호출되지 않는 죽은 코드일 뿐 아니라, 다시 제공하면 격리 결함을 재도입한다. 전환은 병행 지원이 아니라 완전 교체다.

AM-01 당시에는 Console Page 6개, Public Page 3개, Menu 2개, Asset Bundle 4개, AI Task 2개와 A-DS-03 capability 집합을 변경하지 않았다. 이후 G5-IMP-05-S04에서 설정 전용 bundle을 분리해 현재 Asset Bundle은 5개가 됐고, 2026-08-28에는 이미 확정된 다섯 Console Page를 기존 Menu DTO로 직접 노출해 현재 Menu는 Console 5개·Public 1개다. AddonRuntimeContextV1 계약과 플랫폼 API는 바뀌지 않았다.

현행 소비자 계약

use CodingPanda\OjPlatform\AddonApi\V1\AddonManifestBuilderV1;
use CodingPanda\OjPlatform\AddonApi\V1\AddonRegistrationGatewayV1;
use CodingPanda\OjPlatform\AddonApi\V1\AddonRuntimeContextV1;

add_action('oj_platform_register_addons', static function (
    AddonRegistrationGatewayV1 $gateway
): void {
    $gateway->register('oj-ai-dashboard', static function (
        AddonManifestBuilderV1 $addon
    ): void {
        $addon->manifest(/* A-DS-02 고정 manifest */);
        // capability(), consolePage(), publicPage(), menu(), assetBundle(), aiTask()

        $addon->onReady(static function (AddonRuntimeContextV1 $runtime): void {
            if ($runtime->snapshot()->status() !== 'accepted') {
                return;
            }

            Addon_Runtime_Bridge::connect($runtime);
        });
    });
}, 10, 1);
