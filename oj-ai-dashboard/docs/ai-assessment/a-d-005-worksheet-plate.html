A-D-005 · Worksheet and Plate Baseline

활동지와 Plate 문서

현재 Plate 편집기의 실제 plugin 구성, 응답 node, 브라우저·PHP 직렬화, 교사용·학생용·채점용 schema, 배정 이후 공개 문서, 제출 payload와 import·export·PDF 흐름을 코드에서 역추적했다. Plate 채택 자체를 바꾸는 문서가 아니라 활동지 도메인에 맞는 제한된 편집기와 불변 발행 snapshot을 설계하기 위한 기준선이다.

조사일 2026-08-10 상태 사용자 확인·기준선 확정 EditorKit 구성 36개 응답 유형 10개 문서 schema version 1 PDF 산출물 2계열 JS 21,703,513 byte CSS 1,842,293 byte 실행 코드 변경 0건

한 줄 판정

Plate는 구조화 활동지 제작 기반으로 적합하지만, 현재 구현은 Plate의 whole-editor 예제를 거의 그대로 포함한 범용 편집기다. mutable template를 학생 배정과 채점이 계속 다시 읽고, 학생 문서는 알려진 교사용 key만 지우는 denylist로 만들며, 브라우저·PHP·학생 renderer가 서로 다른 node 계약을 사용한다. 따라서 지금의 version: 1 JSON을 발행 계약으로 확정할 수 없다.

활동지 자체 평가: AI가 평가할 대상은 학생 답안이 아니라 특정 immutable worksheet revision의 본문, 응답 구조, 정답·예시답안, 배점·루브릭, 교육과정 연결과 대상 맥락이다. 학생 제출 평가는 별도의 published grading snapshot과 submission revision을 입력으로 사용해야 한다.

현재 schema포함현재 격차
teacher_schema
engine: plate		raw plate_value, 전체 질문, 정답·배점·rubric·교사 메모, 교육과정hidden_from_student는 설명 배열일 뿐 자동 projection 계약이 아님
student_schema
engine: plate_student		제목·교육과정 link·정답을 제거한 질문과 answer schema학생 본문 Plate tree가 없고 별도 assignment service가 live teacher raw를 다시 정리
grading_schema
engine: plate_grading		문항별 정답·예시답안·배점·rubric·교사 메모·교육과정발행 시점에 고정되지 않고 제출 revision 저장 때 live template에서 다시 생성

편집기에서 template를 읽을 때 plate_value가 있으면 브라우저 schema를 새로 만들면서 server가 준 worksheet_rubric, curriculum_links, settings를 버린다. 다음 저장 payload는 이 값을 빈 배열·객체로 보내므로 일반 UI 저장만으로 관련 metadata가 지워질 수 있다.

목표 원칙: teacher·student·grading은 각각 독립적으로 편집하는 세 원문이 아니다. 검증된 canonical worksheet revision 한 개에서 동일 projector version으로 파생하고, 발행 때 세 산출물의 schema ID·version·hash를 함께 고정한다.

활동지·학생 작성 결과물 PDF 다운로드

확정 요구: 활동지와 학생 작성 결과물은 PDF로 내려받을 수 있어야 한다. PDF는 편집·평가의 원본이나 import 형식이 아니라 특정 불변 snapshot에서 생성한 파생 산출물이며, JSON 활동지 package 내보내기와 별도 명령으로 제공한다.

확정한 목표 결정

  1. Plate를 활동지 제작 엔진으로 유지하되 whole-editor를 그대로 사용하지 않고, 승인된 node·mark·command만 가진 WorksheetEditorProfile과 10개 versioned response field를 별도 구성한다.
  2. 활동지는 working draft, immutable revision, immutable published snapshot을 분리한다. assignment와 submission은 template 최신본이 아니라 발행 snapshot·response schema version을 고정 참조한다.
  3. student document·student response schema·grading schema·worksheet evaluation input은 canonical revision에서 allowlist projector로 생성하고 version·hash·leak 검사를 기록한다.
  4. 활동지 자체 평가는 특정 worksheet revision 전체를 독립 subject로 평가한다. 학생 제출 평가는 published grading snapshot과 특정 submission revision만 평가한다.
  5. Plate AI mock·Faker fallback·fake 협업·UploadThing mock·외부 avatar·범용 export CDN을 활동지 bundle에서 제거한다. AI는 플랫폼 task gateway, asset은 애드온 private file command만 사용한다.
  6. raw source 쓰기를 운영 UI에서 제거하고 server validation을 유일한 신뢰 경계로 둔다. stable ID, schema upcaster, document limit, import package checksum과 renderer parity test를 발행 관문에 포함한다.
  7. 활동지와 학생 작성 결과물은 PDF로 내려받을 수 있게 한다. 학생 배포용·교사용·제출 결과물 print profile을 분리하고 정확한 worksheet snapshot·submission revision에서 private export artifact를 생성한다.
  8. 학생 제출은 client content를 직접 저장하지 않고 published response schema로 항상 정규화한다. required·type·허용 값·길이·table·attachment 정책을 제출 전에 검증한다.
