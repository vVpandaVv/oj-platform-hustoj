A-DS-02 · Addon API v1 Consumer Profile

Addon API v1 소비자 프로필

AI 평가 애드온이 OJ Platform의 내부 Container나 Registry를 조회하지 않고 Console·PublicUI·권한·학습 Context·AI 작업을 사용하는 정확한 연결 계약을 고정한다. 이 문서는 소비자 프로필이며 공개 API의 제공자 정본은 플랫폼 C-28이다.

정의일 2026-08-10 API 표면 정의 완료 A-DS-02 사용자 확인·동결 AM-01 사용자 확인·동결 Addon API 1.1.0 C28-I01~I06 · AM-01·AM-02 구현 확인 검증 릴리스 증거 기록clean package·G1 인수 대기 애드온 Runtime 변경 0건

Manifest 등록 형태

public static function register(AddonRegistrationGatewayV1 $gateway): void
{
    $gateway->register('oj-ai-dashboard', static function (AddonManifestBuilderV1 $addon): void {
        $addon->manifest(
            namespace: 'oj_ai_dashboard',
            version: OJ_AI_DASHBOARD_VERSION,
            pluginFile: OJ_AI_DASHBOARD_FILE,
            requiresPlatform: '>=2.0.0-dev.33 <3.0.0',
            requiresAddonApi: '>=1.1.0 <2.0.0',
            diagnosticLabel: 'AI 평가 애드온',
            supportReference: 'oj-ai-dashboard/addon-api-v1'
        );

        $addon->capability(new AddonCapabilityDefinitionV1(
            key: '@A_DS03_CAPABILITY_KEY@',
            label: '@A_DS03_CAPABILITY_LABEL@',
            audience: '@A_DS03_AUDIENCE@'
        ));

        $addon->consolePage(new AddonConsolePageDefinitionV1(
            key: 'addon.oj_ai_dashboard.console.worksheets',
            path: '/oj-console/addons/oj-ai-dashboard/worksheets',
            handler: new WorksheetListPageHandler(),
            capability: '@A_DS03_WORKSHEET_VIEW@',
            assetBundles: ['addon.oj_ai_dashboard.asset.console']
        ));

        $addon->onReady(static function (AddonRuntimeContextV1 $runtime): void {
            if ($runtime->snapshot()->status() === 'accepted') {
                Addon_Runtime_Bridge::connect($runtime);
            }
        });
    });
}
남은 치환 토큰: 플랫폼 최솟값은 2.0.0-dev.33, Addon API 범위는 >=1.1.0 <2.0.0으로 확정했다. @A_DS03_* capability 토큰만 G1 package 작성 전에 실제 key로 치환하며 토큰이 남은 package는 배포하지 않는다.

Runtime 연결

$addon->onReady(static function (AddonRuntimeContextV1 $runtime): void {
    $snapshot = $runtime->snapshot();

    if ($snapshot->status() !== 'accepted') {
        return;
    }

    Addon_Runtime_Bridge::connect($runtime);
});
메서드·시점결과애드온 규칙
onReady(AddonRuntimeContextV1)이 애드온 전용 Runtime Contextbuilder당 정확히 한 번 등록하고 addon ID 조회·저장 없음
snapshot()버전·상태·catalog revision·기여 수량·안전한 진단accepted 확인 뒤에만 Bridge ready 전이
contexts()AddonContextGatewayV1이며 learning·roster 확장 interface도 구현플랫폼 학사 원장을 수정하지 않고 공개 Gateway만 사용
aiTasks()AddonAiTaskGatewayV1provider profile·model·비밀값을 받지 않음
미승인 Manifest: rejected·incompatible·disabled 상태에는 callback이 호출되지 않는다. 해당 진단은 플랫폼 운영자용 애드온 상태 화면이 소유하며 애드온은 Registry나 DB를 우회 조회하지 않는다.

AI 작업 사용

메서드입력·출력실패 처리
canRoute(taskKey)배정 가능 여부·안전한 code·routing revision불가하면 평가 요청 생성 전 차단
snapshot(taskKey)provider key·model key·profile fingerprint·routing revision, 비밀값 제외실행 이력에 snapshot 보존

sourceKind와 instruction: 활동지 자체 평가는 sourceKind=none, 학생 제출 평가는 sourceKind=addon_payload다. 각 task의 불변 AddonAiTaskInstructionV1은 catalog·routing fingerprint에 포함되고 플랫폼 system prompt 다음, 사용자 payload 앞에 적용된다. 플랫폼은 애드온 테이블을 직접 조회하지 않는다.

G2-IMP-05-S04에서 활동지 task 표시 이름과 worksheet_quality.v1은 유지하고 Manifest instruction을 worksheet_quality_prompt.v2, 2,607 bytes, SHA-256 5499f44428a9e504e045fb6035c6d650bef8601a8421567095063a231e5db2cd로 올렸다. v1 985 bytes와 hash는 과거 불변 증거로 보존한다.
