A-DS-06 · Platform Ledger Connector Contract

플랫폼 원장 Connector

사용자·학급·그룹·담당 관계는 OJ Platform 공개 Context API로만 조회하고 인가한다. 애드온은 플랫폼 내부 service·Container·table·Judge DB를 직접 읽지 않으며, stable Context ID와 최소 snapshot만 자기 데이터에 보존한다.

한 줄 결론

정상 경로는 AddonManifestBuilderV1::onReady()가 전달한 AddonRuntimeContextV1::contexts() 하나뿐이다. 2.0.0-dev.33·Addon API 1.1.0은 교사 Context, 학생 자기 참여·학습 Context 목록과 exact assignment roster를 공개 Gateway로 제공한다. G1 애드온은 이 계약만 소비하고 로컬 학사 master나 플랫폼 내부 저장소를 만들지 않는다.

우회 금지: 이 공백을 Oj_Table_Resolver, $wpdb, 플랫폼 내부 Repository, WordPress filter, 로컬 학사 master 또는 전체 assignment를 읽고 PHP에서 숨기는 방식으로 메우지 않는다.

CG11 배정 명단 snapshot 확정 계약

교사가 class·group 전체에 배포할 때 개별 학생을 반복 검증하는 방식만으로는 누락 없는 대상 집합을 증명할 수 없다. 플랫폼이 배정 목적으로만 현재 활성 학생 ID와 membership revision을 bounded page로 제공하고, 첫 page의 roster revision을 나머지 page가 고정해야 한다.
