확정된 최종 현황 결정

  1. A-D-001~008의 사용자 확정 사실과 이 문서의 수량 검산을 AI 평가 애드온의 현재 상태 기준선으로 사용한다. 발견 격차는 131행이며 동일 기준으로 Critical 36·High 79·Medium 16, 미분류 0행이다.
  2. HTML 설계 원본, 플랫폼 patch 금지, oj_ai_* 무접두어, Plate 구조화 문서 개념, 활동지·제출·평가·검토·출력 도메인 의미와 기존 사용자 데이터는 유지한다.
  3. 현재 module 조립, Admin/Platform 연결, 권한·scope, 중앙 schema, mutable Worksheet, 제출·첨부, AI fallback, browser batch, 검토·공개, Reporting SQL, Import direct write와 문자열 중심 test는 목표 Contract에 맞춰 교체한다.
  4. standalone·wp-admin fallback·shortcode·OJ DB resolver·로컬 Academic 원장·중복 역할/AI 설정·가짜 AI·외부 예제·public export 등은 목표 표면에서 퇴출하되 A-DS-15의 사용 현황·backup·preview·rollback·sunset 승인 전에는 삭제하지 않는다.
  5. OJ Platform C-28 공개 애드온 API는 별도 플랫폼 릴리스의 선행 조건이다. 애드온 개발·설치·업데이트·runtime은 이를 만들기 위해 플랫폼 파일·migration·Container·DB를 패치하거나 직접 조회하지 않는다.
