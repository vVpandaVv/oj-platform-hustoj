활동지 자체 AI 평가

학생 제출물이 아니라 저장된 활동지 revision 전체를 AI가 점검한다. 학습목표, 설명, 답변 가능성, 난이도, 루브릭과 안전성을 원문 근거와 함께 진단하고, 교사가 결과를 판단한 뒤에만 승인·발행 흐름이 이어진다.

WorksheetEvaluationNormalizer

  1. Gateway success/problem 불변식과 task·contract·correlation·routing snapshot을 확인한다.
  2. 출력 canonical byte·depth·item·text 상한을 검사하고 unknown top-level·nested key를 거부한다.
  3. schema·source hash·enum·finite number와 차원 집합의 누락·중복을 검사한다.
  4. 모든 evidence anchor가 P04에 있고 quote가 해당 정규화 text의 실제 substring인지 확인한다.
  5. finding을 severity·dimension·anchor·문구 순으로 결정 정렬하고 canonical digest에서 finding_key를 계산한다.
  6. safety_flagged, abstained, 전체 confidence와 ready|needs_attention|action_required|safety_review|not_assessable를 서버가 계산한다.
  7. A-DS-07의 fresh postflight routing snapshot과 lease·source·권한을 다시 확인한 뒤에만 immutable result·item을 원자 commit한다.
실패를 진단으로 바꾸지 않음: schema 오류, unknown anchor, oversize, routing drift와 provider 실패는 “문제 없음”이나 낮은 점수로 저장하지 않는다. 공식 result 없이 실행 실패로 닫고 교사가 원인을 확인하게 한다.
