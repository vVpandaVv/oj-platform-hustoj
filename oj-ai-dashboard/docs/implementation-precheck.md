# OJ AI Dashboard 구현 전 확인 체크리스트

문서 상태: 확정  
작성일: 2026-06-13  
대상 단계: 2단계 진입 전 확인

## 1. 목적

이 문서는 `docs/development-procedure.md`의 1단계 완료 조건 중 "남은 구현 전 확인 항목을 별도 이슈 또는 체크리스트로 분리한다"를 충족하기 위한 체크리스트다.

아래 항목은 설계 변경이 필요한 미결정 사항이 아니라, 구현 전에 실제 OJ 플랫폼 구조를 확인해야 하는 항목이다.

## 2. OJ 연결 확인

| ID | 확인 항목 | 확인 방법 | 완료 기준 | 상태 |
|---|---|---|---|---|
| PRE-001 | OJ 메뉴 hook | OJ 플랫폼 관리자 메뉴 등록 코드 확인 | 교사용 대시보드를 붙일 hook 또는 fallback 위치 확정 | 대기 |
| PRE-002 | OJ 사용자 매핑 | WordPress 사용자와 OJ 사용자를 연결하는 필드/테이블 확인 | `wp_user_id`와 OJ 사용자 key 매핑 방식 확정 | 대기 |
| PRE-003 | OJ 그룹 구조 | OJ 그룹/학급 테이블 또는 repository 확인 | 학년도, 학년, 반이 필드인지 그룹명 파싱 대상인지 확정 | 대기 |
| PRE-004 | OJ 문제 정보 | OJ 문제 repository 또는 테이블 확인 | 문제 ID, 제목, 링크 생성에 필요한 읽기 인터페이스 확정 | 대기 |
| PRE-005 | OJ 제출 기록 | OJ 제출/채점 결과 repository 또는 테이블 확인 | 제출 ID, 사용자, 문제, 결과, 언어, 시간 필드 확정 | 대기 |

## 3. 구현 정책 확정 상태

아래 항목은 이미 확정된 정책이다. 구현 중 다시 설계 결정으로 되돌리지 않는다.

| 항목 | 확정 내용 |
|---|---|
| 플러그인 폴더 | `oj-ai-dashboard` |
| 기본 namespace | `OJAI\Dashboard` |
| 루브릭 | 활동지 전체 또는 문항별 중 하나만 선택 |
| 입력 블록별 루브릭 | 지원하지 않음 |
| 성취기준 | 채점이 아니라 특기사항 생성 컨텍스트로 사용 |
| 피드백 공개 | 교사 승인 후 공개 |
| 재채점 변경 | `change_pending` 상태로 검토 후 반영/거부 |
| ZIP 매칭 우선순위 | 로그인 ID, 번호+이름, 번호, 이름 |
| 학생 명단 필수 컬럼 | 학년도, 학년, 반, 번호, 이름 |
| 화면 문구 | 개발자 설명 문구와 교사용 긴 안내 문구 금지 |
| Plate 통합 | 기존 Plate 편집기 구조를 통째로 가져와 확장 |

## 4. 2단계 진입 조건

2단계 "플러그인 기본 뼈대 생성"에 들어가기 전에 아래를 확인한다.

- 요구 분석서가 최신 상태다.
- 설계서가 최신 상태다.
- 개발 절차 문서가 최신 상태다.
- 개발 하네스가 통과한다.
- 화면 문구 정책이 요구 분석서와 설계서에 반영되어 있다.
- Plate 전체 편집기 통합 원칙이 요구 분석서, 설계서, 하네스에 반영되어 있다.
- OJ 내부 구조 확인 항목은 이 문서에서 추적한다.
