# 변경 이력

## 1.0.5 — 2026-10-26

- 플랫폼이 선택 조회를 지원하면 공개 문제 변경 확인과 제출 조회를 분리합니다. 초안 자동 저장은 제출 목록·전체 개수·소스를 조회하지 않으며 본인 최신 제출 확인은 한 건만 읽습니다. 이전 플랫폼에서는 기존 공개 API를 사용합니다.
- 채점 결과가 바뀌지 않으면 자동 확인 간격을 늘리고, 권한 회수 재검증에서 전체 WordPress 옵션 캐시를 비우지 않습니다.
- 실패한 스키마 갱신은 잠금과 60초 재시도 간격을 적용해 일반 페이지·제출 요청마다 테이블 검사를 반복하지 않습니다.

## 1.0.4 — 2026-10-25

- 제작 단계의 저장된 초안과 수업 언어를 기존 OJ 제출 화면에 자동으로 채웁니다. 학생은 코드를 복사하지 않고 확인한 뒤 직접 제출합니다.
- 준비 중 저장 경합을 막고, 팝업 차단 대체 링크에도 같은 초안을 전달합니다. 전달 링크는 본인·문제·수업에 묶이며 짧은 시간만 사용할 수 있습니다.
- 기존 제출 결과 자동 연결과 초안·응답 보존을 유지하며 코드 원문을 URL이나 AI로 보내지 않습니다.

## 1.0.3 — 2026-10-25

- 제작 단계의 제출번호 입력을 없애고, 기존 OJ 제출 화면에서 돌아오면 본인의 새 제출을 자동 연결하고 채점 결과를 갱신합니다.
- 이전 제출은 학생이 명시적으로 선택할 때만 사용합니다. 연결된 제출을 고정 조회하며 현재 초안과 제출 코드가 다른 경우 안내합니다.
- 결과를 조회하는 동안 초안·응답·최초 예측을 보존하며, 기존 OJ의 제출 권한과 결과 공개 정책을 유지합니다.

## 1.0.2 — 2026-10-25

- OJ 검증 여부와 생성 출처를 분리해 기본 예제를 AI 생성으로 표시하지 않도록 수정했습니다. 기존 활동의 출처도 생성 원장과 부모 버전에서 복원합니다.
- AI 초안의 구조·도움 조각이 일치하지 않으면 호출 한도에 포함되는 한 차례 복구를 거친 뒤 전체 검증을 다시 수행합니다. 복구되지 않은 자료는 배포하지 않습니다.

## 1.0.1 — 2026-10-25

- 실제 사이트 인수 검증에서 확인한 기본 예제의 검토 요구 소실을 수정했습니다. 편집·부분 재생성·재검증에서도 서버가 템플릿 출처를 보존하며 검토 전에 자동 공개하지 않습니다.
- 기존 1.0.0 자료도 생성 작업과 부모 버전에서 템플릿 출처를 확인합니다. 전체 AI 재생성은 새 자료의 품질 검사를 적용합니다.

## 1.0.0 — 2026-10-25

- 학급별 언어·수준·선수 개념·시간·도움 방식과 문제 저장·배정 후 자동 준비, 검증 통과 후 자동 공개를 추가했습니다.
- 오류 재시도·취소·재개·관리자 중지, 공정한 대기열과 사용량 한도, AI 요청 원장 연동을 추가했습니다.
- 수정 전후 실행을 비교하는 품질 검사, 검토 대상 표시와 AI 없는 템플릿 시작을 추가했습니다.
- 학생 Modify 코드와 배열·빈칸 완성 코드의 실제 연습 실행, 현재 코드 통과 확인을 추가했습니다.
- 교사 편집·부분 재생성·전체 재검증·자료 버전·공개·회수·학급 간 재사용을 추가했습니다.
- 미시작 학생을 포함한 전체 명단 보고서·검색·페이지 이동·CSV를 추가했습니다.
- 저장 충돌 비교·초안 복구, 완료 단계 열람, 초점·상태 안내와 개인별 연습 기록 삭제를 보완했습니다.
- OJ Platform 2.4.0 / Addon API 1.6.0을 요구합니다. 기존 수업·응답은 유지하며 전용 저장소를 스키마 3으로 갱신합니다.

## 0.3.0 — 2026-10-24

- 생성 예제와 Modify 기준 코드를 OJ로 검증하고 오류를 최대 두 번 자동 수정했습니다.

## 0.2.0 — 2026-10-24

- 공개 문제로 AI 수업 자료를 생성하고 Parsons·빈칸 도움 자료를 함께 구성했습니다.
