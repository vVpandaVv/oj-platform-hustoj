# 직접 조작 시안 v3: 채택하지 않은 이상치 방식

2026-11-16 사용자 피드백: "이상치는 떨어진 값을 바로 누르는 건 기존이랑 같은 거 아니야?"

맞는 지적이다. 이 시안의 이상치 게임은 `값 관찰 → 이상값 선택 → 점수`라는 기존 행동을 유지한다. 시간 제한, 직접 클릭, 점수 변화와 계산식 표시를 바꿨지만 게임의 핵심 행동과 재미의 구조를 새로 만든 것이 아니다. UI 개선을 게임 방식 개편으로 제시해서는 안 된다. **이상치 게임의 개편안으로 채택하지 않는다.**

이 폴더의 `quick-play-v3.js`, `quick-play-v3.html`은 비교를 위해 남긴 실험 소스다. 설치 사이트에 반영하거나 정식 게임으로 배포한 것이 아니다. 상자 출고 실험도 사용자가 채택한 최종안이 아니다.

상태 전이와 점수의 산술, 종료, 화면 폭을 확인한 테스트는 입력과 표시가 동작한다는 뜻일 뿐이다. 새로운 놀이가 생겼다거나 중학생에게 재미가 검증됐다는 뜻이 아니다.

다음 개편에서 기존 행동과 새 행동을 먼저 나란히 적고 실제로 같은지 확인한다. 명칭·시간 압박·보상·연출만 다른 경우에는 UI 개선으로만 구분한다. 긴 설명이나 다른 버튼을 덧붙이는 것으로 이 문제를 해결하지 않는다.
