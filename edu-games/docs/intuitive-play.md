# 행동으로 익히는 게임 화면

이 문서는 이전 전략/물류 게임의 개선 이력이다. 2026-09-13 이후 일곱 게임의 기본 화면은 [새 핵심 플레이](games/seven-games-play.md)로 교체했다. 아래의 조사권·별·보드 수 설명은 새 play 모드의 규칙이 아니다.

2026-09-12 화면 개선, 2026-09-13 이상치 규칙 보강. 게임 수와 보드 수는 유지한다. 이상치만 아래의 조사·채점 규칙과 시즌을 변경했으며 다른 게임 규칙은 유지한다. 기존 1.0.0 ZIP을 덮어쓰거나 운영 사이트에 배포하지 않았다.

## 공통 기준

- 첫 화면에 조작할 대상과 현재 목표가 보여야 한다.
- 설명을 읽거나 별도의 시작 버튼을 거치지 않아도 첫 행동으로 시작한다. 이상치의 첫 조사 대상 표시는 게임 시작 행동이며 확정 전에는 자유롭게 바꿀 수 있다. 조사 화면에서 단순히 다른 기록을 열거나 분류 경계를 미리 보는 것은 조사권을 쓰지 않는다.
- 행동 직후 무엇이 달라졌는지 보여주고, 잘못된 선택은 실제 자료와 근거를 통해 이해하게 한다.
- 전문 용어와 추가 설정, 전체 보드 목록, 순위가 현재 작업보다 먼저 시선을 차지하지 않게 한다.
- 재도전 목표는 기존의 자원 절약, 높은 점수, 별 수집, 새 보드 해제를 유지한다. 단순한 정답 버튼 반복으로 바꾸지 않는다.

## 이상치 탐정

처음에는 기록 6개마다 여러 버튼과 IQR을 제시했다. 이를 한 기록씩 조사하는 화면으로 바꿨지만, 기초 보드는 재측정 비용이 1이고 모든 기록에 정답 수준의 근거를 주어 동일한 행동을 반복해도 만점이었다. 따라서 화면뿐 아니라 발견 행동과 채점 규칙을 바꿨다.

현재 흐름은 다음과 같다.

1. 같은 조건의 평소 관측 범위와 현재 값을 비교해 조사 후보를 표시한다. 이때 증거와 정답 판정은 열 수 없다.
2. 조사 대상을 확정한다. 첫 선택은 이후 수정으로 지울 수 없지만, 빠뜨린 기록도 추가 조사는 가능하다.
3. 고른 기록에 필요한 현장 메모·원본·측정기 점검을 선택한다. 재측정은 제한된 보조 수단이다.
4. 사실에 따라 사용·보류·제외를 결정한다. 근거가 부족하면 판단할 수 없고, 틀렸다가 수정하면 감점이 남는다.
5. 조사하지 않은 기록은 사용 대기로 두며 모든 기록에 조사 버튼을 누르도록 강제하지 않는다. 실제 후보를 근거 없이 넘겼다면 종료 시 실패 원인을 보여준다.

95°C 기록은 원본 95°F를 변환하지 않은 오류다. 반면 41°C는 폭염 때 운동장 표면에서 실제로 측정한 값이다. 드물거나 다른 값과 멀다는 이유만으로 오류라고 확정하지 않고, 맥락을 확인하는 경험을 만든다. 확장 보드에는 확인 후에도 결론을 내릴 수 없어 보류해야 하는 기록도 있다.

서버는 구매한 근거가 충분해진 뒤에만 원인 판단 피드백을 제공한다. 첫 발견의 정답 목록과 누락·과잉 선택 개수는 종료 후에 공개한다. 평소 범위는 합성 사례의 같은 조건에 대한 비교 자료이며, 이번 여섯 값의 IQR이나 측정기 허용 범위와 혼용하지 않는다. 범위 안이라는 이유만으로 모든 오류가 없다고 단정하지 않는다.

온실은 서늘한 온실과 열대 온실을 따로 비교한다. 계수기 초기화 보드는 초기화 전후를 나누면 이상치 후보가 없는 사례다. 수치만으로 발견할 수 없는 중복 기록 보드는 장거리 걷기의 실제 극단값으로 바꿨다.

### 조사와 점수

- 사건당 조사권 18. 현장·원본·측정기 점검 각 1, 재측정 4, 처리 결정과 최종 제출 각 1.
- 재측정은 최대 2회. 서버에서 제한하며 세 번째 시도는 조사권 차감 없이 거절한다.
- 만점 1,000점에서 첫 선택의 누락·과잉 각각 100점, 필요한 조사 비용을 초과한 조사권당 20점, 잘못된 처리 결정당 50점, 정상 기록의 불필요한 보류당 30점을 뺀다. 감점 계산은 서버에서 한다.
- 잘못된 오류 처리·정상 제외·이상치 후보의 근거 없는 확정이 남으면 실패한다. 기존 성공 점수 하한과 별 기준은 유지한다.
- 첫 보드 검증 결과: 적절한 선택과 필요한 조사 1,000점, 두 후보를 모두 재측정 880점, 여섯 기록 전부 선택하고 조사 440점. 첫 선택에서 후보 하나를 빠뜨렸다가 추가 조사로 해결하면 900점.

### 이전 기록

이상치의 현재 시즌은 `outlier-2026-09-v3`다. 새 세션, 잠금 해제, 최고점·별·순위·학급 보고서에 동일한 버전을 사용한다. 구 시즌 기록은 삭제하거나 새 규칙으로 재채점하지 않고 이전 시즌 조회에 보존한다. 다른 전략 게임은 `strategy-2026-09-v2`를 유지한다. 구 규칙 세션은 새 규칙에서 이어 하지 않는다.

## 범위와 한계

이진수·문자 코드·이미지 복원·타이핑·장치 매칭·키워드 레인은 기존 직접 조작 흐름을 유지했으며 이번에 전면 개편하지 않았다. 특히 키워드 입력이 뜻의 이해로 이어지는지, 타이핑이 문법 이해로 이어지는지는 조작 편의와 별개로 살펴야 한다.

AI 모델의 A/B 합성 범주와 집계 중심 표현은 여전히 추상적이다. 후속 내용 개선에서는 실제 입력 표본과 오분류 사례를 비교하는 장면이 우선이며, 단계나 보드 수를 늘리는 것은 우선하지 않는다. 학생이 안내 없이 실제로 이해하는지에 대한 교실 관찰은 아직 수행하지 않았다.

## 확인

- `D:\php\php.exe tests/strategy.php`: 전략 보드 84개의 해결 가능성과 점수, 근거 공개 시점, 결측값 결과 대조 검증. `outlier-investigation.php`에서 이상치 12개 보드의 첫 후보, 반복 재측정·모두 선택·판단 수정 우회 방지, 무료 표시·초기 선택 고정을 확인한다.
- `STRATEGY_UX=1 node tests/browser-strategy.cjs`: 6종 첫 보드의 직접 시작·완주, 증거 피드백, 경계 미리보기, PC·모바일·터치 검사.
- `node tests/browser-warehouse.cjs`: 첫 화물로 시작, 12개 보드 완주, 기록 재시도·이어 하기·키보드·반응형 검사.
- `D:\php\php.exe -d extension=pdo_sqlite tests/v1.php`: 새 이상치 순위와 학급 보고서가 이전 시즌 기록을 제외하는지 확인한다.

브라우저 검사는 실제 렌더러·프런트엔드·PHP 규칙을 사용하는 격리된 HTTP/저장 대역이다. 운영 WordPress·DB 환경이나 학생 대상 사용성 검사를 대신하지 않는다. `STRATEGY_PREVIEW=1 node tests/browser-strategy.cjs`로 같은 격리 미리보기를 실행할 수 있으며 출력된 로컬 URL의 기록은 운영 기록과 분리된다.
