2026-11-17 코드와 전체 게임 미리보기 확인 결과입니다.

후속 [전체 플레이 경험·새 화면 제안](play-experience-proposal-2026-11-17.md)은 사용자 확인 전 후보입니다. 문자 코드의 금고 열림과 새 팀전·아이템, 다른 게임의 새 규칙은 아래 실제 적용 상태와 구분합니다. 이 표의 화면 재배치를 새 게임 방식의 구현 완료로 해석하지 않습니다.

최신 [주제 교체·암호 금고 개인/팀전](play-topic-reset-2026-11-17.md)에서는 이전 제안 6종을 철회했습니다. 정사각형 24개 금고와 시간 차등 개인전 채점 역시 검토 시안이며, 아래 운영 코드·기존 기록은 변경하지 않았습니다.

앞선 작업은 공통 프레임 개선에 그쳐 전면 개편 완료로 분류하지 않았습니다. 이번 단계에서는 실제 PHP와 게임별 JS 템플릿을 변경하고 `data-game-workspace`/`data-board-layout`의 내부 조작부 배치도 검사합니다. 화면 크기·테마·조작 회귀 검사는 배치와 기능 보존을 확인하는 것이며 학생의 흥미를 검증한 것으로 부르지 않습니다. 게임 규칙·제한시간·채점·저장 API는 변경하지 않습니다.

## 학급 검정 누락 원인

실제 플러그인의 `Code_Typing_Assets`와 애드온 등록에는 `entry.js`, `verified.js`, 각 스타일 및 학급별 평가 API가 남아 있습니다. 기존 전체 미리보기 서버는 고전 게임에 블록의 CSS·JS만 제공하고, 등록 자산 검사에서도 고전 게임을 제외했습니다. 따라서 코드 타이핑의 학급 검정 모듈이 마운트되지 않고 `평가 조회 중`만 남았습니다. 전용 타이핑 검정 미리보기는 정상이라 전체 미리보기의 누락을 기존 검사에서 발견하지 못했습니다.

전체 미리보기에도 실제 등록 자산과 검정 API를 연결하고, 교사 개설 → 학급 배정 → 학생 발견·미리보기 → 첫 입력 응시 → 교사 상태 조회를 같은 서버에서 검사합니다. 이 API는 테스트 전용 SQLite와 테스트 계정만 사용합니다. 설치 사이트의 데이터는 수정하지 않습니다.
