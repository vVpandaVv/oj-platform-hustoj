# 게임·개념 체험 분리 구현

2026-11-18. 사용자 승인으로 설계 시안에서 실제 플러그인 구현으로 전환했다. 기존 학생 기록은 삭제하거나 다른 게임 점수로 변환하지 않는다.

## 범위

- 새 `oj-concept-lab`: OJ Platform만 의존. Edu Games 설치 순서·파일에 런타임 의존하지 않는다.
- 체험 11종: 이상치 탐색, 결측값 처리, 시각화, 조건 필터링·추출, 스택·큐·우선순위 큐, 규칙 기반 분류 경계, 이진 탐색, 개인정보 공개, 네트워크 경로, RLE 압축, 멀티코어 배치.
- 기존 예제 156개는 새 플러그인의 자체 JSON으로 가져왔다. `tools/import-legacy-data.php`는 개발용 일회성 자료 생성기이며 배포·실행 의존성이 아니다.
- 새 게임 ID `cipher-vault`, `dance-bot`. 문자 코드의 이전 기록과 신규 완주 기록을 섞지 않는다. 기존 문자 코드 화면은 별도 연습 경로로 유지한다.
- 암호 금고는 24개 정사각형 개인전과 실시간 팀전. 팀전은 2~6개 팀·인원별 24~48개 금고·봇·교사 운영실·현황판·기존 공용 웹소켓 채널을 사용한다.
- 이전 6개 게임 ID는 이력 조회용 등록만 유지한다. 게임 허브·새 점수 제출·게임 공개 설정에서는 제외하고 이전 주소·숏코드·블록은 체험 플러그인으로 가는 안내를 제공한다.

## 기록·채점

`edu_games_arcade_runs`는 새 두 게임의 상태와 결과를 소유한다. 정답·공개 시각·오답 보정·최종 점수는 서버가 판정하며 클라이언트가 보낸 점수를 저장하지 않는다. 요청 ID와 revision 비교로 중복 보상·동시 갱신을 막는다. 중단 기록은 보존하지만 완주 순위에는 제외한다.

금고는 기본 점수 100/200/300과 시간 보너스 `round(base * reference / (reference + elapsed))`를 합한다. 기준 시간은 20/35/50초이며 제한시간이 아니다. 오답 확정은 해당 금고와 전체 보정 시간에 2초를 반영한다. 같은 난이도·당일 팩의 완주 기록끼리 총점, 보정 밀리초, 오답 수로 비교한다.

댄스봇은 실제로 펼친 명령 순서가 목표와 같아야 득점한다. 반복 묶음은 최대 12개, 동작은 묶음당 32개, 반복 1~8회, 실행 64박자 이내다. 서버가 실행 가능 시각까지 확인하고 기본 박자 점수·명령 절약·속도 항을 공개한다. 맞힌 안무의 결과는 유지하고 다음 안무를 열 때 새 해결 시간을 시작한다.

체험은 게임 순위·점수 API를 사용하지 않는다. 작업은 사이트·사용자별 해시로 분리한 브라우저 저장소에 보관하며 운영 서버에 새로운 학생 평가 결과를 만들지 않는다.

- WordPress 숏코드·블록 콜백/공개 설정 검사 11개, 기존 애드온 자산·페이지 등록 검사 291개 통과.
- 새 체험 플러그인을 단독 등록하고 두 플러그인을 양쪽 설치 순서로 등록한 실제 플랫폼 매니페스트 검사 20개 통과. 개발용 데이터 가져오기 도구는 설치 패키지에서 제외한다.

- 실제 공용 허브 어댑터의 로컬 WebSocket 연결로 다중 사용자 금고 담당 잠금·점수 공유·공격/복구·48개 금고 화면 맞춤·교사 현황판 검사 14개 통과. 같은 연결에서 기존 이진수 팀전 회귀 55개 통과.

- PHP/JavaScript 문법, `git diff --check`, 공식 `release.cmd check` 통과. 새 두 버전이 아직 패키징되지 않았다는 경고와 다른 플러그인의 기존 CSS 경고는 남아 있다.

새 버전 설치 ZIP은 만들지 않았다. 패키징은 사용자 요청이 있을 때 `_release-kit/release.cmd`만 사용한다. 기존 릴리스와 다른 작업자의 변경은 덮어쓰지 않는다. 실제 WordPress 사이트·교실 동시 접속·학생 흥미 관찰은 이번 격리 검사에 포함하지 않는다.

로컬 미리보기는 `edu-games/tests/split-preview.cjs`를 사용한다. `_notes/tmp/edu-split-preview`에는 실행 중인 미리보기에 필요한 격리 SQLite와 주소만 남긴다. 이 저장소는 운영 학생 성적과 연결하지 않는다.

게임 허브는 미리보기의 `/oj-addons/edu-games/games`와 `/`에서 실제 허브 페이지 핸들러로 표시한다. 8개 게임 카드·학급 검정 진입·세 팀전·개념 체험 링크를 유지한다. 기존 게임/타이핑 미리보기 API는 별도로 실행 중인 `browser-play.cjs` 미리보기에 연결하며 `SPLIT_LEGACY_URL`로 해당 로컬 주소를 지정한다(기본 `http://127.0.0.1:60035`). 이 연결은 개발용 미리보기에만 사용하며 설치 플러그인의 의존성·운영 주소에는 영향을 주지 않는다.
