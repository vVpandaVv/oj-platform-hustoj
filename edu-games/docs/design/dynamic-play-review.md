# 정적 시안 철회와 동적 게임판 수정

## 1. 사용자 지적을 재현한 결과

이전 이상치 검증판은 두 칸을 선택하면 **그 두 칸에 같은 주목 값의 새 쌍을 다시 넣었다**. 원래 보드의 나머지 네 칸을 무시해도 두 자리만으로 계속 플레이가 성립했다. 자리의 후보/일반 순서는 매번 같다고 보장되지는 않지만, 다른 곳을 탐색할 이유가 사라진 것은 실제 구조의 결함이다.

구체적으로 기존 규칙 함수로 선택했던 두 슬롯을 30회 반복했을 때 30회 모두 두 슬롯이 여전히 한 쌍이었다. 이것은 '30회 모두 정답이었다'는 결과가 아니다. 옳은 방향을 읽는다고 해도 보드 전체에 대한 선택은 사라진다는 문제를 재현한 것이다.

이전 `interest-cases.cjs` 검사는 숫자만 보는 정책·끝값만 보는 정책과 판정 정책을 비교했지만, **성공한 슬롯만 반복해도 한 쌍이 유지되는지**를 확인하지 않았다. 따라서 그 검사 통과를 흥미 구조의 검증으로 보았던 판단을 철회한다. [이전 쌍찾기 시안](prototypes/outlier-context-playtest.html)은 유지·개량 대상이 아니라 철회된 실험 기록이다.

## 2. 새 이상치 캐치의 규칙

작은 분포 카드 여섯 장과 두 번의 짝 선택을 없앴다. **비교 관측 8개와 새 관측 6개가 같은 수직선 축을 사용하는 한 게임판**으로 바꿨다.

- 숫자의 가로 위치는 실제 측정값이다. 정답을 가리키는 색이나 특수한 자리 표시는 없다.
- 시작 후 1.6초마다 새로운 관측이 들어오고 이전 관측은 아래로 이동한다. 기존 값을 임의로 변경하지 않는다.
- 동시에 비교 관측도 새 표본으로 순차 교체한다. 분포가 이동하면 남아 있는 같은 관측의 후보 여부가 달라진다.
- 학생은 현재 비교 분포에서 유난히 벗어난 새 관측을 선택해 검토한다. 정답 한 관측당 +1이며 원본과 당시 비교 자료는 보존한다.
- 이미 검토한 관측은 어느 자리로 움직이더라도 다시 득점할 수 없다. 오경보를 낸 관측도 같은 비교 상태에서는 연타로 기회를 추가 소모하지 않는다.
- 잘못 고른 일반 값은 기회 1개를 잃는다. 검토하지 않은 후보가 충분히 판단할 시간을 갖고 판에서 나가면 놓침으로 기회 1개를 잃는다.
- 후보가 된 뒤 2.4초 미만으로만 보인 관측의 퇴장에는 놓침 벌칙을 적용하지 않는다. 분포 변경 직후의 즉시 퇴장에 반응하라고 요구하지 않는다.
- 기회 3개 소진 또는 활성 플레이 75초에 종료한다. 일시정지와 탭을 벗어난 동안에는 흐름과 시간이 멈춘다. 검증용 개인 플레이이며 공식 순위/서버 기록은 아니다.
- 정답 개수는 0개·여러 개 모두 가능하다. 후보가 없을 때 무조건 누르지 않는 것도 필요하다.

시간·기회·유입 간격은 검증용 초기값이다. 학생 관찰로 확인한 최적 수치라고 주장하지 않는다. 보상은 검토 수 하나이며 임의 점수 가중치나 숨은 콤보를 쓰지 않는다.

## 3. 움직임이 아니라 판단이 달라지는지

실제 규칙으로 아래 전환을 검사했다.

1. 같은 관측 `45`: 초기 비교 관측 40~46에서는 일반 범위. 그 관측은 그대로 남아 있는데 새 비교 분포가 높은 쪽으로 이동하면 검토 후보가 된다.
2. 초기의 높은 관측: 처음에는 비교 무리에서 멀지만 새 높은 비교 자료가 쌓이면 더 이상 후보가 아니다.
3. 처음에 잘못 선택한 `45`도 비교 자료가 바뀐 뒤에는 올바른 검토가 될 수 있다. 이전 오경보를 소급 취소하지 않고 새 상태의 판단으로 기록한다.
4. 한 번 검토한 ID는 상태·자리와 관계없이 두 번째 점수를 주지 않는다. 자리의 새 관측은 새로운 ID와 값이며 현재 비교 자료로 다시 판정한다.

기존 자료의 숫자를 몰래 바꾸거나 정답 색만 뒤집는 방식이 아니다. **교체된 비교 자료 때문에 판정이 바뀌며, 계산 결과·그림·득점이 같은 규칙을 사용한다.**

게임 규칙은 비교 관측 8개를 정렬해 아래 4개/위 4개의 중앙값 Q1·Q3를 구하고, Q1−1.5×IQR~Q3+1.5×IQR 밖을 후보로 보는 것이다. [NIST의 상자그림 울타리 설명](https://www.itl.nist.gov/div898/handbook/eda/section3/boxplot.htm)을 참고했다. 이 시안은 가상 자료의 기준 대비 이탈을 다루는 교육용 모델이며, 모든 현실 자료의 보편적 판정법이라고 설명하지 않는다. [후보 표시와 오류 확정은 다르다](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35h.htm)는 구분도 유지한다.

## 4. UI를 바꾼 범위

- **작은 그래프 카드 목록 제거.** 게임판이 화면의 주 영역을 차지한다.
- 상단에 게임 이름과 검토 수·기회·남은 시간만 둔다. 별도 설정 폼이나 학습 보고서로 시작하지 않는다.
- 비교 자료는 작은 회색 관측으로, 학생이 조작할 새 관측은 선명한 숫자 표적으로 구분한다. 모든 미검토 표적은 같은 기본 스타일을 쓰고 개별 후보의 색을 자동으로 바꾸지 않는다. 현재 판정 구간은 실제 IQR 계산에 맞는 띠와 숫자로 공개해, 감으로 틀렸다는 느낌을 주지 않는다. 관측 8개→비교 구간→새 값의 상대 위치가 연결된다.
- 새 자료 유입에 따라 기존 관측이 실제 다음 위치로 이동한다. 검토 성공은 그 관측에서 +1과 완료 상태로 나타난다.
- 오경보/놓침의 원인을 해당 값과 당시 비교 자료에 연결한다. 원본을 삭제하거나 '고장'으로 확정하는 연출을 쓰지 않는다.
- 라이트·다크에서 같은 의미의 대비를 유지한다. 중립 표면·청색 새 관측·녹색 검토 완료·붉은 기회 손실을 구분한다.
- 모바일에서도 필수 표적은 44px, 행 간격은 46px로 서로 겹치지 않게 한다. 값이 바뀌어도 버튼의 크기가 바뀌지 않는다.
- 결과는 점수와 오경보/놓침을 보여 주고, 다시 도전하거나 마지막 판을 볼 수 있다. 결과를 자동 초기화하지 않는다.

## 5. 다른 7종에도 적용할 동적 판단 기준

아래는 설계 수정 기준이다. 이번 작업에서 다른 7종의 운영 게임까지 구현한 결과가 아니다. 사용자가 이미 재미있어 했다고 알려 준 초기 이미지 표현은 '움직이지 않는다'는 이유로 폐기하지 않는다. **그림이 학생의 조작으로 축적되는 변화**와 **자동 데이터 유입**은 서로 다른 적절한 방식이다.

| 게임 | 바뀌는 실제 상태 | 선택을 바꾸게 되는 이유 | 반려할 정적 우회 |
| --- | --- | --- | --- |
| 문자 코드 | 진행 중인 송수신, 마감, 복원한 코드표 지식 | 급한 통신·재사용할 대응이 달라 처리 순서와 참조가 달라짐. 표 변경은 명시한 경계에서만 함 | 같은 키/고정 슬롯 반복으로 원문·코드를 안 읽고 성공 |
| 이미지 | 픽셀 배열과 완성 중인 그림 | 색을 찍은 결과가 누적되고 다음 좌표·색/수정이 달라짐. 창작은 스스로 다음 행동을 결정 | 자동 그림 밀기, 임의 타이머로 이미 좋았던 창작을 방해 |
| 결측값 | 확보한 근거 자료와 아직 가능한 복원 패턴 | 어느 위치를 추가 관측했는지에 따라 유효한 방법·예측값이 달라짐 | A 방법만 유지해도 같은 오차, 원래 정답 직접 열기 |
| 시각화 | 현재 집단·범위·집계와 연결된 그래프 | 전체/집단/구간을 바꾸면 분포·비율·변화가 달라져 근거가 바뀜. 원자료는 유지 | 첫 막대/같은 차트 선택 반복, 질문 문구만 바뀌고 표시 정보는 고정 |
| 추출 | 선택해 내보낸 집합, 남은 표시 자료, 새 유입 자료 | 이번에 어떤 합법적인 집합을 추출했는지가 다음 조건의 선택지를 바꿈 | 한 조건 설정 후 자동 처리만 관찰, 같은 번호나 색만 반복 선택 |
| 자료구조 | 실제 보관 순서·다음 출구·받침대·새 블록 | 넣기/꺼내기가 이후 가능한 제거와 공간을 바꿈 | 같은 보관함 클릭이 언제나 최선, 임의 중간 블록 꺼내기 |
| AI 분류 | 아직 구별 못한 규칙 후보, 추가 학습 관측, 고정할 경계 | 어느 학습 후보를 확인했는지에 따라 다음 경계가 달라짐. 평가는 별도 새 자료 | 한 번 선 긋고 자동 결과만 관찰, 평가 라벨 미리 확인, 정답 함수를 몰래 변경 |

공통 통과 조건은 '수치나 장식이 움직이는가'가 아니다. **한 상태에서 유리했던 선택이 다음 상태에서도 항상 최선인가, 다른 선택을 하면 미래 상태도 실제로 달라지는가**를 각각 확인한다. 실시간 입력이 개념을 흐리거나 원래 재미있는 창작을 해치면 실시간화를 강요하지 않는다.

## 6. 실행 검사

실행: `node edu-games/docs/design/review/live-outlier-tests.cjs`

검사는 새 HTML의 실제 규칙 함수를 불러온다. [실행 결과](review/live-outlier-results.json)와 [검사 코드](review/live-outlier-tests.cjs)를 함께 둔다.

- 이전 두 슬롯에 계속 쌍이 생기는 현상 재현.
- 같은 값의 일반→후보, 후보→일반 전환.
- 동일 관측 100회 재선택 무득점, 동일 상태의 오경보 연타 추가 손실 방지.
- 비교 변경 후 재판정, 원본 값 불변, 검토 당시 비교 자료 보존.
- 일시정지, 시간 종료, 기회 소진, 결과 유지와 최고 기록.
- 즉시 판독 정책에서 불가능한 퇴장 놓침이 없는지, 저장 상태가 16KiB 미만인지 확인.
- 60개 컴퓨터 시드에서 분포를 읽는 정책, 고정 슬롯 6종, 최댓값만 고르는 정책 비교. 고정 슬롯 정책은 모든 360회 실행에서 기회를 소진했고, 각 시드에서 사후 가장 좋은 슬롯을 골라도 분포 판독 정책보다 낮았다.

이 결과는 반복 클릭의 허점과 동적 상태 전환 검사다. 컴퓨터 정책은 사람의 시각 탐색·반응 시간을 모델링하지 않으며 학생 흥미가 입증됐다는 결과가 아니다. 새 UI와 흐름을 실제로 플레이하며 다시 반응을 받아야 한다.

## 7. 변경 경계

이번 구현은 [실시간 검증판](prototypes/outlier-live-board.html)이다. 운영 플러그인·DB·기존 학생 기록·다섯 유지 게임을 변경하지 않는다. 이전 정적 검증판을 공식 순위나 제작 기준으로 사용하지 않는다. 설치 패키지·버전·커밋도 이번 요청에 포함하지 않는다.

## 8. 화면·입력 확인

브라우저에서 첫 입력 시작, 검토한 관측 연타, 성공했던 실제 화면 좌표 재클릭, 자동 관측 유입과 비교 자료 갱신, 캔버스 픽셀 변화, 일시정지/재개, 기회 소진, 마지막 판 보기→결과 복귀→재도전을 확인했다. 준비/진행/일시정지/종료 상태가 서로 다른 입력을 허용하고, 종료 뒤에는 다시 점수를 얻지 못한다.

320·390·736·1024px의 라이트/다크 8개 조합에서 표적은 44px로 유지되고 서로 겹치거나 게임판 밖으로 나가지 않았다. 비교 구간과 원자료 줄은 작은 화면에서 고정된 두 줄로 배치해 값이 바뀌어도 게임판 위치가 튀지 않게 했다. 원자료, 계산된 구간 띠, 표시 숫자, 판정은 같은 함수와 값을 사용한다.

이 검사는 현재 로컬 Chromium 실행과 규칙 모델의 결과이며 실제 iPad Safari나 학생의 재미를 검사했다고 주장하지 않는다. 운영 게임의 화면을 검증판과 함께 수정했다고 표시하지 않는다.
