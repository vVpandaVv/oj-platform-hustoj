# 핵심 개념을 게임의 행동으로 만드는 8종 재설계

**후속 검토 반영 필요:** [학생 반응 기반 반복 검토](interest-iteration-review.md)와 [최신 동적 게임판 수정](dynamic-play-review.md)을 따른다. 초기 이미지 활동은 보존하고, 이상치 경보 구간 운영 및 정적 쌍찾기 시안은 철회했다. 아래는 개념 범위를 정리한 이전 후보이며 흥미 검증이나 제작 승인을 받은 최종 규칙이 아니다. 충돌하는 게임 진행 규칙은 최신 문서를 따른다.

2026-11-16. 제작 전 설계 수정본. 운영 코드·기록·공개 설정은 변경하지 않는다. 학생 흥미나 학습 효과를 실험으로 검증했다는 문서가 아니다.

## 1. 이전 설계를 철회하는 이유

이전 [8종 전면 재설계](eight-games-from-scratch-2026-11.md)는 놀이 형식을 먼저 선택하고 교과 내용을 끼워 넣었다. 반려 조건을 적는 것만으로 이 결함이 해결되지는 않는다. 해당 문서와 화면은 제작 기준에서 철회한다.

| --- | --- | --- |
| 암호 도미노 | 코드표를 이용해 원문 전체를 코드열로 바꾸고 되돌리는 수행 | 폐기. 실제 문자 단위 변환을 본게임으로 복귀 |
| 픽셀 큐브 | 숫자 배열을 읽어 픽셀의 색을 구성하고 그림을 숫자로 표현하는 수행 | 폐기. 그림 밀기는 이미지 표현의 대체 활동이 아님 |
| 분포 합치기 | 분포·비교 조건에 비추어 이상치 후보를 판단하는 수행 | 폐기. 가까운 값 합치기는 이상치 판단이 아님 |

| 깃발 영역전 | 관측된 학습점, 분류 규칙과 경계, 새로운 자료의 예측·오류 | 임의의 깃발 이동이 주 활동인 안은 철회. 관측 자료를 고정하고 실제 분류 규칙을 운용 |

다섯 유지 게임(이진수 변환 아케이드, 장치 카드 매칭, 키워드 레인, 코드 타이핑, AI 모델 훈련소)은 제외한다. 개인전·팀전·수행평가·DB·순위·Code Arena도 변경하지 않는다.

## 2. 설계 순서를 바꾼다

순서는 **핵심 개념 → 학생이 직접 해야 하는 수행 → 조작 직후의 데이터 변화 → 계속 판단해야 하는 상황 → 종료·기록**이다. 먼저 보드게임 장르를 정하지 않는다. 같은 조작이 일부 남아도 개념 수행에 꼭 필요하면 보존한다. 새롭다는 이유로 암호화를 도미노나 이미지를 슬라이딩 퍼즐로 바꾸지 않는다.

모든 게임에서 다음 네 연결이 실제로 성립해야 한다.

1. 학생이 한 조작을 특정할 수 있다.
2. 원자료·코드·값·집합·순서·예측 중 무엇이 바뀌었는지 같은 화면에서 보인다.
3. 그 변화가 교과 개념의 정의와 일치한다.
4. 개념을 더 잘 수행하면 게임 결과가 좋아진다. 관계없는 손놀림이나 정답을 공개하는 버튼으로 대체할 수 없다.

타임어택이 어울리는 변환·시각 탐색에는 속도를 쓴다. 추정 방법을 비교해야 하는 결측값에는 같은 자료에서의 오차를 쓴다. 모든 모듈을 타이머+정답 버튼이나 억지 보드게임으로 통일하지 않는다.

이름은 장식이다. 아래에서 규정한 수행을 빼면 해당 게임으로 인정하지 않는다.

## 4. 문자 코드: 암호 통신 연속전

### 반드시 배우는 것

같은 코드표를 공유한 송신자·수신자는 문자마다 대응되는 코드를 사용해 원래 문자열을 되살릴 수 있다. **문자 순서, 공백, 숫자 문자까지 정보**다. 숫자 문자인 `2`는 코드값 `2`와 다르다. 코딩/디코딩과 정보 보안의 암호화는 동일하지 않으며, 게임의 임의 치환표가 ASCII나 안전한 암호라고 설명하지 않는다.

### 학생이 실제로 하는 일

- 수신(복호화): 숫자열을 보고 해당하는 문자를 순서대로 작성한다.
- 송신(암호화): 원문을 보고 해당하는 숫자 코드를 순서대로 작성한다.
- 코드표 복원: 정렬된 원문·코드열의 대응에서 빈 표 칸을 채우고, 그 표로 새 통신을 변환한다.

예시 표는 `M=42, A=17, P=63, 공백=90, 숫자 문자 2=28`이다. 따라서 `MAP 2 ↔ 42·17·63·90·28`이다. `M-A-P`를 연결하거나 MAP이라는 단어를 고르는 것은 성공으로 세지 않는다. 실제로 완성한 대응 전체를 확인한다.

### 한 화면과 흐름

상단에 알파벳표·숫자 문자표·공백 코드, 중앙에 수신/송신 원문, 바로 아래 같은 열의 입력칸이 보인다. 현재 처리 중인 한 칸과 표에서 참조한 대응이 연결된다. 글자와 숫자를 같은 열에 두되 정답을 자동 입력하지 않는다. 공백도 독립된 칸이다.

정확한 통신 하나가 완성되면 봉투가 전송 완료함으로 이동해 **완료 +1**이 뜬다. 다음 통신이 즉시 이어지고 제한시간은 새 통신의 길이·입력 형식에 맞게 초기화된다. 오답 확정 또는 제한시간 초과로 한 판을 끝낸다. 편집 중 실수를 고칠 수 있으며 키를 잘못 눌렀다는 이유만으로 즉시 종료하지 않는다.

모든 문장이 몇 글자냐에 따라 종료되는 것은 아니다. 개인 기록은 이어 간 통신 수, 동률이면 같은 도전 묶음의 처리 시간이다. 긴 숫자 입력이 필요한 암호화와 짧은 문자 입력인 복호화를 똑같은 시간으로 취급하지 않는다. 난도가 올라가도 길이별 입력 가능 하한 아래로 줄이지 않는다. 정확한 초 수는 학생 입력 관찰 전 확정하지 않는다.

### 전략·재도전·콘텐츠

기억한 대응을 재사용하고 공백·숫자를 놓치지 않는 속도와 정확도가 실력이다. 영어 추측이 아니라 표를 빠르고 정확하게 사용하는 게임이다. 새 치환표, 새 원문, 문장 길이·형식 변화가 새 도전이다. 표는 판 중 몰래 변경하지 않고 새 표가 적용되는 경계를 분명히 알린다.

필수 범위는 A–Z·공백·0–9, 양방향 변환, 코드표 복원 전부다. 표 복원은 주어진 대응으로 결정할 수 있어야 하고, 모호하면 미정으로 남긴다. 경쟁용은 변환이 유일하고 비교 가능한 동일 도전 묶음을 사용한다.

**반려:** ABC 순서만 알면 풀림, 단어 보기만 고르면 득점, 표 클릭으로 통째 자동 변환, 공백 생략 인정, 숫자 문자를 코드값 그대로 입력해도 통과.

## 5. 이미지 데이터: 비밀 그림 수신

### 반드시 배우는 것과 직접 조작

이미지는 픽셀 격자이며 배열의 각 위치에는 팔레트의 색상 번호가 들어간다. **숫자 배열→색상 픽셀**과 **그림→숫자 배열**을 모두 수행한다. 색상표를 보고 `2`에 해당하는 색으로 지정 좌표를 칠하면 그 위치의 값만 바뀐다. 숫자 행은 그림의 같은 행과 같은 높이에 맞춘다.

처음에는 목표 그림의 정답을 보여 주지 않는다. 배열을 읽어 칠하면서 숨겨진 사물·기호가 드러난다. 그림 이름만 맞혀서는 완료할 수 없고 모든 칸의 코드가 일치해야 한다. 빈 칸은 코드 0의 배경색과 다르다. 처음부터 전부 배경색으로 채워 득점하는 우회가 없다.

역방향에서는 그림과 팔레트가 주어지고 학생이 행별 숫자열을 만든다. 해당 숫자로 실제 수신 미리보기가 바뀌어 두 그림을 비교할 수 있다. 잘못된 숫자가 엉뚱한 위치/색을 만드는 것이 즉시 보인다. 게임이 정답 코드를 자동 생성해 주는 것은 자유 창작의 내보내기 기능으로만 둔다.

### 화면·경쟁·완결성

상단 16색 이내의 팔레트, 중앙 격자, 바로 옆 동일 행의 숫자열이 핵심 화면이다. 행 선택·실제 누른 동안의 드래그 칠하기·지우기·되돌리기를 제공한다. 마우스/펜을 놓으면 칠하지 않는다. 16×16도 판과 선택한 코드 행을 읽을 크기로 보여 주고 보조 설명을 접는다.

한 팩을 끝내면 종료한다. 같은 팩에서 **완성 그림 수를 우선**, 전부 완성한 사람끼리는 완료 시간으로 비교한다. 잘못 칠한 칸·수정 횟수는 복기용이며 임의 벌점으로 합치지 않는다. 완성 그림 갤러리, 팔레트가 달라진 같은 도안, 새 도안 팩이 재도전 요소다. 배경만 많은 도안을 반복해 속도를 부풀리지 않도록 동일 팩끼리 기록한다.

8×8 도입부터 16×16, 최대 16색, 좌표/행·열 순서, 팔레트 코드, 양방향 표현, 자유 창작을 포함한다. RGB는 추가하지 않는다. 부가 탐구에서는 배열 값을 바꾸는 것과 팔레트 매핑만 바꿔 같은 번호의 표시색이 함께 바뀌는 것을 구별한다. 주 게임의 배열 해독을 그 활동으로 대체하지 않는다.

**반려:** 행 밀기로 숫자를 안 읽고 성공, 그림 보기만 고르면 성공, 틀린 칸의 정답 색을 자동 채움, 코드 0과 미작성 칸 혼동, 도안 일부만 맞추고 전체 모듈 완료로 처리.

## 6. 이상치: 이상치 경보망

### 반드시 배우는 것

이상치 후보는 **비교할 자료·조건·분포에 비추어 유난히 벗어나는 관측**이다. 숫자가 크다고 곧 이상치인 것은 아니다. 후보 표시와 오류 확정·삭제는 다르다. 이전 합치기 안은 이 수행을 하지 않으므로 폐기한다.

### 핵심 게임: 후보를 하나씩 누르는 대신 경보 기준을 운영

출처별 기준 자료가 수직선 위에 분포로 놓이고 새로운 기록이 들어온다. 학생은 두 손잡이로 각 출처의 통과 구간을 놓는다. 구간 밖으로 오는 값은 **검토함**에, 안의 값은 통과함에 들어간다. 자료를 합치거나 지우지 않는다. 새 자료를 보기 전에 설정을 고정하고, 결과를 본 뒤 다음 흐름의 기준을 고친다. 다음 흐름에서는 수집 조건과 기준 자료가 바뀌며 전환 전에 표시한다. 한 번 넓은 구간을 설정한 뒤 자동 통과만 관찰하는 판을 만들지 않는다. 이유 없이 같은 모집단의 기준을 몰래 바꾸지도 않는다.

도입 예시: A의 확인된 기준구간은 18–24, B는 58–64다. `A의 60`은 검토로, `B의 60`은 통과로 보내야 한다. 같은 60을 다르게 처리하는 이유가 같은 화면에 보인다. 도입의 기준구간은 그 사례의 **공개된 운영 기준**이지, 모든 현실 자료의 이상치를 확정하는 보편 공식이 아니다.

분포 팩에서는 주어진 기준 자료의 정렬·중심·퍼짐으로 범위를 구성한다. 심화의 IQR 팩은 사분위수 산출 방식을 먼저 고정하고 학생이 기준점을 잡으면 `Q1−1.5×IQR`, `Q3+1.5×IQR` 울타리가 계산되어 나온다. 단순히 최솟값–최댓값을 정상으로 삼거나, 게임의 숨은 정답에 맞춰 감으로 경계를 좁히게 하지 않는다. 표본이 적거나 분포가 부적합한 판에 해당 공식을 무조건 적용하지 않는다.

### 기록과 재미의 근거

핵심은 **놓침과 오경보를 동시에 줄이는 것**이다. 올바른 후보 발견 +1, 정상 기록을 잘못 검토로 보낸 오경보 -1, 후보 누락 -1이다. 통과한 정상 자료에는 점수를 주지 않는다. 전부 통과시키거나 전부 검토함으로 보내서 점수를 벌지 못하도록 각 도전 팩의 구성과 해당 전략의 결과를 사전 확인한다.

팩의 새 자료 흐름이 끝나면 종료한다. 준비가 끝난 학생은 바로 기준을 고정해 다음 흐름을 시작한다. 동일 팩의 순점수가 같으면 누적 기준 준비 시간이 짧은 기록으로 비교한다. 자료가 이동하는 공통 애니메이션 시간은 준비 시간에 넣지 않는다. 모든 후보를 맞힌 경우에도 같은 고정 점수만 남기지 않는다. 판의 분포와 검토함은 누적되어 이전 결정의 결과를 볼 수 있다. 비교 집단이 늘어나고 낮은 이상값·여러 후보·큰 값이 정상인 집단·시간 조건에 따라 기준이 달라지는 팩이 해제된다. 원본을 유지한 상태로 후보를 다시 비교한다.

경쟁은 기준이 명시되고 판정 가능한 교육용 사례에 한한다. 맥락상 애매한 값, 드물지만 유효할 수 있는 실제 사례는 비경쟁 탐구에서 검토/추가 자료 필요로 다룬다. 재측정을 누르면 정답이 공개되는 기능이나 불확실한 현실 자료를 억지로 정답/오답 채점하는 기능은 없다.

**반려:** 큰 값만 찾으면 성공, 같은 60을 출처와 무관하게 처리, 이상치를 오류/삭제 대상으로 표시, 정답을 본 뒤 기준을 고쳐 같은 기록에 재득점, 구간을 아무렇게나 두어도 비슷한 성과. 이 안의 핵심 위험은 구간 설정이 단순 수치 복사에 그치는가이며 학생 관찰에서 별도로 확인한다.

## 7. 결측값: 데이터 복원전

### 반드시 배우는 것과 실제 조작

결측은 0이 아니다. **무엇을 근거로 어떤 방법을 적용했는지에 따라 실제 추정값이 달라진다.** 학생은 같은 보드의 빈칸을 선택하고, 참고할 관측 자료의 범위를 직접 잡고, 방법을 적용한다. 그 결과가 실제 숫자와 빈 원/점선으로 들어간다. 방법 이름 카드만 붙이고 득점하지 않는다.

한 보드의 여러 빈칸을 복원해 마지막에 가려 둔 관측을 공개하는 **블라인드 복원 퍼즐**이다. 정답을 보지 않은 상태에서 방법과 근거의 적합성을 판단한다. 첫 빈칸을 제출하면 모든 것을 지우는 문제가 아니라, 이전 복원과 원자료를 보며 다음 판단을 한다.

### 방법이 의미 있게 달라지는 예시

`0시=20, 1시=22, 2시=?, 10시=40`에서 같은 관측 3개를 참고하면 평균은 27.33…, 중앙값은 22, 실제 시간으로 양옆을 보간하면 24다. 가린 관측이 24였던 이 실험에서는 절대 오차가 각각 3.33…, 2, 0이다. `시간대로 잇기`를 누르면 1시–10시의 거리와 2시 위치를 이용해 계산되는 것이 보인다.

반면 `10, 11, ?, 12, 80`처럼 큰 값의 영향을 받는 자료에서는 평균과 중앙값이 크게 다르고, 상태가 유지되는 기록에서는 앞값 유지가 의미 있다. 보간이 언제나 유리하도록 자료를 만들지 않는다. 평균과 중앙값이 같은 값이 되는 판에서는 둘 다 인정하며 일부러 가짜 차이를 만들지 않는다.

### 전체 콘텐츠 범위

| 처리 방법 | 학생이 확인하고 수행할 근거 | 구별할 결과/제한 |
| --- | --- | --- |
| 평균 | 같은 수치 특성·집단의 관측값 선택 | 큰 값이 미치는 영향, 결측은 분모에서 제외 |
| 중앙값 | 선택한 관측의 정렬과 가운데 값 | 홀짝 개수, 평균과 다른 결과 |
| 최빈값 | 같은 범주 특성의 빈도 | 수치 평균으로 범주를 만들지 않음, 동률 처리 명시 |
| 상수 | 작업에서 허용한 기본값/명시 상태 | 실제 0과 결측을 혼동하지 않음 |
| 앞값 유지 | 이전에 확인된 상태·시각 | 변화 기록 정책이 뒷받침되는 사례 |
| 뒷값 참고 | 이미 확보한 뒤 관측 | 오프라인 자료에서만 허용, 미래를 몰래 보지 않음 |
| 선형보간 | 양쪽 실제 관측과 시간 간격 | 불규칙 간격, 바깥으로 연장하는 외삽과 구별 |
| 주기 참고 | 같은 요일·시간대의 관측 | 전체 평균과 다른 반복 패턴 |
| 유사 사례 | 조건이 비슷한 다른 관측 | 집단/특성 차이, 임의 출처 혼합 금지 |
| 미확인 보존·다시 수집·이번 집계 제외 | 실제 값이 필요한지, 추정 가능한지 | 사람의 취향·식별번호를 평균으로 만들어 내지 않음, 원본 보존 |

한 화면에 열 가지 버튼을 나열하지 않고 현재 자료에 쓸 수 있는 도구만 제시한다. 잘못된 방법을 무조건 잠가 정답을 알려 주지는 않는다. 계산 불가능한 범주 평균 등은 이유를 대상 옆에서 알린다. 추정값을 실제 관측처럼 다른 빈칸의 근거로 재사용하지 않는다.

### 승부·기록

수치 경쟁 팩은 **알려진 관측을 교육용으로 가린 자료**이며 같은 개수·단위·원자료끼리 절대 오차 합을 비교한다. 낮을수록 좋고, 동률만 완료 시간으로 비교한다. 위 예시에서 27.33으로 채우면 오차 3.33, 24로 채우면 0이므로 왜 기록이 다른지 설명 가능하다. 오차는 내부 정밀도로 합산하고 표시 반올림으로 순위를 뒤집지 않는다.

모든 경쟁 대상 빈칸을 예측하거나 제한시간이 끝나면 종료한다. 미완료 기록은 완성 기록과 같은 순위에 넣지 않아 빈칸을 남겨 평균 오차를 낮출 수 없다. 범주 팩은 틀린 복원 수로 별도 비교한다. 단위가 다른 오차를 임의 배점으로 섞지 않는다.

실제로 정답을 알 수 없거나 채우면 안 되는 사례는 별도 정책/탐구 팩에서 다룬다. 정당한 보류가 필요한 사례를 빠뜨리지 않되, 알려지지 않은 실제 값에 대해 오차를 계산했다고 주장하지 않는다. 이는 모든 현실 결측을 반드시 채우라는 게임이 아니다. 새 자료 팩, 더 작은 오차, 선택한 방법끼리의 복기가 재도전이다.

**반려:** 평균/중앙값 아무거나 늘 같은 성과, A 선택만으로 점수, 실제 예측 없이 방법 이름 채점, 새 수집을 누르면 무조건 최고점, 근거 없는 실제 결측의 유일 정답 강제.

## 8. 데이터 시각화: 그래프 탐색전

### 반드시 배우는 것과 실제 행동

원자료에서 **무엇을 표현하고 읽으려는지**에 맞게 변수·집계·그래프를 구성한다. 그런 다음 실제 도형에서 근거가 되는 막대·시간 구간·부채꼴·구간·점 무리를 선택한다. 차트 이름을 고르거나 길이 조각을 맞추면 끝나는 게임이 아니다.

첫 화면의 짧은 목표는 `가장 많이 늘어난 구간 찾기`다. 학생이 시간과 측정값을 축에 놓으면 관측이 실제 시간 좌표에 배치된다. 선으로 표현하면 증가량이 큰 구간을 빨리 찾을 수 있고, 그 구간을 직접 선택하면 원자료의 두 값과 차이가 연결되어 **발견 +1**이 뜬다. 원자료의 순서나 값을 바꾸어 답을 만드는 것은 금지한다.

### 하나의 지속 보드, 다섯 표현

| 장면 | 실제 표현 조작 | 그래프에서 수행할 발견 |
| --- | --- | --- |
| 막대 | 범주·값·집계 방식 배치 | 범주 비교, 여러 범주 합 비교 |
| 선 | 시간·값 연결, 집단 시리즈 구분 | 증가/감소 구간, 변화량, 서로 다른 시간 간격 |
| 원 | 겹치지 않는 범주와 전체 합 연결 | 부분/전체 비중, 두 부분의 합 |
| 히스토그램 | 수치 변수·구간 경계/폭 배치 | 몰린 구간, 퍼짐, 빈 구간 |
| 산점도 | 두 수치 특성을 두 축에 배치 | 함께 증가/감소하는 점 무리, 패턴에서 벗어난 점 |

기본 차트는 도구가 정확히 그린다. 학생이 데이터/변수를 어떻게 표현할지 결정하는 것이 핵심이지 손으로 원을 정교하게 그리는 능력이 핵심은 아니다. 합법적인 대체 표현으로 근거를 찾아도 인정한다. 정답 차트 하나만 찍는 방식으로 채점하지 않는다. 단, 시간 변화가 사라지는 부적절한 집계, 원의 중복 범주, 잘못된 축/단위는 명확히 드러낸다.

### 게임성과 기록

한 자료 보드에서 찾을 정보가 빠르게 바뀌고, 학생은 표현을 바꾸거나 유지해 더 빨리 발견한다. 모든 과제를 막대의 최댓값 찾기로 만들지 않는다. 잘 선택한 표현은 실제 탐색 시간을 줄이고, 원자료만 훑거나 부적합한 표현을 고집하면 같은 시간에 찾는 양이 줄어든다. 혼자 완결되며 분석가/구조대원 역할 교환이나 출동 버튼이 없다.

한 판의 시간 동안 **맞는 발견 +1, 잘못 선택 -1**이다. 같은 근거를 반복 눌러 추가 득점하지 못한다. 시간 종료 후 발견한 근거들을 원자료와 함께 복기한다. 같은 도전 흐름끼리 기록을 비교하며 새 차트 팩·더 빠른 탐색·더 높은 순점수가 목표다.

0 기준·눈금·단위·범례, 불규칙 시간, 원의 전체, 히스토그램 구간 포함 규칙·폭, 산점도 상관과 인과의 구별까지 포함한다. 같은 폭부터 시작하며 다른 폭 히스토그램은 빈도와 밀도를 구별한 심화 팩으로만 낸다. 툴팁에 정답 판정을 미리 써서 탐색을 대신하지 않는다.

**반려:** 차트 선택 자체에 득점, 원자료 없이 실루엣 맞춤, 그래프와 무관한 경로/출동 선택, 첫 막대만 누르면 성공, 막대 장면만 구현하고 전체 완료로 표시.

## 9. 데이터 추출: 자동 선별 라인

### 반드시 배우는 것과 조작

**조건으로 행을 고르는 것**과 **필요한 열만 남기는 것**을 구분한다. 원자료 표가 게임판이다. 학생이 열 위에 조건을 놓으면 해당 조건에 맞는 행이 통과로 이동하고 출력 열을 바꾸면 그 행의 정보만 줄어든다.

예를 들어 `빨강 AND 원`은 1번만, `빨강 OR 원`은 1·2·3번이 나온다. 학생은 실제 조건 결합을 바꾼다. 색 열을 출력에서 빼면 빨간 행이 사라지는 것이 아니라 출력된 세 행의 색 정보만 사라진다. 두 변화는 같은 자리에서 비교된다.

표 옆에 통과/보류함, 아래에는 출력 표가 보인다. 처음에는 필터 하나만 놓고 이후 겹치기(AND)·대안 묶기(OR)·제외(NOT)를 쓴다. 회로 편집 지식 없이 조작할 수 있지만 내부 실행은 실제 논리식이다. 학생이 특정 행을 손으로 골라 정답 표를 만드는 우회는 두지 않는다.

### 게임성과 기록

구성한 선별기는 여러 새 입력을 계속 처리한다. 주문이 바뀌면 조건 일부를 바꾸고, 두 출력에 공통으로 쓰는 조건은 재사용한다. 이미 본 표의 번호만 외우는 방식으로 다음 자료를 처리할 수 없다. 틀린 출력은 누락/과다/잘못된 열을 원본 행에 연결해 보여 준다.

같은 요구와 입력 팩을 모두 정확히 처리하면 완성이다. **정확한 해를 우선하고, 같은 과제에서 조건이 적은 해**, 그 다음 제작 시간을 비교한다. 잘못된 해가 조건이 적다는 이유로 순위를 얻지 못한다. 조건 수는 화면에 보이는 비교식 수이며 OR 합류를 숨겨 비용을 부풀리거나 가중점으로 바꾸지 않는다. 한 판이 끝나면 다른 요구와 자료 팩을 연다.

문자·범주·숫자 비교, AND/OR/NOT, 조건 묶음, 행/열 선택, 공통 조건 재사용, 출처 추적을 포함한다. 같은 원본이 OR 두 갈래를 통과하면 한 번만 출력한다. 서로 다른 행이 열 선택 뒤 같은 값이 됐다는 이유로 임의 삭제하지 않는다. 결측에 대한 비교 규칙은 콘텐츠에서 명시하고 결측을 0으로 바꾸지 않는다.

**반려:** 출력 열을 숨기는 것과 행 삭제를 혼동, 체크박스와 제출만 있고 결과 집합이 안 보임, 특정 번호 암기, 배선 배치 자체가 난도이고 추출 논리는 부차적임.

## 10. 자료구조: 스택·큐 블록매치

### 반드시 배우는 것

학생이 자료를 **넣고, 다음에 나올 것을 조회하고, 합법적인 출구에서 꺼낸다.** 스택은 LIFO, 큐는 FIFO, 우선순위 큐는 우선순위 규칙이 실제 출구를 결정한다. 임의 위치 선택이나 자동 정렬로 대체하지 않는다.

### 핵심 게임

새 블록을 스택 또는 큐 보관함에 넣고, 꺼낼 수 있는 블록을 출력 줄 끝에 보낸다. 출력 줄에 같은 종류 세 개가 연속되면 그 세 블록이 사라져 공간이 생기고 **세 블록 묶음 +1**이다. 연결 4 같은 다른 대국의 열 번호를 얻는 활동이 아니다. 자료구조에 들어 있는 **자료 자체와 출구 순서**가 제거 가능 여부를 결정한다.

출력 줄이 `A A`인 예시에서 스택의 위가 B, 그 아래가 A라면 A를 바로 꺼낼 수 없다. 큐의 앞이 A이고 뒤가 B이면 큐에서 A를 꺼내 `A A A`를 지울 수 있다. 스택에서 B를 먼저 꺼내면 `A A B`가 남아 공간을 쓴다. 다른 블록과 다음 입력을 고려하면 어느 구조에 보관할지 달라진다.

출력은 자동으로 같은 블록을 찾아 지우지 않고 **연속한 세 개만** 제거한다. 중간 블록은 손으로 끌어낼 수 없다. 블록을 직접 지우거나 다시 입력해 점수를 만드는 기능은 없다. 한 원본 블록은 한 번만 제거 득점에 참여한다.

### 흐름·종료·경쟁

정해진 간격으로 들어오는 블록을 제한된 보관 공간에서 운용한다. 다음 몇 개를 공개해 계획할 수 있게 한다. 기록은 지운 세 블록 묶음 수다. 출력 줄이 막혀도 보관함에 자리가 있으면 계속 판단하고, 다음 입력을 어느 구조에도 넣을 수 없고 합법적인 꺼내기로 공간도 확보할 수 없으면 종료한다. 유한한 도전 덱을 모두 처리하면 완주로 종료한다. 게임 속도는 조절하되 학생에게 불가능한 입력 간격으로 난도를 만들지 않는다.

입력을 언제든 멈추는 연습과 동일 간격/덱으로 비교하는 경쟁을 분리한다. 저장 공간·종류·우선순위가 다른 팩과 자신의 제거 기록이 재도전 목표다. 항상 새 블록을 스택에 넣었다 즉시 빼는 전략과 항상 한 보관함만 쓰는 전략이 경쟁적 최선이 아닌 사례를 생성기 조건으로 확인해야 한다.

스택·큐 팩부터 시작하되 전체 모듈에는 우선순위 큐도 포함한다. 우선순위는 종류 A/B와 별도의 속성이고 큰 수 우선, 동률은 입력 순서다. `peek`은 제거하지 않으며 빈 구조·가득 찬 구조는 불법 동작 대신 해당 상태를 보여 준다. 한눈에 보이는 입구·출구·다음 블록으로 규칙을 전달하고 별도 명령 설정 창을 요구하지 않는다.

**반려:** 아무 블록이나 뽑을 수 있음, 자동 재정렬, 출력 줄의 임의 제거, 구조를 없애도 같은 게임, 스택만 쓰면 항상 이김, 슬롯 잘라내기로 안 보이는 블록이 생김. 저장 운용이 실제로 재미있는지는 아직 검증 전이며 형식만 바꿨다고 확정하지 않는다.

## 11. AI 분류 경계: 분류 경계 수비전

### 반드시 배우는 것

**특성 좌표→분류 규칙→결정 경계→새 자료의 예측과 오류**가 연결되어야 한다. 학습점의 실제 라벨은 학생이 끌어 바꾸지 않는다. 과거 점을 다 맞히는 것과 처음 보는 자료를 잘 맞히는 것이 다름을 경험한다. AI 모델 훈련소의 손글씨 활동은 그대로 둔다.

### 학생 조작과 한 판

한 화면의 고정 학습점과 두 분류 영역이 보인다. 학생이 경계의 손잡이를 움직이면 규칙과 영역이 함께 바뀐다. 예를 들어 `폭 7mm 이상이면 B`에서 새 점 `(6mm,3mm)`는 A로 예측된다. 기준을 5mm로 옮기면 B 영역에 들어간다. 두 축·단위·경계값 포함 방향은 판 위에 표시한다.

다음 새 점 묶음의 좌표와 실제 라벨을 보기 전에 모델을 고정한다. 새 점이 들어와 예측된 통로로 이동한 뒤 실제 라벨이 공개되어 맞음/틀림이 보인다. 오류를 보고 다음 새 묶음에 대한 경계를 조절한다. 이미 공개된 점은 사례로 남을 뿐 다시 처음 보는 평가로 채점하지 않는다.

처음에는 한 축 기준, 다음은 두 특성의 기울어진 선, 이어 분리된 집단/겹침을 다룬다. 최근접 이웃 팩에서는 임의의 깃발을 옮기는 대신 고정 관측의 이웃과 k값을 사용한다. 가까운 점 3개와 다수결, 규칙에 따라 생기는 실제 예측 영역을 보여 준다. 한 알고리즘의 결과를 모든 AI의 원리라고 설명하지 않는다.

### 게임성과 기록

주 기록은 같은 새 자료 흐름에서 올바른 분류 수다. 동률은 새 묶음마다 모델을 고정하기까지의 누적 준비 시간으로 비교하며 공통 평가 애니메이션 시간은 제외한다. 종류별 맞음/틀림도 바로 옆 두 출구에 보여 한 종류만 고정 예측하는 편법을 알 수 있게 한다. 총량만 높은 무의미한 클래스 불균형 팩을 기본 경쟁으로 쓰지 않는다. 모든 새 점이 끝나면 종료한다. 오차가 생기는 위치를 읽고 다음 경계를 바꾸는 능력, 새 분포와 더 복잡한 경계 팩이 재도전 요소다.

학습점과 평가점 분리, 경계 위 등호, 두 특성의 축과 단위, 거리 정규화, 최근접 이웃과 다수결, 관측만으로 규칙이 하나로 결정되지 않는 경우, 과도한 적합과 새 자료 성능을 포함한다. 겹치는 집단에서 언제나 100%가 가능하다고 약속하지 않는다. 거리·득표 동률은 사전 공개된 일관된 규칙을 쓰며 애매함은 별도 표시한다.

**반려:** 점을 직접 정답 출구로 옮겨 경계가 장식, 참조/관측 라벨 조작으로 해결, 평가 정답 미리 보기, 같은 점 재득점, 실제 판정과 그림의 영역 불일치, 임계 숫자가 어느 축의 어디인지 보이지 않음.

## 12. UI/UX는 개념 수행을 드러내는 쪽으로 통일

- 공통 상단은 게임 이름·현재 목표 한 문장·주 기록·필수 조작만 둔다. 게임판이 주 화면이며 과제 설명, 학습 보고서, 설정 폼은 밖으로 뺀다.
- 같은 입력과 결과를 정렬한다. 문자와 코드의 열, 픽셀과 코드의 행, 원자료와 추정점, 원본 행과 출력 행의 위치가 연결되어야 한다.
- 눌러도 되는 대상과 결과 표시는 구분한다. 익숙한 도구는 아이콘과 짧은 이름/툴팁, 모드 선택은 분절 선택, 색은 실제 팔레트로 제공한다. 핵심 조작을 의미 없는 '실행' 버튼 뒤에 숨기지 않는다.
- 성공은 실제 자료가 이동·복원·선별·제거·분류되는 곳에 나타난다. 숫자 점수만 증가하고 판은 의미 없이 바뀌는 효과를 쓰지 않는다.
- 정답을 미리 알려 주지 않으면서 현재 입력·예상 계산·적용된 규칙을 보여 준다. 실패 시 틀린 대상과 근거가 연결되고 긴 텍스트만 띄우지 않는다.
- 일관된 여백·표면·타이포·라이트/다크를 쓰되 각 게임의 조작판을 동일한 문항 카드로 만들지 않는다. 장식은 데이터·픽셀·블록 자체가 담당한다.
- 데스크톱/iPad에서 게임판·목표·필수 도구는 한 화면에 배치한다. 이미지·카드·글자를 잘라서 맞추지 않는다. 작은 화면은 보조 정보를 접고 선택 행/자료를 확대한다. 드래그에는 클릭/방향키 대안, 색에는 기호/라벨 대안을 둔다.

## 13. 이번 수정에서 직접 한 반례 점검

이 표는 문서·예제 검토이지 학생 플레이테스트가 아니다.

| 점검 | 이전 문제가 새 안에서도 가능한가 | 이번 설계에 반영한 차단 |
| --- | --- | --- |
| 코드표 없이 ABC로 성공 | 불가능해야 함 | 비연속 임의 치환표, 실제 원문/코드열 전체 검사 |
| 그림을 보고 행만 밀어 성공 | 불가능해야 함 | 숨긴 그림을 코드 배열로 구성, 역방향 직접 인코딩 |
| 큰 값이면 전부 이상치 | 실패해야 함 | 같은 60이 A/B 맥락에 따라 다른 예시, 후보와 오류 분리 |
| 재측정으로 정답 확보 | 경쟁에서 불가능 | 기준 고정 후 새 흐름, 정답 공개 후 재득점 금지 |
| 평균/중앙값 아무거나 | 자료에 따라 성과가 달라야 함 | 27.33/22/24의 실제 추정·오차 예시, 여러 패턴 팩 |
| 그래프 이름만 선택 | 득점 불가 | 실제 표현에 변수 연결 후 근거 도형/구간 선택 |
| OR와 열 숨기기 혼동 | 실제 결과가 다르게 보여야 함 | 원본 행 유지·출력 필드 변경·동일 원본만 중복 합류 |
| 큐 아래/중간을 마음대로 선택 | 불가능 | 각 구조의 실제 다음 출구만 제거, peek 비파괴 |
| 라벨 보고 같은 평가점 재사용 | 득점 불가 | 묶음 고정/공개 시점 기록, 공개 점은 다음 평가에서 제외 |

예제에서는 개념과 수행의 대응을 다시 확인했지만, 반복할 만큼 재미있는지까지 확인한 것은 아니다. 특히 이상치의 기준 구성, 결측값의 블라인드 복원, 자료구조의 공간 운영이 학생에게 실제 도전으로 느껴지는지 확인해야 한다. 이를 확인하지 않은 채 '완성도 보장'이라고 말하지 않는다.

제작 착수 판단은 각 게임의 **한 판 전체**를 대상으로 한다. 첫 조작·연속 판단·실패·종료·기록 근거·재도전을 짧은 시나리오로 확인한다. 핵심 자료를 가린 우회 전략이 정상 전략과 비슷한 성과라면 다시 설계한다. 개념을 지키기 어렵다는 이유로 다른 놀이로 바꿔 통과시키지 않는다.

- 문자/공백/숫자 문자의 표현과 디코딩: [Computer Science Field Guide – Text](https://www.csfieldguide.org.nz/en/chapters/data-representation/text/). 게임의 치환표를 ASCII나 강한 암호와 동일시하지 않는다.
- 픽셀 격자와 숫자 표현: [Computer Science Field Guide – Images and Colours](https://www.csfieldguide.org.nz/en/chapters/data-representation/images-and-colours/). 이 설계는 사용자 범위에 따라 인덱스 팔레트 16색으로 한정하며 RGB 실습을 가져오지 않는다.
- 이상치 후보·분포 가정·오류와의 구별: [NIST – Detection of Outliers](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35h.htm).
- 대체 방법과 수치/범주 자료 구분: [scikit-learn – Imputation](https://scikit-learn.org/stable/modules/impute.html). 주기 참고·보류·재수집 정책 등은 교육 사례로 따로 명시한다.
- 스택/큐의 연산 의미: [Python Tutorial – Data Structures](https://docs.python.org/3/tutorial/datastructures.html). 게임의 우선순위 큰 수 우선/동률 입력순은 모듈의 명시적 규칙이다.
- 새 자료 평가와 최근접 분류: [scikit-learn – Cross-validation](https://scikit-learn.org/stable/modules/cross_validation.html), [Nearest Neighbors](https://scikit-learn.org/stable/modules/neighbors.html).

자료는 개념 검토 근거이지 제안한 게임의 재미·교육 효과를 입증하는 근거가 아니다. 이번 산출물은 이 설계와 핵심 조작 화면 예시뿐이다. 운영 게임 구현·스키마 변경·패키징·커밋은 하지 않는다.
