# 일곱 게임의 새 핵심 플레이

2026-09-13 구현. 최초 설계의 첫 범위인 **게임별 두 상황, 총 14판**을 기본 게임에 연결했다. 문항을 더 붙이는 대신 각 게임의 상태 전이와 주된 조작을 바꿨다. 학생 대상 재미·난이도 검증이나 운영 사이트 배포가 완료되었다는 뜻은 아니다.

## 구현한 규칙

| --- | --- | --- |
| 관측 지도 수비대 | 지역 지도에서 출처를 비교하고 원값 전송, 단위 변환, 센서 교체, 보류를 설정한다. 설정은 다음 관측에도 남는다. 현장 일지는 독립 온도계 범위·시각·단위를 제공한다. | 6회 관측. 유효 관측, 오염된 보고, 실제 경보, 헛경보, 놓친 경보로 평가. 단위 오류+센서 편향 / 실제 해안 폭염+내륙 센서 편향 두 경우. |

생각하는 시간을 재지 않는다. 관측·입고·탐색·유입은 실행 명령으로 진행되는 시뮬레이션 시간이다. 관측망, 공장, 미로, 게이트에는 남은 과정을 자동으로 실행하는 명령도 있다. 실패한 결과와 판은 그대로 남는다.

## 기록과 점수

새 규칙의 버전은 play-2026-09-v1, 저장 모드는 play다. 게임 ID와 숏코드, 블록, 허브 경로는 바꾸지 않았다. 기존 strategy/board 기록을 삭제하거나 새 점수로 환산하지 않는다.

- 관측망: 유효 관측 ×20 + 실제 경보 ×35 - 잘못된 관측 ×15 - 헛경보 ×25 - 놓친 경보 ×35.
- 지도: 보급소 도착 시 300 + 남은 연료 ×20. 연료 부족으로 도착하지 못하면 0.
- 항구: 배송 ×30 - 과잉 도착 ×5.
- 공장: 정상 배송 ×50 - 반송 ×30 - 누락 ×20.
- 미로: 성공 시 1500 - 탐색 칸 ×15 - 최대 대기 칸 ×10 - 경로 길이 ×5. 메모리 초과는 0.
- 게이트: 두 클래스 성공률의 평균 ×1000 + 남은 검사 ×5. 전부 통과시키거나 전부 반송하면 한쪽 성공률이 0이 된다.
- 표본 로봇: 새 재료에서 두 클래스 성공률의 평균 ×1000. 학습 카드 수를 점수 보너스로 치환하지 않는다.

음수 점수는 0으로 제한한다. 기록 비교는 **같은 게임·같은 상황·같은 버전** 단위다. 서로 다른 상황은 최대 점수도 같지 않다. 교사 보고서의 최고 점수는 원점수이며 서로 다른 상황의 성취율로 해석하지 않는다. 항구는 개인 연습 기록만 화면에 표시하고 독립 협동 순위처럼 제시하지 않는다.

도전 토큰은 사용자·게임·버전·모드에 묶인다. 서버 규칙으로 상태와 점수를 계산하며 revision 비교와 requestId 멱등성을 사용한다. 실패한 저장은 동일한 요청으로 재시도할 수 있다. 완료한 점수는 전체 참여자 페이지네이션 및 교사 보고서의 새 모드에서 조회한다.

## 학습 엔진과 자료

AI 표본은 가로·세로 특성을 가진 합성 재료다. 재활용 여부는 교육용 합성 라벨이며 현실 재료의 재활용 판정 규칙이 아니다. 표본 덱 조합 70개 × 잘못된 라벨 수정 여부 2개 × 상황 2개 = 280개를 scikit-learn 1.8.0의 1-최근접 이웃으로 실제 계산한다.

생성기 scripts/edu-game/build-deck-experiments.py는 모든 지원 조합의 검증/최종 예측을 서버 전용 deck-experiments.php에 생성한다. 게임 서버에 Python 설치는 필요하지 않다. 요청된 덱의 정확한 조합을 조회하며 지원하지 않는 임의 덱을 비슷한 실험으로 대체하지 않는다. 학습·검증·최종 재료의 좌표는 겹치지 않는다. 최종 재료와 원본 라벨은 최종 작업/검수 전 공개 DTO에 넣지 않는다.

항구 차트는 원자료로부터 자동 생성하고 축과 단위를 고정한다. 지도/게이트/미로/회로와 로봇 표본은 실제 게임 상태를 표현하는 SVG·HTML이며 별도 장식 이미지를 사용하지 않는다. 차트는 기존 Chart.js, 탐색 자료구조는 PHP SPL을 재사용한다.

## 현재 범위와 남겨 둔 확장

최초 문서의 모든 확장 기능을 구현한 것은 아니다. 현재 판을 불필요하게 늘리지 않기 위해 다음은 제외했다.

- 관측망: 비교 집단은 전체/내륙/해안으로 제공한다. 자유로운 집단 편집, 출동 도착 지연, 장기 시간축은 아직 없다. 현장 일지는 즉시 제공하지만 재측정 정답 제출 방식은 없앴다.
- 지도: 범위 추정·정찰·우회에 집중했다. 여러 보급소, 확률적 지형, 자동 대체 알고리즘 선택은 아직 없다.
- 항구: 한 기기의 역할 교대 연습이다. 다른 계정·기기 간 비밀 보장이나 실시간 협동은 구현하지 않았다. 선박마다 한 항구에 한 번 배송하며 다중 경유 경로는 없다.
- 공장: 필터·열 추출·분기를 다룬다. 집계 연산과 무제한 자유 격자, 순환 회로는 다음 범위다.
- 미로: 스택·큐 비교가 현재 범위다. 우선순위 큐, 가중 경로와 휴리스틱은 기존 설계의 확장 항목으로 남겼다.
- 게이트: 사각 영역 2개까지다. 곡선 경계나 선분 드래그는 없고 좌표 입력과 실시간 위치 미리보기를 제공한다.
- 로봇: 8개 중 4개인 유한 덱, 원본 검수로 잘못된 라벨 1개를 바로잡는 범위다. 자유 라벨 편집, 다중 모델, 계속 바뀌는 환경은 아직 없다.

## 확인한 것

- PHP: 14개 판 완료와 고정 행동의 실패/열등 결과, 비공개 자료, 실제 추정/탐색/훈련 동작.
- 브라우저: 일곱 게임의 두 상황을 실제 버튼·폼으로 완주. 360px/1280px 화면과 글자 잘림, 응답 유실 후 재시도와 이어 하기.
- API/SQLite: 기록 저장, 사용자·버전·모드 격리, 중복 요청과 오래된 revision 거절, 전체 참여자 페이지네이션, 교사 보고서.
- 기존 전략 보드 규칙 회귀 검사는 유지했다. 기존 84개 판을 새 규칙으로 모두 다시 제작한 것은 아니다.

실행 명령은 tests/play.php, tests/play-api.php, tests/browser-play.cjs다. API 테스트는 PHP pdo_sqlite 확장이 필요하다. 브라우저 테스트는 로컬 PHP와 설치된 Playwright/Chrome을 사용한다. 운영 WordPress/MySQL과 30명 동시 실습은 이번에 확인하지 않았다. 이후 패키징 요청에 따라 1.1.0 설치 패키지에 포함한다. 이전 ZIP은 보존하며 커밋·운영 배포는 수행하지 않았다.
