# 개념을 직접 조작하는 학습 게임 재설계

작성: 2026-09-13. 상태: 핵심 직접 조작을 구현해 기본 화면에 연결함.
이 문서는 설계 의도를 기록한다. 실제 구현 범위와 차이는 [구현 현황](hands-on-implementation.md)에 구분했다. 실행 코드는 변경했지만 기존 1.1.0 패키지는 보존했다. 아래의 학습 효과는 설계 의도이며 학생 실습으로 확인된 결과가 아니다.

## 1. 기준은 이진수 게임이다

이진수 게임에서는 다음 관계를 한 화면에서 볼 수 있다.

0을 1로 바꿈 → 그 자리의 가중치가 더해짐 → 십진수 합계가 변함 → 목표 숫자에 가까워짐.

학생의 조작 자체가 이진수의 원리다. 자리값을 이해하면 목표를 더 빠르고 정확하게 만들 수 있고, 이것이 높은 점수로 이어진다. 설명을 읽고 설정을 고른 다음 결과 보고서를 해석해야 하는 구조가 아니다.

다른 게임도 아래 네 질문에 답할 수 있어야 한다.

1. 학생이 직접 움직이거나 바꾸는 대상은 무엇인가?
2. 그 조작 직후 숫자·모양·순서에서 무엇이 바뀌는가?
3. 그 변화가 어떤 학습 개념을 표현하는가?
4. 개념을 더 잘 이해하면 게임에서 무엇을 더 잘하게 되는가?

이 연결을 설명할 수 없으면 점수, 제한시간, 이야기, 무작위 사례를 추가해도 게임 설계가 완성된 것으로 보지 않는다.

## 2. 현재 구현에서 잘못 잡은 부분

| 현재 게임 | 핵심 문제 | 이번 설계 결정 |
| --- | --- | --- |
| 이상치 | 비교·분포보다 장치별 원값/변환/교체 정책을 선택하는 일이 앞선다. | 우선 목표를 이상한 자료의 발견으로 좁힌다. 이상치 발견과 오류 확정·삭제를 분리한다. |
| 결측값 | 빈칸의 추정 범위가 실제 이동 비용을 바꾸지 않고, 관측된 길만 우회해서 성공할 수도 있다. | 추정값을 만드는 조작과 그 값이 자료의 모양을 바꾸는 장면이 주된 플레이가 되어야 한다. |
| 데이터 추출 | 처리기 번호, 입력선, 필터, 추출 열을 동시에 이해해야 한다. 고정 주문을 해결한 뒤에는 자동 실행만 남는다. | 눈에 보이는 조건 관문으로 먼저 시작하고, 새 주문과 흐르는 자료에 대응하게 한다. |
| 시각화 | 기본 시간대 차트가 이미 제공되고, 두 사례 모두 시간대별 수요를 보는 같은 접근으로 해결된다. 같은 사람이 원자료를 보고 역할을 바꾼다. | 표현을 만드는 사람과 그 표현으로 판단하는 사람을 실제로 분리한다. 차트가 전달하는 정보가 게임 결과에 필요해야 한다. |
| 자료구조 | 두 고정 미로에서 초기 스택/큐와 방향 조합을 선택하고 자동 탐색하면 플레이가 거의 끝난다. | 미로는 탐색 실험실로 내리고, 경쟁 게임은 매번 자료를 직접 넣고 꺼내는 순서 운영으로 바꾼다. |
| 분류 경계 | 좌표 입력이 주된 조작이고, 같은 기본 점들을 조금씩 이동한 유입으로는 판단의 변화가 작다. | 선을 직접 옮기는 조작과 각 자료의 분류 통로 변화를 연결한다. |
| AI 모델 | 사각형의 가로·세로와 재활용 라벨의 관계가 학생에게 자명하지 않고, 고정된 표본의 라벨 검사로 해법이 고정된다. | 알아볼 수 있는 손글씨 이미지와 직접 붙인 라벨이 실제 예측을 바꾸게 한다. |

근거: 각 모듈의 Play_Board.php, assets/play/views.js와 현재 패키지 구현. 학생 대상 실험 결과가 아니라 코드와 화면 구조에 대한 분석이다.

## 3. 공통 화면과 조작

처음부터 모든 도구를 제시하지 않는다. 점수 없는 짧은 첫 장면에서 대상 세 개 정도와 조작 하나만 보여주고, 결과를 눈으로 확인한 뒤 본판에 들어간다. 연습에서는 이 장면을 다시 볼 수 있다.

- 처음 나타나는 대상은 문서나 설정 목록이 아니라 숫자 타일, 자료 점, 물건, 그림이다.
- 대상과 결과를 같은 화면에 배치한다. 클릭 후 다른 탭의 통계표를 읽어야 원인을 알 수 있게 만들지 않는다.
- 적용 전에는 예상 위치·통로·값을 보여주고, 확정 후에는 실제 결과를 보여준다. 미공개 정답까지 미리 보여주지는 않는다.
- '적용', '실행', '검수' 같은 단독 명령을 남발하지 않는다. '다음 물건 꺼내기', '출고', '이 자료를 검토함에 넣기'처럼 행동 대상을 명확히 한다.
- 낯선 기호에는 이름을 제공하고, 드래그가 어려운 경우 클릭 선택과 키보드 조작도 제공한다.
- 의미를 이해시키는 주된 수단은 긴 도움말이 아니라 위치 이동, 연결선, 수식, 색뿐 아닌 형태 변화다.
- 용어는 실제 대상 옆에 붙인다. 예를 들어 '먼저 들어온 순서'가 보이는 통로 옆에 '큐(FIFO)'를 표기한다.
- 화면에서 값이 변한 이유를 설명할 수 없으면 도구를 더 붙이지 않는다.

## 4. 게임별 학습 설계

### 4.1 이상치: 데이터 스캐너

**학습 목표**
자료는 대체로 어떤 범위에 모여 있고, 그 무리에서 유난히 떨어진 값이 있을 수 있음을 이해한다. 큰 값이 항상 이상치인 것은 아니며, 이상치 후보라는 이유만으로 오류나 삭제 대상으로 확정할 수 없음을 구별한다.

**게임 방식**
숫자 타일이 수직선 위의 점으로도 나타나는 스캐닝 아케이드다. 자료 묶음이 들어오면 학생은 유난히 벗어난 점을 검토함으로 옮긴다. 검토함은 휴지통이 아니다. 원본은 계속 남는다. 후보가 없는 묶음은 그대로 통과시킬 수 있다.

**핵심 조작과 즉각적 변화**
숫자 또는 점을 선택 → 원래 자료 무리와의 간격이 연결선으로 나타남 → 선택한 자료를 제외해 계산한 중심이 원본 중심과 나란히 보임.
중심 변화는 영향의 시연이며 그것만으로 이상치를 판정하지 않는다. 검토함 이동을 확정하면 이번 묶음의 판단 결과를 보여준다.

**실제 장면**
24, 25, 24, 26, 80에서는 80이 나머지 무리에서 멀다. 반면 75, 78, 80, 82, 83의 80은 같은 방식으로 취급하면 안 된다. 상위 내용에서는 같은 자료도 비교 집단을 나누었을 때 해석이 달라지는 사례를 쓴다.

**흥미와 경쟁**
흐르는 묶음에서 후보를 정확히 찾아 연속 처리 기록을 만든다. 정상값을 무조건 검토함으로 보내거나 가장 큰 값만 고르는 행동은 콤보를 유지할 수 없게 한다. 같은 시간·같은 자료 흐름의 유효 처리량을 비교한다.

**학습이 드러나는 행동**
숫자의 절대 크기보다 자료 전체의 모양과 비교 집단을 보고 판단한다. 원자료를 지우는 것과 검토 대상으로 표시하는 것을 구별한다.

**잘못 가르치지 않기 위한 제한**
초기 경쟁 자료는 같은 단위·조건이며 뚜렷하게 분리된 사례로 구성한다. 애매한 경계 사례와 맥락 없이는 판단할 수 없는 사례는 별도 비경쟁 탐구로 다룬다. '평균에서 멀면 오류'라는 규칙을 가르치지 않는다.

### 4.2 결측값: 끊어진 데이터 잇기

**학습 목표**
빈칸과 0은 다르다. 다른 관측값을 근거로 추정할 수 있지만, 어떤 값을 참고하느냐에 따라 결과가 달라진다. 추정값은 관측값과 구별해야 한다.

**게임 방식**
숫자와 그래프가 함께 있는 자료 띠가 보드에 쌓이는 복원 퍼즐이다. 빈칸을 채우면 끊어진 선이 이어지고 완료한 자료 띠가 빠져나간다. 단순히 임의의 숫자를 입력하는 방식이 아니라 참고할 자료를 직접 연결한다.

**핵심 조작과 즉각적 변화**
빈칸 양옆의 두 점을 연결 → 사이의 추정 점과 계산식이 즉시 나타남.
같은 집단의 관측값 묶음을 빈칸으로 가져오기 → 대표값이 만들어지고 그래프가 바뀜.
관측점은 실선, 추정점은 빈 원과 점선으로 남긴다.

**실제 장면**
10, 12, ?, 16, 18에서 12와 16을 연결하면 중간값 14가 생긴다. 시간 간격이 같지 않으면 점 간격도 다르게 보여 주어 단순 반으로 나누기와 구별한다. 같은 시각 다른 관측소의 큰 값을 섞으면 연결선이 어떻게 꺾이는지도 보인다.

**흥미와 경쟁**
보드가 차기 전에 근거에 맞게 자료 띠를 이어 내고 연속 복원 기록을 세운다. 동작 속도만이 아니라 어떤 자료를 참고할지 빠르게 판단하는 능력이 처리량을 좌우한다. 초기에는 연결 조작 하나로 시작하고, 집단 대표값과 중앙값은 각각의 관계를 체험한 뒤 추가한다.

**학습이 드러나는 행동**
빈칸을 0으로 놓지 않으며, 다른 집단의 값을 섞기 전에 자료의 조건을 확인한다. 완성된 그래프에서도 추정 구간을 구별한다.

**평가와 진실성**
경쟁에서는 원래 관측값이 있는 교육용 자료 일부를 가려서 복원 성능을 비교한다. 이는 실제 결측값의 정답을 알고 있다는 뜻이 아니다. 한 숫자만 정답으로 강제하지 않고 사례별 합리적인 오차 허용을 사전에 정한다. 실제 결측이나 추정 근거가 부족한 자료에서는 미확인을 유지하는 선택도 인정하며, 이런 사례를 속도 점수로 억지 채점하지 않는다.

### 4.3 데이터 추출: 조건 관문 출고전

**학습 목표**
조건에 맞는 행을 고르는 것과 필요한 열만 남기는 것은 다르다. AND는 동시에 만족하는 자료, OR는 어느 조건이든 만족하는 자료를 모은다.

**게임 방식**
색·크기·종류가 눈에 보이는 물건이 흐르는 출고 아케이드다. 주문이 요구하는 물건이 자동으로 통과하도록 조건 관문을 놓는다. 자료를 하나씩 손으로 골라 보내는 우회는 없다.

**핵심 조작과 즉각적 변화**
빨강 조건을 켬 → 해당 자료만 관문의 예상 통과 경로에 남음.
큰 물건 조건을 겹침 → 두 조건을 모두 만족하는 자료로 줄어듦.
두 조건을 나란히 분기 → 둘 중 하나라도 만족하는 자료가 모임.
출고표에서 열을 선택 → 물건 수는 그대로이고 전달되는 정보만 줄어듦.

**실제 장면**
'빨간색이면서 큰 상자' 주문과 '빨간색 또는 큰 상자' 주문을 비교한다. 같은 두 조건을 써도 연결 방식 때문에 실제 통과 물건이 달라진다. 색 열을 없애는 것이 빨간 물건을 제거하는 것과 같지 않다는 것도 직접 보인다.

**흥미와 경쟁**
앞으로 도착할 자료에도 관문이 계속 작동한다. 주문이 바뀌면 필요한 부분만 바꿔 처리한다. 유효 출고량과 오출고를 기록한다. 후기에는 두 주문을 동시에 운영해 공통 조건을 재사용하는 판단을 넣는다.

**학습이 드러나는 행동**
전부 통과시키거나 하나씩 고르는 대신, 조건을 구성해 아직 보지 못한 자료도 처리한다. 행 선택과 열 선택을 혼동하지 않는다.

**제한**
첫 화면에서 처리기 번호 다섯 개와 연결 설정 폼을 요구하지 않는다. 시작은 조건 하나와 눈에 보이는 통과/대기 두 공간이다. 복잡한 회로 편집은 기본 개념 이후의 확장이다.

### 4.4 시각화: 그래프 통신 구조대

**학습 목표**
같은 자료도 무엇을 축·집단·집계 단위로 삼느냐에 따라 다른 정보가 드러난다. 그래프는 꾸미는 그림이 아니라 다른 사람의 판단을 돕는 표현이다.

**게임 방식**
서로 다른 화면을 사용하는 두 학생의 협동 게임이다. 분석가는 원자료를 가지고 있고, 구조대원은 지도와 전달받은 그래프만 본다. 구조대원은 그래프를 근거로 출발 시각·구조 지역·보급량을 결정한다. 역할을 교대한다.

**핵심 조작과 즉각적 변화**
시간 자료 타일을 가로축에 놓음 → 관측점이 시간 순으로 놓임.
지역 타일로 묶음 → 지역별 막대나 선이 갈라짐.
시간 구간을 조절함 → 같은 원자료가 다른 구간으로 집계되어 최고치와 변화가 다르게 보임.
초기에는 한 조작만 노출하고, 원본 수치와 변환된 도형을 선으로 연결한다.

**실제 장면**
하루 총량이 같은 두 지역이라도 한 지역은 짧은 시간에 수위가 급상승한다. 하루 총량 그래프만 받은 구조대원과 시간별 그래프를 받은 구조대원이 다른 이동 계획을 세울 수 있다. 다른 임무에서는 하루 누적 보급량이 중요해 시간별 변화만 보는 것으로는 부족하다.

**흥미와 경쟁**
좋은 표현으로 동료가 더 많은 구조·배송을 완료하도록 하는 것이 팀 목표다. 차트 종류 이름에 점수를 주지 않는다. 임무 성공과 자원 사용을 같은 조건의 팀끼리 비교한다.

**학습이 드러나는 행동**
그래프를 만든 사람이 '그럴듯한 모양'을 고르는 데서 멈추지 않고, 상대가 필요한 정보를 읽을 수 있게 표현을 바꾼다. 역할 교대 후에는 표현하는 쪽과 읽는 쪽의 차이를 모두 경험한다.

**제한**
한 사람이 원자료를 본 뒤 같은 화면에서 역할을 바꾸는 방식은 경쟁 모드로 인정하지 않는다. 독립 화면을 구현하지 못하면 협동 연습으로만 남긴다. 팀 성적을 개인의 시각화 이해 점수로 해석하지 않는다. 원자료를 왜곡하거나 정답을 자유 문구로 적어 보내는 기능은 두지 않는다.

### 4.5 자료구조: 스택·큐 물류 레이스

**학습 목표**
스택은 마지막에 넣은 자료가 먼저 나오고, 큐는 먼저 넣은 자료가 먼저 나온다. 자료의 위치와 꺼낼 수 있는 순서에는 제약이 있다.

**게임 방식**
새 물건과 출고 주문이 이어지는 보관·출고 아케이드다. 학생은 들어오는 물건을 스택 선반이나 큐 통로에 배치하고, 다음 주문을 맞추기 위해 보관 순서를 운영한다. 미로의 전역 설정을 고르는 것이 주된 플레이가 아니다.

**핵심 조작과 즉각적 변화**
물건을 스택 위에 올림 → 새 물건이 맨 위에 놓이고 다음 출고 대상으로 표시됨.
물건을 큐 입구에 넣음 → 맨 뒤로 들어가고 맨 앞 물건이 출고 대상으로 유지됨.
출구를 선택 → 실제로 꺼낼 수 있는 한 물건만 이동함.

**실제 장면**
A, B, C를 차례로 넣으면 스택 출구에는 C, 큐 출구에는 A가 보인다. 다음 주문이 B라고 해서 중간 물건을 바로 꺼낼 수는 없다. 제한된 임시 공간을 이용하거나 이전 배치 판단을 바꿔야 한다.

**흥미와 경쟁**
같은 시간에 더 많은 주문을 처리하고 불필요한 재이동을 줄인다. 다음 일부 주문은 미리 보이고 그 이후는 공통된 자료 흐름으로 도착한다. 학생은 물건마다 선택하므로 두 버튼 중 하나를 고르고 자동 완료하는 구조가 아니다.

**학습이 드러나는 행동**
출구에 무엇이 나올지 실제로 꺼내 보기 전에 예측하고, 앞으로 필요한 순서에 맞게 넣는다. 중간 원소를 꺼낼 수 없다는 제약을 이용해 임시 공간을 계획한다.

**경쟁과 미로의 위치**
고정 미로는 탐색 실험실로 유지할 수 있지만 경쟁의 중심으로 삼지 않는다. 물류 경쟁은 새 입고·주문 조합과 공간 제약이 계속 판단을 요구해야 한다. 알려 주지 않은 주문 때문에 아무 배치에서도 회복할 수 없는 상황은 생성하지 않는다. 순서 운영 자체가 재미있는지 확인한 뒤에만 우선순위 큐를 추가한다.

### 4.6 분류 경계: 선 긋는 분류 방어전

**학습 목표**
특성값을 기준으로 그은 경계가 분류 결과를 바꾼다. 한쪽의 실수를 줄이려다 다른 쪽의 실수가 늘어날 수 있고, 기존 자료를 잘 나누는 경계가 새 자료에서도 잘 작동한다고 보장할 수는 없다.

**게임 방식**
자료 점이 두 출구로 이동하는 영역 방어 게임이다. 학생은 경계선을 직접 옮겨 분류 규칙을 만든다. 물건별로 정답 출구를 직접 고르는 방식은 막는다.

**핵심 조작과 즉각적 변화**
선의 손잡이를 이동 → 선 양쪽에 속하는 점과 예상 출구가 즉시 바뀜 → 다음 자료 묶음이 그 규칙으로 갈라짐.
좌표는 결과로 함께 보이지만 좌표 입력 폼을 알아야 시작할 필요는 없다.

**실제 자료**
기초에는 이름과 측정 기준이 명확한 두 특성을 쓴다. 손글씨 이미지로 확장할 때는 점을 고르면 원본 이미지와 각 특성을 어떻게 측정했는지 연결해 보여준다. 의미 없는 x/y 사각형과 임의의 재활용 라벨을 바로 제시하지 않는다.

**실제 장면**
기존 예에서 1로 분류된 점을 모두 담으려고 선을 넓히면 7에 해당하는 일부 점도 함께 들어온다. 다음 필자의 새 손글씨가 들어오면 지난 예에 꼭 맞춘 경계의 한계가 드러난다.

**흥미와 경쟁**
여러 필자·모양의 새 자료에서 양쪽 분류의 실수를 얼마나 줄이는지 비교한다. 단순한 평행이동으로 만든 동일한 점 여덟 개를 반복하지 않는다. 경계는 다음 묶음에도 남고, 학생은 틀린 사례를 보고 조정한다.

**학습이 드러나는 행동**
한 종류만 전부 통과시켜 전체 정확도가 높아 보이게 만드는 대신 양쪽 오류를 확인한다. 배운 자료와 새 자료의 성능 차이를 구별한다.

**제한**
이 게임의 경계는 학생이 직접 설계한 규칙이다. 이를 AI가 학습한 결과라고 부르지 않는다. 실제 모델 학습은 다음 게임이 담당한다.

### 4.7 AI 모델: 손글씨 로봇 코치

**학습 목표**
AI는 예시와 라벨을 이용해 학습한다. 잘못된 라벨과 편중된 예시는 예측에 영향을 주고, 학습한 그림을 맞히는 것과 새로운 그림을 맞히는 것은 다르다.

**게임 방식**
학습 카드의 보관 공간이 제한된 로봇 육성 게임이다. 학생은 알아볼 수 있는 손글씨 이미지에 라벨을 붙이고 어떤 예시를 남길지 선택한다. 로봇은 그 예시를 바탕으로 새로운 손글씨를 분류한다.

**핵심 조작과 즉각적 변화**
손글씨 이미지를 0·1·7 학습칸 중 하나에 놓음 → 그 라벨로 실제 모델을 갱신함 → 옆의 연습용 새 그림에 대한 로봇 예측이 바뀜.
예측 오류를 선택 → 그 판단에 가까운 학습 예시가 함께 강조됨.
학생은 잘못 붙인 라벨을 옮기거나 비슷한 그림만 쌓인 학습칸의 표본을 교체한다.

**실제 장면**
비슷한 모양의 1만 학습하면 다른 필자가 쓴 1을 놓칠 수 있다. 낯선 형태의 1을 추가한 뒤 새 그림의 예측이 바뀌는 것을 확인한다. 7을 1 학습칸에 잘못 놓았다면 그 예시와 비슷한 그림들에서 오류가 늘어날 수 있다. 어떤 이미지 하나가 언제나 오답 라벨이 되도록 고정하지 않는다.

**흥미와 경쟁**
연습 중에는 오류를 보고 개선하는 코치 역할을 한다. 기록 도전에서는 보지 않은 공통 평가 자료를 한 번 처리한 결과를 비교한다. 주 목표는 양쪽/각 클래스의 새 자료 성능이고, 같은 성능일 때 사용한 학습 표본 수를 별도 효율 기록으로 비교할 수 있다.

**학습이 드러나는 행동**
단순히 학습 자료를 많이 모으기보다 빠진 모양과 잘못된 라벨을 찾는다. 이미 맞힌 학습 그림이 아니라 처음 보는 그림에서 개선되었는지 확인한다.

**제한**
표본을 추가했다고 일정 점수를 더하는 가짜 학습은 쓰지 않는다. 실제로 선택한 예시·라벨로 계산한 예측을 보여준다. 즉시 바뀌는 예측은 연습/검증 자료에 한정한다. 최종 평가 자료를 계속 미리 보여주면서 독립 평가라고 부르지 않는다.

## 5. 고정 정답과 경쟁의 구분

같은 판에서 같은 행동을 하면 같은 결과가 나오는 것은 정상이다. 문제는 고정된 해법 몇 개를 외우는 것만으로 경쟁이 끝나는 구조다. 점수에 난수를 더하거나 판단과 무관한 클릭을 늘리는 방법으로 해결하지 않는다.

- 자유 연습: 멈추기·되돌리기·같은 자료 재실행을 허용하고 결과 변화를 비교한다. 순위에 넣지 않는다.
- 기록 도전: 동일한 도전 묶음, 난이도, 규칙, 자료 순서를 공유한 참여자끼리 비교한다.
- 재도전: 공개된 묶음의 숙련 기록과 처음 보는 묶음의 전이 기록을 구별한다. 정답을 본 재시도를 처음 보는 도전과 섞지 않는다.
- 콘텐츠: 숫자만 바꿀 것이 아니라 분포, 비교 집단, 결측 위치, 조건 조합, 입력/출고 순서, 필자·표본 구성이 달라져 실제 판단이 달라져야 한다.
- 점수: 이상치/결측/추출/자료구조 아케이드는 정확한 처리량과 연속 성공을 중심으로 삼는다. AI는 새 자료 성능, 시각화는 팀의 임무 결과가 중심이다.
- 동점: 같은 성취라면 공동 순위가 맞다. 의미 없는 반응시간 소수점이나 난수로 억지로 나누지 않는다.
- 시간: 속도가 주제와 연결되는 아케이드에서만 제한시간을 쓴다. 통계적 모호함과 모델 선택을 급하게 결정하도록 강제하지 않는다.
- 공정성: 무작위로 운 좋은 자료를 받은 학생이 유리하지 않도록 같은 도전 ID 안에서 비교한다. 서로 다른 판의 원점수를 하나의 순위로 섞지 않는다.
- 접근성: 입력 속도와 기기 차이가 있으므로 게임 순위를 교과 이해도의 단독 근거로 쓰지 않는다.

정확한 제한시간, 콤보 배수, 물건 유입 간격과 감점치는 지금 확정하지 않는다. 플레이 조작이 성립하는지 보기 전에 숫자를 정교하게 조절하는 일을 반복하지 않는다.

## 6. 학습이 실제로 일어났는지 확인할 최소 기준

완주 테스트와 오류 없는 화면은 게임성과 학습 효과의 검증이 아니다. 자동 테스트가 정해진 해법으로 만점을 받았다는 사실만으로 성공을 선언하지 않는다.

| 게임 | 새 자료에서 확인할 행동 |
| --- | --- |
| 이상치 | 가장 큰 값이 아니라 비교 집단에서 벗어난 값을 찾고, 검토와 삭제를 구별한다. |
| 결측값 | 빈칸을 0으로 처리하지 않고 적절한 관측값을 연결하며 추정 표시를 유지한다. |
| 추출 | AND/OR 연결을 바꿨을 때 통과 집합을 예상하고, 열 제거와 행 제거를 구별한다. |
| 시각화 | 동료가 필요한 판단을 할 수 있도록 집계·축·집단을 바꾼다. |
| 자료구조 | 넣은 순서에서 다음 출고 원소를 예측하고 임시 보관을 줄인다. |
| 분류 경계 | 선을 움직였을 때 어느 자료의 분류가 바뀌는지 예측하고 양쪽 오류를 본다. |
| AI 모델 | 새 자료의 오류를 보고 편중·라벨·대표성을 근거로 예시를 바꾼다. |

다음 구현은 일곱 완성형을 한꺼번에 늘리는 방식으로 진행하지 않는다. 먼저 각 게임의 **핵심 조작 하나와 즉각적 결과 한 화면**만 제시해 확인받는다. 여기서 관계가 안 보이면 제목·도구·점수 기능을 추가하지 않고 그 조작부터 바꾼다. 경쟁 장치와 콘텐츠 확장은 이 관계가 확인된 게임에만 붙인다.
