# 그래프 출동 구조대

2026-09-14. 다섯 시각화의 정답 위치 패턴을 제거하고 직접 조작 결과와 능동 플레이 시간을 중심으로 보강했다. 별도 수신 창, 팝업, 통신 대기는 없다. 기존 게임 ID·숏코드·블록·허브 경로를 유지한다. 공통 진행·채점은 `Hands_Board.php`, 추가 장면의 자료·판정은 `Visualization_Scenes.php`, 화면은 `rescue.js`와 `rescue-scenes.js`에 있다.

## 학습과 행동

모든 자료는 교육용 합성 자료다. 실제 구조 우선순위나 제품 규격·성능을 제안하는 도구가 아니다. 막대그래프는 매시간 새로 접수한 중복 없는 요청을 1건당 1명으로 표현한다. 다른 장면의 cm·건·W·m는 각각의 관측 단위이며 하나의 인원 수로 합치지 않는다.

| 임무 | 판단할 대상 | 직접 보이는 변화 |
| --- | --- | --- |
| 한 시간 긴급 출동 | 지역·시간별 12개 관측 중 최댓값 | 각 관측을 별도 막대로 비교한다. |
| 두 시간 연속 출동 | 09~10시 또는 11~12시의 지역별 합계 | 인접한 두 관측을 더한 6개 막대와 덧셈식이 나온다. |
| 오전 전담 출동 | 09~12시 전체의 지역별 합계 | 네 관측을 더한 3개 막대와 덧셈식이 나온다. |
| 수위 급상승 경보 · 꺾은선 | 같은 한 시간 간격 중 가장 큰 상승폭 | 선분 또는 점을 고르면 두 수위 게이지와 차이가 표시된다. 세 지역 모두 다양한 상승·하강이 가능하다. |
| 공평 보급 · 원그래프 | 세 지역의 요청 대비 지원율을 같게 만드는 배분 | 12·15·18개 물품 수를 바꾸면 요청 원그래프 옆의 내 배분 원그래프, 물품 상자, 지역별 지원율이 함께 바뀐다. |
| 구명조끼 적재 · 히스토그램 | 가장 많은 관측을 포함하는 연속 2~3개 구간 | 범위 슬라이더를 옮기면 5~7개 막대 중 선택 범위, 지원·미지원 인원, 지원 대상 표시가 함께 바뀐다. |
| 중계기 배치 · 산점도 | 전력 한도 내 최대 거리 또는 목적지에 도달하는 최소 전력 | 두 조건에 따라 가로·세로 기준선이 달라진다. 점을 고르면 연결 가능 여부, 거리, 전력과 부족량이 즉시 바뀐다. |

막대는 각 지역·시간의 관측을 독립적으로 생성한다. 묶음별 최선 지역이 같을 수도 다를 수도 있으며, 특정 지역 순서로 정답을 강제하지 않는다. 묶음을 바꿔도 전체 요청의 합은 보존된다. 선택에 따른 지역별 지원량과 전체 미지원량을 함께 표시한다. 두 시간 임무는 겹치지 않는 두 구간 중 하나를 고르는 규칙이며 모든 이동 창을 탐색하는 문제가 아니다.

꺾은선은 같은 간격의 차이를 비교하므로 기울기의 크기를 상승폭으로 비교할 수 있다. 원그래프는 고정된 여섯 배분 조합 대신 총량의 임의 정수 분할을 사용해 정확한 비례 배분이 가능하게 한다. 히스토그램은 동일 폭의 `하한 이상, 상한 미만` 구간으로 원본 관측을 한 번씩 세며 빈도와 최선 구간 위치를 고정하지 않는다. 같은 최대 지원량을 만드는 복수 구간은 모두 성공이다. 산점도는 거리·전력·장치 번호의 순서를 독립적으로 생성한다. 번호로 성능을 추측할 수 없으며, 두 축의 측정 쌍과 제약 조건을 읽는 활동이지 상관관계로 인과를 증명하는 활동은 아니다. 모두 기존 Chart.js를 사용한다.

## 화면 흐름

1. 장면의 임무와 자원 제한이 먼저 보인다.
2. 그래프의 막대·선의 점·조각·산점도 점을 고르거나 숫자 입력으로 배분을 바꾼다.
3. 선택한 관측과 계산 근거가 바로 표시된다. 선택 메뉴와 숫자 입력으로 키보드만으로도 진행할 수 있다. 출동지·장치·구간은 기본 선택하지 않고 보급품은 0개에서 시작한다.
4. 배치를 확정한다. 막대 장면의 시간 범위가 다르거나 배분 합계가 이번 물품 총량과 다르면 제출을 막는다. 총량만 맞춰도 비율이 틀리면 실패다.
5. 같은 자료를 유지한 채 내 선택과 임무에 맞는 선택을 비교한다. 서버에 남은 시간을 보관하고 결과 확인 중에는 시간을 멈춘다. `다음 출동 임무`에서만 자료가 바뀌고 남은 시간부터 다시 흐른다. 새로고침·이어 하기에서도 정지가 유지되며 2시간 세션 만료는 그대로 적용된다.

전체 도전은 일곱 임무를 한 번씩 포함하는 묶음을 매번 섞는다. 특정 장면이 계속 빠지거나 같은 순서만 반복되지 않게 하면서 날짜별 동일 자료·순서로 최고 기록에 재도전한다. 최초 노출 능력 검정은 아니다. 그래프 조작은 클라이언트, 집계와 배치 채점은 서버가 계산한다. 임의 점수·인원·남은 시간을 클라이언트에서 보내도 반영하지 않는다.

## 점수와 기록

- `board-01`: 능동 플레이 120초. 기본 점수는 한 시간 막대 100, 전체 합계 120, 두 시간 합계 140, 꺾은선·히스토그램 150, 산점도 140, 원그래프 200점이며 연속 성공에 10~50점을 더한다. 오답은 100점 감점(최소 0점), 연속 성공 초기화. 조작량을 반영한 초기 배점이며 학생 실측으로 균형을 보증한 수치는 아니다. 지원 인원과 점수는 별개다.
- `practice`: 모든 장면을 순환하는 시간제한 없는 연습, 성공 횟수는 남고 경쟁 점수는 0점이다. `practice-bar`, `practice-line`, `practice-pie`, `practice-histogram`, `practice-scatter`에서 장면을 직접 골라 연습할 수 있다. 서버 세션 만료는 기존처럼 2시간이다.
- 출동 결과 중복 제출이나 다음 임무만 누르는 것으로 득점할 수 없다. 제한시간 이후 추가 출동은 반영하지 않는다.
- 종료 때 점수, 정확도, 최고 연속 성공과 차트별 성공/시도 횟수를 보존한다. 새 점수 버전은 `chart-action-v4-YYYY-MM-DD`. 이전 기록은 삭제하지 않고 새 채점과 분리한다. 도전 순위는 기존 전체 참여자 페이지네이션을 사용한다.

## 확인 범위

`tests/rescue-solo.php`는 막대 임무와 집계 보존을 확인한다. `tests/visualization-scenes.php`는 장면별 120회 생성, 정답 위치·조건의 다양성, 과거 단축 전략의 실패 사례, 오답·입력 검증·점수·연습·섞인 묶음·시간 정지를 확인한다. `tests/visualization-preview.cjs`는 화면 계산과 서버의 일치를 확인한다. 브라우저 검사는 다섯 시각화의 실제 클릭·숫자 입력·범위 조작·결과·다음 임무·정지 중 이어 하기와 모바일/PC 캔버스를 확인한다. API 검사는 실제 PHP 컨트롤러와 SQLite 대역을 사용한다. 실제 WordPress/MySQL 운영 및 학생 실습 검증은 별도다. 후속 패키징 요청에 따라 1.2.0 설치 ZIP에 포함하며 기존 ZIP은 보존한다.
