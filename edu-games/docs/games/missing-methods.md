# 데이터 잇기: 복원 방법 확장

2026-09-13. 기존의 고정 A 그룹과 중앙값 기본 선택을 제거했다. 규칙은 `Missing_Values/Hands_Board.php`, 즉시 반영되는 화면 계산은 `assets/play/missing.js`에 있다.

## 사례

| 도구 | 자료에서 판단할 근거 | 다른 도구를 썼을 때 나타나는 차이 |
| --- | --- | --- |
| 선형보간 | 일정한 변화, 서로 다른 관측 간격 | 전체 평균은 증가 흐름을 잃고 한쪽 값은 중간 변화를 놓친다. |
| 평균 | 반복 관측의 양쪽 오차를 같은 비중으로 반영 | 중앙값이 작은 쪽으로 치우친 사례에서 세 복원값의 오차가 달라진다. |
| 중앙값 | 모여 있는 값과 크게 튄 한 관측 | 평균은 큰 관측에 끌려 세 빈칸을 모두 높게 채운다. |
| 최빈값 | 순서가 의미 없는 종류형 설문 | 앞뒤 응답을 복사한 경우와 가장 빈번한 종류를 넣은 경우를 비교한다. |
| 앞값 채우기 | 변경 명령 전까지 유지되는 설정 | 보간하면 실제 없던 중간 설정이 생긴다. |
| 뒷값 채우기 | 구간 끝에 그 구간 전체의 값이 기록됨 | 앞의 구간 값을 복사하면 바뀐 구간을 놓친다. 과거 기록 복원 사례이며 미래 예측에 쓰라는 뜻이 아니다. |
| 같은 주기값 | 날이 달라도 반복되는 아침·점심·저녁 | 시간상 가까운 값이나 전체 평균이 반복되는 봉우리를 없앤다. |
| 가장 닮은 자료 | 같은 단위의 가로·높이가 비슷한 물건 | 크기가 다른 세 물건을 평균 하나로 채우지 않고 각각의 이웃을 참고한다. |
| 미상으로 보류 | 독립 시행의 실제 결과이며 관련 근거 없음 | 통계량을 계산할 수 있어도 잃어버린 사실을 알아낼 수는 없다. |

가장 닮은 자료는 두 cm 특성의 유클리드 거리에 따른 1-최근접 관측값이다. 주기값은 같은 시간대의 관측 평균이다. 종류 자료에 평균·중앙값을 숫자로 억지 적용하지 않는다. 모든 알고리즘이 모든 자료에서 가능하거나 적절한 것은 아니므로 상황당 비교할 수 있는 3~4개 도구를 제시한다.

## 의미 있는 선택과 채점

- 정답 방법 이름을 대조하는 방식이 아니다. 서버가 선택한 방법으로 세 빈칸을 직접 계산하고 복원 결과를 평가한다. 두 방법이 같은 결과를 내면 같은 점수를 받는다.
- 평균 사례는 중심에서 `-12, -8, -4, +8, +16`, 중앙값 사례는 `-2, -1, 0, +1, +42`의 예시 분포다. 가려 둔 값 세 개는 중심 부근이다. 평균과 중앙값을 아무거나 선택해도 같게 채점되던 허용 오차 문제를 제거했다.
- 이는 방법의 특성을 대비하는 교육용 합성 자료다. 실제 자료에서는 숨겨진 값을 모르므로 이 분포만 보고 정확한 값을 확정할 수 없고, 평균이 언제나 좋거나 튄 값이 반드시 오류인 것도 아니다. 제출 후 설명에도 이번 사례의 결과라는 점을 명시한다.
- 같은 그룹의 관측 전체를 비교 대상으로 사용하는 게임 조건이 있다. 그룹 이름·배치는 바뀌며 항상 A를 고르는 규칙은 없다. 일부 값만 골라 우연히 중심을 맞추거나 다른 그룹을 섞으면 통과하지 않는다. 모든 실제 결측 처리에 전체 관측을 강제한다는 일반 규칙은 아니다.
- 방법은 처음에 미선택 상태다. 그룹만 고른 채로 제출할 수 없다. 숫자 자체를 클라이언트가 점수와 함께 보내도 서버 계산을 바꾸지 못한다.
- 관련 범위가 맞고 세 결과 모두 허용 오차 안이면 60점과 연속 보너스, 그렇지 않으면 20점 감점한다. 총점 하한은 0점이다. 한두 칸만 근접했다고 양수 부분 점수를 주지 않는다.
- 제출하면 `review` 상태로 머문다. 세 원본·복원값·오차와 다른 도구들의 결과를 비교한다. 이후 `다음 데이터`로 넘어가며, 같은 자료를 재제출해 중복 득점할 수 없다.

## 연습과 기록

- 오늘의 도전은 120초이며 아홉 유형이 중복 없이 한 번씩 나오는 순서를 섞고, 그다음 묶음을 다시 섞는다. 수치·비교 그룹·예제 맥락도 달라진다.
- 상황 선택 메뉴의 아홉 `방법 연습`은 시간제한 표시와 경쟁 점수가 없다. 각 방법의 예제를 골라 비교할 수 있다. 서버 세션 만료는 기존처럼 2시간이다.
- 결측값 게임만 `missing-methods-v2-YYYY-MM-DD`로 기록을 분리했다. 다른 여섯 게임의 기록 버전은 바꾸지 않았다. 이전 결측값 점수도 삭제하지 않고 이전 규칙 기록에 남긴다.
- 배포 패키지는 갱신하지 않았다. 현재 로컬 소스와 미리보기의 변경이다.

## 확인

`tests/missing-methods.php`에서 아홉 방법, 평균·중앙값의 실제 차이, 선택 누락, 부분 관측 선택, 잘못된 그룹, 중복 제출, 동등한 추정의 동등한 점수, 무작위 묶음을 확인한다. `tests/missing-preview.cjs`는 화면의 모든 후보 계산을 PHP 서버 결과와 대조한다. 브라우저 검사에서는 모든 방법을 실제 클릭해 제출하고 모바일·데스크톱 화면을 확인한다. 이는 동작 검증이며 실제 학생의 개념 습득을 측정한 결과는 아니다.

참고한 기본 처리 의미: [pandas 결측 자료 문서](https://pandas.pydata.org/docs/user_guide/missing_data.html), [scikit-learn 결측값 대체 문서](https://scikit-learn.org/stable/modules/impute.html). 이 게임의 합성 사례와 점수 기준은 별도의 교육용 설계다.
