작성: 2026-09-12. `edu-games`의 데이터·AI 6종을 대상으로 첫 18판에 66판과 확장 규칙을 추가했다. 기존 게임 ID, 블록, 숏코드와 게임 허브 링크를 유지한다. 기존 303개 개념 연습은 보충 활동으로 남긴다.

## 실제 확장 규칙

### 데이터 추출

- 보관 상자 4개에서 입고·복사·필터·정렬·열 선택·집계·출고를 실행한다. 모든 주문 완료가 승리 조건이다.
- 분류 일치/제외, 값 이하/이상/일치/양끝 포함 범위, 결측/관측값 조건을 지원한다. 순차 필터로 AND 조건을 구성한다.
- 오름차순/내림차순과 이름/ID 동률 기준을 구분한다. 필요한 열을 제거하면 그 열을 사용하는 후속 연산은 거절된다.
- 합계·평균·전체 행 수를 실제 계산한다. 결측은 0과 구분하며 관측값만 집계할지 명시해야 한다. 관측이 전혀 없는 그룹의 합계/평균은 결측이다.
- 결과가 0건인 주문도 올바르게 출고된다. 오출고는 비용과 실수를 남기지만 작업 상자는 보존한다.
- 공동 처리 농산물 보드에서는 필터와 정렬을 공유한 뒤 복사하는 해법이 개별 처리보다 적은 비용과 높은 점수를 얻는다. 모든 기준 비용은 실제 해법으로 달성 가능하다.
- 평균이 정수일 때 저장·복원 과정에서 자료형이 달라져 출고가 거절되지 않도록 정규화했다.

### 결측값 복구

- 3일간 온도·상태·날씨 노드에 재측정, 보간, 이전 값 유지, 최빈 상태, 이웃 평균/중앙값, 보류를 배치한다.
- 재측정은 비용 3, 추정/보류는 1, 다음 날 전달은 1이다. 신뢰도 8/10 이상으로 3일을 운영해야 한다.
- 상태 0은 유효한 관측이다. 상태/날씨에 수치 보간을 허용하지 않는다. 양쪽 관측이 없으면 보간도 할 수 없다.
- 오염된 이웃 관측에는 평균과 중앙값이 다르게 작동한다. 최빈 상태 동률, 재측정 불가, 급변·통신 두절·일시 정지 상황이 포함된다.
- 근거가 없는 선택적 노드는 미확정 보류가 가능하다. 전달된 값과 추정/실측 표시는 중계 기록에 남고 다음 날 자료에 반영된다. 재수정해도 이미 쓴 비용을 돌려주지 않는다.

### 이상치 조사

- 맥락·원장 단위·장치 범위·독립 재확인 증거를 구입한 뒤 보존·주의·격리로 이동한다.
- 모든 기록에 충분한 근거가 있어야 승리한다. 올바른 위치만 외워 근거 없이 배치해서는 성공할 수 없다.
- 새 사건의 독립 재확인은 비용 3이다. 모든 기록을 무조건 재측정하면 예산을 소진하므로 자료에 맞는 근거를 고른다.
- 소수점 누락, 중복 기록, 불가능한 배터리 값, 비율 단위 혼동, 음수 지연, 누적 계수 초기화, 정상 폭우와 복수 오류를 포함한다.
- 증거가 충돌하는 기록은 주의로 남겨야 한다. 정상 주의 표시는 감점하되, 불확실한 기록의 정당한 보류는 감점하지 않는다. IQR 후보 여부만으로 오류를 판정하지 않는다.

### 차트 타일 공방

- 막대·선·히스토그램·원·도넛·산점도를 실제 Chart.js 그래프로 표시한다. 축·기준선·구간 폭과 자료의 배치가 그래프를 바꾼다.
- 동률, 관측값 0, 불규칙한 시간 간격, 반복 표본, 구간 경계, 합계가 100이 아닌 비율을 다룬다.
- 비율은 원/도넛과 백분율 막대를 허용한다. 원/도넛은 원래 개수로 그려도 올바른 비중이면 인정한다. 미배치 비중은 별도로 남긴다.
- 산점도는 X/Y 원자료를 보고 0~10 좌표판에 점을 직접 놓는다. 드문 점을 누락하거나 좌표를 바꾸면 성공하지 못한다. 같은 위치의 복수 점은 개수와 접근성 이름으로 표시한다.
- 마지막 세 미션은 두 작업판을 모두 완성해야 한다. 탭 변경은 비용 없이 가능하고 각 판의 배치·설정은 독립적으로 보존된다. 완료 후에도 두 판을 살펴볼 수 있다.
- 자료형과 목적에 맞는 여러 해법을 인정한다. 예를 들어 히스토그램 구간 폭 2/4, 일반 추세의 선/막대, 원/도넛 대안을 검증한다. 실제 날짜 간격을 요구하는 미션은 연속 시간축을 검사한다.

### 분류 구역 설계

- 경계 조각 3개, X/Y와 포함/제외 임계값, AND/OR 조합을 실제 평면에 반영한다.
- 잘못된 훈련 라벨, 비어 있는 중앙 표본, 원형 영역을 추가했다. 훈련 점을 모두 맞추는 것만으로 성공하지 않는다.
- 최근접 이웃 k=1/3/5와 4곳의 표본 조사를 지원한다. 조사 결과를 훈련 자료에 포함해 예측 영역과 지표를 계산한다. 한 번의 조사가 반드시 모든 눈금의 예측을 바꾸는 것은 아니다.
- 모델·경계·조합·이웃 수·표본 변경은 이전 검증을 무효로 한다. 검증권은 3회이며 검증/최종 정확도가 각각 90% 이상이어야 한다.
- 최종 표본 좌표와 정답은 공개하지 않는다. 예측 영역은 단위 격자 중심 100곳의 예측으로 표시한다.

### AI 모델 운영

- 균형 자료의 직선/곡선/고리, 다른 희귀 범주 비율, 심한 라벨 잡음, 회전·이동한 환경을 구현했다.
- 임무마다 600표본을 훈련 풀 300·검증 150·최종 150으로 분리한다. 세 수집 묶음은 훈련 풀 안에서 서로 겹치지 않는 32개씩이다.
- 새 환경 임무는 최근 수집 묶음과 평가 표본에만 동일 환경 변환을 적용한다. 이전 환경 A/B 자료와 최근 균형 자료의 대표성이 실제로 달라진다.
- 수집/검수 정책 26개와 모델 3개를 결합해 임무당 78개, 총 936개 실험을 계산했다. 결정트리·kNN·로지스틱 회귀와 훈련 전용 스케일러를 사용한다.
- 자료를 추가/검수하면 기존 훈련·검증을 무효로 한다. 훈련은 최대 3회, 전체 예산은 36이다.
- 검증/최종 매크로 F1 각각 85 이상, 각 평가 집합의 A/B 재현율 각각 75% 이상이어야 배포에 성공한다. 매크로 F1은 A/B를 고정 포함하며 한 범주 훈련에는 상수 예측 사용 사실을 표시한다.

## 실험 재현과 한계

두 은행은 scikit-learn 1.8.0으로 개발 시 계산한다. Python이나 실시간 훈련을 WordPress 서버에 요구하지 않는다.

- 운영 모델: `scripts/edu-game/build-strategy-experiments.py` → 모듈의 `strategy-experiments.php`, 936조합.
- 분류 kNN: `export-classifier-specs.php`와 `build-neighbor-experiments.py` → `neighbor-experiments.php`, 12판 × 조사 부분집합 16 × 이웃 수 3 = 576조합.
- 은행과 정답은 HTML/REST 구성에 포함하지 않는다. 현재 선택의 공개 훈련/검증 정보와 종료 후 최종 집계만 반환한다.
- 재현용 분할, 시드와 데이터 해시를 보관한다. 훈련/검증/최종 표본은 서로 분리한다.
- 개발 시 해결 가능성과 목표 비용을 확인할 때 최종 성능도 검사했다. 합성 자료의 반복 퍼즐이며 독립 연구 벤치마크나 공식 AI 작성 검정이 아니다.

## 점수와 기록

승리는 `max(100, 1000 - 20 × 기준 초과 비용 - 50 × 실수 - 품질 감점)`, 실패는 0점이다. 품질 감점은 관측망 신뢰도 손실 1당 50점, 정상 자료 주의 표시 1건당 30점이다. 기준 비용은 달성 가능한 숙련 목표이며 모든 게임의 수학적 최솟값을 증명한 값은 아니다. 마지막 자원으로 승리 조건을 충족하면 성공하고, 다른 자원 소진은 실패다.

975점 이상 별 3개, 850점 이상 2개, 나머지 완주 1개다. 이전 보드를 완주하면 다음 보드가 열린다. 결과를 유지하고 같은 판 재도전/다음 판 이동을 제공한다. 시간·네트워크 속도 보너스는 없다.

- 기존 학습 테이블에 `mode=strategy`, `content_version=strategy-2026-09-v2`로 저장한다. 보드별 최고점·공동 순위·해금은 서버가 계산한다.
- 이번 규칙 변경은 새 시즌으로 분리한다. v1 점수를 삭제하거나 새 기준으로 재채점하지 않는다. v1 진행 세션은 v2로 변환하지 않는다.
- `archive` API와 이전 시즌 기록 버튼으로 로그인 사용자의 과거 완료 기록을 읽기 전용 조회한다. 현재 시즌 순위에 합산하지 않는다.
- 토큰의 사용자/게임/버전/모드/만료 결합, revision 조건부 저장, 요청 ID 재시도, DB 장애와 만료 구분을 유지한다.
- 기존 블록·숏코드·플랫폼 페이지와 순위/개인 통계에 공통 런타임을 연결한다. `board-views.js`를 `view.js`보다 먼저 등록한다.

브라우저는 실제 PHP 규칙/렌더러/JS를 사용하지만 WordPress HTTP·DB는 대역이다. 실제 WordPress 활성화, 테마/플랫폼 통합, DB 마이그레이션, 30명 동시 사용, 6개 반 명단 권한, 교사 검토와 학생 파일럿은 운영 환경에서 확인해야 한다. 실제 학생 기록이나 운영 서버는 변경하지 않았다.

이 문서의 완료 범위는 **6종 보드의 전체 확장**이다. 앞선 장기 계획의 기존 기기 도감/목표 서버 동기화, 교사 학급별 신규 집계와 실시간 다인전은 별도 후속 범위이며 구현 완료로 표시하지 않는다.
