# 데이터·AI 6종 전략 보드 첫 구현

작성: 2026-09-12. 기존 게임 ID, 블록, 숏코드, 게임 허브 링크는 유지한다.

> 이 문서는 첫 18판 구현 당시의 기록이다. 이후 66판과 확장 규칙을 추가한 현재 버전은 [84판 전체 구현 보고서](strategy-full-release-2026-09.md)를 기준으로 확인한다.

## 적용 범위

문제 답안을 작성하는 주 화면을 상태가 변하는 보드로 교체했다. 각 게임 3판, 총 18판의 일인용 게임이다. 기존 303개 개념 문항은 삭제하지 않고 보충 연습으로 유지한다. 전체 계획의 84판을 모두 구현한 것은 아니다.

## 목표·종료·점수

- 모든 게임에 유한한 자원이 있으며 자원 소진 시 종료한다. 마지막 자원으로 목표를 완료하면 승리다. 비용이 부족한 행동은 실행하지 않는다.
- 추출은 두 주문 모두 출고하면 승리. 결측값은 신뢰도 8/10 이상으로 3일 운영하면 승리하며 기준 미달 즉시 종료한다.
- 이상치는 모든 기록을 구역에 배치한 뒤 조사 종료. 오류 미격리와 정상 오격리가 없어야 승리한다. 정상 자료의 주의 표시에는 감점하지만 격리와 같은 실패를 강요하지 않는다.
- 시각화는 전체 자료·축/종류·순서/구간·기준선을 함께 검사한다. 성장 추세는 막대와 선을 모두 허용하고 히스토그램은 구간 폭 2와 4를 허용한다. 막대 기준선은 0, 선도 실제 값을 잘라 숨기면 실패다.
- 분류는 현재 경계의 검증과 최종 평가 정확도가 각각 90% 이상이어야 승리한다. 경계나 조합을 바꾸면 이전 검증은 무효다.
- AI는 검증과 최종 평가의 매크로 F1이 각각 85 이상이고 각 집합의 A/B 재현율도 각각 75% 이상이어야 승리한다. 자료를 바꾸면 재훈련·재검증이 필요하다.
- 승리 점수는 `max(100, 1000 - 20 × 기준 대비 초과 비용 - 50 × 실수 - 품질 감점)`이다. 실패는 0점. 결측 신뢰도 손실 1당 50점, 정상 주의 표시 1건당 30점을 추가 감점한다.
- 기준 비용은 검증한 목표 비용이지 모든 게임의 수학적 최솟값을 증명한 값은 아니다. 시간·네트워크 속도 보너스는 없다.
- 975점 이상 별 3개, 850점 이상 2개, 나머지 완주 1개. 승리 시 다음 판을 해금한다. 각 게임 별 9개와 모든 보드 1,000점이 유한한 숙련 목표다.
- 완료 화면과 사용 자원·품질 판정을 남기고 같은 판 재도전 또는 다음 판을 선택한다.

## AI 실험의 근거와 한계

`scripts/edu-game/build-strategy-experiments.py`가 scikit-learn 1.8.0으로 합성 자료를 계산한다. 생성된 서버 전용 `strategy-experiments.php`를 실행 중 조회하며 학생 요청에서 실시간 훈련하지 않는다.

임무마다 600표본을 훈련 풀 300, 검증 150, 최종 평가 150으로 분리한다. 세 수집 묶음은 훈련 풀 안에서 중복 없는 32개씩이다. 각 묶음의 미수집/미검수/검수 상태 27개 중 빈 상태를 뺀 26개와 모델 3개를 조합해 임무당 78개, 총 234개 실험을 저장한다. 스케일러는 훈련 자료로만 학습하며 지표·혼동행렬은 동일 조합의 예측에서 계산한다. 분할 ID와 데이터 해시도 보관한다.

세 모델은 깊이 제한 결정트리, k=5 최근접 이웃, 로지스틱 회귀다. 한 클래스만 있는 훈련 입력에는 다수 클래스 상수 예측을 사용한다. 원 라벨과 오류 라벨을 구분해 검수의 영향을 실제 계산한다. 검수가 항상 성능을 올린다는 보장은 하지 않는다.

최종 평가 표본의 좌표/정답과 전체 실험 은행은 HTML·REST에 보내지 않는다. 배포 후에는 최종 집계 지표만 표시한다. 개발 시 승리 가능한 판인지 확인하고 기준 비용을 정할 때 최종 지표도 확인했다. 따라서 이 고정 게임 세트의 반복 기록을 독립적인 연구 평가나 공식 AI 작성 검정으로 해석하면 안 된다. 분류 경계도 고정된 훈련/검증/최종 표본을 쓰는 연습 퍼즐이다.

## 저장·통합

- 규칙: 각 모듈의 `Strategy_Board.php`. 공통 자원/점수 규칙: `src/Boards/Rules.php`.
- 렌더러/화면: `Strategy_Renderer.php`, `assets/strategy/`. 기존 첫 화면은 새 보드, 기존 문항은 접힌 보충 연습이다.
- API: `/edu-games/v1/strategy/{game}/{start|update|resume|summary}`. 숨김 게임과 플레이 권한을 검사한다.
- 기존 `edu_games_learning_runs`에 `mode=strategy`, `content_version=strategy-2026-09-v1`로 분리 저장한다. 기존 학습/물류/아케이드 기록을 합산하거나 삭제하지 않는다.
- 사용자·게임·버전·모드에 묶인 2시간 토큰, revision 조건부 저장, 같은 요청 ID 재시도를 사용한다. 서버가 보드 해금·행동·점수·별을 계산한다. DB 읽기 장애는 만료와 구분해 이어 하기 토큰을 보존한다.
- 순위는 같은 보드/버전의 개인 최고점 기준, 동점 공동 순위다. 다른 학생은 익명 도전자로 표시한다. 순위·개인 통계·팀 순위 페이지에 개인 보드 기록을 추가했으며 **학급 합산 순위는 아니다**. 접힌 기록은 열었을 때만 읽는다.
- 학습 테이블의 `decimal(5,2)`는 1,000점을 담지 못해 `decimal(7,2)`로 확장하고 실제 열 형식을 확인한 뒤 스키마 버전 2를 기록한다. 과거에 이미 잘린 점수를 추측하여 복구하지 않는다.

## 검증과 남은 작업

- PHP의 18개 보드 해법, 실패·잘못된 행동·경계 포함·복수 차트 해법, 234개 실험의 혼동행렬/정확도, API 저장·동시성·사용자 격리 테스트를 제공한다.
- `tests/strategy-schema.php`는 마이그레이션 완료 확인과 재실행 방지를 테스트한다. 실제 MySQL 마이그레이션은 이 환경에서 실행하지 않았다.
- `tests/browser-strategy.cjs`는 실제 PHP 렌더러·규칙과 브라우저 자산으로 버튼 조작, 18판 완주, 화면 폭 320/360/768/1280/1440, 저장 재시도·이어 하기·터치를 검증한다. WordPress HTTP와 DB는 격리된 대역이다.
- 전체 계획까지 추가로 필요한 66판, 시각화의 비율/관계·복수 작업판, 경계의 잡음/편중 표본, AI의 분포 변화 임무는 후속 작업이다. 현재 3판의 제목이나 값만 바꾼 복제를 새 콘텐츠로 집계하지 않는다.
- 실제 WordPress 테마·계정·권한·DB 업그레이드·네트워크 장애 확인, 30명 동시 사용과 6개 반 누적 부하, 학생 난이도/접근성 파일럿은 배포 전 별도 검수해야 한다. 이 작업에서 운영 배포는 하지 않았다.
