# 장치 카드 매칭: 센서·액추에이터 확장

## 적용 범위

2026-09-11, 기존 24종에 **센서 9종·액추에이터 5종을 추가해 38종**으로 확장했다. 전체 분류에서 센서는 11종, 액추에이터는 7종이다. LED·부저는 기존처럼 정보 출력 장치로 별도 분류한다.

| 추가 센서 | 구별할 역할 |
| --- | --- |
| 온습도 센서 | 공기의 온도와 상대 습도 측정 |
| PIR 움직임 센서 | 적외선 변화로 움직임 감지, 거리·인원수 측정과 구별 |
| 방수 온도 센서 | 금속 탐침이 닿는 부분의 온도 측정 |
| 가스 센서 | 특정 대상 가스에 반응, 모든 가스의 종류를 구별하지 않음 |
| 누름 힘 센서 | 저항 변화로 눌림과 대략적인 세기 감지 |
| 기울기 스위치 센서 | 기울어짐에 따른 접점 변화, 정밀 각도 측정과 구별 |
| 자석 감지 리드 스위치 | 가까운 자석에 따른 접점 변화 |
| 무게 센서(로드셀) | 하중에 의한 변형을 읽어 무게 측정 |
| 회전 감지 엔코더 | 회전 방향·회전량 입력, 모터와 구별 |

| 추가 액추에이터 | 구별할 역할 |
| --- | --- |
| DC 모터 | 축의 연속 회전 |
| 진동 모터 | 치우친 추의 회전으로 떨림 발생 |
| 냉각 팬 | 날개를 돌려 공기 이동 |
| 수중 펌프 | 모터로 물 이동 |
| 직선 액추에이터 | 축을 직선으로 밀고 당김 |

사진은 장치 종류를 식별하는 예시이며, 최신 출시 모델이나 실습용 구매 목록을 의미하지 않는다. 특히 수중 펌프 사진은 가정용 제품이고 직선 액추에이터는 산업용 예시다. 이 카드는 배선 실습 지침이 아니다. 전력 장치를 마이크로컨트롤러 핀에 직접 연결할 수 있다는 의미로 설명하지 않는다.

## 게임 연결

- 기존 숏코드 `[device_matching]`, 블록, 허브 연결을 그대로 사용한다.
- 6·8·10·12쌍, 별점·점수, 순위 저장, 뒤집기 애니메이션, 오답 후 계속하기는 유지한다.
- 한 도전에서 아직 나오지 않은 장치를 우선 선택한다. 현재 38종에서는 총 36쌍이 전부 다른 장치다. 새 도전은 다시 섞으며 이전 도전과의 중복까지 막지는 않는다.
- 이전 24종 규칙이 전달된 경우에도 부족한 수만 기존 장치에서 채우며, 같은 단계에 동일 장치가 두 쌍 나오지는 않는다.
- 장치 기능 보충 연습도 24문항에서 38문항으로 늘렸다. 전체 개념 문항은 303개다.
- 설명이 잘리지 않도록 카드 높이를 208px로 고정했다. 키보드 접근성은 유지하며 동작 줄이기 설정도 반영한다.

## 사진 검수

Wikimedia Commons의 실제 사진 14개를 다운로드해 플러그인에 포함했다. 게임 중 외부 사진 서버에 접속할 필요가 없다. 사진 전체를 직접 확인했고 부품이 작게 보이는 작업대 사진, 분해된 PIR 사진, 장치 이름과 외형이 불일치하는 후보 등을 제외했다. 생성 이미지나 도식으로 대체하지 않았다.

- [사진별 출처·저자·라이선스](../../assets/device-matching/ATTRIBUTION.md)
- [원본 메타데이터·파일 해시](../../assets/device-matching/expanded-sources.json)
- 게임 하단의 사진 출처 목록에서 38종의 원본 페이지에 접근할 수 있다.
- 원본 사진은 추가 편집하지 않고 Commons 썸네일을 사용했다. 원본 단계의 자르기·편집 이력은 출처 문서에 표시했다.

개념 설명은 [Adafruit DHT 안내](https://learn.adafruit.com/dht/overview), [PIR 작동 원리](https://learn.adafruit.com/pir-passive-infrared-proximity-motion-sensor/how-pirs-work), [FSR 안내](https://learn.adafruit.com/force-sensitive-resistor-fsr), [기울기 스위치 안내](https://learn.adafruit.com/tilt-sensor/overview), [SparkFun 로드셀 안내](https://learn.sparkfun.com/tutorials/getting-started-with-load-cells/all)를 참고하여 각 센서의 측정 대상과 한계를 구별했다.
