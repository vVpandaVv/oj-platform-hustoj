# 2026.09 콘텐츠 보강 적용 내역

작성: 2026-09-11. 대상: `edu-games`의 기존 게임 13종.
코드 보강과 로컬 검증 결과이며, 실제 학급 서버 배포·수업 승인까지 완료했다는 뜻은 아니다.

후속 변경: [게임성 보강·별도 개편 계획](gameplay-redesign-2026-09.md). 자료구조의 기본 화면은 물류 보드로 교체했고 아래 명령 추적 문항은 보조 연습으로 유지한다. 도감·개인 도전 목표·플랫폼 자산 등록도 후속 문서에 기록했다.

## 학습과 기록

- 게임 ID·블록·숏코드·허브 경로·기존 공개 설정을 유지한다. 새 플러그인을 만들지 않았다.
- 문항형 7종은 `Learning_Renderer`를 사용한다. 장치·타이핑·키워드는 기존 게임 아래 보조 활동을 펼쳤을 때만 개념 세션을 시작한다.
- 안내 연습은 힌트를 함께 제공한다. 독립 연습은 제출 후 최대 10회까지 수정할 수 있다. 평가는 첫 제출로 확정하며 힌트·재제출은 차단한다.
- 세트는 최대 6문항이다. 이 규칙은 새 개념 연습에만 적용된다. 문자 코드의 문항별 타이머와 오답·시간 초과 종료, 카드 세트 진행, 타이핑 제한시간은 바꾸지 않았다.
- 다음 문제는 명시적으로 선택한다. 결과를 자동으로 지우지 않는다. 첫 답·최종 답·시도 수·도움 사용·소요 시간을 구분한다.
- 학습 점수는 첫 답 정답률이다. 수정 후 정답률은 별도이며 속도 보너스가 없다. 개념 이해와 타이핑 속도·기억력 점수를 합산하지 않는다.
- 기존 개인·팀 순위와 개인 통계 화면에 새 개념 기록 조회를 추가했다. 새 평가는 버전·난이도를 나눠 최고 점수를 사용하고 동점은 공동 순위다. 다른 학습자는 최소 익명 표기로 표시한다.

## 코드와 저장

문제/정답/허용 정책은 각 `src/Games/Modules/*/Learning_Content.php`가 소유한다. 공유 계약과 세트 전이는 `src/Learning/Question.php`, `Catalog.php`, `Run.php`에 있다. 화면은 `assets/learning`이다.

`/edu-games/v1/learning/{game}/start`, `update`, `resume`, `summary`를 추가했다. 기존 WordPress REST 인증·nonce와 플레이 권한·공개 상태를 사용한다. 서버가 문제 순서를 발급하며 공개 필드만 내려보낸다. 정답·해설은 제출 후에 제공한다.

새 테이블 `{prefix}edu_games_learning_runs`는 별도 옵션 `edu_games_learning_schema=1`로 생성한다. 기존 테이블과 점수는 삭제·이동·재채점하지 않는다. 콘텐츠 `concept-2026-09-v1`, 규칙 `learning-1`, 루브릭 `first-answer-1`을 저장한다. 설치 시 별도의 수동 SQL은 필요하지 않다. 설치 권한/오류는 실제 스테이징 환경에서 확인해야 한다.

사용자·게임·버전·만료시간으로 토큰을 결합하고, 저장은 `revision` 조건부 UPDATE로 선점한다. 중복 요청 ID는 마지막 저장 결과를 반환한다. 충돌은 409로 알리고 다시 읽는다. 확실한 저장 실패는 입력을 유지해 재시도할 수 있다. 세션은 2시간 유효하며 사용자당 분당 새 세트는 10회로 제한한다.

## AI 실험

- scikit-learn 1.8.0, NumPy 2.3.5, SciPy 1.16.3으로 사전 계산했다.
- 0·1·7 손글씨 중 훈련 라벨링 15개, 비교용 검증 108개, 별도 평가 108개를 분리했다. ID 교집합이 없다. 선택하지 않은 훈련 풀 항목은 이 소규모 실험에 사용하지 않는다.
- 모델은 k=3 최근접 이웃, 깊이 6 결정 트리, 로지스틱 회귀다. 필요한 스케일러는 훈련 배치에만 맞춘다.
- 정답 개수마다 무작위 라벨 오염을 반복한다. 0~14개 정답은 40회, 모두 정답은 동일 자료 1회다. 학생이 바로 그 항목을 틀린 상황을 재현하거나 실시간 훈련하는 것은 아니다.
- 평균 정확도와 가장 가까운 대표 실험의 정수 혼동행렬과 지표를 함께 표시한다. 반복 평균과 표준편차는 별도다. 행=실제·열=예측, 지표는 매크로 평균이다.
- 전부 보류한 경우 정답/완료율 0으로 처리하고 성능 비교를 만들지 않는다. 보류율·판단한 항목의 정확도·완료율을 따로 표시한다.
- 타이타닉은 새 기본 화면에서 제외했다. 이전 자료·시도·전용 API·교사 보고서는 호환용으로 보존한다.

생성 파일 SHA-256: `87da762df645590ce169e80ca92f960361c431211144f8cdb43194ff9f912986`.

브라우저 검사는 Chrome/Playwright로 360·768·1280·1440px에서 표·차트·입력을 확인했다. 오류 후 재제출, 첫 답 보존, 새로고침 이어 하기, 기록 조회, 실제 픽셀 클릭·드래그·해제·키보드·되돌리기·8×8 전환·파일 왕복을 포함한다. 그래프의 비어 있지 않은 픽셀도 확인했다. 픽스처는 실제 렌더러와 학습 전이를 사용하지만 WordPress HTTP/DB는 대역이므로 실제 설치 통합 검사를 대신하지 않는다.

전체 355개 검사 후 동일 내용 변형을 수정했다. 변경된 33문항과 공통 흐름은 별도 62개 검사로 재확인했으며, 두 검사 횟수를 중복 없이 전체 문항 수로 합산하지 않는다.

실행 예:

```powershell
D:\php\php.exe tests/regression.php
D:\php\php.exe tests/learning-content.php
D:\php\php.exe tests/learning-state.php
```

타이핑 검사는 `PYTHON_BINARY`, `ZIG_BINARY`를 지정해 `node tests/typing-syntax.cjs`로 실행한다. 기본은 구문/컴파일만 한다. 검토한 배포 예제를 실행하고 출력 자료를 갱신할 때만 `RUN_TRUSTED_SAMPLES=1`을 사용한다. 사용자 입력을 실행하는 서버 기능이 아니며, 이 도구를 임의 학생 코드의 샌드박스로 사용하면 안 된다.

실행 검사는 프로세스 시작 시간을 포함해 예제당 15초, 출력 64KB를 상한으로 한다. Windows에서는 PowerShell을 통해 C 실행 파일을 호출한다. 첫 실행에서 직접 Node 실행이 실패/지연되어 이 경로로 전체를 재검증했다. 운영 서버에서 학생 코드를 실행하지 않는다. 연습 종료 뒤 표시하는 예상 출력은 제시 코드의 출력이지 학생 입력을 실행한 결과가 아니다.

## 남은 승인·확장

1. 실제 WordPress/OJ Platform의 활성화·새 테이블 생성·블록·숏코드·PublicUI 통합을 스테이징에서 확인해야 한다. 로컬 픽스처 성공을 실서버 성공으로 간주하지 않는다.
2. 30명 동시 시작·제출과 6개 반 계정 분리, 실제 DB 경합, p50/p95·오류율은 아직 측정하지 않았다. 180명 완전 동시 접속을 보장하지 않는다.
3. 새 개념 기록의 학급별 교사 집계·오개념 대시보드는 후속 작업이다. 현재 새 화면은 개인 기록과 익명 평가 순위이고, 기존 팀 순위/AI 교사 보고서는 기존 기록 전용이다.
4. 교사의 문항·복수 정답 정책 검토와 학생 5~8명의 이름 가린 그림 인식 파일럿은 미실시다. 이미지 수가 늘었다고 인식률 80%가 검증된 것은 아니다.
5. 데스크톱·모니터 사진은 밝고 단독 구도인 현대 제품 후보를 더 확보해야 한다. 이번 검토에서 구형 제품이나 식별이 더 어려운 후보로 무리하게 교체하지 않았다.
6. 유한 문제 은행의 연습/평가 사이 미노출 보장, 시험 감독, 반별 보존·삭제 정책은 구현하지 않았다. 현재 평가는 형성평가용이며 공식 코딩 역량 인증이 아니다.

기존 설계 명세의 모든 출시 승인 기준이 완료된 것은 아니다. 배포 시 기존 공개 설정을 사용해 교사가 검증한 활동부터 열고, 코드 롤백 시에도 새 테이블을 삭제하지 않아 기록을 보존한다.
