# 변경 기록

## 1.4.0 rc.4

- 서버 프로젝트·파일·로컬 복구 사본을 열 때 URL에 남은 교재 목표를 표시하지 않고 일반 불러오기·복구 안내만 표시합니다. 저장본의 단원은 추측하지 않습니다.
- 새 예제를 열었을 때 현재 시나리오와 교재 링크가 일치하는 경우에만 단원 안내를 표시합니다. 선택창 이름은 **다음에 열 예제**로 바꾸고 기존 교재별 로컬 문맥·초안 보호는 유지합니다.
- 목표 표시·불러오기 핸들러 단위 검사와 선택창·초안 분리 정적 회귀 검사를 추가하고 플러그인·엔진·모듈 캐시 버전을 함께 갱신했습니다.

## 1.4.0 rc.3

- OSPF/BGP 구성도에서 PC-A와 R1 사이 포트 이름이 장비 상자에 가려지지 않도록 간격을 확보했습니다. 경계 잘림과 포트 이름 겹침을 브라우저 회귀 검사에 포함했습니다.

## 1.4.0 rc.2

- OSPF/BGP 초기 예제의 PC-A가 구성도 왼쪽 경계에서 잘리지 않도록 배치했습니다. rc.1 저장 파일 호환과 실행 기능은 유지합니다.

## 1.4.0 rc.1

- Linux IPv6 정적 주소·경로, NS/NA 프레임과 이웃 캐시, ICMPv6 왕복·Hop Limit·출구 MTU/Packet Too Big을 추가했습니다.
- IOS OSPFv2 단일 영역 인접 관계·SPF와 eBGP IPv4 피어·AS_PATH·Weight·광고 철회가 실제 전달 경로를 구성합니다.
- IPv6/OSPF/BGP 초기 예제 및 교재 L21~L23의 직접 실행 링크를 추가했습니다.
- 새 설정의 브라우저·서버 저장 검증과 이전 schema 2 프로젝트 호환을 유지합니다. 실제 타이머·펌웨어가 아닌 교육용 모델의 범위를 명시했습니다.

## 1.3.0 rc.3

- 교재 전용 `?exercise=l01`~`l20` 허용목록과 단일 `CURRICULUM` 배열을 추가했습니다. 지정 예제를 초기 상태로 열고 현재 실습의 제목·업무 목표를 표시합니다. 기존 예제 선택과 명령 도움말은 유지합니다.
- 교재 실습별로 로컬 복구 사본의 저장·목록·20개 보관 한도·삭제 범위를 분리했습니다. 같은 예제를 쓰는 다른 단원과 일반 초안은 덮어쓰거나 정리하지 않습니다. 링크를 다시 열면 초기 구성으로 시작하며 이전 구성은 해당 실습의 복구 목록에서 선택합니다.
- 정상 exercise가 scenario보다 우선합니다. 알 수 없거나 중복된 exercise는 무시하고 기존 scenario 선택·일반 초안 복원으로 돌아갑니다. URL의 임의 제목·목표·문자열은 화면에 삽입하지 않습니다.
- 삭제 등의 확인창 제출을 장비 설정 폼 처리에서 제외해 진행·취소가 정상 작동하도록 수정했습니다.
- 빈 구성의 상태 문구를 짧게 배치해 모바일에서도 화면 밖으로 잘리지 않게 했습니다.
- 20개 매핑, 기존 예제 URL, 신규 시작과 복구·동시 탭·문맥별 삭제·보관, 모바일 목표 표시와 rc.2 설정 호환을 검증하는 테스트를 추가했습니다. DB와 프로젝트 형식, 통신 엔진의 재현 범위는 그대로입니다.

## 1.3.0 rc.2

- 실제 WordPress 화면에서 확인한 Windows 설정 적용 안내를 호스트용 문구로 수정했습니다. IOS/FortiOS의 시작 설정 저장을 Windows에서도 해야 하는 것처럼 표시하지 않습니다.
- Windows GUI 안내와 이전 1.3.0-rc.1 프로젝트 호환 검사를 추가했습니다.

## 1.3.0 rc.1

- Windows PC·서버 프로필과 같은 네트워크 상태를 공유하는 CMD·PowerShell 전환, 전용 프롬프트·도움말·완성·가상 파일을 추가했습니다.
- CMD의 주소·DHCP·DNS·ping·tracert·ARP·경로·연결 조회·findstr과 PowerShell 네트워크 조회·설정을 가상 패킷에 연결했습니다. TCP 연결 검사는 HTTP 요청 없이 핸드셰이크·종료를 수행합니다.
- Windows 방화벽 프로필·규칙·포트·주소·인터페이스·ICMP 조건과 명시적 차단 우선·허용 연결 응답·연관 ICMP 처리를 추가했습니다. 조회·추가·변경·활성화·비활성화·삭제와 WhatIf를 제공합니다.
- 제한된 객체 파이프와 Where/Select/Sort/Measure/Format·Select-String을 추가했습니다. Windows 실습 11, GUI 동기화, 서버 JSON 검증과 기존 자료 호환도 포함합니다.
- 실제 OS·프로그램·.NET·셸 스크립트를 실행하지 않으며 브라우저의 기존 자원 제한을 유지합니다.

## 1.2.0 rc.2

- Ctrl+L 화면 지우기, 선택한 입력의 Ctrl+C 복사, 명령 이력에서 작성 중인 입력 복원을 추가했습니다. 기존 완성·붙여넣기·확인 응답·장비별 모드는 유지합니다.

## 1.2.0 rc.1

- 패턴을 NFA로 처리하며 단계·문자·줄·패턴·상태·공유 작업 예산을 제한합니다. 파이프를 동기 조회로 제한하고 필터를 먼저 검증합니다.
- 분석 도구 도움말·Tab 완성·종료 상태·임시 명령 이력과 TOOLS-GUIDE.md를 추가했습니다. 따옴표 안의 물음표 입력과 출력 텍스트 표시를 검증했습니다.
- 기존 프로젝트 형식과 DB schema를 유지합니다. 이전 1.1.0 후보 버전도 현재 버전으로 읽습니다.
