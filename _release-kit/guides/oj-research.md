## 서버 준비

공통 서버 안내의 OJ Platform 설치 단계를 완료합니다. 연구 플러그인을 위해 추가 서버 프로그램을 설치할 필요는 없습니다. PHP는 함께 사용하는 OJ Platform의 요구 버전을 따릅니다.

## 업로드

1. OJ Platform을 먼저 활성화합니다. 공통 애드온 API 1.2 이상, 2.0 미만을 사용합니다.
2. WordPress **플러그인 → 새 플러그인 추가 → 플러그인 업로드**에서 `{{package}}`를 설치·활성화합니다. 기존 설치는 교체 업데이트합니다.
3. 신규 사이트에 설치 재개 안내가 나오면 OJ 설치 화면에서 실행합니다. 연구용 테이블 3개만 추가하며 기존 수준 평가와 연구 자료를 재계산하지 않습니다.

## 관리자 화면 설정과 수업

1. **OJ Console → 운영 → 기능 관리 → 그룹 수업 연구**를 켜고, **학습지원 → 수업 연구**로 이동합니다.
2. **수업 만들기**에서 대상 그룹, 문제 번호, 차시, 풀이 시간, A·B 비교 조건을 정합니다. 기본은 수준별 AI와 공통 AI 비교이며 AI 없는 수업과의 비교도 선택할 수 있습니다.
3. 시작·종료 설문이 기본 제공됩니다. 문항·척도, AI 한도, 배정 방식, 선택 사전·사후 과제는 모달에서 수정합니다. **수업 맥락·보고서 설명 설정**에서 학년·경험·언어·기기·기간·교사 도움·해설 공개 시점을 선택하고 학습 내용과 중점 지표는 체크합니다. 새 수업에는 수준별 AI 피드백의 알고리즘 학습 효과를 살펴보는 중학교 수업 예시(4주·6차시·45분)가 채워집니다. 실제 조건으로 수정하세요. 선택은 보고서 문장으로 정리되고 기존 연구의 설명은 유지됩니다. 시작 설문은 자기보고이며 기존 학생 수준을 변경하지 않습니다.
4. 참여 동의 확인 방식을 선택하고 **자료 보관 계획 선택 · 용어 안내**에서 장소·담당자·기간·폐기·철회 방법을 고릅니다. 동의서 이름·관리번호는 문서를 찾기 위한 선택 항목으로, 없으면 비워 둡니다. 실제 동의서나 학생 이름은 입력하지 않습니다. 미정 상태로 설정 저장은 가능하며 시작 설문을 열기 전에는 계획을 정해야 합니다. 기존 서술은 **직접 절차 작성**으로 유지할 수 있습니다. 동의를 확인한 학생만 선택해 **시작 설문 열기**를 누르면 기존 수준과 AI 지침·모델 설정을 보관하고 조건이 고정됩니다. 검수한 정답·해설 자료는 등록 전에 준비합니다.
5. 학생은 로그인 후 `/research`에서 설문에 응답합니다. 교사가 **수업 시작**을 누르면 A·B가 자동 배정됩니다. 학생은 **풀이 시작**을 눌러 기존 OJ 문제 화면에서 제출하고 배정된 조건에 따라 AI를 사용합니다.
6. 다음 차시는 버튼 하나로 진행합니다. 마지막 차시를 마치면 종료 설문이 열립니다. 시작·마무리 과제를 선택한 경우 해당 활동이 사이에 추가됩니다. 학생의 과제 완료 확인이 있어야 성취 점수를 계산합니다.
7. **보고서·첨부자료**를 열면 최신 판정과 설문이 반영됩니다. 시스템 작동, 학생 경험, 학습 수행을 구분하고 문항별 응답 인원·해당 없음·무응답을 표시합니다. 교사 관찰·학생 명단·운영 설정은 필요할 때 모달로 엽니다. 설문과 세부 조건을 모달에서 편집한 경우 창을 닫은 뒤 수업 설정을 저장합니다.
8. 결과 보고서, 전문가 자문 요청서와 첨부자료(설문지·운영 조건과 AI 지침·문제 자료·결과 상세표·교사 관찰 및 자유 의견)를 각각 선택합니다. **미리보기**는 모달, **별도 열기**는 독립 화면입니다. 각 문서를 HTML(인쇄/PDF), Markdown으로 내려받고 전체 분석 자료는 CSV·JSON으로 받습니다. 전문가 의견은 검토자가 작성하며 자동 판정하지 않습니다. 공유 전 자유 의견의 개인 정보를 확인합니다. JavaScript가 꺼져 있어도 별도 문서와 펼침 설정을 사용할 수 있습니다.
9. 설문과 채점 확인 후 **수업 보관**을 누르면 입력을 닫고 결과를 고정합니다. 대기 중인 제출이 있으면 보관을 막습니다.

### 해석 기준

- 기본 설문은 시작 자기평가 3문항, 종료 자기평가 3문항·수업 만족도 1문항·AI 경험 3문항입니다. 조건문·반복문·오류 위치 찾기를 각각 묻고 시작·종료 자기평가 문구를 맞췄습니다. 5점 척도는 모든 점수의 의미를 표시합니다. AI를 사용하지 않았거나 읽지 않았다면 AI 문항에서 해당 없음을 고릅니다. 기존 저장 문항은 바뀌지 않습니다. 현장용 초안이므로 전문가 문항 검토와 소수 학생의 문장 이해 확인이 필요합니다.
- **목표 인원 비율**은 A·B에 배정할 인원의 상대 비율입니다. 1:1은 비슷한 인원, 2:1은 A가 B의 약 두 배를 뜻합니다. 점수·수준·AI 한도와 무관합니다. 수준별 인원이 적거나 그룹 단위로 배정하면 실제 비율은 달라질 수 있습니다.
- **공통 AI용 실제 프롬프트**는 공통 AI 조건의 모델 요청에 전달됩니다. 모든 집단 공통 메모가 아닙니다. 수준별 AI는 등록 시 보관한 기존 수준별 지침을 사용하며 AI 사용 안 함에서는 AI 요청을 차단합니다. 등록 뒤에는 지침도 고정됩니다.
- 수업 중 정답률과 재제출 변화는 수행 기록입니다. 독립 성취 향상을 보려면 별도의 시작·마무리 과제와 비교 조건을 설정합니다.
- AI 전달 기록은 읽기·이해·활용을 증명하지 않습니다. 현재 자동 수집에는 코드 변경분, 전체 실패 요청 비율, AI 지연 계측이 포함되지 않습니다.
- 만족도만으로 학습 효과를 판단하지 않습니다. 교사 도움·반복 연습 등은 관찰에 남기고 전문가가 결론의 범위를 검토합니다.
- 그룹은 수업을 표시하는 단위, A·B는 비교 조건입니다. 기본 배정은 선택한 그룹 전체 학생을 기존 수준별로 층화합니다. 학급 자체를 비교하려면 그룹 단위 배정을 선택합니다.
- 기존 상세 연구·독립 채점 연구는 그대로 유지됩니다. 새 간편 수업으로 자동 변환하지 않습니다.
- 보관·폐기, 교사 도움, 해설 공개, 외부 AI 사용 선택은 운영 계획을 기록하는 항목입니다. 파일을 자동 이동·삭제하거나 외부 접속을 차단하지 않습니다. 보관 기간은 기관 기준에 맞게 선택합니다. 중점 지표 선택은 분석 계획에 반영되며 기본 지표를 숨기거나 수집 범위를 바꾸지는 않습니다.

## 삭제 시

진행 중인 연구는 종료·보관한 뒤 비활성화합니다. 플러그인 파일을 삭제해도 연구 테이블은 남으며 재활성화하면 다시 연결합니다. 활성 연구가 남은 상태로 파일을 제거하면 플랫폼이 해당 학생의 연구 제출·AI를 차단합니다. 연구 자료가 있는 계정 삭제는 플러그인을 활성화한 상태에서 처리합니다.
