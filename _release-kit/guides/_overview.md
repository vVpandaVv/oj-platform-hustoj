## 설치 순서

1. **서버 준비** — [00-server-setup.md](00-server-setup.md)를 1단계부터 순서대로 진행합니다. 처음 한 번만 하면 됩니다.
2. **OJ Platform** — 관리자 화면에서 업로드하고 설치 마법사와 채점 DB 연결을 마칩니다.
3. **애드온** — 필요한 것만 관리자 화면에서 업로드하고, 각 안내서의 설정을 합니다.

PRIMM은 플랫폼을 먼저 설치한 뒤 별도 ZIP으로 설치합니다. 코드 순서 배열과 코드 빈칸 채우기 도움 활동은 플랫폼 2.3.23 이상을 사용하며, PRIMM용 별도 서버 설치 단계는 없습니다.

## 관리자 화면에서 ZIP 올리는 방법 (모든 플러그인 공통)

1. 관리자 화면 **플러그인 → 새 플러그인 추가 → 플러그인 업로드**
2. `packages/` 폴더의 ZIP 선택 → **지금 설치**
3. 이미 설치된 플러그인이면 **현재 파일을 업로드된 파일로 교체**
4. **플러그인 활성화**

`content/` 폴더의 파일은 플러그인이 아닙니다. 업로드 화면에 올리지 마세요.

## 서버 준비 단계

**1~12단계는 공통 필수**입니다(6단계 phpMyAdmin은 DB 관리용 권장). 아래는 해당 플러그인을 쓸 때 진행합니다.

기존 서버의 보안 업데이트는 **20단계 백업 → 2단계 OS·PHP 패키지 확인과 갱신 → 5단계 HTTPS 헤더·GET 응답 확인** 순서로 진행합니다. 앱 ZIP 교체 후에는 필요한 스키마 갱신과 실제 기능 확인까지 마칩니다.

## 삭제할 때 주의

비활성화는 모든 플러그인에서 데이터를 유지합니다. **삭제**하면 다음 플러그인은 자료를 지웁니다: Edu Games(점수 기록), Learning Materials(자료 파일), Code Arena(경기 기록), ReadContents(읽기자료 전체), Teaching Tools(세션 기록).

## 서버 준비 안내

상시 OJ 서버 설치 메뉴는 표시하지 않습니다. 필수 준비가 빠졌다면 플러그인 목록 또는 관리자 OJ 콘솔 첫 화면의 안내를 따라갑니다. AI·ML은 필수 저장소 준비 전 활성화가 제한될 수 있으므로 플러그인 목록에서 먼저 해결합니다. 활성화 후에는 각 플러그인 설정의 **서버 설치·복구**에서 명령을 복사합니다. 준비를 마치고 새로고침하면 안내가 사라집니다.
