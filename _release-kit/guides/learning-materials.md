## 하는 일

PDF·PPT·Word·Excel·텍스트·이미지 파일(파일당 최대 50MB)과 Google 문서 공유 링크를 반·그룹에 공유합니다.

## 1. 서버 준비

[서버 준비](00-server-setup.md) 1~12단계(필수)를 마치고 OJ Platform을 설치한 뒤 진행합니다. 업로드 한도는 7·8단계에서 이미 128MB로 설정됩니다.

OJ Platform `{{platform_requires}}` 이상이 필요합니다.

## 2. 업로드

관리자 화면에서 `packages/{{package}}`를 업로드하고 **활성화**합니다.

## 3. 관리자 화면 설정

| 화면 | 설정 |
|---|---|
| `/oj-console/roles` | 자료 관리(교사), 자료 열람(학생) 권한 |

교사 화면은 `/oj-console/addons/learning-materials`, 학생 화면은 `/oj-addons/learning-materials`입니다.

Learning Materials 1.1.0은 OJ Platform 2.3.0 / Addon API 1.4의 활동 제공자로 공식 등록됩니다. Teaching Tools 같은 다른 애드온은 이 플러그인의 내부 테이블·클래스·REST 라우트를 직접 읽지 않고, 플랫폼의 `AddonIntegrationGatewayV1`을 통해 현재 사용자가 열 수 있는 자료만 검색합니다.

- 목록에서 제목·설명·파일명·분류·태그를 검색하고 형식·분류·태그·그룹으로 필터링합니다. 학생 목록은 12개, 관리 목록은 20개씩 표시합니다.
- 등록·편집 화면에서 **분류**, 쉼표로 구분한 **태그**(최대 10개, 각 40자), **상단 고정**을 설정합니다. 고정한 자료가 먼저 표시됩니다.
- 새 자료는 **초안**으로 시작합니다. **공개**로 바꾸면 학생에게 표시되고 **보관**은 학생에게 숨깁니다. 기존 버전의 자료는 공개 상태를 유지합니다.
- **공개 시작·종료**는 WordPress 사이트 시간대로 입력합니다. 시작 시각부터 공개하고 종료 시각부터 숨깁니다. 비워 두면 기간 제한이 없습니다. 별도 예약 작업 없이 요청 시마다 확인합니다.
- 초안·보관·공개 전·공개 종료 자료는 학생의 직접 주소와 다운로드도 차단합니다. 관리자는 상세 화면에서 미리볼 수 있습니다.
- 상세 화면의 **새 창에서 보기**, **원본 다운로드**(링크 자료는 **Google에서 열기**)를 대체 경로로 제공합니다.
- 관리자 상세 화면의 **관리자 미리보기 진단 → 진단 실행**에서 원본 파일, 기존 링크 만료, 로그인 없는 파일 접근, Google의 204 응답·iframe 제한·연결 실패를 확인합니다. Google 공유 문서는 원본 공유 권한도 별도로 확인합니다. 진단은 서버 응답을 확인하며 브라우저 내부의 슬라이드 렌더링까지 보장하지는 않습니다.

이 애드온의 저장 항목과 보관 안내는 OJ Platform의 **운영 → 약관과 정책** 통합 재고에 등록됩니다. 사이트의 개인정보 처리방침은 해당 플랫폼 화면에서 관리자가 통합해 작성·게시하며, 이 플러그인은 별도 문구를 제시하지 않습니다.

업로드 지원 확장자는 PDF, PPT, PPTX, DOC, DOCX, XLS, XLSX, TXT, CSV, JPG, JPEG, PNG, GIF, WEBP입니다. PDF·텍스트·이미지는 사이트에서 직접 표시하고, PowerPoint·Word·Excel은 자료 상세 화면을 열면 Google 미리보기를 자동으로 표시합니다. 실패하면 **다시 시도**를 누르거나 상단 **다운로드**로 원본을 받습니다. 업로드 파일 미리보기에는 Google 계정이나 Drive 업로드가 필요하지 않습니다. 사이트는 Google 서버에서 접근 가능한 HTTPS 주소여야 하며, 방화벽·접근 제한이 있으면 미리보기가 실패할 수 있습니다.

자료 등록·편집 화면에서 파일 대신 **Google 공유 링크**를 붙여 넣을 수 있습니다. Google 문서·시트·슬라이드 및 Drive 파일 링크를 지원하며, 웹에 게시된 문서 링크도 사용할 수 있습니다. 링크 자료도 자동으로 미리보기를 표시하고 상단 **Google에서 열기**로 원본을 엽니다. Google 공유 권한은 자동으로 바뀌지 않습니다. 수업 대상에게 공유하거나 링크 보기 권한을 설정해야 하며, 제한된 문서는 학생의 Google 로그인이 필요할 수 있습니다. 파일로 바꾸려면 Google 링크를 지우고 새 파일을 선택합니다.

업데이트 시 기존 자료와 그룹 연결을 유지하면서 링크·분류·태그·고정·공개 상태·공개 기간 열이 자동으로 추가됩니다. 링크 자료를 삭제해도 Google 원본 문서는 삭제되지 않습니다.

외부 URL 뷰어를 사용하므로 Google API 키나 OAuth 설정은 필요하지 않습니다. 뷰어 주소는 `embedded=true`를 사용합니다. `embedded=1`은 Google의 SAMEORIGIN 응답으로 사이트 안에서 표시가 차단될 수 있습니다.

업로드한 Office 자료를 열면 로그인·열람 권한·그룹·공개 기간을 확인하고 파일별 10분짜리 서명 링크를 발급합니다. 링크 소유자는 만료 전까지 파일을 받을 수 있으며 Google에도 링크와 파일이 전달됩니다. 파일 교체·삭제 또는 공개 그룹·상태·기간 변경 시 기존 링크는 무효가 됩니다. 학생용 링크는 공개 종료 시각에도 차단합니다. 관리자의 초안 미리보기 링크는 별도로 서명합니다. 링크 만료가 Google에서 이미 가져간 사본의 삭제를 보장하지는 않습니다. 등록한 Google 공유 링크는 Google의 원본 뷰어로 연결하며 별도 파일 서명 링크를 만들지 않습니다.

외부 Google URL 뷰어는 공식 범용 API로 지원이 보장되지 않습니다. Google의 간헐적인 204 빈 응답으로 프레임이 비어 있으면 12초 간격으로 최대 3회 로드를 시도합니다. 자동 재시도는 같은 서명 링크를 사용하며, 뷰어의 예기치 않은 자동 다운로드는 차단합니다. 최종 실패하면 상단 **다운로드**를 이용합니다. 외부 뷰어 내부의 오류까지 자동 판별할 수는 없으며, **다시 시도**를 누르면 새 링크를 발급합니다.

연동 API는 `POST /wp-admin/admin-post.php?action=learning_materials_preview_link`입니다. 로그인 쿠키, `material_id`, `wp_create_nonce('learning_materials_preview')`로 생성한 `nonce`가 필요합니다. 응답의 `data.viewer_url`을 사용하며, 업로드 파일에는 `data.expires_at`도 포함됩니다. 파일 제공 액션 `learning_materials_preview_file`은 로그인 대신 서명·만료 시간·현재 파일과 공개 그룹을 검증하고 GET·HEAD·단일 바이트 범위 요청을 지원합니다. 두 API 응답은 캐시하지 않아야 하며, 서명 URL 쿼리는 접근 로그에서 숨기는 것이 좋습니다.

진단 API는 `POST /wp-admin/admin-post.php?action=learning_materials_diagnose`이며 자료 관리 권한, `material_id`, `wp_create_nonce('learning_materials_diagnostics')`로 만든 `nonce`가 필요합니다. `expires_at`을 선택적으로 전달하면 기존 링크의 만료도 검사합니다. 응답은 `data.checks`의 `label`, `status`(ok/warning/error), `message`이며 서명 URL이나 서버 파일 경로는 포함하지 않습니다.

판서 등 다른 애드온의 활동 목록에는 현재 로그인한 사용자가 학습자료 열람 또는 관리 권한으로 볼 수 있는 공개 자료만 제공합니다. 목록 제공과 실제 보호 파일 열람에 같은 권한·그룹·공개 기간 기준을 적용하며, 수업에 자동 참가해도 자료 접근 권한은 우회하지 않습니다.

## 삭제 시

그룹 필터와 자료의 공개 그룹에는 그룹명을 표시합니다. 관리자는 학생으로 등록되지 않은 그룹도 해당 그룹의 관리 권한으로 이름을 조회합니다. 일반 사용자는 가입 권한이 확인된 그룹명만 조회할 수 있습니다.

자료와 업로드 파일이 모두 삭제됩니다(비활성화는 유지).
