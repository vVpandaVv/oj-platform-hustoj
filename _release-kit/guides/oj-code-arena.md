## 하는 일

실시간 팀 대전 타자·코딩 게임입니다. 기본 내장 엔진은 업로드만 하면 바로 동작합니다.

WordPress ZIP에 원클릭 설치용 서버 파일도 포함됩니다. 별도 `packages/oj-code-arena-server-{{version}}.zip`은 수동·원격 서버 설치용이며 **WordPress 업로드 화면에 올리지 마세요.**

## 1. 서버 준비

[서버 준비](00-server-setup.md) 1~12단계(필수)를 마치고 OJ Platform을 설치한 뒤 진행합니다.

선택: 응답이 느리면 **18-1단계(공통 실시간 서버의 아레나 모듈)**. 티칭툴은 설치하지 않아도 됩니다.

## 2. 업로드

관리자 화면에서 `packages/{{package}}`를 업로드하고 **활성화**합니다. 기본 문제은행과 권한이 자동으로 준비됩니다.

## 3. 관리자 화면 설정

| 화면 | 설정 |
|---|---|
| `/oj-console/roles` | 학생 `oj_code_arena_play`, 교사 `oj_code_arena_teach`. 설정을 맡길 교사에게는 `oj_code_arena_settings`(코드 아레나 설정) |
| `/oj-console/addons/oj-code-arena/settings` (**교사 메뉴 › 코드 아레나 › 설정**, 사이트 관리자 또는 '코드 아레나 설정' 권한을 받은 교사) | 게임 엔진, 자유 대전, 경기 기록 보관 기간. **부하 시험** 실행: p95가 600ms 이하면 내장 엔진 유지, 1.5초를 넘으면 서버 준비 18단계 진행 |

교사 화면은 OJ 콘솔 **코드 아레나**(`/oj-console/addons/oj-code-arena`) 한 메뉴이고, 화면 안에서 수업 게임 · 문제은행 · 경기 기록 · 설정으로 옮겨 갑니다. 설정 탭은 사이트 관리자와 설정 권한을 받은 교사에게만 보입니다. 학생 화면은 `/oj-addons/oj-code-arena/play`입니다.

학생 로비·대기실·경기 화면은 에듀게임과 같은 밝은 바탕, 공통 서체·버튼·최대 1120px 너비를 사용합니다. 아레나 자체 자산으로 동작하므로 에듀게임 설치는 필요하지 않습니다. UI 업데이트만을 위해 게임 서버를 재설치하거나 연결 설정을 바꿀 필요는 없습니다. 에듀게임의 순위 삭제 기능은 아레나 경기 기록에 적용되지 않습니다.

WordPress 관리자 화면에는 코드 아레나 설정 메뉴가 없습니다. 플러그인 목록의 **설정** 링크는 콘솔 설정 화면으로 갑니다.

웹소켓을 쓰려면 **내장 엔진을 유지한 채** 고급 설정에서 같은 사이트의 `wss://사이트/arena`와 내부 주소 `http://127.0.0.1:3210/arena`를 저장합니다. **서버 원클릭 설치** 명령을 서버 SSH에서 실행한 뒤 **공통 실시간 서버(WebSocket)**로 전환하고 상태 확인과 실제 수업 입장을 확인합니다. 구체적인 서버 작업은 **18-1단계**를 따릅니다. 기존 3200 독립 서버 사용자도 내부 주소를 3210으로 바꾼 후 새 명령을 실행합니다.

두 플러그인은 각각 공통 서버 런타임을 포함하므로 **어느 것을 먼저 설치해도 되고 하나만 운영해도 됩니다.** 이미 서버가 있으면 아레나 모듈만 추가하고 다른 모듈의 등록·인증키·데이터를 보존합니다. 같은 서버를 써도 각 플러그인의 설치 명령은 한 번씩 실행해 모듈을 등록해야 합니다.

설치·업데이트는 수업이 없을 때 실행합니다. 공통 서버 재시작은 모든 실시간 연결에 영향을 주며 진행 중 경기는 종료됩니다. WordPress 경기 기록과 서버의 미전송 결과 파일은 유지합니다. 상태 확인은 HTTP 통신·아레나 등록·비밀키 인증 검사이며 브라우저 WebSocket은 실제 입장으로 확인합니다.

## 삭제 시

경기 기록과 문제은행이 삭제됩니다(비활성화는 유지).
공통 Node 서비스는 WordPress 플러그인 삭제로 제거되지 않습니다. 서버 준비 **18단계의 모듈 제거 절차**로 아레나 등록만 해제합니다. 티칭툴 등 다른 모듈이 사용 중이면 공통 서비스를 중지·삭제하지 않습니다. 미전송 결과가 남아 있으면 먼저 보관합니다.

## 서버 설치 창

설정의 **서버 설치·복구** 창에서 명령을 복사해 같은 서버의 SSH에서 실행합니다. 주소를 먼저 저장하고, 실행 후 WebSocket 엔진을 선택해 상태를 확인하세요.

공통 준비 화면은 OJ Platform 2.2.7 이상에서 제공합니다. 명령은 서버 설치 권한이 있는 관리자가 실행합니다.

서버 준비가 필요한 경우에만 플러그인 목록과 관리자 OJ 콘솔 첫 화면에 안내합니다. 준비를 마치면 새로고침 후 안내가 사라집니다. 상시 OJ 서버 설치 메뉴는 표시하지 않습니다. 실시간 서버는 사용하도록 선택한 경우 설정 화면에서 연결을 자동 확인합니다.
