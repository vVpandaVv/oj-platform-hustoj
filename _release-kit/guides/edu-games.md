## 하는 일

교육 미니게임 13종과 개인·팀 순위, 학습 통계를 제공합니다.

## 1. 서버 준비

[서버 준비](00-server-setup.md) 1~12단계(필수)를 마치고 OJ Platform을 설치한 뒤 진행합니다. 추가 서버 작업은 없습니다.

## 2. 업로드

관리자 화면에서 `packages/{{package}}`를 업로드하고 **활성화**합니다. (1.2.0 ZIP은 쓰지 마세요.)

## 3. 관리자 화면 설정

| 화면 | 설정 |
|---|---|
| `/oj-console/addons/edu-games/manage` | 게임별 공개·비공개, 팀 (콘솔 메뉴 **학습 활동 › 교육 게임**) |
| `/oj-console/roles` | 학생 `edu_games_play`, 교사 `edu_games_manage` |

게임 기록과 AI 모델 훈련소 성적은 같은 메뉴 화면 위의 구획에서 엽니다(OJ Platform 2.1.0 이상).

학생 화면은 `/oj-addons/edu-games/games`입니다.

13종 게임은 공통 서체·버튼·점수판과 최대 1120px 너비를 사용합니다. 게임 허브·블록·숏코드에 동일하게 적용하며, 게임판 고유 조작과 채점 규칙은 유지합니다. 게임 아래 **순위와 기록**을 펼치면 순위를 볼 수 있습니다.

OJ Platform 2.1.0 이상에서는 계정 메뉴의 **화면 모드 → 라이트·다크·시스템** 선택이 게임·허브·순위와 집중 화면에도 적용됩니다. 시스템은 기기의 밝기 설정을 따릅니다. 진행 중 모드를 바꿔도 입력·선택·점수는 유지되고, 그래프 축·격자의 색도 바뀝니다. 사진·팔레트·직접 칠한 픽셀·손글씨 표본의 색은 바꾸지 않습니다. 별도 게임 설정이나 데이터 이전은 필요하지 않습니다. 업데이트 후 기존 탭은 새로 고침해 변경된 자산을 불러오세요.

게임을 시작하면 **집중 화면**이 열리고 점수·게임판·필수 조작을 화면 높이에 맞춰 배치합니다. 이미지 제작·복원 등은 상단 **모니터 버튼**으로 엽니다. **X 또는 Esc**로 원래 페이지로 돌아오며 입력·선택·진행 기록은 유지됩니다. 나가기는 일시 정지가 아니므로 진행 중인 게임의 시간은 계속 흐릅니다. 순위로 이동하면 집중 화면을 닫고 기록을 표시합니다. 아주 작은 창이나 화면 확대에서는 글자와 조작을 숨기지 않도록 내부 스크롤을 허용합니다. 추가 설정·서버 설치·데이터 이전은 필요하지 않습니다.

사이트 관리자(`manage_options`)로 로그인하면 개인 순위의 기록 옆에 **휴지통 버튼**이 표시됩니다. 확인창에서 이름·점수를 확인한 뒤 **기록 삭제**를 누르면 해당 도전 한 건이 영구 삭제되고 순위·관련 통계가 갱신됩니다. 같은 학생의 다른 기록이 있으면 다음 최고 기록이 다시 표시됩니다. 학생의 모든 기록을 한 번에 지우는 동작은 아닙니다. 일반 교사의 `edu_games_manage` 권한만으로는 삭제할 수 없으며 진행 중 도전·별도 수집 진도는 삭제하지 않습니다. 삭제 후 복구는 데이터베이스 백업이 있어야 가능합니다.

게임 하단에 자동으로 붙던 별도 개념 문제 풀이·평가 영역은 표시하지 않습니다. 게임 자체의 연습·도전·검정과 점수·순위는 그대로이며, 기존 개념 평가 데이터와 기록 조회도 유지됩니다.

데이터·AI 게임 7종은 점수·남은 시간·연속 성공·개인 최고 기록을 상단에 표시합니다. 상황 변경은 **도전 설정**, 다시 도전과 순위 조회는 종료 화면에서도 가능합니다.

- 이상치는 숫자를 검토함으로 옮겨 평균 변화를 확인하고, 결측값은 복원 도구와 관측값으로 빈칸을 채웁니다. 결측값의 결과 확인 시간은 경쟁 시간에서 제외합니다.
- 데이터 추출은 색·모양 관문과 출고 라벨을, 자료구조는 입고·스택·큐·배송 상자를 직접 조작합니다.
- 시각화는 그래프 선택·적재 범위·보급품 배정에 따라 지원 결과가 바뀝니다. 분류 경계는 경계선과 배송길을, 손글씨 로봇은 이름표·9칸 기억·오인식 근거를 함께 보여 줍니다.

별도 설정이나 데이터베이스 이전은 필요하지 않습니다. 결측값은 시간 계산 변경에 맞춰 새 순위로 분리하며 이전 기록은 보관 조회에 남습니다. 다른 게임의 채점 규칙과 기존 기록은 유지합니다.

장치 카드는 카드 수와 화면 폭에 맞춰 마지막 줄까지 채워 배치합니다. 카드 안에서 분류 라벨을 위한 공간을 확보하고 남은 영역에 사진 전체를 비율대로 맞추므로, 집중 화면에서 카드가 작아져도 사진이 잘리지 않습니다. 오답 두 장은 잠시 공개한 뒤 다시 뒤집히며 닫기가 끝나면 다음 카드를 선택할 수 있습니다. 오답 대기 중 다시 시작하면 이전 뒤집기 예약을 취소합니다. 맞힌 카드가 사라진 자리는 기억한 위치를 유지하기 위해 그대로 둡니다. 문자코드의 계정 기록 동기화 오류와 이진수 게임이 스크롤 중 사이트 메뉴를 덮는 레이어 문제도 수정했습니다. 이 수정에 따른 추가 설정은 없습니다.

Safari 호환성을 위해 카드 앞·뒷면을 명시적으로 전환하고 3D 합성에 의존하지 않는 접힘 애니메이션을 사용합니다. 화면 회전 후에도 오답 카드가 닫히고 다음 선택을 받도록 하며 사진 전체 맞춤은 유지합니다. 이진수 입력·커서 보존, 긴 낙하 단어의 가장자리 표시, 결측값 계산식·문자코드 복원·시각화의 좁은 화면 배치도 보완했습니다. 업데이트 후 기존 탭은 새로 고침해 변경된 자산을 불러오세요. 별도 설정이나 데이터 이전은 필요하지 않습니다.
