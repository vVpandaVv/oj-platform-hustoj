## 하는 일

교육 미니게임 13종과 개인·팀 순위, 학습 통계를 제공합니다.

## 1. 서버 준비

[서버 준비](00-server-setup.md) 1~12단계(필수)를 마치고 OJ Platform을 설치한 뒤 진행합니다. 기본 REST 모드는 추가 서버 작업이 없습니다. 이진수·장치 카드 팀전에 WebSocket을 사용하려면 같은 안내서의 **18-3단계**로 공용 서버에 에듀게임을 등록합니다.

## 2. 업로드

관리자 화면에서 `packages/{{package}}`를 업로드하고 **활성화**합니다. (1.2.0 ZIP은 쓰지 마세요.)

## 3. 관리자 화면 설정

| 화면 | 설정 |
|---|---|
| `/oj-console/addons/edu-games/manage` | 게임별 공개·비공개, 팀 (콘솔 메뉴 **학습 활동 › 교육 게임**) |
| `/oj-console/addons/edu-games/team-games` | 실시간 팀전 교사 운영실·정식 경기 생성·팀 배정·현황판 |
| `/oj-console/roles` | 학생 `edu_games_play`, 교사 `edu_games_manage` |

이전 이름의 교육 게임을 사용한 사이트에 `oj_addon_hustoj_edu_games_play` 권한이 남아 있으면, 승인된 Edu Games가 이 키 하나를 학습자 권한으로 호환 선언합니다. 이 권한 때문에 일반 학생의 사용자 목록·그룹 비밀번호 초기화가 보호 계정으로 오탐되는 경우를 방지합니다. 기존 역할·개별 권한을 추가하거나 삭제하지 않으며 게임 접근 권한을 새로 부여하지 않습니다. 이전·현재 관리 권한과 다른 미등록 권한, 관리자·superadmin 보호는 그대로 유지합니다. 호환 선언은 Edu Games가 정상 승인된 요청에서만 적용됩니다. 공개 애드온 API와 DB 구조는 바뀌지 않습니다.

게임 기록과 AI 모델 훈련소 성적은 같은 메뉴 화면 위의 구획에서 엽니다(OJ Platform 2.1.0 이상).

학생 화면은 `/oj-addons/edu-games/games`입니다.

### 게임 순위

`/oj-addons/edu-games/ranking`에서 왼쪽 게임 목록을 선택합니다. 휴대폰에서는 상단 선택 메뉴를 사용합니다. 참여자 수·최고 점수·내 순위와 상위 기록을 먼저 표시하고, 전체 참여자는 20·50·100명씩 페이지를 나눕니다. 본인 행은 파란색으로 강조하며 다른 페이지를 보아도 내 순위는 전체 기준으로 유지합니다. 라이트·다크 화면 모드를 따릅니다.

**기록**에서 현재 게임과 이전 규칙 기록을 구분합니다. 이전 보드·평가는 도전별로 조회합니다. 기존 이름 공개 범위·동점 기준·0점 기록·관리자 한 건 삭제는 유지합니다. **팀 평균 순위**는 소속 팀원의 개인 최고 기록 평균이며 실시간 팀전 경기 결과가 아닙니다. **팀 내 순위**는 소속 팀 참여자만 집계합니다. 팀 초대 코드 참여·나가기는 **내 팀**, 팀 생성·관리는 콘솔에서 제공합니다. 기존 블록·숏코드의 순위와 게임 규칙은 바꾸지 않습니다. 추가 데이터 이전·서버 변경 없이 업데이트 후 순위 탭을 새로 고침합니다.

### 이진수 실시간 팀전

개인전은 그대로 유지합니다. 게임 허브 또는 이진수 개인전 상단의 **실시간 팀전**으로 입장합니다. 직접 주소는 `/oj-addons/edu-games/binary-team`이며, 일반 페이지에는 **이진수 팀전** 블록 또는 `[binary_team]`·`[oj_binary_team]`을 넣을 수 있습니다. 이진수 게임을 비공개하면 팀전도 학생에게 비공개됩니다.

교사의 경기 만들기 → 6자리 코드 공유 → 학생 참가 → 팀 편성 → 모두 준비 → 교사 시작 순서입니다. 2~6팀, 팀당 2~6명이며 모든 팀 인원이 같아야 시작합니다. 30명은 6팀×5명으로 편성합니다. 학생은 정식 경기 참가와 자기 **연습방** 생성만 할 수 있습니다. 정식 경기의 팀 배정·시작·일시 정지·재개·종료·재경기는 교사 전용입니다. 경기용 팀은 기존 그룹·팀 순위의 소속을 바꾸지 않습니다.

같은 팀의 8줄 게임판을 함께 조작하되 한 줄에는 한 명의 담당 표시가 붙어 충돌을 막습니다. 다른 줄은 동시에 해결합니다. 담당은 직접 놓거나 마지막 조작 후 9초가 지나면 해제됩니다. 비트·합계·점수·남은 시간을 공유하며 새로 고침 후에도 재접속합니다. 진행 중 새 참가·팀 변경은 불가하고, 접속이 끊겨도 시작 인원 기준 난도를 낮추지 않습니다.

게임판은 개인전과 같은 연속된 8줄 격자·가운데 위험선·사각형 비트 버튼·현재값 칸을 사용하고 담당 열만 추가합니다. 빈 줄과 비트 사이에 별도 상자나 여백을 두지 않습니다. 위아래 자리값은 비트 열에 맞추고, 좁은 화면에서는 문제·입력·담당을 비트 위로 옮깁니다. 보드 이름·출제 간격·역변환 비율은 **팀 현황**을 펼쳐 확인합니다. 이 화면 수정에는 DB 이전·WebSocket 서버 재설치가 필요하지 않습니다. ZIP 업데이트 후 기존 탭을 새로 고침하세요.

역변환은 개인전처럼 정확한 10진수 값이 완성되면 **Enter 없이 자동 제출**합니다. 입력 중인 숫자와 IME 조합 중에는 오답을 자동 제출하지 않습니다. Enter·제출 버튼도 유지하며 같은 줄의 중복 제출은 합칩니다. 정답 인정·점수·담당 잠금은 기존 서버가 판정하고 기존 제출 간격 제한도 유지합니다.

개인전보다 출제가 빠르고 역변환 비율이 높습니다. 팀 표준의 첫 출제 간격은 2인 3초·3인 2초·4인 1.55초·5인 1.25초·6인 1.1초이며, 30초마다 빨라집니다. 출제 간격 하한 1초와 가장 오래된 미해결 줄의 최소 노출 7초를 유지합니다. 역변환은 50%에서 최대 75%로 늘어납니다. **팀 도전**은 더 빠르며 기존 개인전 난도는 바뀌지 않습니다.

경기 시간은 2·3·5분 중 고릅니다. 8줄 포화 뒤 다음 출제에서 해당 팀이 종료되고, 제한 시간·전 팀 포화·방장 종료로 결과를 저장합니다. 정답 기본 100점에 단계·연속 성공·최대 40점의 속도 보너스를 더하며 오답 제출은 10점 감점합니다. 일시 정지 시간은 속도와 경기 시간에서 제외합니다. 10분 넘게 정지한 경기는 종료됩니다.

**참여 기록**에서 팀 순위·정오답·생존 시간·학생별 기여를 확인합니다. 기록은 20경기 단위로 페이지를 나누며 참가자·방장·사이트 관리자만 조회합니다. 기존 개인 순위와 섞지 않습니다. 전원이 접속을 끊어도 기록 조회 또는 정기 정리 시 종료 결과 저장을 재시도합니다.

### 교사 운영실·현황판·봇 연습 (두 팀전 공통)

콘솔의 **교육 게임 → 실시간 팀전** 또는 `/oj-console/addons/edu-games/team-games`를 엽니다. 위쪽에서 이진수·장치 카드 게임을 전환하고 **정식 경기/연습 경기**, 팀 수·정원·시간·난도를 정합니다. 교사 권한은 `edu_games_manage`입니다. 운영실은 콘솔에서만 표시하며 공개 팀전·숏코드·블록은 교사 계정에도 참가·연습 화면만 제공합니다. 공개 화면의 운영실 링크와 정식 경기 운영 버튼은 표시하지 않습니다.

**교사 직접 배정**은 학생을 미배정 대기로 모읍니다. 이름 옆 팀 선택으로 직접 배정하거나 **무작위 팀 배정**으로 전체 참가자를 섞어 균등 배정합니다. **빈 팀부터 자동 배정**을 선택하면 참가 시 인원이 적은 팀에 들어갑니다. 편성이 바뀌면 사람의 준비가 해제됩니다. 미배정 없음·각 팀 2명 이상·동일 인원·전원 접속/준비 후 시작합니다. 학생은 정식 경기의 팀을 직접 바꾸거나 운영할 수 없습니다.

**현황판 열기**는 읽기 전용 별도 창을 엽니다. 담당 교사·사이트 관리자만 모든 팀의 순위·점수·해결 수·현재 판/포화·보드 활동·기여·접속/준비·최근 경기 소식을 봅니다. 정답·문제 내용·닫힌 카드는 전송하지 않으며, 현황판 입장권으로 경기 조작도 할 수 없습니다. 학생은 자기 게임판과 팀별 요약 점수를 봅니다. 현황판 주소는 `/oj-addons/edu-games/team-board?game=binary-conversion&room=방코드` 또는 `game=device-matching`입니다.

연습방에는 **봇 추가**, **빈자리 봇 채우기**, **봇 모두 빼기**가 있습니다. 채우기는 가장 큰 팀 인원(최소 2명)에 맞춰 부족한 인원만 보충합니다. 공개 화면에서는 교사·학생 모두 선수 참가가 기본입니다. 혼자 연습방을 만들고 **봇과 바로 시작**을 누르면 선수 참가·부족한 봇 추가·준비·시작까지 한 번에 처리합니다. 기본은 나 1명과 봇 3명의 2대2 경기입니다. 다른 사람이 참가한 방에서는 이 버튼을 표시하지 않고 전원 준비 후 시작합니다.

**봇 난이도**는 입문·보통·도전 중 선택하며 기본값은 **입문**입니다. 이전에 만든 방도 대기실에서 방장이 바꿀 수 있습니다. 봇은 문제를 읽고 생각하는 시간·실수·쉬는 시간을 가지며, 카드 봇은 공개된 카드만 최대 4·8·12장 기억하고 일정 시간 뒤 잊습니다. 이전의 빠르고 항상 정확한 이진수 풀이를 완화했습니다. 경기 중에는 봇 난이도를 바꾸지 못하고 정식 경기에는 봇을 추가할 수 없습니다.

팀전 점수판·버튼·게임판은 개인전의 스타일을 사용합니다. 이진수는 형식·문제·8개 비트·현재값과 위아래 자리값·아래부터 쌓이는 8줄 배치를 유지하고 담당만 추가합니다. 장치 카드는 같은 물음표 뒷면·사진·설명 앞면과 2D 뒤집기를 사용합니다. 화면 폭·높이에 맞춰 열 수를 정하고 작은 카드의 큰 사진·설명은 하단에서 확인합니다. 팀별 점수·팀원 기여는 **팀 현황**을 펼쳐 확인합니다. 닫힌 카드 내용과 정답은 노출하지 않습니다. 개인전과 정식 팀전 채점·난도는 변경하지 않습니다.

방장은 대기실·경기·결과 화면의 **방 닫고 나가기/방 닫기** 또는 내 방 목록의 **방 닫기**로 방을 삭제할 수 있습니다. 진행·일시 정지 중인 경기는 현재 결과가 저장된 뒤 방만 삭제하고, 이미 저장된 기록은 남깁니다. 저장에 실패하면 방도 삭제하지 않습니다. 대기실은 기록을 새로 만들지 않고 정리합니다. 일반 참가자의 **방 나가기**는 자기 참가만 해제합니다. **방 목록/목록 보기**는 방을 유지하는 화면 이동입니다. 이전에 남은 방도 내 방 목록에서 닫으세요.

참여 기록은 **전체·정식·연습**별로 필터링하고 각각 페이지를 나눕니다. 봇 포함 여부도 표시합니다. 업데이트 시 기존 팀전 테이블 두 개에 경기 구분 열·인덱스를 자동 추가합니다. 이전 버전의 기록은 보존하고 연습으로 표시합니다. 비활성화·삭제 정책은 기존과 같습니다. 경기가 없는 시간에 ZIP 업데이트 후 기존 탭을 새로 고침합니다. 기존 1.8 이상 에듀게임 WebSocket 서버·설정을 그대로 사용할 수 있습니다. 이 기능을 위한 서버 추가 설치는 없습니다.

기본 통신은 에듀게임 자체의 **0.7초 경량 동기화**이며 경량 경로를 사용할 수 없으면 REST로 자동 전환합니다. WebSocket을 사용할 때도 서버가 정답·시간·채점과 방별 동시 조작을 처리합니다. 업데이트 시 전용 방·결과 테이블 두 개와 서명 키를 자동 생성하므로 경기가 없는 시간에 업데이트하세요. 운영 서버의 동시 접속 처리량은 서버 사양에 따라 확인해야 합니다.

### 장치 카드 매칭 팀전

개인 카드 게임은 유지합니다. 허브의 **장치 카드 팀전**, 개인 카드 게임의 **실시간 팀전**, 또는 `/oj-addons/edu-games/device-team`으로 입장합니다. **장치 카드 매칭 팀전** 블록이나 `[device_team]`·`[oj_device_team]` 숏코드도 사용할 수 있습니다. 장치 카드 게임의 공개 설정을 함께 따릅니다.

방 생성·코드 참가·같은 인원의 팀 편성·전원 준비 후 시작은 이진수 팀전과 같습니다. 두 게임의 방·기록·입장권·WebSocket 채널은 분리합니다. 첫 판은 팀당 2인 24장·3인 32장·4인 40장·5인 48장·6인 56장입니다. 단계가 오르거나 **팀 도전**을 선택하면 최대 64장까지 늘어납니다. 경기 중 접속이 끊겨도 판 크기는 시작 인원 기준으로 유지합니다.

각자 두 장을 골라 사진과 이름·설명의 짝을 찾습니다. 서로 다른 쌍은 동시에 찾을 수 있고 다른 팀원이 연 카드에는 담당이 표시됩니다. 열린 카드를 누르면 큰 사진과 설명을 확인하며 다른 사람의 선택을 가로채지 않습니다. **선택 놓기**로 자기 첫 카드를 돌려놓거나 12초 동안 추가 선택이 없으면 자동 해제합니다. 오답 두 장은 1.1초 뒤 다시 닫히고 20점 감점하며, 실수 횟수로 게임을 막지 않습니다. 맞힌 카드 자리는 위치 기억을 위해 남습니다.

카드의 앞·뒷면과 테두리·글자·2D 뒤집기는 개인전과 같은 스타일을 사용하고, 단계·완료 쌍 수·간격도 같은 형식으로 표시합니다. 인원에 맞는 24~64장은 유지하므로 카드 크기와 열 수는 개인전과 다를 수 있습니다. 사진은 비율을 유지해 전체가 보이게 맞추고 작은 카드의 사진·설명은 하단에서 크게 확인합니다. 담당 표시만 팀전용으로 추가합니다. 이 변경에는 DB 이전·WebSocket 서버 재설치가 필요하지 않습니다.

모든 쌍을 찾으면 2.2초 뒤 다음 판이 자동으로 열립니다. 정답 기본 100점에 단계·연속 성공·최대 30점의 빠른 연결 보너스를 더하고 판 완료 보너스를 받습니다. 제한 시간 2·3·5분 또는 방장 종료로 점수·맞힌 쌍·오답·도달 단계·팀원 기여를 저장합니다. 참여 기록은 20경기씩 페이지로 표시하며 개인전·이진수 기록과 섞지 않습니다.

사진과 설명은 38종에서 **70종**으로 늘렸고 기존 개인전에도 적용합니다. 팀전은 직전 판 장치를 제외하고 사용 횟수가 적은 장치를 우선 뽑습니다. 재경기에도 같은 방의 출제 이력을 유지하고 모든 팀의 같은 판에는 같은 장치와 배치를 제공합니다. 새 방에서는 이력을 새로 시작합니다. 사진은 로컬 파일로 제공하며 **사진 출처**에서 저작자·라이선스를 확인합니다. 작은 화면에서도 사진 전체를 맞추고 큰 확인 영역을 별도로 제공합니다.

업데이트 시 기존 팀전 테이블 두 개에 게임 구분 열과 인덱스를 자동 추가하고 기존 이진수 기록은 보존합니다. 별도 테이블은 추가하지 않습니다. 경기가 없는 시간에 ZIP을 업데이트하세요.

### WebSocket 연결 (선택)

사이트 관리자(`manage_options`)로 **학습 활동 → 교육 게임 → 실시간 팀전 WebSocket**을 엽니다. 이진수·장치 카드 팀전이 같은 설정을 사용합니다. **공용 WebSocket 서버 사용**을 켜고 사이트 주소에 `/edu-games-live`를 붙인 `wss://사이트/edu-games-live`를 저장합니다(HTTP 사이트는 `ws://`). **공용 서버에 에듀게임 등록**에 표시되는 명령과 설정 코드로 [서버 준비](00-server-setup.md)의 18-3단계를 실행한 뒤 **연결 상태 확인**을 누릅니다. 설정 코드는 인증키가 포함된 관리자 전용 정보입니다.

이미 1.7.x WebSocket 서버를 사용하는 경우 주소·비밀키는 그대로 유지합니다. 새 ZIP 업로드 후 18-3단계의 `realtime-server/install.sh --update`를 한 번 실행해 에듀게임 모듈을 갱신해야 장치 카드의 새 채널을 사용할 수 있습니다. 갱신 전에도 경량 HTTP/REST 모드로 게임을 진행할 수 있습니다.

기존 공용 서버가 있다면 같은 `/opt/oj-realtime-hub`에 에듀게임 앱·채널을 추가합니다. 다른 앱의 등록·인증키·방은 섞이지 않습니다. 서버가 없는 경우에도 에듀게임 ZIP에 포함된 공용 설치기로 독립 설치할 수 있습니다. 공용 서비스가 재시작되므로 경기·수업이 없는 시간에 실행하세요.

저장 후 기존 게임 탭을 새로 고침하면 WebSocket을 우선 사용합니다. 게임 화면의 연결 칸은 **WebSocket / REST**로 표시하며 연결 실패·서버 중단 시 REST로 자동 전환하고 재연결을 시도합니다. 응답이 유실돼도 같은 요청 번호로 재시도하므로 이중 채점하지 않습니다. 개인전·난도·기록 형식은 그대로입니다.

13종 게임은 공통 서체·버튼·점수판과 최대 1120px 너비를 사용합니다. 게임 허브·블록·숏코드에 동일하게 적용하며, 게임판 고유 조작과 채점 규칙은 유지합니다. 게임 아래 **순위와 기록**을 펼치면 순위를 볼 수 있습니다.

OJ Platform 2.1.0 이상에서는 계정 메뉴의 **화면 모드 → 라이트·다크·시스템** 선택이 게임·허브·순위와 집중 화면에도 적용됩니다. 시스템은 기기의 밝기 설정을 따릅니다. 진행 중 모드를 바꿔도 입력·선택·점수는 유지되고, 그래프 축·격자의 색도 바뀝니다. 사진·팔레트·직접 칠한 픽셀·손글씨 표본의 색은 바꾸지 않습니다. 별도 게임 설정이나 데이터 이전은 필요하지 않습니다. 업데이트 후 기존 탭은 새로 고침해 변경된 자산을 불러오세요.

게임을 시작하면 **집중 화면**이 열리고 점수·게임판·필수 조작을 화면 높이에 맞춰 배치합니다. 이미지 제작·복원 등은 상단 **모니터 버튼**으로 엽니다. **X 또는 Esc**로 원래 페이지로 돌아오며 입력·선택·진행 기록은 유지됩니다. 나가기는 일시 정지가 아니므로 진행 중인 게임의 시간은 계속 흐릅니다. 순위로 이동하면 집중 화면을 닫고 기록을 표시합니다. 아주 작은 창이나 화면 확대에서는 글자와 조작을 숨기지 않도록 내부 스크롤을 허용합니다. 추가 설정·서버 설치·데이터 이전은 필요하지 않습니다.

사이트 관리자(`manage_options`)로 로그인하면 개인 순위의 기록 옆에 **휴지통 버튼**이 표시됩니다. 확인창에서 이름·점수를 확인한 뒤 **기록 삭제**를 누르면 해당 도전 한 건이 영구 삭제되고 순위·관련 통계가 갱신됩니다. 같은 학생의 다른 기록이 있으면 다음 최고 기록이 다시 표시됩니다. 학생의 모든 기록을 한 번에 지우는 동작은 아닙니다. 일반 교사의 `edu_games_manage` 권한만으로는 삭제할 수 없으며 진행 중 도전·별도 수집 진도는 삭제하지 않습니다. 삭제 후 복구는 데이터베이스 백업이 있어야 가능합니다.

게임 하단에 자동으로 붙던 별도 개념 문제 풀이·평가 영역은 표시하지 않습니다. 게임 자체의 연습·도전·검정과 점수·순위는 그대로이며, 기존 개념 평가 데이터와 기록 조회도 유지됩니다.

데이터·AI 게임 7종은 점수·남은 시간·연속 성공·개인 최고 기록을 상단에 표시합니다. 상황 변경은 **도전 설정**, 다시 도전과 순위 조회는 종료 화면에서도 가능합니다.

- 이상치는 숫자를 검토함으로 옮겨 평균 변화를 확인하고, 결측값은 복원 도구와 관측값으로 빈칸을 채웁니다. 결측값의 결과 확인 시간은 경쟁 시간에서 제외합니다.
- 데이터 추출은 색·모양 관문과 출고 라벨을, 자료구조는 입고·스택·큐·배송 상자를 직접 조작합니다.
- 시각화는 그래프 선택·적재 범위·보급품 배정에 따라 지원 결과가 바뀝니다. 분류 경계는 경계선과 배송길을, 손글씨 로봇은 이름표·9칸 기억·오인식 근거를 함께 보여 줍니다.

별도 설정이나 데이터베이스 이전은 필요하지 않습니다. 결측값은 시간 계산 변경에 맞춰 새 순위로 분리하며 이전 기록은 보관 조회에 남습니다. 다른 게임의 채점 규칙과 기존 기록은 유지합니다.

장치 카드는 카드 수와 화면 폭에 맞춰 마지막 줄까지 채워 배치합니다. 카드 안에서 분류 라벨을 위한 공간을 확보하고 남은 영역에 사진 전체를 비율대로 맞추므로, 집중 화면에서 카드가 작아져도 사진이 잘리지 않습니다. 오답 두 장은 잠시 공개한 뒤 다시 뒤집히며 닫기가 끝나면 다음 카드를 선택할 수 있습니다. 오답 대기 중 다시 시작하면 이전 뒤집기 예약을 취소합니다. 맞힌 카드가 사라진 자리는 기억한 위치를 유지하기 위해 그대로 둡니다. 문자코드의 계정 기록 동기화 오류와 이진수 게임이 스크롤 중 사이트 메뉴를 덮는 레이어 문제도 수정했습니다. 이 수정에 따른 추가 설정은 없습니다.

Safari 호환성을 위해 카드 앞·뒷면을 명시적으로 전환하고 3D 합성에 의존하지 않는 접힘 애니메이션을 사용합니다. 화면 회전 후에도 오답 카드가 닫히고 다음 선택을 받도록 하며 사진 전체 맞춤은 유지합니다. 이진수 입력·커서 보존, 긴 낙하 단어의 가장자리 표시, 결측값 계산식·문자코드 복원·시각화의 좁은 화면 배치도 보완했습니다. 업데이트 후 기존 탭은 새로 고침해 변경된 자산을 불러오세요. 별도 설정이나 데이터 이전은 필요하지 않습니다.

## 삭제 시

점수·세션·팀 기록이 삭제됩니다(비활성화는 유지). 이진수 팀전의 방·결과 테이블, WebSocket 연결 설정, 서명 키, 정기 정리 작업도 삭제합니다. 비활성화 시 정기 작업만 중지하고 기록은 보존합니다. 외부 공용 서비스의 앱 등록은 자동 삭제하지 않습니다. 더 사용하지 않을 때 서버 준비 18단계의 모듈 제거 절차로 `edu-games` 앱만 제거하고 다른 앱이 사용하는 공용 서버는 중지하지 마세요.
