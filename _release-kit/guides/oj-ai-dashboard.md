## 하는 일

활동지, AI 평가, 교사 검토, 피드백, 보고서·PDF를 제공합니다.

## 1. 서버 준비

[서버 준비](00-server-setup.md) 1~12단계(필수)를 마치고 OJ Platform을 설치한 뒤 진행합니다. **13단계(AI 활동지 저장 폴더)**를 진행합니다. 8단계(PHP 확장)와 13단계가 빠지면 활성화가 거부됩니다.

선택: 첨부파일 바이러스 검사는 **19단계(ClamAV)**.

## 2. 업로드

1.2.10에서 애드온 등록이 거부된 경우 이 수정본 ZIP으로 기존 플러그인을 교체합니다. 자산 묶음의 CSS 개수 초과를 수정한 것으로, 플러그인을 삭제하거나 기존 평가 데이터를 초기화할 필요가 없습니다.

관리자 화면에서 `packages/{{package}}`를 업로드하고 **활성화**합니다. 빨간 오류가 나오면 메시지에 적힌 확장 또는 폴더 단계를 다시 확인합니다.

## 3. 관리자 화면 설정

아래 AI 연결·배정·전송 동의는 **AI 기능을 사용할 때만** 설정합니다. 활동지 작성·교사 검토 승인·배포·학생 제출·교사 직접 채점에는 AI 연결이 필요하지 않습니다.

활동지 검토에서 **문서 확인 → 교사 검토 승인 → 배포용 버전 발행** 순서로 진행합니다. AI 미실행 또는 결과 없는 실패·취소 상태에서도 승인할 수 있습니다. AI 점검을 실행한 경우 진행 중 작업은 완료하거나 취소하고, 이미 나온 결과·안전성 경고는 교사가 검토합니다. AI 점검만으로 자동 승인·발행되지 않습니다.

활동지 본문의 표 안을 클릭한 뒤 도구 모음의 **표 너비 설정** 아이콘에서 **너비 단위(px / %)**, **표 너비**, 대상 **열**, **열 너비**를 지정하고 **적용 → 저장**합니다. **100%**는 본문 전체 폭, **80%**는 본문 폭의 80%이며 PDF는 여백을 제외한 인쇄 영역을 기준으로 합니다. % 모드의 열 너비는 30%·70%처럼 비율로 지정하고, 다른 열을 비례 조정하여 합계를 100%로 유지합니다. **열 너비 균등**도 사용할 수 있습니다. px 모드는 기존과 같이 열당 40~1,600px입니다. 저장·재열기·학생 화면·PDF에 유지되며 기존 활동지나 이미 발행한 배포본의 내용은 자동 변경하지 않습니다.

긴 활동지를 편집할 때 상단 도구 모음은 본문 위에 고정됩니다. 표 안의 글자·크기 조절 핸들이 메뉴를 덮지 않으며 스크롤한 위치에서도 편집 도구를 사용할 수 있습니다.

활동지 작성에서 **문항 목록**을 열면 목록과 편집창 사이의 세로 경계를 드래그해 목차 폭을 조절할 수 있습니다. 긴 문항 제목은 줄바꿈으로 표시하며 조절한 폭은 해당 브라우저에 기억됩니다. 경계를 더블클릭하면 기본 폭으로 돌아옵니다. 키보드로 경계에 초점을 둔 뒤 좌우 방향키·Home·End로도 조절할 수 있습니다. 편집 공간이 너무 좁아지지 않도록 최대 폭을 제한하고, 모바일처럼 좁은 화면에서는 목록을 편집창 위에 표시합니다. 목차 폭 조절은 활동지 내용이나 저장 상태를 변경하지 않습니다.

| 순서 | 화면 | 설정 |
|---|---|---|
| 1 | `/oj-console/settings/ai-provider` | AI 연결 프로필과 **API 키** (OJ Platform 설정) |
| 2 | `/oj-console/settings/ai-routing` | 평가·피드백 작업에 사용할 프로필 |
| 3 | **교사 메뉴 › 활동지 평가 › 설정** (`/oj-console/addons/oj-ai-dashboard/settings`, 사이트 관리자 또는 '활동지 평가 설정' 권한을 받은 교사) | **외부 AI 전송 동의** 체크 |

교사 화면은 **수업 > 활동지 평가**(`/oj-console/addons/oj-ai-dashboard/projects`)입니다. 화면 위의 구획(평가 프로젝트, 활동지 보관함, 배포·제출, 평가, 평가 기준, 보고서, 설정)으로 이동합니다. OJ Platform 2.0.x에서는 구획 대신 애드온 자체 메뉴가 보이고, 설정은 같은 수업 메뉴의 **활동지 평가 설정**으로 들어갑니다.

교사에게 설정을 맡기려면 `/oj-console/roles`의 애드온 권한에서 교사 역할에 **활동지 평가 설정**을 부여합니다. 사이트 관리자는 권한을 따로 받지 않아도 설정할 수 있습니다. WordPress 관리자 화면에는 이 애드온의 메뉴가 없습니다.

OJ Platform 2.1 이상에서는 사용자 메뉴의 **화면 모드**(라이트·다크·시스템)를 활동지 평가에도 적용합니다. 교사 화면·학생 화면·편집기가 같은 설정을 따르며, 시스템 모드는 기기의 설정을 따릅니다. 선택은 해당 브라우저에 유지됩니다. PDF·이미지·그림 원본의 색은 변경하지 않습니다.

업데이트할 때 프로젝트가 없는 기존 활동지를 현재 프로젝트 화면으로 이관합니다. **먼저 DB와 비공개 첨부파일을 백업**하세요. 활동지마다 프로젝트와 기준 초안을 추가하며 활동지 ID·원본 버전·배포·제출·점수·첨부파일은 변경하지 않습니다. 이관 중 오류가 생기면 해당 활동지의 작업을 취소하고 업데이트를 완료하지 않습니다. 원인을 해결한 뒤 다시 불러오면 이미 이관된 활동지는 중복 생성하지 않고 이어서 처리합니다.

활동지 보관함, 복사본, 예전 활동지 주소는 모두 프로젝트의 **활동지 작성**으로 이동합니다. 새로 복사하거나 가져온 미연결 활동지는 첫 진입 시 소유권 확인 후 프로젝트를 추가합니다. 구형 기준 작성 화면은 표시하지 않습니다. 이관한 기준은 **초안**이며 **평가 기준**에서 확인·확정한 뒤 미발행 초안의 **최신 확정 기준 적용**을 눌러 사용합니다. 적용 전에는 기존 활동지 기준이 유지됩니다. 이미 발행한 활동지와 평가 기록은 기존 기준을 유지하므로 새 기준은 **기존 활동지 복사**로 적용합니다. 연결 확인에 실패하면 오류와 **다시 시도**가 표시됩니다.

현재 실행되지 않는 옛 독립 관리자 화면·숏코드·중복 REST 모듈은 소스에서 제거했습니다. OJ Console과 학생 공개 화면을 사용하며, 기존 활동지·첨부파일 호환 처리 및 데이터 관리의 이관·복구 기능은 유지합니다. 코드 정리로 기존 활동지·제출·점수나 데이터베이스를 삭제하지 않습니다.

OJ Platform 2.3.13 / Addon API 1.4.0의 변경 내용을 검토하여 호환성 승인 기준에 반영했습니다. 설치 상태 재사용·조회 최적화·404 화면 변경을 포함하며 애드온 공개 API는 유지됩니다. 플랫폼의 제출 요청 제한 설정은 코딩 문제 제출에 적용되며, 이 애드온의 활동지 제출 기회나 AI 평가 요청 정책을 변경하지 않습니다. 업데이트 시 기존 AI 프로필·배정·동의 설정은 유지합니다.

**AI 평가 > 그룹·배포 선택 > 점수 다운로드**에서 해당 배포 전체의 채점 완료 점수를 CSV로 받습니다. 검색·상태 필터와 무관하며 **교사 확정 점수만** 선택할 수도 있습니다. AI 점수와 교사 확정 점수는 별도 열이고, 미확정 점수는 빈 칸입니다. 실패·진행 중·재제출 중인 결과는 제외됩니다. 학생 답변은 포함하지 않으며, 다운로드해도 점수를 승인하거나 학생에게 공개하지 않습니다. CSV는 UTF-8(BOM 없음)입니다. Excel에서 한글이 깨지면 **데이터 > 텍스트/CSV에서** UTF-8로 가져오고, 아이디 열은 텍스트 형식으로 지정합니다.

AI 평가 후에는 항목별 **평가 루브릭**에 AI 추천 수준이 선택됩니다. 교사는 학생 답변과 근거를 확인하고 다른 수준을 선택할 수 있으며 최종 합계가 갱신됩니다. 변경한 항목의 사유를 지정하고 **선택 점수 확정**을 누릅니다. 수준별 기준이 없는 항목은 점수를 직접 입력합니다.

**배포·제출 > 제출 현황 > 학생 보기** 또는 평가 화면의 **문제·답안 전체 보기**에서 PDF 생성 없이 전체 문항과 학생의 공식 제출 내용을 함께 확인합니다. 배포 당시 문항을 사용하며 AI 연결은 필요하지 않습니다. 제출 관리·교사 검토·AI 채점 중 하나의 권한과 해당 대상에 대한 교사 접근 권한이 필요합니다.

**배포·제출 > 제출 현황 > PDF 일괄 다운로드**에서 해당 배포의 공식 제출본을 학생별 PDF로 생성하여 ZIP으로 받습니다. 미제출 학생은 제외되며 내보내기 권한이 필요합니다. 생성 중 화면을 나가도 서버 작업은 계속되며, 같은 브라우저 탭에서 다시 들어오면 상태를 확인할 수 있습니다. 준비된 ZIP을 다시 받거나 새로고침 아이콘으로 최신 제출본을 다시 생성할 수 있습니다. 실패·만료 시 다시 생성하세요. 원본 첨부파일은 별도 ZIP 항목으로 넣지 않습니다.

AI를 사용하지 않을 때는 제출 학생을 선택하여 **교사 직접 채점**을 누릅니다. AI 연결·전송 동의·AI 채점 권한 없이 교사 검토 권한으로 사용할 수 있습니다. 모든 항목의 루브릭 또는 점수를 입력한 뒤 **채점 점수 확정**을 누릅니다. AI 실패 후에도 직접 채점할 수 있으며, 이 과정에서 AI 요청은 전송되지 않습니다. 입력 중인 점수는 확정 전에 저장되지 않습니다.

**AI 점수 승인**, **선택 점수 확정** 또는 **채점 점수 확정** 후에는 승인 완료·확정 점수가 표시되고 점수 입력과 중복 승인 버튼이 사라집니다. 다시 수정하려면 **점수 승인 회수**에서 사유를 입력합니다. 회수 후 검토 대기로 돌아가며 기존 조정값을 참고해 수정·재승인할 수 있습니다. 승인·회수 이력과 AI 원본 결과는 보존합니다. 이미 공개한 결과는 회수 시 숨겨지므로 점수·피드백 등을 재확인하고 다시 공개하세요. **반려**는 AI 후보 점수에 대한 검토이며 승인 회수와 다릅니다.

## ML 실습 분석 연결 (1.2.0 이상)

OJ ML Playgrounds 1.2.0 이상과 함께 사용하면 ML 원본 제출을 활동지로 복사하지 않고 분석할 수 있습니다. 교사와 학생의 진입 화면은 계속 **ML 실습**입니다. 이 기능은 AI 플러그인의 분석 작업과 비공개 결과 저장만 사용하며, ML의 최종 교사 평가·공개 절차는 유지합니다.

- OJ Platform **AI 작업 배정**에 새 작업 `addon.oj_ai_dashboard.ml_submission_assessment`을 배정하세요. 다른 활동지 평가 작업 설정을 변경할 필요는 없습니다.
- ML 과제에 항목별 루브릭을 설정하고, 교사가 학생 제출 상세에서 전송 동의 후 AI 평가를 요청합니다. 교사 검토 권한과 해당 수업의 평가 권한을 요청·실행·결과 조회 때 다시 확인합니다.
- AI 입력에는 검증된 실행 없는 요약과 학생의 포트폴리오 답변만 포함됩니다. ML 파일·데이터셋·모델을 실행하거나 원본을 AI 저장소로 복사하지 않습니다. 자유 입력에 포함된 개인정보는 교사가 확인해야 합니다.
- AI 결과는 **교사 검토용**입니다. 근거가 부족하면 점수 반영을 막으며, 결과가 있어도 교사의 ML 평가 공개 전에는 학생에게 보이지 않습니다.
- 대기열은 WP-Cron에서 순차 처리합니다. 호출 도중 중단된 작업은 비용 중복을 피하도록 자동 재호출하지 않으므로 교사가 상태를 확인하고 재시도해야 합니다.
- ML 평가에 반영한 점수·피드백은 ML의 보존 정책을 따릅니다. AI 분석 사본은 기본 30일 후 예약 정리 대상이며 보존 유예가 지정된 자료는 유지합니다. 요청 식별자·동의·실행 상태 같은 감사 메타데이터에는 답변·분석 본문을 저장하지 않습니다. AI 비활성화 중에는 예약 정리가 실행되지 않으므로 장기간 끄는 경우 운영자가 별도 보관·정리해야 합니다. 비활성화는 ML 수동 평가와 이미 공개된 결과를 제거하지 않습니다.

실제 API 호출과 비용이 발생하므로 연결 설정 후 시험 과제에서 먼저 검증하세요. 설치 안내서에 기재된 연결은 로컬 코드 검사만으로 운영 서버의 키·모델·예약 작업까지 검증했다는 의미가 아닙니다.

## 다른 플러그인의 공통 AI 평가 연결

같은 WordPress의 다른 플러그인도 서버 API로 과제 설명·문항별 텍스트 답안·평가 기준·배점을 제공하여 AI 점수와 피드백 초안을 받을 수 있습니다. 해당 플러그인 개발자가 소스 제공자를 연결해야 하며, 설치만으로 모든 플러그인에 평가 버튼이 추가되는 것은 아닙니다.

- **AI 작업 배정**(`/oj-console/settings/ai-routing`)에서 **공통 답안 평가**(`addon.oj_ai_dashboard.external_submission_assessment`)에 AI 프로필을 배정합니다. 기존 활동지·ML 작업과 별도입니다.
- 요청 화면에서 외부 AI 전송 동의를 받고 처리 상태를 조회합니다. 원본 플러그인은 요청·실행 전후·조회 시 교사의 원본 접근 권한을 확인합니다. 결과는 교사 검토용이며 자동 확정·공개하지 않습니다.
- 같은 입력·모델의 중복 요청은 재사용하고, 답안·기준·모델이 달라지면 이전 결과를 현재 점수로 제공하지 않습니다. 실패·중단은 명시적 재시도로 처리하며 기존 WP-Cron·비공개 보관 정책을 따릅니다.
- 개발자 계약과 호출 예제는 플러그인 문서 `docs/ai-assessment/common-assessment-api-2026-10-18.html`에 있습니다. 필터는 `oj_ai_external_assessment_gateway_v1`와 `oj_ai_external_assessment_sources_v1`입니다. 공개 인터넷용 HTTP API는 아닙니다. 원본 파일·이미지를 자동으로 수집하거나 실행하지 않습니다.

## 삭제 시

데이터를 지우지 않습니다.

## 서버 설치 창

설정의 **서버 설치·복구**에서 비공개 저장소·필수 PHP 확장 준비 명령을 복사합니다. 활성화 전에는 WordPress 플러그인 목록의 **서버 준비 필요 → AI 활동지 설치 안내**로 들어갑니다. 필요하면 같은 화면에서 ClamAV를 설치합니다.

공통 준비 화면은 OJ Platform 2.2.7 이상에서 제공합니다. 명령은 서버 설치 권한이 있는 관리자가 실행합니다.

OJ Platform 2.2.9 이상에서 업로드된 플러그인만 공통 화면에 표시합니다. 복사 명령은 `sudo bash …/resources/server/install.sh` 형식입니다. 필요한 PHP CLI는 설치기가 준비하며, PHP 보조 파일은 `wp-config.php` 검사·수정에만 사용합니다.

서버 설치기는 해당 플러그인의 `resources/server/install.sh`에 포함됩니다. AI·ML의 `wp-config-helper.php`도 각 ZIP에 포함되며 Platform의 설치 파일을 사용하지 않습니다.

활성화 후에는 각 플러그인 설정·관리 화면의 **서버 설치·복구** 창에서 자체 설치 명령을 바로 복사합니다. wp-admin 공통 화면으로 이동할 필요가 없습니다.

서버 준비가 필요한 경우에만 플러그인 목록과 관리자 OJ 콘솔 첫 화면에 안내합니다. 준비를 마치면 새로고침 후 안내가 사라집니다. 상시 OJ 서버 설치 메뉴는 표시하지 않습니다.
