## 하는 일

학생별 Python 노트북(브라우저에서 실행)과 교사 열람, 데이터셋 가져오기를 제공합니다. 서버에 Python은 필요 없습니다.

## 1. 서버 준비

[서버 준비](00-server-setup.md) 1~12단계(필수)를 마치고 OJ Platform을 설치한 뒤 진행합니다. HTTPS(5단계)가 없으면 `input()`과 디버거가 동작하지 않습니다.

학생 PC 브라우저에서 `cdn.jsdelivr.net` 접속이 가능해야 합니다.

## 2. 업로드

관리자 화면에서 `packages/{{package}}`를 업로드하고 **활성화**합니다.

## 3. 관리자 화면 설정

| 화면 | 설정 |
|---|---|
| `/oj-console/roles` | 학생 `oj_code_lab_use`, 교사 `oj_code_lab_review`, Kaggle을 설정할 교사에게 '코드 실습실 설정'(`oj_code_lab_settings`) |
| `/oj-console/addons/oj-code-lab/settings` — 교사 메뉴 › 코드 실습실 › 설정 (사이트 관리자 또는 '코드 실습실 설정' 권한을 받은 교사) | (선택) Kaggle 사용자 이름·API 키 |

교사 화면은 콘솔 학습 활동 › 코드 실습실(`/oj-console/addons/oj-code-lab`)이며, 화면 위 ‘학생 노트북’·‘추천 데이터’·‘설정’ 구획으로 오갑니다. 플랫폼 2.0.x에서는 구획 대신 학습 활동 › 코드 실습실 추천 데이터, 코드 실습실 설정 메뉴가 따로 보입니다. 학생 화면은 `/oj-addons/oj-code-lab/lab`(학습 활동 › 코드 실습실)입니다.

코드 셀의 **디버그**로 한 줄씩 실행하고 변수를 확인할 수 있습니다. 실행이 끝나거나 오류가 나도 **디버깅 중단** 버튼이 남습니다. 완료된 뒤 누르면 기록과 줄 강조만 닫고 실행 결과·변수·다른 셀의 실행과 입력 대기는 유지합니다. 아직 디버깅 중일 때 누르면 실행을 중단하고 변수를 초기화합니다.

텍스트 셀은 **+ 텍스트**로 추가합니다. 마크다운 도구 막대와 입력 옆 미리보기로 제목·강조·목록·코드·링크·이미지·표를 작성할 수 있습니다. **닫기** 또는 `Ctrl/Cmd+Enter`로 서식이 적용된 내용만 보고, **편집**이나 두 번 클릭으로 다시 수정합니다. 교사 화면에도 같은 서식이 표시되며 저장과 다운로드에는 원문이 보존됩니다.
