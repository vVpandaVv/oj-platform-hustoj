## 하는 일

타이머, 자리배치, 뽑기, 사다리, 판서, 학생 미니 판서, 빠른 응답, 조 짜기, 타임어택, 실시간 수업 신호와 수업 운영 보드를 제공하는 수업 보조도구입니다. 정식 버전 {{version}}은 OJ Platform 2.3.0 / Addon API 1.4 이상에서 동작합니다.

## 1. 서버 준비

[서버 준비](00-server-setup.md) 1~12단계(필수)를 마치고 OJ Platform을 설치한 뒤 진행합니다. 판서, 학생 미니 판서와 수업 신호를 거의 지연 없이 주고받으려면 업로드 후 **18-2단계(공통 실시간 서버의 티칭툴 모듈)**를 진행합니다.  서버를 설치하지 않아도 기존 REST 방식으로 자동 작동합니다.

## 2. 업로드

관리자 화면에서 `packages/{{package}}`를 업로드하고 **활성화**합니다.

## 3. 관리자 화면 설정

교사 화면은 콘솔 사이드바 수업 그룹의 **교실 도구**(`/oj-console/addons/teaching-tools`)이고, 학생은 `/oj-addons/teaching-tools/join`에서 6자리 코드로 참여합니다. 학급·그룹 명단을 쓰는 자리배치, 뽑기, 조 짜기, 타임어택에서는 **목록 새로고침**으로 최신 명단을 다시 불러옵니다.

학생과 함께 쓰는 모든 도구에서 **학생 연결 → 학급·그룹 자동 연결**을 선택하고 대상을 지정할 수 있습니다. 타이머·자리배치·뽑기·사다리·판서·학생 미니 판서·빠른 응답·조 짜기·타임어택을 시작하면 서버가 명단 권한을 확인하고 학생을 자동 등록합니다. 학생은 로그인 상태여야 하며, 참여 화면은 약 5초 간격으로 배정된 활동을 찾아 코드 없이 엽니다. 여러 활동은 목록에서 바꿀 수 있습니다. OJ Platform의 다른 화면에서도 배정된 활동에 처음 자동 참가하고 활동 링크를 표시합니다. 같은 화면에서 매분 재참가하지 않으며 실제 참여 화면과 수업 신호에서 연결 상태를 갱신합니다. 명단의 표시 이름·관리용 이름과 서버가 확인한 그룹 정보는 참가·동기화 때 그대로 유지합니다. 교사 화면만 사용하는 방식은 학생을 연결하지 않습니다. 그룹 밖 학생은 코드를 알아도 자동 연결 수업에 들어갈 수 없습니다.

그룹을 선택한 뒤 **활동 시작 시 학생 화면 자동 열기**를 켜고 수업을 시작하면, 로그인한 대상 학생이 다른 OJ 페이지를 보고 있어도 현재 탭이 해당 활동 화면으로 바뀝니다. 배정 활동이 있을 때는 약 5초 간격으로 확인하며, 다른 OJ 화면에 배정 활동이 계속 없으면 확인 간격을 최대 30초까지 늘립니다. 화면으로 돌아오면 즉시 확인합니다. 이미 참여 화면에 있는 학생도 새 활동으로 전환합니다. 기본값은 꺼짐이며, 꺼두면 현재 화면을 유지하고 활동 링크만 표시합니다. 수업 신호의 자동 참여 설정에서도 같은 옵션을 고를 수 있습니다. 학생이 화면을 보고 있을 때 적용되며, 외부 사이트나 다른 프로그램을 제어하거나 팝업 창을 여는 기능은 아닙니다.

이번 DB 부하 개선은 플러그인 ZIP을 올린 뒤 교사·학생 페이지를 새로고침하면 적용됩니다. 별도 DB 명령이나 실시간 서버 재설치는 필요하지 않습니다. 다른 애드온의 설치·활성화 없이 티칭툴 자체 발견 경로를 사용합니다.

학생별로 이미 연 활동의 코드와 확인 시각을 현재 브라우저에 최대 100개 저장하며, 기록의 유효기간은 24시간입니다. 같은 활동으로 반복 이동하거나 이전 활동이 다시 열리지 않게 하며, 계정이 바뀌면 별도 기록을 사용합니다. 브라우저 저장소를 사용할 수 없으면 강제 이동하지 않고 기존 참여 링크를 유지합니다.

학생 참여 화면 상단의 **수업에서 나가기**를 누르면 학생의 실시간 연결과 자동 조회를 멈추고 코드 입력 화면으로 돌아갑니다. 교사의 수업과 이미 제출한 기록은 유지되며 제출하지 않은 입력은 다시 참여할 때 초기화됩니다. 나간 코드는 학생별로 브라우저에 최대 100개·24시간 기록해 같은 수업으로 자동 복귀하지 않게 합니다. 코드나 배정 활동 버튼으로 직접 다시 참여할 수 있습니다. 수업 신호에서 나가면 해당 브라우저의 신호 연결도 해제합니다.

같은 상단의 전체화면 아이콘으로 학생도 수업을 크게 볼 수 있습니다. 전체화면에서도 나가기 버튼을 사용할 수 있고, 같은 아이콘이나 Escape로 해제합니다. 전체화면 권한이 없으면 창 안의 화면 확대로 전환합니다. 학생 나가기/전체화면 변경은 플러그인 ZIP만 갱신하면 적용되며, 서버 모듈 1.2.3은 그대로 사용합니다.

**iPad·iPhone에서는 교사와 학생 모두 브라우저 창 안의 최대화로 열립니다.** Safari의 네이티브 전체화면 종료 제스처와 아래 방향 필기가 충돌하지 않도록 하는 방식으로, Safari 주소창까지 숨기지는 않습니다. 최대화는 같은 전체화면 버튼으로 해제합니다. 데스크톱 모드 iPad에도 적용됩니다. 다른 브라우저·기기는 기존 네이티브 전체화면을 우선 사용합니다.

학생 판서 보기의 **화면 맞춤**은 PDF 페이지 영역에 맞춰 빈 칠판 여백을 줄여 표시합니다. **너비 맞춤**은 자료를 창 너비로 키우고 상단부터 읽으며, **칠판 전체**는 PDF 밖의 판서까지 표시합니다. +/− 버튼과 슬라이더로 맞춤 크기의 25~400%를 선택하고 초기화 아이콘으로 100%로 돌아갑니다. 확대 후 마우스 드래그·터치 스크롤로 이동하거나 Ctrl/Command+마우스 휠로 확대/축소할 수 있습니다. 학생의 보기는 교사의 페이지·필기를 변경하지 않으며 전체화면과 창 크기 변경에도 PDF와 필기를 함께 맞춥니다. 확대 시 PDF와 필기를 더 높은 해상도로 다시 렌더링하되 최대 3000×1800으로 제한합니다.

교사 판서에서는 기본 마우스 드래그·글자 선택과 그리기 중 휠 스크롤을 막고, 하나의 마우스·펜·터치 입력만 사용합니다. 다른 손가락, 취소 이벤트, 캡처 손실이 선 끝을 다른 위치로 옮기지 않도록 처리하고 칠판 밖의 좌표는 범위 안으로 제한합니다. 브라우저의 Escape나 운영체제의 전체화면 종료 제스처 자체를 비활성화하는 기능은 아닙니다. 이 변경도 ZIP만 갱신하며 실시간 서버 모듈을 다시 설치할 필요는 없습니다.

필기 중에는 이미 완성된 선을 반복해서 그리지 않고 새로 그은 부분만 갱신합니다. 학생 화면의 연속 메시지는 한 프레임에 묶어 표시하며, 필기 때마다 PDF를 다시 준비하지 않습니다. 한꺼번에 들어온 좌표는 512개 이하로 나눠 보내고 연결이 끊기면 저장본·스냅샷으로 복구합니다. **이번 지연 개선은 ZIP만 갱신한 뒤 교사·학생 페이지를 모두 새로고침하면 적용됩니다.** 서버 모듈은 1.2.3 그대로 사용합니다. 연결 상태가 자동 새로고침이면 WebSocket 전송이 아닌 REST 복구 방식이므로 실시간 서버 설정도 확인하세요. 실제 지연은 기기·PDF 복잡도·네트워크에 따라 달라집니다.

**같은 교사 계정으로 교사 화면과 학생 참여 화면을 함께 열어도 됩니다.** 참여 화면의 연결은 계정 권한과 별개로 읽기 전용 티켓을 사용하므로 기존 교사 연결을 교체하지 않습니다. 이전 ZIP에서 두 화면을 같은 계정으로 열어 지연이 있었다면 새 ZIP을 올리고 두 화면 모두 새로고침하세요. 서버 모듈 1.2.3·공통 서버 1.0.1은 다시 설치하지 않습니다.

참여 제한은 5분 동안 서로 다른 잘못된 코드 10개를 입력했을 때만 적용합니다. 같은 만료 코드의 반복 확인은 한 번만 집계하고, 이미 참여한 학생·그룹 자동 등록 학생·수업 소유자의 정상 수업 접속은 제한과 무관하게 허용합니다. 업데이트하면 이전 방식에서 누적된 제한은 사용하지 않습니다.

명단 기반 도구의 **화면 이름**에서 표시 이름, 관리용 이름, 익명 번호 중 하나를 고릅니다. 선택은 교사 브라우저에 저장되며 중복된 이름은 번호로 구분합니다. 학생 식별자는 화면·REST·세션에서 `id`로 통일하고, 이메일과 로그인 아이디는 명단 응답에 포함하지 않습니다. 직접 입력한 학생은 현재 화면에서만 쓰는 `manual:` ID를 받으며 로그인 계정과 자동 연결되지 않습니다.

**자리배치**는 앞자리(기본 1~2행), 짝, 떨어뜨리기 조합과 행·열·대각선 최소 간격을 같이 적용합니다. 선택 조건에는 현재 보이는 이름뿐 아니라 표시 이름, 관리용 이름 또는 `#학생ID`를 입력할 수 있습니다. 동명이인은 명단에 붙은 구분 번호까지 입력하거나 `#학생ID`를 사용합니다. 조건을 모두 만족하는 후보 중에서 무작위로 고르며, 명단에 없거나 모호한 조건과 만족할 수 없는 배치는 경고합니다. 결과를 가리고 자리를 클릭해 한 명씩 공개하거나 모두 공개할 수 있고, PNG 저장·인쇄·배치 저장/불러오기를 지원합니다. 새로 저장한 배치는 학생 `id`와 이름·관리용 이름·익명 번호를 함께 보관하므로, 불러온 결과 화면에서도 표시 이름을 즉시 바꿀 수 있습니다.

수업 신호를 시작할 때 **참여 코드** 또는 **학급·그룹 자동 참여**를 선택합니다. 자동 참여에서는 플랫폼에 등록된 학급·그룹 하나를 고릅니다. 서버가 교사의 명단 접근 권한을 다시 확인하고 시작 시점의 구성원을 자동 등록하며, 지정 명단 밖 학생은 해당 코드를 알아도 들어갈 수 없습니다. 수업 중에 명단을 새로고침할 수 있고, 한 교사가 여러 학급 수업을 동시에 운영해도 각 수업 연결을 따로 관리합니다.

학생이 코드로 참여하거나 지정 명단에 포함되면 같은 로그인 브라우저에서 문제나 다른 플러그인 화면으로 이동해도 오른쪽 아래 **수업 신호** 바가 유지됩니다. 자동 참여 대상 학생은 화면을 새로고침하지 않아도 약 5초 안에 새 수업을 찾습니다. 여기에서 활동을 열고 준비·이해·어려움·재설명·도움·완료 신호를 보낼 수 있으므로 참여 화면을 계속 띄우지 않아도 됩니다. 교사도 수업을 시작한 뒤 다른 화면에서 접속 수와 주요 신호를 확인하고 학생별 신호를 처리할 수 있으며, 전체 관리는 바의 **수업 신호 화면 열기**를 사용합니다.

전역 연결 정보는 현재 브라우저의 `localStorage`에 참여 코드, 사용자 ID, 교사/학생 역할, 마지막 활동 확인 시각과 사용자가 연결 해제한 현재 수업 코드만 저장합니다. 페이지를 열 때 서버가 활성 세션과 권한을 다시 확인하고 수업 종료·만료·권한 변경 시 활성 연결 기록을 자동으로 지웁니다. 학생은 바의 **이 브라우저 연결 해제**로 같은 수업의 자동 재접속을 멈출 수 있으며, 참여 페이지에서 코드를 직접 입력하면 다시 연결됩니다. 전역 바는 로그인한 OJ Platform 및 다른 애드온 화면에만 표시되고 관리자·비로그인·일반 WordPress 화면에는 표시되지 않습니다.

**빠른 응답**은 객관식, 척도, 한줄 응답, 워드클라우드와 익명 질문을 지원합니다. 교사는 응답 접수를 열고 닫으며, 금지어를 설정하고 서술·워드클라우드·질문을 공개·숨김·삭제합니다. **학생 미니 판서**는 학생별 그림을 썸네일로 모으고 크게 볼 수 있습니다. 이 응답들은 현재 수업 세션에만 저장되며 별도 성적표나 영구 제출 기록을 만들지 않습니다.

**수업 운영 보드**의 순서표는 이름 붙여 수업안으로 저장·불러오기할 수 있습니다. 수업 신호에서는 공동 진행자와 관찰자를 지정하고, 전체 또는 선택한 학생에게만 차별화 활동을 보내며, 권한이 있는 교사는 CSV 수업 보고서를 내려받습니다. 소음 신호의 마이크 음성은 녹음하거나 서버로 보내지 않습니다.

Learning Materials가 활성화돼 있고 PDF 자료가 있으면 **판서 → 학습자료 배경**에서 선택할 수 있습니다. 가져올 범위는 **전체 페이지**가 기본입니다. 자료를 선택하고 칠판을 열면 PDF의 모든 쪽이 판서 페이지로 준비되어 이전·다음 버튼으로 바로 넘깁니다. 수업 중에는 **페이지 추가** 또는 **PDF 배경 → 전체 N쪽 추가**로 문서 전체를 현재 페이지 뒤에 삽입합니다. 아무것도 쓰지 않은 초기 빈 칠판은 자료로 대체합니다. **선택한 한 쪽**으로 바꾸면 기존처럼 미리 본 쪽만 추가하거나 현재 배경만 교체할 수 있습니다. **자료 새로고침**으로 수업 중 추가한 PDF를 다시 불러오며, 기존 판서와 페이지별 되돌리기 기록은 유지합니다.

한 칠판은 최대 500페이지입니다. 문서가 남은 공간을 넘으면 일부만 가져오지 않고 안내합니다. PDF 파일은 한 번 읽어 재사용하고 이웃 쪽을 미리 렌더링하며, 이미지 캐시는 6쪽으로 제한합니다. PDF.js를 플러그인 안에 포함하므로 외부 CDN 설정 없이 동작하고 PDF 배경도 PNG 저장에 포함됩니다. 원본은 Learning Materials의 보호 저장소에 그대로 있습니다. 기존 WebSocket 서버에서 101쪽 이후 펜 미리보기까지 쓰려면 **18-2단계의 설정 유지 업데이트 명령**으로 티칭툴 서버 모듈을 한 번 갱신하세요. 일반 페이지 전환과 확정된 판서는 기존 서버·REST 방식에서도 표시됩니다.

**학생 PDF 배경**은 시작 전에, 또는 수업 중 도구 모음에서 선택합니다.

- **기존 자료 열람 권한 유지(기본값)**: 학생도 원본 자료의 열람 권한·공개 기간·그룹 조건을 만족해야 배경이 보입니다. 접근할 수 없으면 학생에게 사유와 다시 불러오기 버튼을 표시하고 필기는 계속 보여 줍니다.
- **이 수업 참가자에게 배경 공유**: 교사가 열 수 있는 PDF의 현재 쪽과 다음 쪽을 차례로 2000×1200 배경 이미지로 준비합니다. 수업 참가자는 원본 자료 권한 없이도 공유된 배경을 보며 확대·이동할 수 있습니다. 원본 PDF 다운로드 권한은 주지 않습니다. 교사에게 준비·실패 상태와 재시도 버튼이 표시됩니다. 모든 쪽을 처음부터 변환하지 않으므로 처음 방문한 쪽은 준비 시간이 필요할 수 있습니다.

공유 배경은 수업당 최대 500개이며 일반 삽입 이미지 30개와 별도입니다. 업로드는 이미지당 5MB 이하, WordPress 이미지 편집기와 PHP OpenSSL이 필요합니다. 저장 파일은 사이트 인증 키로 암호화하며 활성 수업의 교사·참가자에게만 복호화해 제공합니다. 공유를 끄거나 수업이 끝나면 새 이미지 요청을 거부하고, 종료·만료 정리·플러그인 삭제 시 파일을 정리합니다. 이미 학생이 본 화면이나 캡처까지 회수하지는 않습니다. 사이트 인증 키를 바꿨다면 칠판을 닫고 새 수업을 시작해 배경을 다시 준비합니다.

동시 참여 판서의 상단 **참여 코드 · QR**을 누르면 코드·링크·QR을 함께 접거나 펼칩니다. 처음에는 펼쳐지고, 접으면 한 줄만 남아 판서 공간을 확보합니다. 전체화면에서도 조작할 수 있으며 칠판 사용 중에는 접은 상태를 유지합니다.

칠판을 열기 전 **PDF 미리보기**와 전체화면에서도 같은 자료 선택 창을 사용합니다. PDF 모듈은 MJS MIME 설정이 없는 서버에서도 동작하도록 JS 확장자로 제공합니다. 요청이 30초 안에 완료되지 않으면 대기를 끝내고 오류를 표시하며 다시 선택해 재시도할 수 있습니다. 모듈 로딩 실패, 파일 손상·암호, 실제 접근 거부를 구분해 안내합니다. 접근 거부인 경우 **학습자료 열람 권한**, 자료의 공개 기간과 학생 그룹을 확인하거나 교사가 명시적으로 수업 배경 공유를 선택합니다. 수업 참가 권한만으로 원본 자료 권한이 추가되지는 않습니다.

WebSocket을 사용하려면 **교실 도구 → 설정**에서 실시간 전송을 켜고 기본 `wss://.../classroom-live` 주소를 저장합니다. 그 화면에 나오는 **서버 원클릭 설치** 명령을 서버에서 한 번 실행하고, 요청하면 별도로 복사한 설정 코드를 숨김 입력에 붙여 넣습니다. 코드는 명령줄 인수로 넘기지 않습니다. 설치 후 **버전·연결 다시 확인**을 누릅니다.

설정 상단의 **설치 버전**에서 티칭툴 플러그인·설치된 서버 모듈·공통 실시간 서버 버전을 함께 봅니다. 서명 인증된 서버와 현재 플러그인의 동봉 코드를 비교하며, 낮으면 **업데이트 필요**와 설정 유지 명령을 안내합니다. 인터넷 최신 버전을 조회하는 기능은 아닙니다. 연결 실패·인증 실패·버전 정보 없음은 최신으로 표시하지 않습니다. 새 ZIP을 올린 뒤 서버 명령도 실행해야 서버 모듈이 갱신됩니다.

판서는 실시간 연결 중에도 5초 간격으로 저장본을 확인하고, 연결이 끊기면 600ms 자동 조회로 전환합니다. 교사·학생 화면에서 연결 상태를 확인할 수 있으며, 교사에게 저장 오류가 보이면 메시지를 확인하세요. 네트워크 요청은 시간 제한 후 재시도하고 최신 revision보다 오래된 판서는 덮어쓰지 않습니다. 새 서버 모듈은 무응답 연결도 감지해 재연결합니다. 필기는 512KiB 세션 용량 한도 안에서 공유되며 초과 시 저장 오류를 표시합니다.

전체화면 권한이 없는 브라우저에서는 창 안의 화면 확대로 대신 열립니다. 같은 버튼 또는 Escape로 해제할 수 있고 칠판을 닫으면 원래 화면으로 복구합니다. PDF 배경·펜·도형은 확대 화면에서도 같은 위치에 표시됩니다.

티칭툴 ZIP 자체에 공통 런타임을 포함합니다. 아레나가 먼저 설치되어 있으면 같은 서버에 티칭툴 모듈만 추가하고, 없어도 단독 설치됩니다. 인증키·앱·채널·방은 분리합니다. 갱신은 모든 실시간 연결을 재시작하므로 수업·경기가 없을 때 실행합니다. 상태 확인은 HTTP 경로·앱 등록·서명 인증 검사이며 실제 판서·미니 판서·수업 신호 연결은 참여 화면에서 확인합니다.

서버 모듈만 갱신할 때는 새 플러그인 ZIP을 먼저 올린 뒤 **교실 도구 → 설정 → 기존 설정 유지 업데이트**에서 명령을 복사해 SSH에서 한 번 실행합니다. 기존 설치 명령에 `--update`를 붙이는 방식이며 설정 코드나 비밀키를 다시 입력하지 않습니다. 서버에 저장된 주소·키·포트·환경값, 다른 모듈과 미전송 데이터를 유지하고 nginx·서비스 설정은 변경하지 않습니다. 백업·재시작·인증 확인에 실패하면 이전 서버를 복구합니다. 최초 설치 또는 주소·키를 변경하려면 기존 **서버 설치·복구** 명령과 새 설정 코드를 사용하세요. 실행 순서와 실제 경로는 **서버 준비 18-2단계**에 있습니다.

조 짜기 실력 배정, 타임어택, 학습 활동 검색은 OJ Platform 2.3의 `AddonIntegrationGatewayV1` 하나로만 연동합니다. 명단 범위와 사용자 권한을 플랫폼이 다시 검증하며, Teaching Tools는 HUSTOJ DB나 다른 플러그인의 테이블·클래스·REST 라우트를 직접 읽지 않습니다. 공식 계약을 사용할 수 없으면 우회하지 않고 오류를 표시합니다.

**교실 도구 → 설정**에서 진행 중 세션 만료 시간과 만료 자료 보관 일수를 정합니다. 저장 항목과 보관 안내는 OJ Platform의 **운영 → 약관과 정책** 통합 재고에서 검토하고, 사이트의 개인정보 처리방침은 플랫폼 화면에서 관리자가 통합해 작성·게시합니다. Teaching Tools는 별도 문구를 제시하지 않습니다.

## 삭제 시

세션, 판서 이미지, WordPress에 저장된 실시간 설정이 삭제됩니다(비활성화는 유지). 공통 서버는 자동 제거하지 않습니다. 18단계의 모듈 제거 절차로 티칭툴 등록만 해제하며, 아레나 등 다른 모듈이 사용 중이면 공통 서비스를 중지·삭제하지 않습니다.

## 서버 설치 창

서버 설치·복구 시 GPL 전문도 서버 모듈과 공통 허브에 함께 설치됩니다. 이 고지 파일은 삭제하지 마세요.

설정의 **서버 설치·복구** 창에서 명령을 복사해 같은 서버의 SSH에서 실행합니다. 주소를 먼저 저장하고, 실행 후 **버전·연결 다시 확인**으로 확인하세요.

공통 준비 화면은 OJ Platform 2.2.7 이상에서 제공합니다. 명령은 서버 설치 권한이 있는 관리자가 실행합니다.

서버 준비가 필요한 경우에만 플러그인 목록과 관리자 OJ 콘솔 첫 화면에 안내합니다. 준비를 마치면 새로고침 후 안내가 사라집니다. 상시 OJ 서버 설치 메뉴는 표시하지 않습니다. 실시간 서버는 사용하도록 선택한 경우 설정 화면에서 연결을 자동 확인합니다.
