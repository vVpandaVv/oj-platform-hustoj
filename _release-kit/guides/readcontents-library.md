## 하는 일

읽기자료(주제·장·레슨) 편집기와 공개 열람 화면입니다. 플러그인에는 본문이 없으므로 콘텐츠 ZIP({{content_files}})을 따로 가져옵니다.

## 1. 서버 준비

[서버 준비](00-server-setup.md) 1~12단계(필수)를 마치고 OJ Platform을 설치한 뒤 진행합니다.

**15단계(읽기자료 업로드 폴더)**에서 가져오기 폴더를 만들고 콘텐츠 ZIP을 서버에 올립니다.

## 2. 업로드

관리자 화면에서 `packages/{{package}}`를 업로드하고 **활성화**합니다. 3.2.12 이하가 설치되어 있으면 **삭제하지 말고 교체**하세요.

업데이트 후 편집기와 학생 레슨 화면을 새로고침합니다. 화면 모드에서 **라이트·다크·시스템**을 선택하면 학생 레슨의 본문·표·조작부가 플랫폼 모드를 따릅니다. 이미지와 작성자가 지정한 본문 색은 유지합니다. 콘텐츠를 다시 가져오거나 DB를 다시 등록할 필요가 없습니다. 업데이트를 위해 플러그인을 삭제하지 마세요.

레슨 편집 화면에서는 목차와 본문을 각각 스크롤합니다. 다른 레슨을 선택하면 목차 위치는 유지되고 본문만 맨 위로 이동합니다. 모바일에서는 상단 목차 아이콘으로 목록을 열어 선택합니다. 콘텐츠 라이브러리와 목차 편집 목록은 기존 페이지 스크롤을 유지합니다.

목차와 본문이 나란히 보일 때 두 영역 사이의 세로 조절선을 드래그하면 목차 너비를 바꿀 수 있습니다. 조절선을 선택한 뒤 좌우 방향키로도 조절할 수 있으며, 두 번 클릭하면 기본 너비로 돌아갑니다. 선택한 너비는 같은 브라우저에서 기억합니다. 화면이 좁아지면 본문 공간에 맞춰 자동으로 제한합니다.

학생 레슨 화면에서도 공개된 주제 목차가 본문 옆에 표시됩니다. **목차 숨기기**를 누르면 본문을 넓게 볼 수 있고, **목차 보기**로 다시 열 수 있습니다. 학생 화면의 너비와 숨김 상태는 편집기와 별도로 기억합니다. 모바일에서는 목차가 기본으로 접히며 **목차 보기**로 펼칩니다. 비공개 레슨이나 비공개 상위 항목 아래의 레슨은 학생 목차에 표시하지 않습니다.

## 3. 콘텐츠 가져오기

1. 콘솔 **읽기자료** 메뉴(`/oj-console/addons/readcontents-library`) → **보조 기능(더보기) → 패키지 가져오기/내보내기 → 서버 ZIP 가져오기**
2. 새로고침 아이콘을 누르고 `{{content_file}}`을 선택 → 미리보기
3. 처음 가져올 때는 **기존 레슨 유지**(기본)를 사용할 수 있습니다. **개정 콘텐츠로 갱신할 때는 기존 주제를 먼저 내보내 백업하고, 중복 비교에서 같은 레슨인지 확인한 뒤 기존 레슨 대체**를 선택합니다. 유지로 가져오면 기존 본문은 바뀌지 않습니다.
4. 새로 만들거나 대체한 레슨은 **초안** 상태입니다. 이미지·본문·시각화와 이미지별 이용 조건을 검토한 다음 필요한 공개 상태로 변경합니다. 사이트에서 따로 수정한 본문은 대체 과정에서 덮어써지므로 비교 결과를 먼저 확인하세요.

콘텐츠 갱신을 위해 플러그인을 삭제하거나 재설치하지 않습니다. 큰 콘텐츠 ZIP은 서버 ZIP 가져오기를 이용하며, 장별 콘텐츠 ZIP을 사용할 때도 같은 주제·레슨으로 대응되는지 확인합니다.

장별 ZIP은 **01장부터 16장까지 순서대로** 처리합니다. 새 장은 기존 마지막 장 뒤에 추가되므로 임의 순서로 가져오면 목차 순서가 달라질 수 있습니다. 서버 가져오기 목록은 하위 폴더를 검색하지 않으므로 `chapters/` 폴더가 아니라 그 안의 개별 ZIP을 지정 가져오기 폴더 바로 아래에 올립니다. 사이트에서 레슨의 위치나 slug·제목을 바꾼 경우에는 원본 ID가 같아도 중복 판정이 달라질 수 있습니다.

16장의 WebP 이미지 4개는 가져온 뒤 표시를 확인합니다. WordPress 기본 허용 형식이지만 사이트의 MIME 제한이나 GD/Imagick 설정에 따라 처리 결과가 달라질 수 있습니다.

공개 화면은 `/oj-addons/readcontents-library`입니다. 학생 메뉴 **학습 활동 › 읽기자료**는 새로 설치하면 켜져 있습니다. 사용자 메뉴 설정을 이미 저장한 사이트에서 보이지 않으면 메뉴 설정에서 켭니다.

## 4. 보관·복원·삭제

- 콘텐츠 라이브러리의 각 주제 카드에서 **보관함 아이콘** 또는 **휴지통 아이콘**을 누릅니다. 목차 편집에서는 항목을 선택한 뒤 상단 선택 항목 관리에서 실행합니다. 레슨 본문 화면에도 같은 버튼이 있습니다.
- **보관함으로 이동**은 본문을 유지하고 학생 화면에서 숨깁니다. 먼저 저장되지 않은 본문을 저장하며 저장에 실패하면 중단합니다.
- 라이브러리 상단 **보관함** 또는 더보기 → **보관함**에서 주제·챕터·장·레슨을 확인합니다. **초안으로 복원** 또는 **영구 삭제**를 선택합니다. 상위 항목도 보관 중이면 상위 항목부터 복원합니다.
- **영구 삭제**는 확인 후 실행하며, 보관된 하위 항목까지 포함하여 목차와 본문을 삭제합니다. 복구할 수 없습니다. 미디어 라이브러리의 공용 첨부파일은 유지합니다.

## 플러그인 삭제 시

**모든 읽기자료가 영구 삭제됩니다**(비활성화는 유지).

## 서버 설치 창

읽기자료 편집기의 **서버 ZIP 가져오기 준비 → 서버 설치·복구**에서 가져오기 폴더 준비 명령을 복사합니다. 콘텐츠 ZIP 업로드는 기존 15단계대로 진행합니다.

공통 준비 화면은 OJ Platform 2.2.7 이상에서 제공합니다. 명령은 서버 설치 권한이 있는 관리자가 실행합니다.

OJ Platform 2.2.9 이상에서 업로드된 플러그인만 공통 화면에 표시합니다. 복사 명령은 `sudo bash …/resources/server/install.sh` 형식입니다. 필요한 PHP CLI는 설치기가 준비하며, PHP 보조 파일은 `wp-config.php` 검사·수정에만 사용합니다.

서버 설치기는 해당 플러그인의 `resources/server/install.sh`에 포함됩니다. AI·ML의 `wp-config-helper.php`도 각 ZIP에 포함되며 Platform의 설치 파일을 사용하지 않습니다.

활성화 후에는 각 플러그인 설정·관리 화면의 **서버 설치·복구** 창에서 자체 설치 명령을 바로 복사합니다. wp-admin 공통 화면으로 이동할 필요가 없습니다.
