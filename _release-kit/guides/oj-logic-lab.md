## 서버 준비

1. 공통 [서버 준비](_server.md)의 WordPress·PHP 준비와 OJ Platform 설치 단계를 마칩니다. PHP 8.3, WordPress 6.6, OJ Platform 2.5.9 및 Addon API 1.9 이상이 필요합니다. 추가 실습 서버나 API 키는 필요하지 않습니다.

## 업로드

1. WordPress 관리자 → 플러그인 → 새로 추가 → 플러그인 업로드에서 `{{package}}`를 설치합니다.
2. OJ Platform을 먼저 활성화하고 OJ Logic Lab을 사이트별로 활성화합니다.

## 기존 버전에서 업데이트

0.5.0·RC 또는 정식 이전 버전이 설치되어 있으면 플러그인 업로드에서 `{{package}}`를 선택하고 현재 버전을 교체합니다. 기존 회로·입력·클록·타이밍·수동 경로·경유점과 저장 키를 유지하며 DB 마이그레이션은 없습니다. 같은 사이트 주소·브라우저·계정에서 기존 저장 회로와 자동 복구 사본을 계속 사용합니다.

## 관리자 화면 설정과 사용

1. OJ Platform 권한 화면에서 필요한 학습자에게 **논리회로 실습 참여** 권한을 부여합니다. 학습 지원 → **논리회로 실습**을 엽니다. 경로는 `/oj-addons/oj-logic-lab/learn`입니다.
2. 처음에는 **초보 모드**로 시작합니다. 장치를 라이브러리에서 드래그하여 추가하고 출력 핀에서 입력 핀으로 드래그하여 연결합니다. AND·OR·NOT·NAND·NOR·XOR·XNOR·버퍼·3상 버퍼는 문자 연산자 대신 벡터 게이트 기호로 표시하며 회로도 SVG에도 같은 기호를 사용합니다. 기본 목록 외 장치는 ‘다른 장치도 보기’에서 펼칩니다. 배선은 장치를 우회하고 공통 출력만 구간을 공유합니다. 교차 곡선은 비접속, 분기점의 점은 접속입니다.
   장치를 이동하는 동안에도 배선이 핀을 따라 실시간으로 움직입니다. 스위치 중앙도 끌어서 이동하며 짧게 클릭할 때만 입력이 바뀝니다. 배선 통로가 없는 위치에는 놓을 수 없으며 원래 위치와 배선으로 복원합니다. Esc로 이동을 취소할 수 있습니다.
   **배선 경로 조정:** 가로 구간은 위아래로, 세로 구간은 좌우로 드래그합니다. 공통 구간의 분기는 함께 이동하며 핀 바로 앞의 짧은 구간은 고정됩니다. 장치 통과·다른 신호선과 겹치는 경로는 적용하지 않습니다. 잘못 놓거나 Esc를 누르면 이전 경로로 복원합니다. Ctrl/Cmd+Z로 실행 취소할 수 있고, 배선 선택 → **자동 경로로 되돌리기**로 해당 신호의 수동 경로를 해제합니다. 수동 경로는 JSON·브라우저 저장·회로도 SVG에 함께 반영됩니다.
   **꺾임점·경유점 편집:** 배선을 선택해 표시된 ◇ 또는 ● 점을 드래그합니다. **경유점 추가** → 배선 구간 클릭으로 중간 점을 넣습니다. 점 선택 → **선택한 점 삭제** 또는 Delete로 그 점만 지웁니다. 인접 구간은 직각으로 연결하며 충돌하는 이동·삭제는 적용하지 않습니다. 공통 점은 분기들이 함께 바뀝니다. 핀 앞과 다른 신호의 교차점은 고정됩니다. 경유점도 저장·불러오기와 실행 취소에 포함됩니다.
3. 초보 모드는 입력 카드의 0/1을 누르면 출력 카드가 즉시 갱신됩니다. 플립플롭은 **클록 한 번**으로 진행합니다. D·JK·T·SR 플립플롭과 버스 레지스터에는 클록 삼각형, D·SR 래치에는 레벨 동작 기호를 표시합니다. 고급 모드의 하강 에지는 클록 입력의 반전 원으로 구분하고, Q 반전 출력에도 원을 표시합니다. RST는 반전 원이 없는 활성 High 입력입니다. 초보 모드에서는 보존된 고급 에지 설정과 관계없이 실제 동작에 맞는 상승 에지 기호를 표시합니다. 지연 없이 계산하고 상승 에지를 사용하며 setup/hold 검사는 생략합니다. 미연결 입력은 X이며 RST만 0으로 처리합니다. RST는 활성 High입니다.
4. 세부 실험은 상단의 **고급 모드**를 선택합니다. 장치별 전파 지연·tCQ, 초기 Q, 시작 입력 0/1/X/Z, 클록 주기·듀티비·위상, 플립플롭 에지·setup/hold를 설정합니다. 실행·스텝·다음 이벤트, 파형과 타이밍 경고, CSV 내보내기를 제공합니다. setup/hold 위반은 X로 표현하는 교육용 디지털 모델입니다.
5. 모드를 바꾸면 실행 상태만 초기화하며 회로와 고급 설정은 보존합니다. 모드도 회로에 저장합니다. 모드 정보가 없는 이전 JSON은 고급 모드로 불러옵니다. 예제와 새 회로는 현재 모드를 유지합니다.
6. 초보 모드의 **진리표·상태표**, **회로 검사**, **실습 과제**를 사용합니다. 표는 입력·상태 합계 8비트, 최대 256행이며 정답 검사는 사본에서 실행합니다. 과제 시작 전 회로는 브라우저 복원 사본으로 보관하며 ‘원래 회로로 돌아가기’로 복원합니다.
7. 고급 모드에서 **현재 회로를 부품으로**를 눌러 입력·출력 포트를 지정하고 저장합니다. 내 부품함에서 클릭하거나 라이브러리에서 드래그하여 추가합니다. 부품은 24종, 포트는 입력·출력 각각 16개, 중첩은 4단계까지입니다. 회로 JSON에는 부품 정의도 함께 포함됩니다.
8. 버스 입력·출력·분리·결합·가산기·레지스터는 2·4·8·16비트를 지원합니다. 기본 게이트·MUX의 폭도 설정할 수 있습니다. 폭이 다른 핀은 분리·결합 장치를 거쳐 연결합니다. 8비트 가산기 예제로 확인하세요.
9. **입력 시나리오**에서 ns 시각과 입력 값을 예약하고 실행합니다. **파형 측정** 또는 파형 클릭으로 A/B 커서를 배치해 Δt를 확인합니다. 시나리오는 고급 모드에서만 적용하며 시작 입력값을 덮어쓰지 않습니다.
10. **회로도 SVG**는 현재 설계한 전체 회로의 배치·핀·배선을 자동으로 파일로 생성합니다. 확대·인쇄가 가능하며 원본 회로는 유지합니다. 진리표에서 게이트 연결을 자동 합성하는 기능은 아닙니다.
11. Shift+클릭 또는 Shift+빈 공간 드래그로 다중 선택하고, 함께 이동·복사·붙여넣기·정렬합니다. Ctrl/Cmd+A/C/V와 실행 취소·다시 실행을 사용할 수 있습니다. 충돌하는 이동·정렬은 적용하지 않습니다. 신호 배선을 선택해 이름을 붙이고 **주석 추가**로 설명을 작성합니다. 이름과 주석은 JSON·SVG에도 포함됩니다.
12. 고급 모드의 파형은 확대·축소, 이전·다음 구간, 최신 시각 따라가기와 **관찰 신호 선택**을 제공합니다. 기본 400 ns, 표시 범위 10~1,000,000 ns이며 전이는 신호별 최대 3,000개·전체 최대 100,000개를 보관합니다. 예제의 **4비트 ALU**, **레지스터 전송**, **간단한 데이터패스**로 컴퓨터구조를 실습합니다.
13. 저장 버튼은 현재 브라우저·사이트·계정별 로컬 저장입니다. 다른 PC나 사용자와 공유하려면 JSON을 내보내고 불러옵니다. 편집 후 0.5초에 자동 임시 저장하며 다음 접속의 **이전 작업 복구**로 복구합니다. 확정 저장 사본은 덮어쓰지 않습니다. 새 회로·예제·파일 전환 전의 미저장 작업은 **최근 작업 복구**에 최대 3개 보관합니다. 미저장·자동 저장 실패 표시를 확인하고 저장 제한 시 JSON으로 내보내세요. 0.1~0.5 및 RC 기존 회로의 장치·설정·수동 배선·경유점을 유지합니다. 복구·불러오기 후 실행은 저장된 초기값에서 0 ns로 시작합니다. 배치·이름·주석·파형 보기와 그 실행 취소는 실행 시간과 상태를 유지합니다. 부품함과 과제 복원 사본은 해당 작업 때 별도 로컬 저장되며 서버 동기화는 하지 않습니다.

## 부하와 운영 점검

장치 100개·연결 240개까지 지원하며 큰 회로의 드래그는 Worker에서 계산합니다. 자동 저장·편집·시뮬레이션은 브라우저 안에서 처리하고 서버 저장 API나 주기 조회를 사용하지 않습니다. 애드온 전용 테이블·쿼리는 없으며 플랫폼 인증·권한 조회는 OJ Platform의 공통 동작을 따릅니다. 업데이트 후 기존 계정으로 저장 회로 복원, 모드·클록 설정, 학습 권한 부여/거부를 확인하세요.

## 삭제 시

서버 전용 테이블이나 설정을 생성하지 않습니다. 플러그인을 삭제해도 브라우저 회로·자동 임시 사본·최근 작업 사본·부품함·과제 복원 사본과 내보낸 파일은 남습니다. 삭제 전에 실습 화면의 도움말 → **이 브라우저의 저장 회로 삭제** 또는 브라우저 사이트 데이터 삭제를 사용하세요. 내보낸 JSON·CSV·SVG 파일은 직접 삭제합니다.
