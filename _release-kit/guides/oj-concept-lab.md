## 하는 일

게임과 분리한 **정보 개념 체험**입니다. 이상치·결측값·시각화·필터링과 추출·자료구조·분류 경계, 이진 탐색·개인정보 최소 공개·네트워크 경로·연속 길이 부호화·멀티코어 병렬 처리를 직접 조작하고 결과를 비교합니다. 기존 자료 기반 예제 156개를 포함합니다. 점수·게임 순위·수행평가는 만들지 않습니다.

## 1. 서버 준비

[서버 준비](00-server-setup.md) 1~12단계와 OJ Platform 설치를 마칩니다. 추가 서버·WebSocket은 필요 없습니다.

## 2. 업로드

관리자 화면에서 `packages/{{package}}`를 업로드하고 활성화합니다. OJ Platform의 애드온 승인과 역할 권한을 확인합니다.

## 3. 화면과 설정

| 대상 | 경로·설정 |
|---|---|
| 학생 | 학습 지원 메뉴 **개념 체험** 또는 `/oj-addons/oj-concept-lab/activities` |
| 교사 | 콘솔 `/oj-console/addons/oj-concept-lab/manage`에서 체험별 공개·비공개 |
| 권한 | 학생 `oj_concept_lab_learn`, 교사 `oj_concept_lab_manage` |
| 일반 페이지 | `[oj_concept_lab]` 또는 **정보 개념 체험** 블록. `activity="missing-values"` 등으로 체험 지정 |

체험 허브는 게임 허브와 같은 작은 아이콘 카드로 표시합니다. PC·태블릿은 4열, 좁은 화면은 2열이며 카드 전체를 눌러 체험을 엽니다. 카드에는 짧은 개념 이름과 한 줄 설명을 표시하고, 전체 개념명은 이름 위의 툴팁·접근성 이름과 체험 화면의 제목에서 확인합니다. 라이트·다크 화면 모드를 따르며 체험별 예제·조작·되돌리기·작업 상태와 공개 설정은 바뀌지 않습니다.

각 체험은 조건 변경·실제 결과 비교·되돌리기를 제공합니다. 네트워크 경로는 **전송 확정 전**에만 경로의 한 칸 취소·전체 취소·되돌리기가 가능합니다. 확정하면 비용·도착 집계를 반영하고 되돌리기 이력을 닫으므로 이후 경로 선택을 취소해도 이미 확정한 전송은 수정되거나 환불되지 않습니다. 확정 내역을 화면에 남기며 **새 전송 실험**은 별도의 처음 상태로 시작합니다. 자료구조는 넣기·꺼내기·조회, RLE는 연속 구간 묶기·복원 비교, 병렬 처리는 코어별 작업 배치와 한 틱 실행입니다.

기존 Edu Games의 6개 데이터·자료구조·분류 활동은 새 게임 제출을 중단하고 기존 주소에 체험 이동 안내를 표시합니다. 기존 점수·학습 기록·교사 보고서는 Edu Games에 남습니다. 체험 상태는 사이트·로그인 사용자별로 구분한 브라우저 저장소에만 남으므로 기기 간 성적 동기화 기능은 아닙니다. 공용 기기는 사용 후 로그아웃합니다.

## 삭제 시

비활성화·일반 삭제는 체험 공개 설정을 보존합니다. 명시적으로 `OJ_CONCEPT_LAB_REMOVE_DATA`를 참으로 설정하고 플러그인을 삭제한 경우에만 자체 공개 설정을 삭제합니다. 브라우저 작업 상태는 해당 기기의 사이트 저장소를 지워 정리합니다. Edu Games 기록·학급·학생 성적은 읽거나 삭제하지 않습니다.
