1. 데이터 전송이 가능한 USB 케이블로 V1·V2 보드를 연결하고, HTTPS의 Chrome·Edge에서 장치 선택 창과 연결 취소·재연결을 확인합니다.
2. **HEX 다운로드** 파일을 MICROBIT 드라이브에 복사해 실행하고, **USB 업로드** 후 같은 동작이 실행되는지 확인합니다.
