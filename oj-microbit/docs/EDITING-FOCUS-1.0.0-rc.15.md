# 편집 몰입형 적용과 검증 범위

대상: 1.0.0-rc.15. 작성일: 2026-11-06.

선택한 편집 몰입형 시안을 문제 생성, 문제 설명, 학생 풀이 화면에 적용했습니다. 외부 MakeCode 내부 화면은 실제 임베드를 유지하고, 주변의 정보 구조·색상 토큰·여백·버튼·패널 전환을 정리합니다. 별도의 OJ 로고·학생/교사 역할 전환용 모형 메뉴를 제품에 추가하지 않습니다.

## 문제 생성

- 상단 3단계: 문제 설명 → 장치·동작 → 공개 설정. 현재 단계 하나만 표시합니다.
- 장치·동작의 공개 예시 / 비공개 채점 탭과 장치 그림을 사용합니다. 한 단계 안의 여러 핀과 한 핀의 연속 동작은 기존 모달에서 설정합니다.
- 시작 코드는 장치·동작 안의 선택 사항입니다. 직접 펼치기 전에는 MakeCode를 불러오지 않습니다. 이후 탭과 펼침 전환은 같은 편집기를 재사용합니다.
- 초안 저장과 공개 전 검토·확정 절차를 유지합니다. 자동 저장·그림 업로드처럼 초안에서 시연만 했던 기능을 동작하는 제품 기능처럼 표시하지 않습니다.
- 공개 문제를 수업에 적용하는 기존 별도 메뉴와 결과 범위를 유지합니다.

## 학생 풀이

- 제목, 저장 상태, 임시 저장과 채점하기를 한 곳에 모읍니다. 상세 설명은 문제 보기, 파일·HEX·USB는 파일·기기에서 엽니다.
- 실행 결과를 접은 넓은 편집기가 기본입니다. 넓은 영역에서는 결과를 옆에, 콘텐츠 폭이 좁으면 편집기와 결과를 한 화면씩 표시합니다.
- 실제 코드 실행과 공개 예시의 기대 동작을 별도의 탭과 설명으로 구분합니다. 비공개 조건을 학생 화면에 보내지 않습니다.
- 공개 예시 없이도 실제 코드를 실행하고 센서 입력을 바꿀 수 있습니다. 공개 예시가 없는 기대 동작 탭은 예시가 없다고 안내합니다.

## 상태 보존 규칙

실행 결과 열기·닫기와 문제 보기 전환은 클래스와 hidden 속성만 변경합니다. iframe을 이동·제거·생성하거나 프로젝트를 다시 가져오지 않습니다. 실행기 API, 저장 요청, 채점 요청과 DB 쿼리를 추가하지 않습니다.

패널이 닫혀도 변수·카운터·진행 중인 대기·타이머·입력과 I²C 상태는 이어집니다. 일시정지는 별도 버튼으로 수행합니다. 기대 동작을 보는 동안에도 실제 프로그램은 계속 실행합니다. 브라우저 탭 자체가 숨겨지면 기존 정책대로 일시정지합니다.

처음부터, 코드 변경, 파일 가져오기와 초안 복구는 명시적인 새 실행입니다. 복구·가져오기 후에도 패널 제어를 유지합니다. 페이지 이동과 새로고침은 실행 세션을 종료합니다.

## 로컬 검사와 실제 환경 구분

로컬 브라우저 검사는 배포할 CSS·JS, 실제 플랫폼 PHP 렌더러와 CSS, 실제 PXT 컴파일러 및 opaque-origin iframe/Worker를 사용합니다. controller와 REST는 권한 경계를 유지한 로컬 fixture입니다.

검사 항목은 320·390·768·1280px 배치, 밝은/어두운 화면, 키보드 모달, 비공개 조건, 지연 중 입력 변경, 카운터 증가, 일시정지·계속, I²C 상태, 실행 패널과 편집기 정체성, 초기화 경계와 네트워크 요청 수입니다. 시안 원본과 비교한 형태·크기 기록 및 PNG를 브라우저 검사 문서에 함께 보관합니다.

실제 WordPress 테마·캐시, Microsoft MakeCode 실서비스에서의 카테고리 표시, USB 보드 전송, 실제 Docker/HUSTOJ 병행 부하와 MySQL 실행 계획은 설치 서버에서 확인해야 합니다. 로컬 fixture 검사를 실사이트나 실기기 검증으로 표시하지 않습니다.

## 업데이트

새 ZIP을 WordPress에서 업로드하고 사이트·브라우저 캐시를 지웁니다. 실행기도 설정 → OJ Microbit의 기존 설치 명령으로 새 패키지 버전에 맞춥니다. 설치기·이전 버전 복구 로직은 rc.14에서 점검한 구현을 유지하며 HUSTOJ 관리 명령은 추가하지 않았습니다. DB 스키마 5, 저장 SQL과 채점 계약 oj-gpio/3, 상태 유지 프로토콜 oj-live/1은 유지합니다.
