## 메뉴 사용

- 기본 **문제** 메뉴: 전체 유형·프로그래밍·마이크로비트 필터와 실제 문제 목록. 학생은 문제 보기, 교사는 허용된 원본 관리로 이동합니다.
- 기본 **수업** 메뉴: 해당 수업의 마이크로비트 문제, 적용·결과·제출 링크. 현재 수업의 권한을 확인한 뒤 메타데이터만 조회합니다.
- 표준 역할은 기본 메뉴를 쓰고 중복 전용 메뉴를 숨깁니다. 애드온 관리 권한만 있는 사용자는 기존 권한 범위의 전용 관리 바로가기를 사용하며 일반 문제 수정 권한을 새로 주지 않습니다.

## 검증 범위

실제 플랫폼 CSS와 Pretendard 폰트, 실제 PHP 목록 렌더러를 사용한 Chromium **15개 흐름**, JavaScript **89개 검사**, 페이지 오류 **0개**입니다. 버튼 글자/배경 대비 4.5:1 이상, 키보드 초점, 밝은/어두운 화면, 좁은 표의 내부 스크롤, 빈 상태·오류, 현재 메뉴와 미저장 이동을 확인했습니다. [브라우저 결과와 측정값](browser-ui-ux-validation-1.0.0-rc.4.json), [빈 상태 모바일](ui-empty-mobile-1.0.0-rc.4.png), [기본 문제 목록 모바일](ui-native-problems-mobile-1.0.0-rc.4.png), [어두운 화면](ui-problems-dark-1.0.0-rc.4.png)을 확인합니다.

기반 플랫폼의 계약 회귀는 실제 contributor→handler→페이지 URL→HTML 전송을 루트 및 /school에서 확인합니다. 공개/교사 메뉴 선택, 실제 라우팅 경로 보존, 등록된 자기 경로만 허용, 권한·커서·4개 공급자 상한과 실패 격리를 검사합니다. 주입 없는 마이크로비트 팩터리 생성도 SQLite/실제 클래스 경계로 검사합니다.

## 남은 현장 확인

실제 WordPress 설치·사용 테마·프록시·캐시·역할 설정과 MySQL, MakeCode 서비스·USB·HUSTOJ 부하는 이번 브라우저 fixture가 대신하지 않습니다. [체크리스트](ACCEPTANCE-CHECKLIST.md)에서 두 ZIP 설치 후 문제·수업 기본 메뉴와 직접 링크를 확인합니다.

새 기본 수업 섹션은 기존 수행 모드의 상세 제한을 따릅니다. 기존 마이크로비트 직접 페이지의 결과 공개 정책을 일반 프로그래밍 제출의 모든 수행 모드 정책으로 자동 바꾸지는 않았습니다. 평가 운영 시 직접 링크를 포함한 별도 정책·권한 확인이 필요합니다. 스키마 5, 일반/수업 기록 분리와 채점 계약은 유지합니다.
