# 마이크로비트 독립 메뉴 점검 — 1.0.0-rc.5

점검일: 2026-11-04. 기반: OJ Platform 2.5.9 / Addon API 1.9.

## 메뉴 구성

| 사용자 | 메뉴 | 작업 |
|---|---|---|
| 교사 | 마이크로비트 문제 → 문제 목록 | 초안·공개 문제 편집, 공개 전 점검, 일반 제출 확인 |
| 교사 | 마이크로비트 문제 → 문제 생성 | 전용 생성 페이지에서 핀·시간·시작 코드를 작성하고 저장·공개 |
| 교사 | 마이크로비트 수업 | 관리 수업 선택, 공개 문제 적용·회수, 수업별 결과·제출 확인 |
| 학생 | 마이크로비트 문제 | 공개 문제 설명 → MakeCode 풀이 → 실험·임시 저장 → 제출·채점 |
| 학생 | 마이크로비트 수업 | 참여 수업의 배정 문제 풀이·제출, 해당 수업의 본인 기록 확인 |

일반 프로그래밍의 문제·수업 목록에는 마이크로비트 제공자를 등록하지 않습니다. rc.4의 통합 유형 필터·목록·상위 메뉴 별칭을 제거했습니다. 플랫폼의 그룹(학급)·수업 참여/관리 원장은 기존 공개 계약으로 재사용하며 일반/수업별 저장 프로젝트와 결과를 구분합니다.

## 페이지 이동

- 문제·수업 두 전용 메뉴와 교사용 문제 생성 링크를 실제 등록 페이지 주소로 연결합니다. 현재 항목은 강조색·밑줄·aria-current로 하나만 표시합니다.
- 생성 페이지는 별도 view 쿼리 없이 새 문제를 엽니다. 켜졌다 꺼짐·서보·I²C 예제는 허용된 템플릿 이름을 새 주소에 유지합니다.
- 초안 저장·공개 완료 후 저장된 문제 식별자를 포함한 편집 주소로 이동합니다. 이동이 차단돼도 저장된 ID·버전을 보존해 다시 저장할 때 중복 생성하지 않습니다.
- 문제·수업·생성 간 이동과 예전 깊은 링크는 해당 전용 페이지로 이동합니다. 배정·문제·수업 ID와 페이지 커서를 유지하고, 다른 수업 기록으로 대체하지 않습니다.
- 미저장 이동 취소는 작업을 보존하며 승인 후 beforeunload 확인을 한 번만 처리합니다. 하위 폴더 주소, 새 탭·뒤로가기·복귀도 점검 대상입니다.

## 데이터와 검증 경계

이번 변경은 기존 전용 목록과 채점 API를 사용하며 DB 스키마·인덱스·채점 계약을 바꾸지 않습니다. 목록 기본 20개/최대 50개, 커서·요약 조회와 일괄 결과 조회 규칙을 유지합니다. 일반 문제·수업 4개 surface에서 마이크로비트 출력·링크·제공자 등록이 없음을 실제 catalog 계약으로 확인합니다.

전체 자동 검사 **1,484개**, 실제 CSS·PHP 렌더러를 사용한 브라우저 **15개 흐름·오류 0개**가 통과했습니다. 결과는 [rc.5 검증 기록](rc-validation-1.0.0-rc.5.json), [브라우저 측정](browser-ui-ux-validation-1.0.0-rc.5.json)을 확인합니다. 이전 rc.4 증거·ZIP·동결 파일은 보존합니다. 실제 WordPress 테마·메뉴 저장 설정·역할·MySQL·HUSTOJ 병행 부하·Docker·USB는 [현장 체크리스트](ACCEPTANCE-CHECKLIST.md)에서 확인합니다. 일반 프로그래밍 수행 모드의 정책이 전용 마이크로비트 결과 페이지에 자동 적용된다고 가정하지 않습니다.
