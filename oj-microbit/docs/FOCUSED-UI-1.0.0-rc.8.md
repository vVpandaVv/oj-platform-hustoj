# 집중형 화면과 여러 핀 설정 — 1.0.0-rc.8

2026-11-04. OJ Platform 2.5.9/API 1.9 이상. 스키마 5와 oj-gpio/3, PXT micro:bit 9.1.1/core 13.0.1을 유지합니다.

## 생성·보기 화면

새 문제의 예시는 빈 상태로 시작합니다. 작성 화면은 **안내 작성 → 동작 조건 → 코드 준비 → 공개 점검** 중 현재 단계만 표시합니다. 왼쪽 단계 메뉴는 모바일에서 위쪽 네 칸으로 바뀝니다. 저장하거나 단계를 바꿔도 열린 MakeCode 편집기를 재사용합니다.

**동작 조건 → 첫 단계 만들기**에서 **단계 → 사용할 핀 여러 개 선택 → 핀별 입력값·출력값 → 간격·유지시간**을 차례로 정합니다. P0 센서, P1 LED, P2 모터를 함께 선택할 수 있으며 새 장치도 같은 화면에서 여러 개 연결합니다. 값 화면에서 P1의 **→ 다음 값 추가**로 켜짐→꺼짐 같은 직렬 동작을 구성합니다. 마지막에 **핀 N개 함께 적용**을 누르면 모두 반영됩니다.

기존 단계의 **단계 수정**은 그 시점의 모든 입력·출력 핀과 기존 직렬 동작을 불러옵니다. 핀마다 도우미를 다시 열지 않습니다. 이전·작성 취소·Escape는 원본을 보존하고, 잘못된 핀 하나가 있어도 일부만 적용하지 않습니다. 초기 입력은 모든 예시에 필요하므로 새 입력 핀의 빠진 처음 값은 다른 예시에도 0으로 준비하며 기존 값은 유지합니다.

입력의 **다음 입력 단계까지 간격**과 출력의 **유지시간**은 별개입니다. 반응 한도는 값이 나타날 때까지, 유지는 나타난 뒤를 확인합니다. 바로 켠 뒤 0.5초 기다리면 0.2초 유지 조건을 충족할 수 있지만 켜기 전에 0.5초 기다리면 반응 한도 0.1초를 넘습니다. 뒤 꺼짐 조건의 한도도 별도로 만족해야 합니다.

여러 핀은 같은 기준 시점부터 확인하는 **병렬 가지**, 한 핀의 값은 실제 유지 완료 뒤 확인하는 **직렬 화살표**입니다. 그림은 채점 조건의 관계를 표시하며 학생 코드의 스레드 검출은 아닙니다. 입력 간격을 바꾸면 단순 시간표의 뒤 기준 시점도 함께 이동합니다. 복잡한 기존 시간표·I²C 거래와 단일 고정 시각 조건의 의미는 보존하며 **세부 채점 설정**에서 확인합니다.

학생 화면은 **문제 제목 → 이번에 만들 동작 → 연결할 장치 → 이렇게 동작하면 돼요 → 문제 풀기** 순서입니다. 공개 예시의 입력과 기대 출력을 읽고 정확한 핀·반응·오차 표는 필요할 때 펼칩니다. 비공개 예시는 학생 화면에 추가하지 않으며 수업의 배정·권한·기록 범위를 유지합니다.

## 예: 센서·LED·모터를 한 번에

1. **동작 조건 → 첫 단계 만들기 → 다음**으로 이동합니다.
2. 핀 선택에서 **새 장치 연결**로 P0 센서, P1 LED, P2 모터를 목록에 추가하거나 이미 연결한 핀을 모두 체크합니다.
3. P0 입력 800, P1 출력 켜짐, P2 출력 800을 정합니다. P1의 **→ 다음 값 추가**를 눌러 다음 출력을 꺼짐으로 정합니다.
4. 다음 입력 단계까지 간격 1초, P1 켜짐 유지 0.5초·꺼짐 유지 0.2초, P2 유지 0.2초로 정합니다. 기본 반응 한도는 각 동작 0.1초입니다.
5. **핀 3개 함께 적용**을 누릅니다. P1의 직렬 동작과 P2의 병렬 가지를 확인합니다. **단계 수정**은 이 세 핀과 모든 기존 값을 다시 불러옵니다.

병렬 핀들의 필요시간은 서로 더하지 않고 최대값을 사용합니다. 같은 핀의 직렬 동작은 각 반응·유지시간을 더하므로 위 P1은 최악 0.9초가 필요합니다. 간격이 짧으면 적용 전에 안내합니다. 잘못된 값 하나나 저장 중 원본 변경이 있으면 핀·예시 일부만 반영하지 않습니다.

기존 고정 시각 검사는 한 동작일 때 같은 종류로 보존합니다. 그 핀에 다음 값을 명시적으로 추가할 때만 출력 시퀀스로 바꿉니다. 겹치는 동일 핀 조건은 자동 병합하지 않고 세부 설정으로 안내합니다. I²C 바이트·레지스터·거래 순서는 세부 설정에서 보존하며 P19·P20 버스 예약을 지킵니다. 허용 오차가 전체 출력 범위를 덮는 조건은 기존 서버 규칙대로 거부합니다.

## 모바일

작은 화면에서는 네 단계 메뉴가 위쪽에 배치됩니다. 두 상태는 켜짐→꺼짐을 한 줄에, 긴 직렬 동작은 아래 방향으로 표시합니다. 여러 핀 선택·값·시간은 모달 내부에서 스크롤하고 적용/이전 버튼은 보이는 위치에 둡니다. Tab/Shift+Tab 순환과 Escape·취소 후 원본/초점 보존을 지원합니다. 실제 모바일 가상 키보드·회전·확대와 Safari는 현장 확인 항목입니다.
