# 변경 기록

## 1.0.0-rc.9 — 2026-11-04

- 집중형 샘플과 실제 생성·보기 화면의 차이를 수정했습니다. 버튼 모서리·제목 여백·단계 메뉴·입력값 정렬·작은 출력 행·하단 동작을 맞추고 반복 설정을 접었습니다.
- 생성 첫 안내 폼부터 네 작성 단계와 학생 보기를 데스크톱·모바일에서 점검하며 샘플 원본과 같은 내용·크기의 위치·크기 비교 검사를 추가했습니다.
- DB 쿼리·스키마·채점·USB·PXT 버전과 권한은 유지합니다. 실제 사이트의 설치 버전·캐시·테마 확인은 별도입니다.

## 1.0.0-rc.8 — 2026-11-04

- 선택한 집중형을 생성·보기 화면에 적용했습니다. 작성은 현재 단계만, 학생 보기는 설명·장치·공개 동작·풀이를 우선 표시합니다.
- 한 모달에서 여러 입력·출력 핀을 선택하고 핀별 값·직렬 동작·시간을 함께 작성·수정합니다. 적용 전 전체 검증·취소·기존 조건 보존을 지원합니다.
- 모바일 여백·네 칸 단계 메뉴·두 상태 화살표와 모달 내부 스크롤·항상 보이는 적용 버튼을 보완했습니다.
- 허용 오차의 전체 범위 금지를 기존 서버 규칙과 맞췄습니다. DB 쿼리/스키마·채점 실행기·PXT·USB 번들은 유지합니다.

## 1.0.0-rc.7 — 2026-11-04

- 새 예시를 빈 단계에서 시작하고 단계·핀·값·시간을 네 화면 모달로 차례로 작성합니다. 적용 전 취소·이전 이동과 키보드 초점 순환을 지원합니다.
- 같은 시점의 핀은 병렬 가지, 한 핀의 연속 값은 직렬 화살표로 교사·학생 화면에 표시합니다. 복잡한 기존 시간표와 I²C 세부 편집은 보존합니다.
- 입력 단계 간격·출력 반응 한도·최소 유지시간의 안내를 분리하고 실제 PXT로 0.2초/0.5초 및 병렬·직렬 경계를 검증합니다. DB 쿼리·스키마·채점 실행기는 유지합니다.

## 1.0.0-rc.6 — 2026-11-04

- 문제·수업 1차 메뉴 아래 전용 항목을 배치하고 본문 중복 탐색을 제거했습니다. 문제 목록은 한 줄 행입니다.
- 학생 기대 동작을 쉬운 단계 카드로, 교사 작성을 네 단계 접기 화면과 작은 입력 카드로 바꿨습니다. 정확한 원래 채점 조건은 선택적으로 펼칩니다.
- 시작 코드의 지연 로딩·저장 후 프레임 재사용, 초기 정리와 코드 변경 구별, 저장 중 변경 보존을 추가했습니다.

## 1.0.0-rc.5 — 2026-11-04

- 생성 전용 경로, 예제 선택 유지와 저장 후 문제 편집 이동, 현재 메뉴·미저장 이동을 연결했습니다.
- OJ Platform 2.5.9/API 1.9, 스키마 5와 기존 시뮬레이터·채점 계약을 유지합니다.

## 1.0.0-rc.3

- 공개 문제와 수업 적용을 분리. 새 공개 문제는 수업 밖 사용자도 일반 풀이·채점 가능하며 기존 제한 배포는 명시적 전환 전까지 보존.
- 공개 문제를 여러 수업에 적용하고 배정별 프로젝트·제출·학생별 최근 결과를 분리. 일반 제출과 다른 수업 기록을 소급 합산하지 않음.
- 현재 수업 명단·미제출 학생·최근 결과와 배정별 제출 상세를 제공하고 수업 관리/참여 권한과 실행 후 권한을 재확인.
- 스키마 5의 수업 저장소·커서/요약 인덱스·원자적 제출과 결과 저장·작은 개인정보/보관 배치 추가.
- 기존 채점 계약·PXT와 장치 모델 유지. 공개/수업 격리 회귀 및 시험 서버 안내 갱신.
