# OJ Logic Lab

1.0.2는 D·JK·T·SR 플립플롭, D·SR 래치와 버스 레지스터를 실제 회로 기호로 표시합니다. 클록 삼각형·하강 에지 입력 반전 원·Q 반전 출력을 그리며 래치는 레벨 동작으로 구분합니다. 라이브러리·속성 아이콘과 회로도 SVG도 같은 기호를 사용합니다. 장치 크기·핀 좌표·회로·타이밍·저장 형식과 계정별 저장 키는 유지합니다.

논리회로·컴퓨터구조 수업용 브라우저 시뮬레이터입니다. PHP 8.3, WordPress 6.6, OJ Platform 2.5.9 및 Addon API 1.9 이상이 필요합니다. 플랫폼의 학습 지원 메뉴에서 **논리회로 실습**을 엽니다. 경로는 `/oj-addons/oj-logic-lab/learn`입니다. 플랫폼의 `oj_logic_lab_learn` 참여 권한을 사용합니다.

## 초보 모드와 고급 모드

새 회로는 **초보 모드**로 시작합니다. 상단에서 두 모드를 전환합니다. 초보 모드의 기본 장치 목록과 ‘다른 장치도 보기’로 31종 기본 장치를 사용할 수 있습니다. 고급 모드의 내 부품함에는 직접 만든 회로 부품도 저장합니다.

| 항목 | 초보 모드 | 고급 모드 |
| --- | --- | --- |
| 주된 작업 | 장치 추가 → 배선 → 입력에 따른 출력 확인 | 장치와 시뮬레이션의 세부 설정·시간 변화 관찰 |
| 입력·출력 | 0/1 입력 버튼과 출력 카드, 입력 변경 즉시 계산 | 회로의 핀·LED·프로브·파형으로 관찰 |
| 전파 지연 | 계산용 사본에서 지연 0으로 처리 | 저장된 장치별 전파 지연·tCQ 적용 |
| 클록 | ‘클록 한 번’으로 모든 클록에 같은 상승 에지를 전송 | 주기·듀티비·위상을 설정하고 자동 실행 |
| 플립플롭 | 상승 에지 사용, setup/hold 검사 생략 | 상승/하강 에지, 초기 Q, setup/hold 설정 |
| 시간 관찰 | 수동 클록 횟수 표시 | ns 스텝·다음 이벤트·파형·CSV |

모드를 전환하면 **실행 상태와 시간은 초기화**합니다. 회로의 장치·배선·입력값과 고급 설정은 보존합니다. 초보 모드는 별도 사본에서 이상적 논리를 계산하므로 고급 모드로 돌아가면 기존 세부 설정을 다시 적용합니다. 이름 변경과 스위치 전환은 원본 회로에 반영합니다. 초기 Q는 두 모드에서 원래 저장값을 사용하며 변경은 고급 모드에서 합니다.

모드도 회로와 함께 저장·내보내기·복원합니다. 모드 정보가 없는 이전 JSON은 기존 타이밍 동작을 유지하도록 고급 모드로 불러옵니다. 예제와 빈 회로 만들기는 현재 모드를 유지합니다. 지연에 따른 글리치 예제는 고급 모드에서 제공합니다.

## 진리표·상태표, 오류 안내, 실습 과제

- 초보 모드의 **진리표·상태표**는 회로 사본에서 지연과 예약 입력을 제외하고 계산합니다. 조합회로는 모든 입력 조합, 순차회로는 가정한 현재 Q와 입력에 대해 공통 상승 클록 한 번 후의 다음 Q를 계산합니다. 입력 비트와 상태 비트의 합계는 최대 8개, 표는 최대 256행입니다. 조합 피드백은 표를 만들기 전에 해소해야 하며 플립플롭 상태표에는 클록 장치가 필요합니다.
- CSV 내보내기와 행별 **입력만 적용**을 제공합니다. 표 생성 자체는 현재 입력·초기 Q·타이밍·실행 상태를 바꾸지 않습니다. 행 적용 시 입력만 바꾸고 실행을 초기화합니다.
- **회로 검사**는 미연결 입력·클록 누락·금지 SR 입력·버스 폭 불일치·조합 피드백·배선 통로 부족·최근 setup/hold 위반을 안내합니다. 해당 장치·핀으로 이동하고 수정 방법을 확인할 수 있습니다. 미연결 RST는 정상으로 간주합니다.
- **실습 과제**는 AND, XOR, 반가산기, 전가산기, D 플립플롭, 2비트 동기 카운터의 6단계입니다. 입력·출력만 준비된 회로를 열어 직접 설계하고 단계별 힌트와 전체 입력·동작 조건 정답 검사를 사용합니다. 검사는 사본에서 하며 입력·출력 장치 ID를 유지해야 합니다. 구조·타이밍을 수정하면 현재 통과 표시를 해제하고 다시 검사합니다.
- 과제 시작 전 회로는 계정별 브라우저 복원 사본으로 보관합니다. **원래 회로로 돌아가기**로 장치·배선·설정을 복원합니다. 기존 명시적 저장 회로는 과제 시작으로 덮어쓰지 않습니다. 브라우저 저장이 제한되면 복원 사본은 현재 창에서만 유지됩니다. 검사 횟수와 통과 상태는 회로 JSON에 포함되며 서버 성적표나 평가 기록은 생성하지 않습니다.

## 내 부품과 다중 비트 버스

- 고급 모드의 **현재 회로를 부품으로**는 전체 회로를 복사하여 저장합니다. 입력 스위치·버스 입력·클록 중 외부 입력으로 사용할 장치를 선택하고 LED·프로브·버스 출력 중 외부 출력을 선택한 뒤 포트 이름을 지정합니다. 입력·출력은 각각 최대 16개, 출력은 한 개 이상이어야 합니다. 선택하지 않은 입력 장치는 내부 설정을 유지합니다.
- 부품함 또는 라이브러리의 내 부품 버튼에서 클릭·드래그로 인스턴스를 추가합니다. 인스턴스의 내부 상태는 서로 독립적입니다. 부품 정의와 의존성은 회로 JSON에 함께 포함됩니다. 부품은 최대 24종, 중첩은 4단계, 펼친 회로는 장치 600개·연결 1,800개로 제한합니다. 자기 참조는 거부합니다.
- 부품함은 현재 브라우저·사이트·계정에 저장합니다. 부품함에서 삭제해도 현재 회로에서 사용 중인 정의는 보존합니다. 상위 부품이 참조하는 부품은 상위 부품을 먼저 정리해야 합니다.
- 2·4·8·16비트 버스 입력·출력·분리·결합·가산기·레지스터를 추가했습니다. 기본 논리게이트·버퍼·3상 버퍼·MUX도 고급 속성에서 비트 수를 설정할 수 있습니다. CLK·RST·EN·선택선·자리올림은 1비트입니다. 분리·결합의 B0는 최하위 비트입니다.
- 버스 값은 비트 수만큼의 2진수, 10진수, `0x` 접두사의 16진수, X/Z를 입력합니다. 출력과 속성은 16진수 및 2진수로 확인합니다. 버스 가산기의 CI는 상수 0 또는 1에 연결하세요. 비트 수가 다른 핀의 새 연결은 거절합니다. 기존 연결의 폭을 변경하면 연결을 지우지 않고 검사에서 알리며 불일치 입력은 X로 처리합니다.
- 분리·결합 장치의 비트 수를 줄여 연결된 핀이 사라지거나 장치가 겹치는 변경은 거부합니다. 저장 값이 더 작은 폭의 범위를 넘으면 값을 먼저 낮춰야 합니다. 8비트 버스 가산기 예제로 시작할 수 있습니다.

## 입력 시나리오·파형 측정·자동 회로도

- 고급 모드 **입력 시나리오**에서 시각(ns)·입력 장치·값을 예약합니다. 같은 시각의 여러 입력은 한 배치로 적용하고 동일 입력·동일 시각의 중복은 거절합니다. 최대 256개, 시각 0~1,000,000 ns입니다. 시나리오는 JSON에 저장되며 초보 모드와 진리표·정답 검사에서는 적용하지 않습니다.
- 시나리오 편집은 0 ns로 초기화하고 지정 시각까지 실행할 수 있습니다. 예약 입력은 저장된 시작 입력값을 덮어쓰지 않으므로 초기화하여 반복 실험할 수 있습니다. 입력 장치를 삭제하면 해당 장치의 예약도 함께 제거합니다.
- 파형을 차례로 클릭하여 A/B 커서를 배치하거나 **파형 측정**에서 시각을 직접 입력합니다. 두 커서 사이의 절대 시간차 Δt를 표시합니다. 현재 표시 구간 밖의 커서는 그림에서만 숨기며 시간차 계산은 유지합니다. 버스 파형에는 구간별 16진수 값을 표시합니다.
- 두 모드의 **회로도 SVG**로 현재 장치·핀·배선·접속점·교차 점프와 신호값을 독립 SVG 파일로 자동 생성합니다. 벡터 파일이므로 확대·인쇄할 수 있고 편집기 화면의 확대·이동 상태와 관계없이 전체 회로를 담습니다. 회로의 현재 배치를 사용하며 원본을 수정하지 않습니다. 배선 통로가 없는 연결이 있으면 내보내기를 거절합니다.
- 이 기능은 설계한 회로의 회로도 내보내기입니다. 진리표에서 게이트 연결을 자동 합성하는 기능은 포함하지 않습니다.

## 회로 편집

- Shift+클릭으로 여러 장치를 선택하거나 Shift+빈 공간 드래그로 영역을 선택합니다. 전체 선택과 Ctrl/Cmd+A/C/V로 복사·붙여넣기를 지원합니다. 선택 장치를 함께 드래그하거나 방향키로 이동합니다. 왼쪽·위쪽·가로 중심 정렬은 장치·배선 충돌을 검증하여 한 번에 적용합니다. 복사는 선택 내부의 연결과 내 부품 정의를 포함하며 외부 장치와의 연결은 제외합니다.
- 신호 배선을 선택해 이름(40자)을 지정합니다. 주석 추가 후 내용(300자)을 편집하고 드래그합니다. 주석은 최대 100개이며 JSON·회로도 SVG에 포함됩니다. 주석과 이름은 전기적 연결·시뮬레이션에 영향을 주지 않습니다.
- 실행 취소·다시 실행은 각 방향 최대 60회·약 12 MiB로 제한합니다. 큰 회로(장치 40개 또는 배선 60개 초과)의 드래그는 Worker에서 계산하며 진행 중에도 마지막 유효 배치와 배선을 표시합니다. Worker 사용이 제한된 환경에서는 같은 검증을 주 화면에서 계산합니다.

- 라이브러리의 장치를 드래그하거나 클릭하여 추가합니다. 장치 이동과 출력 → 입력 배선 연결을 드래그로 지원합니다. 핀 클릭 두 번, 핀의 Enter 키도 사용할 수 있습니다.
- 장치를 드래그하는 동안에도 배선을 표시하며 핀을 따라 실시간으로 다시 배선합니다. 매 화면 갱신에서 한 번만 계산하고 그리드 위치가 바뀌었을 때만 경로를 찾습니다. 장치 겹침·배선 통로 부족 위치에서는 마지막 유효 배치를 유지하고 빨간 테두리로 알립니다. 그 위치에 놓으면 원래 위치·배선으로 복원하며 Esc로도 이동을 취소할 수 있습니다. 이동 중 신호와 타이밍 상태는 유지합니다. 스위치의 중앙도 끌어서 이동할 수 있으며, 짧게 클릭했을 때만 입력이 전환됩니다.
- 배선의 가로 구간을 위아래로, 세로 구간을 좌우로 드래그하면 12 px 그리드에 맞춰 경로를 직접 조정합니다. 같은 출력에서 공유하는 구간은 해당 분기들이 함께 이동합니다. 핀 바로 앞의 12 px 연결 구간은 고정되며 핀까지의 연결은 자동으로 이어집니다. 장치 통과·다른 신호의 같은 구간 점유·교차점에서 꺾임·작업 영역 이탈은 거부합니다. 직각 교차는 기존처럼 점프 곡선으로 구분합니다.
- 배선을 선택하면 **◇ 꺾임점·● 경유점**을 표시합니다. 점을 드래그하면 가로·세로 양방향으로 이동하고 인접 구간을 직각으로 연결합니다. **경유점 추가**를 누른 뒤 선택한 신호의 배선 구간을 클릭하면 그리드에 맞춰 경유점을 넣습니다. 직선 위의 경유점도 유지됩니다. 점을 선택하고 **선택한 점 삭제** 또는 Delete를 누르면 그 점을 제거하며, 꺾임점은 반대쪽 직각 경로로 다시 연결합니다. 재연결이 장치·다른 신호선과 충돌하면 삭제하지 않습니다. 공유하는 좌표의 점은 해당 분기들을 함께 편집합니다. 핀·핀 앞 구간과 다른 신호의 교차점에는 점을 추가하거나 이동할 수 없습니다.
- 잘못된 드롭은 이동 전 경로로 복원하고 Esc로도 취소합니다. Ctrl/Cmd+Z 및 다시 실행을 지원하며, 선택한 신호의 속성에서 **자동 경로로 되돌리기**를 누르면 해당 신호의 수동 경로만 해제합니다. 수동 경로는 연결당 최대 64개 좌표로 회로 JSON·브라우저 저장·SVG에 반영됩니다. 이전 JSON에는 수동 경로가 없어도 그대로 동작합니다. 장치 이동 시 수동 경로를 유지하며 핀 연결을 다시 찾고, 유효한 통로가 없으면 이동을 거부합니다. 장치 추가·설정으로 수동 경로를 막는 변경도 적용하지 않습니다.
- AND, OR, NOT, NAND, NOR, XOR, XNOR, 버퍼, 3상 버퍼, MUX, DEMUX, 반가산기, 전가산기, D/JK/T/SR 플립플롭, D/SR 래치, 스위치, 클록, 상수 0/1, LED, 프로브를 제공합니다.
- A* 직교 배선은 장치를 우회합니다. 같은 출력의 공통 구간만 공유하고 분기점에 접속점을 표시합니다. 서로 다른 신호는 선분을 공유하지 않으며 교차점에 점프 곡선을 표시합니다. 배선 구간에서 새 분기를 시작하려면 원래 출력 핀에서 새 입력으로 연결합니다.
- 배선 통로가 없는 연결·이동은 거절합니다. 불러온 회로의 미배선은 오류로 알리고 선을 그리지 않습니다. 장치 간 최소 24 px 간격, 장치 100개·연결 240개 제한이 있습니다.
- Delete는 경로점을 선택했으면 그 점만, 장치·신호 배선을 선택했으면 해당 대상을 삭제합니다. 배선 선택 후 개별 끝단도 삭제할 수 있습니다. 실행 취소·다시 실행, 키보드 이동, 확대·축소·전체 보기·화면 이동을 제공합니다.

## 타이밍과 신호

- 고급 모드는 정수 ns 단위의 이벤트 기반 시뮬레이션입니다. 클록의 주기(최소 2 ns), 듀티비(1–99%), 첫 상승 위상(0 ns 이상)을 설정합니다. High·Low 시간은 반올림하고 각각 최소 1 ns로 제한합니다.
- 장치별 전파 지연, 순차회로 출력 지연(tCQ), 초기 Q, 플립플롭의 상승/하강 에지·setup·hold 시간을 설정합니다. 플립플롭 RST는 활성 High 비동기 리셋이며 미연결 RST만 비활성 0입니다.
- 미연결 입력은 X, 비활성 3상 출력은 Z입니다. 0·1·X·Z를 표시합니다. 한 입력에 복수 출력을 연결하는 버스 충돌 모델은 지원하지 않습니다.
- 플립플롭의 내부 저장 상태와 지연된 출력은 분리합니다. tCQ보다 짧은 클록 주기에서도 각 에지의 결과가 tCQ 후 순서대로 출력됩니다. 비동기 RST와 setup/hold 위반은 이전의 대기 중 캡처를 무효화합니다. 게이트는 관성 지연을 사용합니다. 지연보다 짧은 펄스는 소거될 수 있습니다. setup은 에지 전 데이터 변경 간격, hold는 에지 후 데이터 변경 간격을 검사합니다. 위반은 Q=X와 경고로 표시합니다. 물리적 메타안정성·아날로그 파형·실제 소자 편차는 모델링하지 않습니다. 래치에는 setup/hold 검사를 적용하지 않습니다.
- 순차회로는 초기 Q를 명시적으로 설정하며 초기 입력은 0 ns 이전부터 안정된 것으로 간주합니다. X로 시작한 조합 피드백을 임의의 발진으로 해석하지 않습니다. 지나치게 많은 이벤트는 오류로 중단합니다.
- 실행/정지, ns 단위 스텝, 다음 이벤트, 초기화, 신호 파형과 CSV 내보내기를 제공합니다. 파형은 기본 400 ns이며 확대·축소(10~1,000,000 ns), 이전·다음 구간, 최신 시각 따라가기와 관찰 신호 선택을 제공합니다. 신호별 최대 3,000개, 전체 최대 100,000개 전이를 보관하므로 긴 실행에서는 오래된 기록이 소거됩니다. CSV는 남아 있는 기록 전체를 내보냅니다. 경고는 최근 200개를 보관합니다.
- 반가산기·전가산기·D 플립플롭·2비트 동기 카운터·글리치·버스 가산기 외에 4비트 ALU, 레지스터 전송, 간단한 데이터패스 예제를 제공합니다. ALU는 S1S0=00 AND, 01 OR, 10 XOR, 11 ADD이고 레지스터 전송은 같은 에지의 변경 전 값을 샘플링합니다. 구조·입력 이력·타이밍 변경은 시간을 0 ns로 되돌립니다. 장치·배선 배치, 이름·주석, 파형 보기 변경과 그 실행 취소·다시 실행은 실행 시간·상태·예약 이벤트를 유지합니다. 스위치 입력 전환은 현재 시각에서 일어납니다.

## 저장과 삭제

회로 JSON 내보내기·불러오기와 브라우저 저장·복원을 제공합니다. 이전 회로 파일도 불러올 수 있으며 장치·배선·알려진 설정을 유지합니다. 편집이 확정된 후 0.5초에 자동 임시 저장하고 창을 떠날 때 남은 임시 저장을 시도합니다. 다음 접속의 복구 배너로 되살립니다. 저장 버튼은 별도 확정 사본이며 임시 저장으로 덮어쓰지 않습니다. 다른 임시 사본이 없으면 확정 사본을 자동으로 엽니다. 새 회로·예제·파일로 전환하기 전의 미저장 회로는 최근 3개 사본으로 보관하고 ‘최근 작업 복구’에서 엽니다. 미저장·임시 저장 중·완료·실패 상태를 표시합니다. 저장 공간이 차거나 제한되면 오류를 알리며 JSON 내보내기를 사용합니다. 전환 전 사본은 저장 실패 시 현재 창 안에서 유지합니다. 부품 저장과 과제 시작은 각각 부품함과 복원 사본도 저장합니다. 사이트·계정별 키로 구분하며 서버 DB·외부 서비스·AI로 회로를 전송하지 않습니다. 브라우저 데이터는 개인정보 도구나 플러그인 삭제로 지워지지 않습니다. 도움말의 **이 브라우저의 저장 회로 삭제**는 저장 회로·자동 임시 사본·전환 전 사본·부품함·과제 복원 사본을 지웁니다. 현재 열린 회로와 내보낸 JSON·CSV·SVG 파일은 별도로 관리합니다.

## 저장 파일 형식과 호환성

현재 형식은 `schema: 1`, `formatVersion: 1`인 UTF-8 JSON입니다. 앱 릴리스 버전과 파일 형식 버전은 별개입니다. `formatVersion`이 없는 기존 schema 1 파일도 읽으며 모드가 없으면 기존 동작과 같은 advanced로 해석합니다. 더 새로운 schema/formatVersion은 현재 작업을 바꾸지 않고 거절합니다. 이전 앱에서 새 파일을 다시 저장하면 새 선택 항목이 없어질 수 있으므로 RC 또는 정식 버전에서 내보낸 파일은 같은 형식을 지원하는 RC·정식 버전에서 편집하세요.

| 필드 | 내용 및 제한 |
| --- | --- |
| `nodes`, `wires` | 장치 100개·배선 240개, 고유 ID, 핀 끝단, 장치 좌표·알려진 config 유지 |
| `wires[].path` | 선택적 직교 경로 2~64 좌표, `waypoint:true` 보존, 장치·다른 신호선과 충돌 시 적용 거절 |
| `components`, `stimuli`, `exercise` | 내 부품·의존성, 예약 입력, 실습 진행 정보 유지 |
| `settings` | mode, step, speed 및 wave 보기. wave는 span, start(null=따라가기), signals(null=전체, 빈 배열=없음) |
| `netNames`, `notes` | 출력 키 `node:pin`의 이름과 ID·좌표·텍스트 주석. 이전 파일에는 생략 가능 |

시간·현재 Q·이벤트 대기열·파형 기록·실행 취소 이력은 실행 중 데이터이며 저장 파일에 넣지 않습니다. 복구·불러오기는 저장된 초기 Q와 입력·설정에서 0 ns로 시작합니다. 계정별 기존 저장 키 `oj-logic-lab:v1:<계정>`은 그대로 사용하고 `:draft`, `:backups`만 추가합니다. 0.1~0.5 실제 배포본으로 생성한 13개 회로와 RC의 10개 회로(수동 경로·경유점·주석·신호 이름·파형 보기 포함)를 호환성 검사에 보관합니다.

## 서버와 DB 부하

회로 편집·시뮬레이션·자동 저장·파형 관찰은 브라우저 로컬 연산입니다. 이 애드온은 테이블·서버 저장 API·주기 조회를 만들지 않고 회로를 DB에 쓰거나 외부에 보내지 않습니다. 정적 JS/CSS와 Worker의 최초 다운로드 외에 작업 중 서버 요청을 만들지 않습니다. WordPress와 OJ Platform의 인증·권한·페이지 제공에 필요한 공통 조회는 플랫폼에 따릅니다. 애드온 PageHandler를 예열 후 1,000회 실행한 검사에서는 추가 DB 쿼리 0회를 확인했습니다. `tests/db-budget.php`와 실제 WordPress 게이트에서 이 예산을 회귀 검사합니다.
