# 교사·학생 사용 안내

**현재 rc.3의 양식 원클릭 적용·보관함·필수 답변·루브릭·지정 CSV·반려 재검토는 [단계별 사용 안내](workflow-rc3.md)를 확인하세요.** 결과 화면 학생 행의 `제출 보기·평가` / `상태·해결 방법`, `제출 이력`, `재제출 설정` 버튼으로 바로 이동할 수 있습니다.

## 과제 운영

초안은 수정·삭제할 수 있습니다. 게시 후에는 제목·설명·마감·최대 시도만 변경하고, 과제 유형·명단·핵심 정책은 고정됩니다.

- **복제**: 현재 수업 명단으로 새 초안을 만듭니다. 시작·마감은 비워 두므로 다시 지정합니다.
- **지금 종료**: 새 실습과 제출을 막습니다.
- **보관**: 학생 목록에서 숨기고 기록은 보존합니다.
- **보관 복원**: 종료 상태로 돌립니다. **재개**하면 게시 상태가 됩니다. 마감이 지났다면 재개 후 마감도 연장해야 제출 가능합니다.
- 영구 삭제는 시도가 없는 초안에만 허용됩니다. 학생 기록을 없애기 위한 삭제 버튼은 제공하지 않습니다.

## 학생 한 명만 다시 제출하도록 하기

1. 학생별 제출 결과에서 과제를 선택합니다.
2. 해당 학생의 추가 도구에서 **학생별 제출 허용** 설정을 엽니다.
3. 최대 시도를 현재 사용 횟수보다 크게 입력합니다. 예: 사용 2회 → 최대 3회.
4. 과제 마감도 지났다면 개인 마감을 미래 시각으로 연장합니다.
5. 변경 사유를 적어 저장합니다.
6. 학생이 결과 페이지를 다시 열고 **수정 후 다시 제출**을 누릅니다.

개인 허용은 기본 과제 한도를 늘리는 방향으로만 작동합니다. 기본 마감이 없는 과제에는 개인 마감을 새로 제한하지 않습니다.
상한은 100회입니다. 교사가 같은 학생 설정을 동시에 수정하면 먼저 저장한 변경을 유지하고 다른 요청은 충돌로 거부합니다.

거부 사유가 과제 유형 불일치라면 횟수를 늘리는 것만으로 해결되지 않습니다. 학생이 과제에 맞는 프로젝트를 수정해야 합니다.
서버 검사 대기는 학생 실수로 취급하지 말고 운영자가 검사 복구를 먼저 확인합니다.

## 제출 결과 보기와 평가

- 기본 표는 학생별 최신 접수를 보여주며 미제출 학생도 포함합니다.
- **전체 제출 이력**에서 과거 시도, 접수 시각, 검사 상태와 평가를 확인합니다.
- 안전 바로보기는 학생 답안·설정·기록 지표만 표시합니다. 모델이나 첨부파일은 실행하지 않습니다.
- 기록된 지표는 학생이 수정할 수 있으므로 서버 재채점·부정행위 판정 근거로 보증하지 않습니다.
- 평가 저장은 비공개 초안입니다. **공개**를 눌러야 학생에게 보입니다. 공개 후 새 초안을 작성해도 이전 공개 평가가 유지됩니다.
- 이름·로그인 계정 검색과 상태 필터를 사용할 수 있습니다. CSV는 현재 필터의 모든 페이지를 최대 5,000명까지 내보내며, 교사가 내려받은 개인정보 파일은 직접 관리합니다.
- REPORT만 있는 계정은 요약 조회만 가능합니다. 안전 바로보기·원본·평가는 REVIEW 또는 MANAGE와 현재 OJ 수업 평가 권한이 필요합니다.

## 학생 안내

1. 실습 시작 → 프로젝트 준비 → 브라우저에서 학습합니다.
2. 앱의 **OJ에 제출하기**를 누릅니다. 먼저 다운로드할 필요가 없습니다.
3. 접수 번호·시각·SHA-256 영수증을 확인합니다. 접수와 검사 완료는 다른 단계입니다.
4. 결과 페이지에서 자기 전체 이력과 교사가 공개한 평가를 봅니다.
5. 사용 종료 시 로컬 삭제 성공 확인 → 별도 다운로드 파일 정리 → OJ 로그아웃 → 모든 실습 탭 닫기 순서로 마칩니다.

제출 전 로컬 작업은 서버에 자동 백업되지 않습니다. 브라우저 종료·기기 초기화 전에 반드시 제출 또는 기관 정책에 맞는 보존을 완료하세요.
