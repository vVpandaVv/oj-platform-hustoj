OJ Platform과 연결하는 브라우저 ML 실습, 학생별 제출 이력과 실행 없는 안전 바로보기.

== Description ==
1.4.1은 채점 후 현재 등급·점수·판단 기준을 바로 표시하고, 점수 조정을 눌러 다른 등급 카드를 선택할 수 있게 합니다. 저장과 학생 공개는 분리되며 AI 플러그인 없이도 사용할 수 있습니다. 1.4.0의 데이터 설명·통계 요약·근거 부족 보호를 포함합니다.
1.4.0은 교사·학생 데이터 설명과 서버 CSV 통계 요약을 평가에 연결합니다. 원본 행·범주 값은 외부 AI에 보내지 않으며, 항목별 필수 근거가 부족하면 교사 확인 필요로 표시하고 AI 점수 반영을 막습니다.
1.3.3은 평가항목 추가를 상단에, 삭제를 접힌 항목 옆에 표시합니다. 교사 과제 목록은 일반 과제와 보관 탭으로 분리하며 보관된 제출·평가는 유지합니다.
1.3.2는 과제·채점·설정 화면을 간결한 그룹형 인터페이스로 정리합니다. 설명은 필요할 때 펼치고, 루브릭은 항목 요약과 선택 등급부터 확인합니다. 오류·삭제·공개 안내와 기존 저장 형식은 유지합니다.
1.3.1은 평가 항목마다 등급명·고정 점수·구체적인 판단 기준을 작성하는 루브릭을 제공합니다. 교사는 등급을 선택해 채점하며 AI가 정의되지 않은 점수를 제안하면 반영하지 않습니다. 기존 과제와 평가는 자동 변환하지 않습니다.
1.3.0은 그룹 전용 과제 생성과 단계별 콘솔, 새 과제의 항목별 기본 평가 기준을 제공합니다. OJ AI Dashboard 없이도 실습·제출·항목별 수동 채점·학생 공개까지 동작하며 OJ Platform은 필수입니다. 선택적 AI에는 포트폴리오 외에 프로젝트와 실험 당시 설정·실행 결과 요약을 전달하고 전송 범위를 표시합니다.
1.2.4는 상단 제출 경고가 작업 화면과 겹치지 않도록 짧은 사유 버튼과 별도 확인창으로 표시합니다. 좁은 화면에서는 아이콘으로 축약하며 전체 사유는 줄바꿈·스크롤로 확인할 수 있습니다.
1.2.1은 범주가 많은 분류의 결과 표시와 저장 메모리 사용을 보완합니다. 학습 전에 범주 수와 결과 표시 방식을 안내하며, 기존 프로젝트·과제 유형·제출 정책을 자동 변경하지 않습니다.
1.2.0부터 OJ AI Dashboard 1.2.0과 선택적으로 연결해 같은 제출·평가 화면에서 AI 분석을 요청하고 교사 비공개 초안으로 반영할 수 있습니다. 최종 점수와 공개는 교사가 결정합니다.
기관 전용 플러그인입니다. WordPress.org 심사·게시 완료를 의미하지 않습니다.
학생 브라우저에서 학습하고 서버는 제출된 MLPX와 평가를 보관합니다.
과제에서 금지한 학습 유형·알고리즘은 실습 화면에서 새로 선택할 수 없습니다. 직접 제출 전 현재 선택과 과거 실행 기록을 확인해 불일치 사유를 안내하며, 기존 기록은 자동 삭제하지 않습니다. 서버의 최종 검사는 유지합니다.
교사는 개인별 시도·마감 연장, 전체 이력, 점수·피드백 공개, CSV와 과제 복제·종료·재개를 사용할 수 있습니다.
운영 설정, 점검 모드, 검사 복구, 비공개 저장소 점검 및 개인정보 도구를 제공합니다.
과제별 포트폴리오 문항을 편집해 학생에게 Markdown 양식으로 제공할 수 있습니다.
교사 작업 버튼·상태 카드·모바일 상세 화면과 설정 바로가기를 제공합니다.
학생 실습의 넓게 보기·집중 모드·전체화면, 접이식 안내·제출 확인과 교사의 크게 채점하기를 제공합니다.
공용 PC 보호 상태와 로컬 데이터 삭제 동작은 화면을 넓혀도 유지합니다.
공용 PC 삭제 확인창·결과 표시·다중 탭 삭제 순서와 OJ 개인정보 URL 상속을 제공합니다.
2026-09-11 RC6의 실제 삭제·재로그인 후 미노출·서버 원본과 평가 보존을 확인하여 기관용 기술 운영을 승인했습니다.
1.0.0은 검증된 RC6의 버전 메타데이터와 문서만 승격합니다. 서버 관리·로그·백업·복원은 운영자 직접 수행 영역이며 36명 실제 부하 검사는 미실시입니다.
1.2.0의 AI 연결은 별도 신규 기능입니다. 로컬 회귀 검사와 실제 서버의 AI 제공자·예약 작업·잠금 검증은 구분해야 하며, 이전 1.0.0 운영 승인에 자동 포함되지 않습니다.

단일 WordPress 사이트와 전용 InnoDB DB를 지원합니다. 멀티사이트는 지원하지 않습니다.
OJ Platform >=2.0.0-dev.33 <3.0.0, OJ Addon API >=1.1.0 <2.0.0이 필요합니다.
지원 범위 선언은 모든 플랫폼 버전에 대한 시험 완료를 의미하지 않습니다.

== Installation ==
배포 ZIP과 함께 제공하는 릴리스 킷의 OJ ML Playgrounds 설치 안내서(배포 묶음의 install-guides/)를 먼저 읽으세요. INSTALL.md와 docs/upgrade-1.0.md는 과거 1.0.0 참고 문서이며 현재 설치 안내를 대신하지 않습니다.
1. HTTPS, PHP ZIP, 웹 루트 밖 비공개 저장소를 준비합니다.
2. OJ Platform을 먼저 활성화합니다.
3. 운영자가 DB·비공개 저장소·기존 플러그인의 복구 준비를 마친 뒤 배포 ZIP 전체를 업로드하여 교체합니다.
4. PHP-FPM/OPcache와 WordPress·프록시·브라우저 캐시를 갱신하고 스키마를 확인합니다. 이미 스키마 4인 설치는 추가 DB 변경이 없습니다. 스키마가 4보다 낮으면 OJ 콘솔 교사 메뉴 › ML 실습 › 설정에서 DB 업데이트를 실행합니다.
5. 기존 실습 탭을 모두 닫고 다시 열어 OJ 권한, 운영 한도와 개인정보 URL을 확인합니다. 삭제 확인창의 취소·실제 삭제·다중 탭·재로그인 후 미노출·서버 제출 보존을 시험합니다.

== Frequently Asked Questions ==
= AI 평가 플러그인이 꼭 필요한가요? =
아니요. OJ Platform만 필수입니다. ML에서 과제·실습·제출·안전 바로보기·항목별 수동 평가와 공개를 진행할 수 있습니다. AI 분석은 별도 동의 후 요청하는 선택 기능입니다.

= 서버나 학생 PC에 uv가 필요한가요? =
아니요. 배포 ZIP 실행에는 필요하지 않습니다. 서버 PHP에는 ZIP 확장이 필요합니다.

= 제출 내용을 실행하나요? =
안전 바로보기는 허용한 JSON을 읽고 포함된 UTF-8 CSV를 서버에서 통계로 집계합니다. 모델·코드·첨부파일은 실행하지 않습니다.
학생이 기록한 지표를 다시 계산하거나 진위를 보증하지 않습니다.

= 외부 서비스에 연결하나요? =
선택 기능인 AI 평가는 교사의 전송 동의 후 OJ Platform에 설정한 AI 제공자에 과제·평가 기준·안전 요약·포트폴리오 답변을 전송합니다. 원본 데이터·모델·첨부 파일과 학생 식별자는 보내지 않습니다. 자유 입력에 개인정보가 있는지 교사가 먼저 확인해야 합니다. AI 기능을 요청하지 않으면 이 전송은 발생하지 않습니다.
표 데이터 기본 실습은 자체 제공 자산을 사용합니다.
이미지 기능은 브라우저가 Google Cloud Storage의 MobileNetV2 모델을 내려받을 수 있습니다.
모델 주소: https://storage.googleapis.com/tfjs-models/savedmodel/mobilenet_v2_1.0_224/model.json
해당 요청으로 브라우저 IP와 일반 HTTP 메타데이터가 외부로 전송됩니다.
개인정보 안내: https://policies.google.com/privacy
기관의 방화벽·고지 정책을 먼저 확인하세요. 자체 호스팅/선택 동의 UI는 아직 제공하지 않습니다.

= 삭제하면 제출물이 사라지나요? =
일반 비활성화·플러그인 삭제는 DB와 원본을 유지합니다.
보존기간 정리, 확인된 개인정보 삭제 또는 명시적 파기 설정은 별개이며 되돌릴 수 없습니다.

WordPress 도구 › ML 실습 운영 화면을 없애고 서버 상태와 DB 업데이트를 콘솔 설정 화면으로 옮겼습니다(Site Health 검사는 유지). 설정은 사이트 관리자와 'ML 실습 설정' 권한을 받은 교사가 바꿀 수 있습니다. 버튼·알림·배지·표·확인창을 플랫폼 부품으로 바꾸고 문구를 정리했습니다. 내장 앱·MLPX 형식·DB 스키마 4·검사와 평가 동작은 바꾸지 않습니다.
