# 보안 및 개인정보

## 지원 경계

기관용 단일 사이트 출시 후보입니다. 악성 제출물은 신뢰하지 않습니다.
서버는 ZIP 경로·크기·압축률·문서/해시를 검사하고 모델, 코드, 전처리기, 첨부파일을 실행하지 않습니다.
안전 바로보기는 허용한 JSON에서 허용 필드만 읽고 출력 시 HTML을 이스케이프합니다.

원본은 웹 루트 밖에 보관합니다. 교사 원본·바로보기에는 현재 OJ 평가 권한과 nonce가 필요합니다.
학생에게는 자기 접수 결과와 공개 평가만 제공합니다. 서버에 제출되기 전 작업은 서버에 자동 백업되지 않습니다.

MLPX의 내부 해시는 손상 탐지용이지 전자서명이나 학업적 진위 보증이 아닙니다.
악성 확장 프로그램·OS 관리자·디스크 포렌식은 브라우저 암호화의 보호 범위가 아닙니다.

## 공용 PC와 외부 요청

- 기관의 개인정보 처리방침과 보존기간을 설정하고 학생별 브라우저/OS 프로필을 권장합니다.
- 로그아웃과 로컬 삭제는 다릅니다. 다운로드, CSV, 원본 파일과 백업은 자동 삭제되지 않습니다.
- 이미지 기능은 Google Cloud Storage에서 MobileNetV2를 내려받을 수 있습니다. 해당 요청에 IP와 HTTP 메타데이터가 포함됩니다.
- 외부 모델 자체 호스팅·선택 동의 UI는 이 후보판에 없습니다. 기관 정책 확인 전에는 이미지 기능을 배포 범위에서 제외합니다.
- 한국어 기관용 UI입니다. 전체 gettext/POT 국제화 및 WordPress.org 공개 디렉터리 검수는 아직 별도 과제입니다.

## 삭제 정책

기본값은 무기한 보존과 삭제 유예입니다. 보존기간 정리는 종료·보관 과제의 원본만 대상으로 하며 평가와 메타데이터는 남깁니다.
WordPress 개인정보 삭제 도구는 확인된 요청에 대해 기관이 삭제를 허용했을 때만 작동합니다.
교사 작성 과제와 다른 학생 평가의 작성자 기록은 자동 삭제하지 않고 보존 사실을 알립니다.
백업, 내보내기 사본, WordPress 사용자 자체와 다른 플러그인 데이터는 별도로 관리해야 합니다.

## 문제 신고와 대응

실제 학생 파일, 인증 쿠키, nonce, 암호화 키, 서버 경로, SQL 또는 DB 덤프를 공개 이슈에 붙이지 마세요.
기관의 지정 운영자에게 버전, 발생 시각, 재현 절차와 화면의 문의 코드를 비공개로 전달합니다.
공개된 보안 신고용 주소가 아직 없으므로 기관 배포 전 담당자와 연락 경로를 반드시 지정합니다.

계정 교차 노출·파일 무결성 오류가 의심되면 점검 모드를 켜고 관련 파일·로그를 보존한 뒤 조사합니다.
원인을 모른 채 파일 검증을 끄거나 공개 URL로 우회하지 마세요.
