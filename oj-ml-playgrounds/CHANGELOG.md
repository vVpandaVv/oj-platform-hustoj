# 변경 기록

## 1.4.2 — 2026-10-26

- DB·사이트 접두사·설치 URL·플러그인/스키마 버전에 묶인 소유권 확인을 최대 5분간 재사용해 모든 WordPress 요청의 반복 메타데이터 조회를 줄입니다. 실패 시에는 접근을 차단하고 30초 후 다시 검사합니다.
- DB 이전·복구·삭제의 소유권 검사는 실제 DB를 직접 확인하며, 다른 설치로 복사한 확인 기록은 재사용하지 않습니다. 데이터 구조와 기존 과제·제출·평가는 유지합니다.

## 1.4.1 — 2026-10-23

- 채점 화면의 항목별 현재 등급·점수·판단 기준을 먼저 보여 주고, 점수 조정을 누르면 등급별 기준 카드를 펼쳐 선택할 수 있습니다. 저장된 루브릭 스냅샷을 사용하며 AI 초안 반영과 수동 평가 모두 같은 선택 상태를 표시합니다.
- 등급을 바꾸면 항목 점수와 합계를 즉시 갱신하되 저장·공개는 별도로 수행합니다. 공개된 평가를 수정해 비공개 저장하면 학생은 다시 공개하기 전까지 이전 공개 평가를 봅니다. AI 플러그인 없이도 동작합니다.
- 평가 저장 중에는 점수·피드백·버튼을 함께 잠가 늦게 입력한 내용이 새 화면으로 교체되며 소실되는 상황을 방지합니다. 중복 저장 요청을 막고 실패하면 기존 입력과 컨트롤 상태를 복원합니다.
- 저장 후 재조회·공개 분리·동시 수정 충돌·감사 로그 실패 롤백과 등급 카드의 키보드·모바일 회귀 검사를 보강합니다. 1.4.0의 데이터 설명·통계 요약·근거 부족 보호를 포함하며 DB 스키마·학습 모델·내장 앱은 변경하지 않습니다.

## 1.4.0 — 2026-10-23

- 과제의 공통 데이터 설명과 학생 포트폴리오의 지정 설명 항목을 평가 맥락으로 연결합니다. 학생 설명 문항은 명시적으로 추가하며 기존 답변·과제는 자동 변경하지 않습니다.
- 제출된 UTF-8 표 데이터 CSV를 서버 내부에서 제한된 스트림으로 읽고 열별 자료형·결측 수/비율·고유값 수·보호된 평균/표준편차·익명 빈도 요약을 생성합니다. 원본 행·예시 값·범주 이름·파일 경로를 외부 AI에 전달하지 않습니다.
- 현재 설정과 실험 당시 데이터의 연결을 구분합니다. 통계는 전처리 전 원본 집계이며 모델 재학습·전처리 후 재계산·지표 진위 검증을 하지 않습니다. 처리 한도·지원 형식·소집단 보호에 따른 생략을 명시합니다.
- 평가항목별 필요 근거(데이터 설명·통계·비교 실험)를 설정합니다. AI가 숫자 점수를 반환해도 필수 근거가 부족한 항목은 교사 확인 필요·점수 없음으로 표시하고 초안 반영을 서버에서 차단합니다. 미설정 기존 항목은 AI에 한해 설명·통계를 보수적으로 요구하며 명시적 보고서 전용 항목은 선택 해제할 수 있습니다.
- 설명·통계·근거 요구가 AI 입력 해시에 포함되어 오래된 결과를 재사용하지 않습니다. 기존 AI 연결 계약·선택 의존성·수동 평가를 유지하고 DB 스키마 4와 내장 ML Playgrounds 0.12.1은 변경하지 않습니다. 실제 외부 AI 호출·서버 설치는 별도입니다.

- 보관·보관 취소·결과 조회·복제를 유지하고 새 초안 생성·복제 후에는 과제 탭을 표시합니다. 탭 전환 시 작성 중인 폼을 보존하며 지연 응답·오류가 다른 탭을 덮어쓰지 않도록 검사합니다.
- 항목 개수 변경 저장·재조회, 탭별 권한·페이지·키보드·모바일 회귀를 보강합니다. 제출·평가 데이터와 DB 스키마 4·내장 앱은 변경하지 않습니다.

- 여백·글자 위계·입력·버튼을 통일하고 중첩 테두리를 줄였습니다. 모바일 표의 화면 밖 넘침을 격리하며 키보드 초점과 비활성 상태를 유지합니다.
- 기존 평가 점수·저장 형식·AI 없는 직접 채점·DB 스키마 4와 내장 앱은 변경하지 않습니다. 운영 서버 설치는 별도입니다.

- AI에는 교사의 전체 등급표와 정확한 점수 선택 규칙을 기존 평가 계약으로 전달합니다. 정의되지 않은 점수는 반영을 차단하고 교사 확인을 안내하며 가까운 등급으로 임의 변환하지 않습니다. 등급표가 바뀌면 이전 AI 결과를 무효화합니다.

- DB 스키마 4와 ML Playgrounds 0.12.1 유지. AI가 없거나 설정되지 않아도 기존 수동 평가는 계속 사용할 수 있습니다. 설치 안내서 원본에 연결 설정과 점검 절차를 추가했습니다.
